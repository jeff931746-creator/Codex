## 已确认顶层目标

- 通过玩法产出与捐献筛选活跃成员，并将玩家收益沉淀为军团成长。
- 解决现有军团缺乏共同成长目标的问题。
- 建立军团长线养成目标，让捐献、等级、任务和集结围绕军团成长循环。

## 已确认模块拆分

1. 货币作用与资源归属
   - 军团建设材料：玩法产出后进入玩家背包，未入团也可囤积。
   - 军团币：玩家个人货币，捐献和周任务产出，退团/换团后保留，使用受当前军团资格限制。
   - 军团经验：归属当前接受捐献的军团，用于军团等级。
   - 贡献值：仅展示，不参与结算、排名、踢人、权限、惩罚。

2. 军团等级
   - 1.0 开放到 3 级。
   - 等级关联军团商店、集结次数、军团科技继续升级资格、成员人数、管理职位/权限。
   - 不写升级节奏。
   - 科技只写资格边界：离团/换低等级军团后既有属性仍生效，只限制继续升级。

3. 管理权限
   - 职位包含盟主、副盟主、可配置集结职位、普通成员。
   - 普通成员不可发起集结。
   - 职位数量和权限走配置。

4. 集结功能
   - 集结是组织工具，不是招募玩法。
   - 有权限职位在配置场景内发起，成员弹窗确认后传送到指定玩法房间。
   - 发起校验失败不扣次数、不进冷却。
   - 发起成功扣军团集结次数并进入冷却。
   - 成员拒绝、超时、不可传送、房间满只影响该成员，不影响其他成员响应。
   - 目标房间在发起后关闭/结束，次数是否返还待确认。

5. 军团任务
   - 保留为周维度激励。
   - 1.0 主任务类型仅保留：捐献、讨伐、军团试炼、狩猎。
   - 不写登录、聊天、在线、访问界面、商店购买、集结响应等杂项任务。
   - 奖励以军团币为主。

6. 退团 / 换团影响
   - 未捐材料保留在玩家背包。
   - 已捐材料不返还。
   - 已产生军团经验留在原军团。
   - 玩家军团币保留。
   - 原军团贡献不转入新军团。
   - 已获得科技属性保留。
   - 科技继续升级按当前军团等级判断。
   - 原职位和集结权限立即失效。
   - 周任务进度、未领取奖励、历史贡献可见性待确认。

## 后续接续方式

新会话如果继续 UE，不要直接写入飞书文档。先按“一个界面一个界面”给用户审核。

建议顺序：

1. 军团主页
2. 军团捐献页
3. 军团任务页
4. 集结发起页
5. 成员集结确认弹窗
6. 管理权限页
7. 军团升级反馈

每个界面先给线稿和字段，再等用户确认后再进入下一个界面。
