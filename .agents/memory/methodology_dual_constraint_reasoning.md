# 双约束推理短卡

用于立项推演、玩法组合、系统方案选择、机制拆解等需要“拆解 -> 组合 -> 验证”的任务。

## 核心规则

任何候选方向都必须同时过两道约束：

1. **结构合法性**：这个方向在结构上是否成立？
   - 是否有清晰的独立机制或系统职能。
   - 关键模块之间是否互相支撑，而不是互相打架。
   - 是否能说明“不满足哪些条件就淘汰”。

2. **体验闭环**：这个方向能否产生可感知体验？
   - 能否用一句话说清玩家看到/做什么。
   - 核心循环是否闭合：投入 -> 行动 -> 反馈 -> 下一次投入。
   - 成长、策略、情绪或展示是否能被玩家感受到。

任一约束不成立，就不要保留为可行方向。

## 使用步骤

1. 先拆参考案例，提取结构条件和体验条件。
2. 枚举候选方向，不从表象相似处硬套。
3. 对每个候选写两句话：`结构为什么成立` / `体验为什么闭合`。
4. 淘汰项必须说明卡在哪个约束。
5. 输出时只保留双约束都通过的方向，并写明适用前提。

## 常见失败

- 只有画面，没有结构：看起来酷，但机制装不住。
- 只有结构，没有体验：逻辑能讲通，但玩家感受不到。
- 定义了约束却不逐项检查。
- 约束太虚，导致无法判断通过/不通过。

## 快速自检

- 我是否提取了结构条件？
- 我是否提取了体验条件？
- 每个候选是否都过了两道检查？
- 淘汰理由是否可追溯？
