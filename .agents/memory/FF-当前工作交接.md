## 立项规划关键点

- 项目定位：竖屏横版多人在线 RPG 小游戏。
- 核心表达：上班摸鱼挂机，下班杀人爆装。
- 社交生态链路：`挂机玩法（单机） -> 良性社交（合作） -> 竞争社交（贪婪） -> 恶性社交（仇恨）`。
- 经典成长路径：`个人 -> 组队 -> 公会 -> 帮战 -> 国战`。
- 首周需要从个人成长逐步导向 PVEVP、PVP、军团归属和 GVG 长线目标。
- 玩法背包/临时包裹是“杀人爆装”落地的重要承接机制，用于保护核心资产并制造可争夺收益。

## 7日链路修正口径

- D1：单人变强，建立基础目标。
- D2：成长目标明确，强化可追求性。
- D3：多人感知，开始看到他人和协作需求。
- D4：资源争夺，但不要把月卡放成 D4 功能。
- D5：轻 PVP 冲突，寻血和玩法背包应在这里承接。
- D6：形成军团基础目标。
- D7：军团共同目标升级，承接后续 GVG/战役/区服生态。

已修正的问题：

- 月卡不是 D4 功能，应作为 D1/D2 基础付费权益贯穿首周。
- 门票不能泛化为 D5 PVP 消耗，应归属具体竞技场、副本或月卡权益。
- 战令不能只放 D7，应区分竞技场战令、版本战令、合服战令；D7最多作为长线预告或版本承接。
- 矿点如果指寻血矿点，应归入 D5 寻血/玩法背包，不放在 D4 世界狩猎。
