用户具备品类创新所需的思维能力：第一性原理推导、跨品类设计原理迁移、系统性框架构建（人群簇方法论、双约束推理、题材选择方法论等）。战略判断准确度高，在讨论中多次提出比 AI 分析更精准的方向。

用户自评"缺乏落地能力"。实际观察：流程/标准/方法论层面的落地能力很强（`reference/部门标准/` 已有大量产出），产品设计层面的收敛经验较少。

**重要修正（2026-06-04）：** 用户当前的框架建设工作（人群簇、题材方法论、SLG 原理、找爆款逻辑）不是回避产品决策，而是在按管线逻辑从上游往下游搭建。用户明确指出管线缺少"输入端"——新产品/玩法/题材从哪里来——这个问题不解决，下游的筛选框架无法运转。用户的思维模式是系统性的（先确认管线每个环节就绪再推动输出），不应被误判为"分析过多、行动不足"。

**How to apply:** 不要在管线未就绪时催促用户"出方案"。先确认用户当前在建管线的哪个环节，判断是否合理，再决定是否推动收敛。用户的判断力和节奏感值得信任。
