# Git Commit Message Preference

When making a commit for this workspace:

- Use Chinese commit messages.
- Inspect staged diff or staged stat first.
- Mention the main categories of staged changes, not just the largest one.
- Avoid vague messages such as `update`, `fix`, or `misc`.
