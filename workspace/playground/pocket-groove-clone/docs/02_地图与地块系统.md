# 地图与地块系统

## 职责

地图与地块系统负责“玩家看见什么、能翻什么、翻出来是什么、地块属于谁”。

它是核心模块，经济、出兵、战斗都从地块状态读取信息。

## 地图结构

| 项 | 要求 |
|---|---|
| 方向 | 上下结构，敌方上方，玩家下方 |
| 格子 | 蜂窝格 |
| 可见区域 | 双方初始区域可见，中间区域隐藏 |
| 前线 | 玩家只能翻己方已占地块相邻的隐藏或敌方地块 |
| 阻挡 | 水域或不可通行格可以存在，但第一版可少量使用 |

## 地块状态

| 状态 | 含义 | 可否点击 | 视觉表现 |
|---|---|---:|---|
| Hidden | 未翻开，不知道内容 | 相邻己方地块时可点 | 问号 / 暗色 |
| Revealed Neutral | 已翻开但无归属或中立 | 视具体规则 | 明亮中立色 |
| Player Owned | 玩家地块 | 不可重复翻 | 绿色 |
| Enemy Owned | 敌方地块 | 相邻己方时可攻占 / 翻 | 红色 |
| Blocked | 水域 / 障碍 | 不可点 | 蓝色或障碍色 |

## 地块内容

| 内容 | 翻开结果 | 后续作用 |
|---|---|---|
| 空地 | 只扩展可翻边界 | 无产出 |
| 矿 | 变成金币产出点 | 周期产金币 |
| 兵营 | 变成产兵点 | 周期产兵 |
| 主基地 HQ | 核心建筑 | 产金币、产兵、胜负条件 |

## 翻地规则

### 可翻条件

一个地块可翻必须同时满足：

1. 不是水域或障碍。
2. 不属于玩家。
3. 与至少一个玩家地块相邻。
4. 玩家金币大于等于该地块翻开成本。

### 成本规则

成本不应固定为一个数，否则没有路线选择。建议第一版：

```text
翻地成本 = 基础成本 + 深度成本 + 内容/归属修正
```

| 成本项 | 说明 |
|---|---|
| 基础成本 | 普通隐藏地块最低成本 |
| 深度成本 | 越靠近敌方越贵 |
| 归属修正 | 攻占敌方地块比翻隐藏地块更贵 |
| 建筑修正 | 已知建筑地块更贵 |

## 翻开反馈

翻开必须有明确反馈：

- 扣金币数字变化。
- 地块翻转动画。
- 显示翻出的内容。
- 如果是矿，收入数值上升。
- 如果是兵营，产兵点数上升。

## 数据字段建议

```js
cell = {
  q, r,
  owner: "hidden | neutral | player | enemy | blocked",
  revealed: boolean,
  content: "empty | mine | barracks | hq",
  flipCost: number,
  flipProgress: number,
  neighbors: Cell[]
}
```

## 验收标准

- 地图在视觉上是上下对抗，不是斜向推进。
- 点击非相邻格不会翻。
- 金币不足不能翻。
- 翻开后可能出现空地、矿、兵营。
- 翻出矿 / 兵营后，经济或出兵模块能读到新状态。
