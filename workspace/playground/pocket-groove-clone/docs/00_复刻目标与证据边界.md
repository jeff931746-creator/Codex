## 目标

先复刻视频中可见的核心玩法闭环，不先追求美术、动效、商业化和完整局外系统。

## 当前确认的核心体验

玩家不是直接无限点兵，也不是单位自动染色推进。核心是：

1. 地图上下对抗：敌方在上，玩家在下。
2. 玩家消耗金币翻开前线相邻地块。
3. 翻开的地块可能为空，也可能是矿、兵营等功能地块。
4. 主基地和矿持续产出金币。
5. 主基地和兵营持续产兵。
6. 金币决定能不能继续翻地，兵营数量决定推进压力。
7. 翻地、经济、出兵互相形成闭环。

## 1:1 复刻范围

这里的 1:1 指功能结构优先，不指逐像素复制。

必须复刻：

- 上下结构地图。
- 地块翻开机制。
- 翻地金币消耗。
- 空地 / 矿 / 兵营 / 主基地地块类型。
- 主基地与矿产金币。
- 主基地与兵营产兵。
- 敌我双方推进。
- 胜利 / 失败结算。

暂不优先：

- 完整美术资源。
- 真实联网 PvP。
- 广告、内购、长期养成。
- 多地图关卡编辑器。

## 关键纠偏

| 错误方向 | 为什么错 | 正确方向 |
|---|---|---|
| 斜向战场 | 视频战场是上下推进，斜向会改变空间判断 | 地图必须按上下纵向构图 |
| 无限手动出兵 | 视频核心约束来自金币和建筑产能 | 出兵来自 HQ / 兵营，玩家主要花钱翻地 |
| 单位走过即染色 | 视频重点是玩家翻地块，翻开有内容 | 地块需要隐藏态、翻开态、归属态 |
| 没有经济系统 | 失去“翻不翻、先翻哪”的决策 | 金币产出与翻地消耗必须是主循环 |
| 所有格子一样 | 无法形成发现奖励和路线选择 | 格子内容必须有空 / 矿 / 兵营差异 |
