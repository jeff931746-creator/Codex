# 建筑与出兵系统

## 职责

建筑与出兵系统负责“哪些地块会产出资源或单位”。

玩家不应该无限点击买兵。兵力来源应绑定到 HQ 和兵营。

## 建筑类型

| 建筑 | 归属 | 产出 | 胜负相关 |
|---|---|---|---|
| HQ | 玩家 / 敌方 | 金币 + 基础兵 | HQ 被占领即失败 / 胜利 |
| 矿 | 玩家 / 敌方 | 金币 | 不直接决定胜负 |
| 兵营 | 玩家 / 敌方 | 士兵 | 推进能力来源 |

## 建筑状态

```js
building = {
  type: "hq | mine | barracks",
  owner: "player | enemy",
  cellId,
  productionTimer,
  productionInterval
}
```

建筑不是独立对象也可以，第一版可直接作为地块内容字段，但逻辑上要当成建筑处理。

## 出兵规则

| 来源 | 出兵类型 | 周期 | 说明 |
|---|---|---:|---|
| HQ | 基础兵 | 慢 | 保底推进 |
| 兵营 | 基础兵或更快兵 | 中 | 主要兵力来源 |
| Rush 技能 | 临时多出一波 | 即时 | 可选，消耗金币 |

## 产兵方向

| 阵营 | 默认目标 |
|---|---|
| 玩家 | 向上，优先敌方 HQ 或最近敌方建筑 |
| 敌方 | 向下，优先玩家 HQ 或最近玩家建筑 |

## 单位不负责的事

单位不负责翻隐藏地块。隐藏地块主要由玩家 / AI 花金币翻开。

单位可以负责：

- 攻击敌方单位。
- 攻占已揭示的敌方建筑或地块。
- 给前线施加压力。

## 与经济系统的接口

| 建筑 | 给经济系统的数据 |
|---|---|
| HQ | 每秒金币产出 |
| 矿 | 每秒金币产出 |
| 兵营 | 不产金币，但改变兵力规模 |

## 与地图系统的接口

当地块翻开为兵营：

1. 地图系统把 `content` 设置为 `barracks`。
2. 建筑系统开始读取这个地块。
3. 如果归属玩家，则加入玩家产兵点。
4. 如果后续被敌方占领，则从玩家产兵点移除，加入敌方产兵点。

## 验收标准

- 玩家不点按钮也会从 HQ 出兵。
- 翻出兵营后，产兵数量或频率明显增加。
- 敌方也从 HQ / 兵营出兵。
- 兵营被占领后，产兵归属改变。
- 出兵不是无限点击购买。
