# GDD 重写清单

## 核心结论

`docs/gdd/` 下的 v1 GDD 不再作为实现依据。v2 GDD 必须从立项纸面原型规则向下展开，先写“底部翻格 + 基地连结”，再写经济、出兵和战斗。

## 一、v1 文档问题

| v1 文档 | 主要问题 | 处理 |
|---|---|---|
| `00_核心玩法总需求GDD.md` | 主循环把“玩家选择前线地块”写成地图点击，没有定义底部操作 | 重写 |
| `01_地图翻格系统GDD.md` | 错误地以“玩家点击地块”为流程起点 | 重写 |
| `02_经济系统GDD.md` | 没有绑定底部按钮成本和目标格 | 部分保留，重写接口 |
| `03_建筑与出兵系统GDD.md` | 出兵节奏未服务一分钟承接 | 重写节奏 |
| `04_战斗推进系统GDD.md` | 战斗节奏过强，容易遮盖翻格爽点 | 重写节奏和边界 |
| `05_敌方AI与结算GDD.md` | 敌方 AI 过早进入，影响核心承接验证 | 后置 |

## 二、v2 GDD 目录

| 文档 | 职责 |
|---|---|
| `docs/gdd_v2/00_核心玩法总需求GDD.md` | 定义立项补证后的核心体验和总流程 |
| `docs/gdd_v2/01_底部翻格与基地连结GDD.md` | 定义底部按钮、目标格、基地网络、地块揭示 |
| `docs/gdd_v2/02_经济建筑与出兵节奏GDD.md` | 定义金币、矿、HQ、兵营和慢速出兵 |
| `docs/gdd_v2/03_战斗节奏与结算GDD.md` | 定义慢速战斗、不可穿隐藏格、HQ 结算 |

## 三、实现前检查

实现前必须逐条确认：

- 玩家输入是底部翻格按钮，不是地图点击。
- 己方 HQ 首屏可见。
- 每个可翻目标格能从己方 HQ 连通。
- 新翻开地块显示连结路径。
- 出兵时间晚于第一次翻格反馈。
- 60 秒内不会出现战斗结算。
- 地图是敌我同图连续拓扑。

## 四、下一版 demo 最小验收

| 验收项 | 通过标准 |
|---|---|
| 首屏 | 己方 HQ、敌方方向、连续地图、底部翻格按钮同时可见 |
| 第一次操作 | 点击底部按钮后，目标格翻开并连到 HQ |
| 经济 | 翻出矿后金币恢复速度变快 |
| 出兵 | HQ/兵营慢速产兵，不抢首 60 秒主视觉 |
| 战斗 | 单位只走已揭示连通路，不穿隐藏格 |
| 节奏 | 1 分钟内以翻格为主，10 分钟内能形成路线 |
