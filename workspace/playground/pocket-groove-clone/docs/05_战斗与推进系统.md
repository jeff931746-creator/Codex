# 战斗与推进系统

## 职责

战斗与推进系统负责单位移动、接敌、攻击、死亡和建筑占领。

它不负责翻隐藏地块，也不负责金币计算。

## 单位行为

第一版单位只需要一种基础兵。

| 行为 | 说明 |
|---|---|
| 生成 | 从 HQ / 兵营生成 |
| 寻路 | 向敌方核心或最近敌方建筑移动 |
| 接敌 | 与敌方单位接触后攻击 |
| 死亡 | HP 降为 0 消失 |
| 占领 | 到达敌方已揭示建筑后推进占领进度 |

## 目标优先级

玩家单位：

1. 最近敌方兵营。
2. 最近敌方矿。
3. 敌方 HQ。
4. 最近敌方普通地块。

敌方单位同理反向。

## 占领规则

建筑不应一碰即变色，建议使用占领进度：

```text
占领进度 += 附近己方单位数量 × 单位占领力 × dt
被敌方单位接触时占领进度下降或暂停
占领进度满后建筑归属改变
```

第一版可以简化为单位停留一段时间后占领。

## 战斗表现

必须让玩家看出：

- 哪边兵更多。
- 哪个方向正在推进。
- 哪个建筑正在被争夺。
- 为什么突然失败或胜利。

## 与地块系统的关系

战斗推进只处理已揭示地块。

隐藏地块不能被单位直接穿过，也不能被单位自动翻开。否则会破坏金币翻地的核心选择。

## 验收标准

- 单位从建筑生成后向敌方方向移动。
- 单位接触敌人会战斗。
- 兵营增加后，推进压力增强。
- 单位不能穿过未翻开的隐藏地块。
- HQ 被占领触发胜负。
