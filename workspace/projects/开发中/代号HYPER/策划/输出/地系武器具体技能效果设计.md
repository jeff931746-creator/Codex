## 一、设计口径

本稿沿用“阵地控场 + 厚重蓄势”的地系主轴，保留旧稿 11 个技能 ID 与武器分布，但重写技能效果。

每个技能只允许 1 个核心表现特点。核心特点必须是玩家能看到或理解的动作、状态变化或反馈结果。辅助效果只能服务这个特点，不能横向新增第二个卖点。删掉所有数值后，技能仍然必须有记忆点。

## 三、剑盾技能

### #1 岩棘甩盾

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 剑盾 / 红 |
| 核心表现特点 | 盾牌离手后在敌人之间回旋弹击，最后飞回手上。 |
| 技能效果 | 玩家甩出岩棘盾，盾牌脱手飞向前方敌人，并在附近敌人之间回旋弹击。每次命中都会产生岩刺碎裂反馈。盾牌飞回手上时，盾面岩棘重新合拢，下一次盾击呈现更厚重的破甲撞击。 |
| 强化方向 | 只沿“回旋弹击”加深：扩大可寻找敌人的范围、增加对被地系压制敌人的锁定优先级、强化回盾后的撞击反馈。 |
| 辅助效果服务关系 | 盾牌离手期间可以短暂暴露承压风险；回盾后的承压强化只用于表达“盾牌回归后更稳”，不独立做护盾流。 |
| 删数值后的记忆点 | 盾飞出去打一圈，回到手上变成更硬的一击。 |

### #3 砂岩冲撞

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 剑盾 / 橙 |
| 核心表现特点 | 举盾向前撞出一条砂岩冲线，把正面敌人顶开。 |
| 技能效果 | 玩家举盾蓄势后向前短距冲撞，盾面推出一条砂岩冲线。被命中的敌人被顶开、打断或压入冲线末端的裂痕区域。 |
| 强化方向 | 只沿“举盾冲撞”加深：加宽冲线、强化顶开反馈、提高对被阻隔或被压制敌人的打断表现。 |
| 辅助效果服务关系 | 命中后可获得短暂承压空间，用于让玩家冲进阵地后站住；它服务冲撞后的站稳，不作为独立生存卖点。 |
| 删数值后的记忆点 | 举盾撞过去，地上留下一条砂岩冲线。 |

### #11 砂岩盾击

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 剑盾 / 蓝 |
| 核心表现特点 | 盾牌砸地后，岩环从脚下向外扩散压住敌人。 |
| 技能效果 | 玩家原地用盾砸地，脚下扩散砂岩冲击环。被岩环扫过的敌人出现下沉、踉跄或被压住的反馈，地面留下短暂砂砾裂纹。 |
| 强化方向 | 只沿“砸地扩散岩环”加深：扩大岩环覆盖、增强压制反馈、让裂纹更容易承接后续地系技能。 |
| 辅助效果服务关系 | 可附带砂蚀，用来标记敌人已经被地系压住；砂蚀是压制结果，不是技能记忆点。 |
| 删数值后的记忆点 | 一盾砸地，岩环把周围敌人压得一顿。 |

## 四、刀技能

### #14 砾岩裂刃

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 刀 / 橙 |
| 核心表现特点 | 蓄势重斩后，地缝裂开并喷出砾岩刃。 |
| 技能效果 | 玩家站定举刀蓄势后向前重斩。刀锋落地后，前方地面裂开，砾岩刃从裂缝中喷出，命中敌人时表现为被地面反向割开。 |
| 强化方向 | 只沿“地缝喷刃”加深：延长裂缝推进、扩大裂缝开口、让已被聚集或压制的敌人受到更完整的喷刃反馈。 |
| 辅助效果服务关系 | 可对被地系压制的敌人追加破防反馈，用来证明“先压制再重斩”成立；不额外给攻击强化或回血卖点。 |
| 删数值后的记忆点 | 刀砍下去不是刀气飞出，而是地面裂开喷刃。 |

### #19 崩岩重斩

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 刀 / 橙 |
| 核心表现特点 | 上举蓄力后劈出一道崩岩断脊，断脊短暂留在地上。 |
| 技能效果 | 玩家高举刀蓄势，向前劈出厚重崩岩线。路径上的敌人被震起或压倒，地面留下隆起的崩岩断脊，敌人穿过时会受到阻碍反馈。 |
| 强化方向 | 只沿“崩岩断脊”加深：提升断脊长度、断脊厚度、阻挡反馈，或让蓄势越完整断脊越厚重。 |
| 辅助效果服务关系 | 击飞或阻碍只服务于断脊“劈开战场”的表现，不再叠加泛用增伤、回血或多段 AOE。 |
| 删数值后的记忆点 | 一刀劈出地上的岩脊，把战场切开。 |

## 五、双刀技能

### #26 砂脉引力

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 双刀 / 橙 |
| 核心表现特点 | 双刀插地后，砂脉涡流把敌人拖向中心。 |
| 技能效果 | 玩家将双刀插入地面，周围砂脉向中心旋转。敌人脚下出现砂流牵引反馈，并被地面拖向砂脉中心。 |
| 强化方向 | 只沿“砂脉拖拽”加深：扩大牵引范围、提升拖拽稳定性、增加对已站在地面影响上的敌人的收束效果。 |
| 辅助效果服务关系 | 可附带短暂停滞，用来保证敌人被拖到中心后能被后续技能命中；不再额外给力量增幅作为第二卖点。 |
| 删数值后的记忆点 | 插刀进地，砂流把敌人拽到脚边。 |

### #32 裂岩掀地

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 双刀 / 橙 |
| 核心表现特点 | 双刀撬起地面，向前翻起一排裂岩浪。 |
| 技能效果 | 玩家双刀戳地后向前掀起地面，裂岩浪沿前方推进。敌人被翻起的地面撞击，表现为站位被打乱、受击节奏被切开。 |
| 强化方向 | 只沿“掀地推进”加深：提升裂岩浪推进距离、宽度、连续翻涌频率，或让聚集敌人被同一排岩浪完整扫过。 |
| 辅助效果服务关系 | 可给玩家短暂贴身承压空间，用来解释“贴近敌群掀地后不立刻崩盘”；如果承压反馈抢过掀地记忆点，则删除。 |
| 删数值后的记忆点 | 双刀不是砍人，而是把地板掀起来拍人。 |

## 六、弓箭技能

### #37 砂岩榴弹

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 弓箭 / 橙 |
| 核心表现特点 | 岩弹抛射落地后炸出弹坑，形成远程定点压制。 |
| 技能效果 | 玩家向目标区域抛射砂岩榴弹，榴弹落地爆裂并留下弹坑。弹坑内敌人移动受阻，远处敌人被迫离开或被压在定点区域。 |
| 强化方向 | 只沿“落地弹坑”加深：扩大弹坑影响、提高弹坑持续反馈、允许对被标记地面进行更准确的抛射。 |
| 辅助效果服务关系 | 爆炸伤害服务于“弹坑落点有威胁”；砂蚀可作为被弹坑压制后的状态，不再用榴弹数量或 buff 数做核心。 |
| 删数值后的记忆点 | 远程丢一发岩弹，在地上炸出不能轻易踩的坑。 |

### #44 砂岩箭雨

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 弓箭 / 紫 |
| 核心表现特点 | 信号箭升空后，岩箭从上方钉住一片区域。 |
| 技能效果 | 玩家射出信号箭标记目标区域，随后岩箭从空中落下并钉入地面。区域内敌人受到持续落箭压制，地面出现密集箭痕。 |
| 强化方向 | 只沿“信号箭标记落箭区”加深：提升覆盖稳定性、落箭频率、对远处地面影响区的补阵能力。 |
| 辅助效果服务关系 | 可附带砂蚀，用来表示敌人被箭雨持续压住；核心不是伤害段数，而是“标记后天上落岩箭”。 |
| 删数值后的记忆点 | 一箭上天，指定区域被岩箭钉住。 |

## 七、法杖技能

### #47 地脉陨石

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 法杖 / 红 |
| 核心表现特点 | 法杖化阵后，陨石沿地脉标记连续砸落。 |
| 技能效果 | 玩家举杖展开地脉法阵，在目标地面形成陨石落点标记。随后陨石按标记连续砸落，每次落点都会让地面震裂，并短暂改变敌人站位。 |
| 强化方向 | 只沿“地脉标记砸陨石”加深：增加落点覆盖、强化连续砸落节奏、让被地系压制的区域更容易被陨石追击。 |
| 辅助效果服务关系 | 护盾只服务于玩家站桩引导陨石时不被打断；碎裂、小陨石、普攻引导等旧稿横向卖点应删除。 |
| 删数值后的记忆点 | 先在地上点出地脉落点，再让陨石一颗颗砸下来。 |

### #48 地流树墙

| 字段 | 内容 |
|---|---|
| 武器 / 品质 | 法杖 / 橙 |
| 核心表现特点 | 岩石树墙从地面升起，直接改变敌我之间的通路。 |
| 技能效果 | 玩家插杖引动地流，岩石树墙从指定区域升起。树墙升起时推开接触敌人，成型后阻挡或分割敌人行进路线。 |
| 强化方向 | 只沿“树墙改变通路”加深：调整墙体形态、提升阻隔可靠性、让树墙与已有地面影响连接成更完整的阵地。 |
| 辅助效果服务关系 | 玩家在墙内获得承压空间，是因为树墙挡住敌人路径；减伤不作为独立卖点，只作为阵地维持结果。 |
| 删数值后的记忆点 | 插杖起墙，把战场路口直接改掉。 |
