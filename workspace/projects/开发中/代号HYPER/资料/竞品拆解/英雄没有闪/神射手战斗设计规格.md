# 英雄没有闪 战斗设计规格书（从神射手反推）

> 用途：拆解神射手战斗设计 → 一份可照着造新职业的规格 + 数值配比锚点
> 数据来源：神射手全部第一手截图（见同目录《神射手技能数据.md》）
> 标注：🔶=第一手数据可确认的规格　🔸=从单职业归纳的配比（造其他职业时为参考锚点，非铁律）

---

## 一、顶层结构（槽位框架）🔶

| 槽位 | 选择规则 | 角色 |
|---|---|---|
| 基础技能 | 3选1，每技能符文N选1 | 产能 + 标签发动机 |
| 核心技能 | 3选1，每技能符文N选1 | 主输出形态（**流派锚点**） |
| 掌控技能一 | 3选1，每技能符文2选1 | 部署/控制工具（诡诈系） |
| 掌控技能二 | 3选1，每技能符文2选1 | 位移（灵动系） |
| 终极技能 | 3选1，每技能符文3选1 | 战斗形态切换 |
| 被动技能 | 9选3（第4格条件解锁） | 流派末端放大器 |

**关键规则**：
- 每槽只能选1个技能，每技能只能激活1个符文 → 稀缺性逼出取舍
- 符文养成全职业共享（换职业不清零）

---

## 二、双资源系统（战斗节奏的骨架）🔶

战斗里有两套独立的资源，互不干扰：

### 资源1：能量经济（基础↔核心）
- 基础技能：CD=0，**恢复**能量10-11/次，无消耗 → 产能
- 核心技能：CD=0，**消耗**能量30-40/次 → 耗能
- 节拍：约 **3-4次基础技能 = 攒够1次核心技能**
- 战斗基本节奏：前奏（基础攒能）→ 节点（核心爆发）→ 循环

### 资源2：CD经济（掌控/终极）
- 掌控技能：纯CD，不参与能量
- 终极技能：纯CD，不参与能量
- 这两槽是"定时投放的大招"，节奏由CD控制，和能量循环解耦

**设计含义**：能量系统让"普攻→核心"形成可感知的搓招节奏；CD系统让掌控/终极成为节奏之上的periodic爆发点。两套并行，玩家手里始终有"马上能放的小招"和"等CD的大招"。

## 三、标签接口规则（流派如何成立）🔶

### 标签是真机制字段
效果文本会直接查询标签（实证："延长所有具有**神射手标签**技能的射程"）。标签不是分类说明，是运行时检测的字段。

### 每条流派 = 一条跨槽标签链
- 主流派标签必须**跨≥3个槽**才能成链（神射手=基础+核心+掌控一）
- 一个技能可带多标签（暗影箭=神射手+元素，是两链交叉点）→ 用交叉标签做流派融合点

### 标签链的内部结构：发动机 + 受益者
每条成立的链都有这个结构：

| 流派链 | 发动机（产全局状态） | 受益者（吃状态放大） |
|---|---|---|
| 神射手 | 瞄准射击（高频续"射程buff"） | 蓄力射击、旋刃轮 |
| 元素 | 暗影箭·流星橙（叠元素易伤10层） | 重型武器元素符文、灌注 |
| 破甲 | 枪斗术/暗影步橙符文（施破甲） | 落井下石被动 |

**发动机本身不是主力输出，职责是制造一个全局状态（buff/易伤/破甲），让受益者被放大。**

## 四、符文系统规则（流派的实现层）🔶

### 每个符文 = 4层词条，按养成等级逐层解锁
蓝(lv1) → 紫 → 金 → 橙(满级)。🔒=未达等级未解锁（养成进度，非设计规格）。

### 四层词条的内容分工🔸（造符文的配比锚点）

| 层 | 性质 | 典型内容 |
|---|---|---|
| **蓝** | 基础数值增幅 | 伤害+20~30% / 暴击率+15% / 急速+10~15% / 附伤概率+15% / 能量恢复+5% / 荆棘伤害+30% |
| **紫** | **行为改写或关键机制（符文的灵魂）** | 倍率跳变(600~3600%) / 形态转换("改为…") / 带权衡的强化（如霰射护身：强化100%但放弃近距额外伤） |
| **金** | 角色级通用增益（统一+5%档） | 物理/元素伤害+5% / 最终伤害+5% / 暴击率+5% / 附伤概率+5% / 闪避率+5% |
| **橙** | 路线特化强效果 | 条件触发高倍率（额外100~200%） / 特殊机制（必定暴击、双重施法、破甲翻倍） / 叠层（最多6~200层） |

**核心规律**：
- 蓝=数值，紫=质变，金=统一+5%通用小增益（明确数值锚点），橙=路线特化天花板
- 紫层是符文存在的意义——它让"同一技能不同符文≈两个技能"
- 基础技能的紫常不带🔒（蓝紫双开），核心技能的紫常带🔒（养到才解锁改写）→ 核心技能的Build深度藏在养成里

### 符文是"标签链的接线开关"
选哪个符文决定技能接不接入某条链：重型武器选感电符文→才打电元素→才接入元素链→才喂得到伏特火花。

### 符文做流派内子变体
同一流派内，符文按固定两轴分叉：
- **目标形式**：单体集中 / 线形穿透 / 范围落地
- **伤害节奏**：瞬时爆发 / 持续叠加
- 实证（蓄力射击三符文）：狙击=单体锁定(Boss) / 穿透=线形穿透(群怪) / 箭雨=范围落地(控场)

## 五、被动系统规则🔶

9选3。两类，缺一不可：

| 类型 | 数量 | 规则 | 神射手实例 |
|---|---|---|---|
| 通用型 | ~5 | 任何流派可用，不需上游条件 | 夜幕奇袭(满残血+20%)、治疗药水(续航)、乘胜追击(回能)、暗影覆身(核心触发闪避)、狂徒(近战减伤+急速) |
| 专精型 | ~4 | **必须上游有对应条件才生效** | 落井下石(破甲链末端)、伏特火花(电弧灼烧专精)、王牌射手(复仇联动)、混合物(元素链末端) |

**约束**：专精被动只放大"已建好的标签链"，没有上游来源就是空被动 → 防止玩家靠被动绕过流派逻辑。

## 六、数值配比锚点表🔸

> 以下为神射手单职业归纳，造新职业时作为起点，按职业定位微调。

### CD配比
| 技能类型 | CD |
|---|---|
| 基础 | 0秒（能量产出节流） |
| 核心 | 0秒（能量消耗节流） |
| 掌控·位移 | 12秒 |
| 掌控·工具/控制 | 14-18秒 |
| 终极 | 20-30秒（增伤型30，爆发型20） |

### 能量配比
| 技能类型 | 能量 |
|---|---|
| 基础 | 恢复10-11/次 |
| 核心 | 消耗30-40/次 |
| 掌控/终极 | 不参与 |

### 伤害倍率配比
| 层级 | 基础倍率 | 符文改写后峰值 |
|---|---|---|
| 基础技能 | 70-140% | — |
| 核心技能 | 280-350% | 600-1500% |
| 掌控技能 | 200-400% | 500-800% |
| 终极技能 | 1500% | 2100-3600% |

规律：终极>核心(改写)>掌控>核心(基础)>基础。终极是单次倍率天花板，符文改写能把任意技能推高2-4倍。

## 七、造一个新职业的执行步骤（checklist）

照这个顺序填，产出一个结构合格、手感接近的职业：

**Step 1 — 定职业身份**
- 几条流派？（神射手=3条）
- 每条流派的"割草幻想"是什么？（狙击手/刺客/法师式——必须是三种不同手感，不是三组数字）

**Step 2 — 定标签 + 流派链**
- 每条流派一个主标签，确保主标签**跨≥3槽**
- 设计1-2个交叉标签技能（一技能带2标签）做流派融合点
- 每条链指定：1个发动机（持续产 buff/易伤/破甲 等全局状态）+ 若干受益者

**Step 3 — 填5个技能槽（每槽3技能）**
- 基础×3：各流派的产能起手 + 标签发动机
- 核心×3：各流派的主输出形态（**锚点**，决定距离/伤害类型/节奏）
- 掌控一×3：部署/控制工具
- 掌控二×3：位移（冲/撤/隐）
- 终极×3：各流派的战斗形态切换

**Step 4 — 给每个技能配符文（每符文4层词条）**
- 蓝=数值增幅，紫=行为改写（灵魂，必须质变），金=统一+5%通用，橙=路线特化
- 用符文做流派内子变体（单体/线形/范围 × 爆发/持续）
- 用符文做"接线开关"——某符文让技能接入某条标签链

**Step 5 — 配9个被动**
- 5通用（任意流派可用）+ 4专精（每个对应一条标签链末端放大）

**Step 6 — 套数值配比表**
- CD/能量/倍率按第六节锚点填

**Step 7 — 验证（双约束）**
- 结构：每条流派能否从 基础→核心→掌控→终极→被动 连成一条自洽标签链？
- 体验：三条流派是否给三种可清晰描述的不同割草手感？任一条说不清 = 不合格，重做
