| 共同任务积分 | 军团任务、军团试炼、共同进度产生的稳定积分 |
| 军团求助 | 成员将战报或损失事件发布到军团，请其他成员协助处理 |

## 1. 需求目的

军团积分的核心目的不是“给军团做一个榜”，而是把首周已经开放的多个玩法行为转成一个可比较、可解释、可追赶、可反向指导行动的军团级目标。

没有军团积分时，首周 D4-D7 容易变成几个松散玩法：

```text
世界狩猎各打各的
寻血只沉淀为个人对手记录
军团求助只停在聊天帮忙
军团试炼只是另一个日常入口
```

军团积分把这些行为串成一条共同目标：

```text
公共收益参与
  -> 高风险争夺
  -> 成员求助和协助
  -> 军团共同任务
  -> 军团积分排行
  -> 下一轮玩法选择
```

### 1.1 面向军团的目的

- 让军团在首周拥有可见共同目标，而不是只做签到、捐献、商店。
- 把成员在世界狩猎、寻血、防守、求助、试炼中的行为汇总到同一套军团表现里。
- 让军团管理者能根据分玩法积分判断下一步该组织公共 Boss、寻血、防守、处理求助还是试炼。
- 让强军团能通过组织能力领先，但不让排行只被高战击杀决定。

### 1.2 面向成员的目的

成员不直接消费军团积分。军团积分对成员的价值来自它把军团目标拆成可参与任务：

- 高战成员可以通过寻血、反击、防守提高高风险争夺积分。
- 普通活跃成员可以通过世界狩猎、公共 Boss、军团试炼提高公共收益积分和共同任务积分。
- 被抢成员可以通过战报求助让自己的损失进入成员协助积分。
- 低战成员也能通过任务、试炼、补回、保护获得稳定贡献。

### 1.3 面向首周长线的目的

军团积分解决的是首周从“个人成长”过渡到“组织目标”的断点。

```text
如果 D7 只出现军团榜，
但前面没有公共收益、寻血、防守、求助和试炼作为来源，
这个榜会变成空榜、活跃榜或击杀榜。

如果军团积分能明确来自 D4-D7 的玩法递进，
玩家会知道：我参与哪个玩法，就会推进哪一类军团积分。
```

## 2. 玩法总览

### 2.1 一句话定义

首周军团积分是把世界狩猎、寻血、防守、军团求助、军团试炼等玩法结果汇总为军团排名，并反向提示军团下一步行动的军团级公共数值。

### 2.2 总循环

```text
军团查看当前排名和分玩法积分
→ 判断哪类积分落后或有待处理事项
→ 组织成员参与对应玩法
→ 成员完成公共收益、PVP 争夺、求助协助或共同任务
→ 系统按玩法类型增加军团积分
→ 军团排名和分玩法占比变化
→ 军团根据差距选择下一轮行动
```

### 2.3 军团积分在首周链路中的位置

| 上游玩法 | 积分处理 | 下游影响 |
|---|---|---|
| 世界狩猎、公共 Boss | 转为公共收益积分 | 让公共收益参与影响军团排名 |
| 寻血、入侵、防守 | 转为高风险争夺积分 | 让 PVP 结果进入军团目标 |
| 战报求助、反击、保护、补回 | 转为成员协助积分 | 让个人损失被军团处理 |
| 军团任务、军团试炼 | 转为共同任务积分 | 给普通活跃成员稳定贡献位置 |
| 军团榜展示 | 汇总四类积分 | 形成共同目标和下一步玩法推荐 |

## 3. 核心玩法循环

### 3.1 军团目标循环

```text
查看军团排名
→ 查看四类积分占比
→ 找到当前短板
→ 进入推荐玩法
→ 完成玩法行为
→ 军团积分增加
→ 排名或差距变化
```

这一层服务所有军团成员。军团积分把“今天要干什么”从口头组织变成界面可见目标。

### 3.2 公共收益循环

```text
D4 开放世界狩猎和公共 Boss
→ 军团成员参与公共目标
→ 伤害、参与、归属或协助被汇总
→ 增加公共收益积分
→ 玩家理解公共玩法会影响军团排名
```

公共收益积分不承担强 PVP 压力。它的作用是让玩家先看到其他玩家、其他军团和公共目标价值。

### 3.3 高风险争夺循环

```text
D5 开放寻血、入侵、防守
→ 成员携带或争夺临时收益
→ 发生入侵、防守、追回或有效反击
→ 增加高风险争夺积分
→ 战报记录发生场景、收益变化、对方军团和可处理动作
```

高风险争夺积分不按纯击杀计分。击杀必须和收益变化、防守、追回或战报有关，才对军团排行有意义。

### 3.4 成员协助循环

```text
成员被抢或被打断
→ 战报可发布为军团求助
→ 其他成员选择反击、保护或补回
→ 求助被回应
→ 增加成员协助积分
```

成员协助积分让个人 PVP 后果进入军团协作。它不是排行主来源的起点，而是 D5 高风险争夺之后的组织处理环节。

### 3.5 共同任务循环

```text
D6-D7 开放军团任务和军团试炼
→ 成员完成共同进度
→ 增加共同任务积分
→ 低战和普通活跃成员获得稳定贡献位置
```

共同任务积分保证军团排行不是高战专属。它让低风险玩家也能参与军团排名推进。

## 4. 系统规则拆解

### 4.1 军团积分来源

首版军团积分来源分为四类。

| 积分类别 | 来源玩法 | 进入排行的原因 |
|---|---|---|
| 公共收益积分 | 世界狩猎、公共 Boss | 让军团围绕公共收益形成组织参与 |
| 高风险争夺积分 | 寻血、入侵、防守、追回 | 让 PVP 结果进入军团目标 |
| 成员协助积分 | 战报求助、反击、保护、补回 | 让个人损失被军团成员处理 |
| 共同任务积分 | 军团任务、军团试炼 | 让非高战玩家也能稳定贡献 |

个人推关、普通签到、纯聊天、无损失切磋不进入主排行。它们可以作为个人成长或军团活跃辅助，但不能成为军团排行的主要来源。

### 4.2 公共收益积分

计分对象：

```text
成员参与世界狩猎
成员参与公共 Boss
军团成员获得 Boss 奖励权
成员协助本军团完成公共收益
```

设计判断：

- D4 玩家刚进入公共收益竞争，不应立刻承受高风险 PVP 压力。
- 公共收益积分负责让玩家理解“军团成员一起参与公共目标，会让军团排名前进”。
- 它应按参与、伤害、归属和协助汇总，不应按击杀玩家汇总。

### 4.3 高风险争夺积分

计分对象：

```text
成功入侵
成功防守
带回临时收益
追回被抢收益
对同一对方军团形成有效反击
```

设计判断：

- D5 的核心不是刷击杀，而是围绕临时收益发生抢夺、防守和追回。
- 击杀只有改变收益、产生战报、触发防守或追回时才进入排行。
- 如果只按击杀计分，玩家会绕开收益目标刷低价值对象，排行会变成击杀榜。

### 4.4 成员协助积分

计分对象：

```text
成员发布有效战报求助
其他成员完成反击
其他成员完成保护
其他成员帮助补回同类收益
求助在有效时间内被回应
```

设计判断：

- 只发布求助不应给高分，否则会鼓励刷求助。
- 求助被回应才说明军团真的处理了成员问题。
- 反击、保护、补回都能计分，是为了让高战、普通活跃和低战成员都有参与位置。

### 4.5 共同任务积分

计分对象：

```text
军团任务进度
军团试炼参与
共同进度完成
低战或普通活跃成员的稳定贡献
```

设计判断：

- 首周军团排行不能只奖励 PVP 强者。
- 军团任务和试炼提供稳定目标，让普通活跃成员也能推动排名。
- D7 需要把前面的公共收益、PVP、求助协作收束成一个军团共同目标。

### 4.6 职业竞技场的处理

职业竞技场首版不作为军团排行主来源。

原因：

```text
它偏个人竞技和商业化支线
它不天然产生公共收益、成员求助或军团协作
过早纳入会稀释世界狩猎、寻血、军团试炼的首周主线
```

首版可以展示成员个人荣誉，但不进入军团主排行。

## 5. 军团积分解决的问题

### 5.1 把玩法参与翻译成军团目标

世界狩猎、寻血、军团求助和军团试炼原本是不同玩法。军团积分让它们进入同一套目标：

```text
参与什么玩法
→ 增加哪类积分
→ 本军团排名变化多少
→ 下一步该补哪类玩法
```

这样军团榜不是一个结果页，而是下一步行动页。

### 5.2 防止排行变成单一击杀榜

如果只把寻血击杀计入排行，首周军团目标会被高战玩家垄断。

四类积分能把贡献拆开：

```text
公共收益积分：组织公共目标
高风险争夺积分：处理 PVP 收益和防守
成员协助积分：帮助成员处理损失
共同任务积分：稳定推进军团目标
```

这种结构让高战玩家有价值，但不让他们占满全部价值。

### 5.3 让 D4-D7 的开放顺序有理由

军团积分不是 D7 才突然出现的榜，而是从 D4 开始逐步积累。

```text
D4 公共收益先进入排行
D5 高风险争夺接入排行
D6 成员协助接入排行
D7 共同任务和总榜收束排行
```

这个节奏让玩家先理解公共收益，再接受 PVP 冲突，再理解军团协助，最后看到共同目标。

### 5.4 给不同军团不同目标

强军团目标：

- 提高高风险争夺积分。
- 争夺公共 Boss 归属。
- 快速回应成员求助。
- 维持总榜领先。

中等军团目标：

- 稳定公共收益积分。
- 在寻血和防守中避免被拉开。
- 通过成员协助补足短板。
- 在共同任务中保持日常推进。

弱军团目标：

- 通过共同任务积分保持基础排名。
- 参与公共收益拿稳定分。
- 避免在高风险争夺中被连续压制。
- 通过求助和保护降低成员流失。

## 6. 资源结构

### 6.1 产出总览

| 资源/产出 | 来源 | 用途 | 为什么需要它 |
|---|---|---|---|
| 军团积分 | 四类玩法结果汇总 | 军团排行、阶段目标、下一步推荐 | 给军团首周共同目标 |
| 公共收益积分 | 世界狩猎、公共 Boss | 分玩法积分、推荐公共玩法 | 让公共收益进入军团目标 |
| 高风险争夺积分 | 寻血、入侵、防守、追回 | 分玩法积分、推荐 PVP 行动 | 让 PVP 结果影响军团排名 |
| 成员协助积分 | 求助、反击、保护、补回 | 分玩法积分、提示待处理求助 | 让个人损失被军团处理 |
| 共同任务积分 | 军团任务、军团试炼 | 分玩法积分、稳定日常目标 | 给非高战成员贡献位置 |
| 成员贡献 | 成员参与四类玩法 | 内部贡献展示 | 让个人知道自己如何影响军团 |
| 下一步推荐 | 分玩法积分缺口 | 引导玩法入口 | 让榜单反向推动行动 |

### 6.2 军团积分为什么不是个人货币

军团积分如果做成个人货币，会和个人奖励、功勋、贡献等系统抢功能。它应该回答的是“我们军团现在处在什么位置”，而不是“我能兑换什么”。

结构分工应保持清楚：

```text
个人奖励回答：我参与这次玩法有什么收益？
成员贡献回答：我对军团做了什么？
军团积分回答：我们军团在服务器里表现如何？
军团排行回答：我们和其他军团差在哪里？
```

### 6.3 军团积分的来源、存量、使用与清理

| 项 | 当前设计 |
|---|---|
| 来源 | 公共收益、高风险争夺、成员协助、共同任务 |
| 存量 | 首周周期内累计到军团总积分 |
| 使用 | 军团排行、分玩法占比、下一步推荐、阶段奖励依据 |
| 损失 | 首版不建议做直接扣分，先用对方得分和差距表达压力 |
| 清理 | 首周周期结束后结算，进入下一周期或长线军团榜 |

首版不做直接扣分，是为了降低理解成本。寻血、防守失败可以让对方得分、本军团失去追回机会，但不建议一开始就让玩家看到军团分数被频繁扣减。

### 6.4 军团积分过多、过少、缺失的影响

| 情况 | 会坏在哪里 | 表现 |
|---|---|---|
| 公共收益积分过高 | D4 公共 Boss 压过后续玩法 | 玩家只刷公共目标，不进入寻血和求助 |
| 高风险争夺积分过高 | 排行被高战 PVP 垄断 | 普通成员觉得无法贡献 |
| 成员协助积分过高 | 玩家可能刷求助和互助 | 军团行为变成处理战报而不是参与玩法 |
| 共同任务积分过高 | 排行变成日常活跃榜 | PVP 和公共收益失去意义 |
| 军团积分变化过低 | 玩法反馈弱 | 玩家参与后看不到排名变化 |
| 没有分玩法积分 | 玩家不知道该做什么 | 排行只剩总分，无法指导下一步 |

## 7. 军团积分与玩法的关系

### 7.1 D4 公共收益先建立排行入口

D4 不适合直接把玩家推到高风险 PVP。世界狩猎和公共 Boss 的价值是让玩家看到公共目标和其他军团。

公共收益积分在这里承担第一层认知：

```text
我参与公共目标
→ 我的军团也获得表现
→ 军团排名会变化
```

### 7.2 D5 高风险争夺让排行开始有冲突

寻血、入侵、防守把公共收益推进到玩家之间的抢夺。

高风险争夺积分要绑定收益、防守和追回，而不是单纯击杀：

```text
我带回临时收益
→ 军团获得高风险争夺积分

我防住入侵
→ 军团获得高风险争夺积分

我追回被抢收益
→ 军团获得高风险争夺积分
```

### 7.3 D6 成员协助让个人战报进入军团

D6 的关键不是新增一个聊天求助入口，而是让军团能处理成员遇到的问题。

成员协助积分只在求助被处理后增加：

```text
成员发布战报
→ 其他成员反击、保护或补回
→ 求助被回应
→ 军团获得成员协助积分
```

### 7.4 D7 共同任务把排行收束为长期目标

D7 需要让军团榜不只是 PVP 结果，而是首周所有成员行为的总览。

共同任务积分提供稳定收束：

```text
成员完成军团任务和试炼
→ 军团获得共同任务积分
→ 普通活跃玩家也能影响排行
→ 军团榜承接后续沙盘或战役预告
```

---

## 8. 首周权重节奏

首版不在设计拆解中硬填具体数值，具体比例应进入数值表和测试。这里先定义权重方向。

```text
D4：公共收益积分占比最高
  -> 先让玩家理解公共目标和军团参与

D5：高风险争夺积分开始提高
  -> 让寻血、入侵、防守进入排行，但不压过全部来源

D6：成员协助积分提高
  -> 让战报求助、反击、保护、补回成为军团行为

D7：共同任务积分和总榜展示提高
  -> 让军团试炼、军团任务、总排行收束首周目标
```

权重底线：

```text
公共收益积分不能低到玩家感觉世界狩猎和 Boss 与排行无关
高风险争夺积分不能高到玩家只刷击杀、不关心收益和防守
成员协助积分不能只奖励发布求助，必须奖励被处理的求助
共同任务积分不能高到覆盖 PVP 争夺，但必须让非高战成员有稳定贡献
```

---

## 9. 不同玩家的参与难度与门槛

| 用户层 | 主要入口 | 主要门槛 | 与军团积分的关系 |
|---|---|---|---|
| 低战低活跃成员 | 军团任务、军团试炼、补回 | 时间、理解、基础战力 | 通过共同任务积分和部分成员协助贡献 |
| 普通活跃成员 | 世界狩猎、公共 Boss、保护、补回 | 在线时间、玩法理解 | 推进公共收益积分和成员协助积分 |
| 中高战成员 | 寻血、入侵、防守、反击 | 战力、操作、资源投入 | 推进高风险争夺积分 |
| 高战核心 | 高价值 PVP、关键反击、防守 | 战力、连续战斗、组织响应 | 决定高风险争夺上限 |
| 军团管理者 | 排行、分玩法占比、推荐玩法 | 判断、组织、成员动员 | 决定军团优先补哪类积分 |

### 9.1 管理者看到的是积分结构

管理者需要判断：

- 当前总排名是否需要追分。
- 哪类积分落后。
- 世界狩猎、寻血、求助、试炼哪个更值得组织。
- 成员是否有能力参与当前推荐玩法。

军团榜如果只展示总分，管理者无法做决策；必须展示分玩法积分和下一步推荐。

### 9.2 普通成员看到的是可参与入口

普通成员不需要理解完整公式。他只需要看到：

```text
我去世界狩猎，可以加公共收益积分
我去寻血或防守，可以加高风险争夺积分
我处理求助，可以加成员协助积分
我做军团试炼，可以加共同任务积分
```

### 9.3 弱势军团的被排除风险

如果高风险争夺积分占比过高，弱势军团可能被强军团连续压制，成员只能看到排名落后却没有可行行动。

因此弱势军团必须保留三个追分入口：

- 世界狩猎和公共 Boss 的基础参与。
- 军团任务和试炼的稳定推进。
- 成员求助中的保护、补回，而不只反击。

## 10. 难度变化与失效点

### 10.1 难度来源

| 难度来源 | 表现 |
|---|---|
| 公共目标竞争 | 世界狩猎和公共 Boss 参与人数上升 |
| PVP 风险 | 寻血、入侵、防守带来收益波动 |
| 战报处理压力 | 求助数量增加，需要成员响应 |
| 军团任务进度 | 试炼和共同任务需要稳定活跃 |
| 排名差距 | 距离上一名差距影响追分压力 |

### 10.2 失效情况

| 情况 | 表现 | 需要调整 |
|---|---|---|
| 公共收益积分过弱 | D4 公共目标和排行脱节 | 提高公共收益积分可见度 |
| 高风险争夺积分过强 | 玩家只刷 PVP，不做试炼和求助 | 限制纯击杀计分，绑定收益变化 |
| 成员协助积分过弱 | 战报求助没人处理 | 提高已回应求助的积分反馈 |
| 共同任务积分过强 | 排行变成日常活跃榜 | 降低共同任务在总分中的占比 |
| 分玩法展示不清 | 玩家不知道下一步该做什么 | 强化分玩法占比和推荐玩法 |
| 弱军团无追分入口 | 弱势玩家流失 | 保留公共收益和共同任务稳定分 |

## 12. 军团积分的边界

军团积分负责把首周多个玩法的军团相关结果汇总成排名，并把排名反向转成下一步玩法指引。

它负责四件事：

```text
记录军团在公共收益中的参与表现
记录军团在高风险 PVP 中的收益、防守和追回表现
记录军团成员之间是否完成求助协助
记录军团任务和试炼的稳定推进
```

它不负责四件事：

```text
不直接替代个人奖励
不直接决定 PVP 胜负
不直接开放完整军团战或沙盘
不承担职业竞技场的个人排名职责
```

相邻机制的分工要保持清楚：

| 相邻机制 | 分工 |
|---|---|
| 个人战报 | 记录个人战斗经过、收益变化和后续可处理动作 |
| 军团求助 | 把可处理战报交给成员反击、保护、补回 |
| 军团任务 / 试炼 | 提供稳定协作目标和非高战贡献入口 |
| 军团排行 | 汇总四类积分，展示军团间差距 |
| 后续沙盘 / 战役 | 承接 D7 之后的长期军团争夺 |

边界判断标准是：一个行为只有改变军团在公共收益、PVP 争夺、成员协助或共同任务中的表现，才应进入军团积分。只证明个人成长、个人在线或个人荣誉的行为，不应成为军团主排行来源。

## 13. 验证指标

### 13.1 军团目标是否成立

| 验证问题 | 观察指标 |
|---|---|
| 军团是否围绕排行组织行动 | 军团榜打开率、推荐玩法点击率、军团组织话题 |
| 玩家是否理解哪些玩法影响排行 | 分玩法详情点击率、玩法结算后查看排行比例 |
| 排行是否能反向推动玩法参与 | 从排行页进入世界狩猎、寻血、求助、试炼的比例 |
| D4-D7 递进是否成立 | 各日主推玩法参与率和积分占比变化 |

### 13.2 分层是否健康

| 用户层 | 验证重点 | 观察指标 |
|---|---|---|
| 低战成员 | 是否能通过任务和试炼贡献 | 共同任务参与率、低战成员贡献占比 |
| 普通活跃成员 | 是否参与公共收益和补回 | 世界狩猎参与率、补回参与率 |
| 中高战成员 | 是否承担寻血、防守、反击 | 高风险争夺积分贡献、战报回应率 |
| 高战核心 | 是否影响高风险上限但不过度垄断 | 高风险积分集中度、总积分集中度 |
| 军团管理者 | 是否利用分玩法积分组织成员 | 推荐玩法点击后的成员参与人数 |

### 13.3 积分结构是否稳定

| 验证问题 | 异常表现 |
|---|---|
| 是否变成击杀榜 | 高风险争夺积分占比过高，其他积分无人参与 |
| 是否变成活跃榜 | 共同任务积分占比过高，PVP 和公共收益失效 |
| 是否变成空榜 | D7 开榜前缺少 D4-D6 积分来源 |
| 求助是否真的被处理 | 求助发布多、回应少、成员协助积分低 |
| 弱军团是否还有追分方式 | 弱军团只在高风险争夺中被压制，无公共收益和任务增长 |

## 14. 可迁移结论

### 14.1 多玩法排行必须先拆来源，再做总分

适用前提：一个排行需要汇总多个玩法，且这些玩法服务不同玩家层和不同阶段。

判断标准：

```text
玩家能说清楚自己参与哪个玩法会增加哪类分
管理者能根据分项差距组织下一步行动
总分不会掩盖玩法短板
```

不适用情况：玩法本身只有单一竞技目标，例如纯个人竞技场排名。

### 14.2 PVP 积分必须绑定收益变化或目标处理

适用前提：PVP 玩法会产生击杀、防守、抢夺、追回等多种结果。

判断标准：

```text
击杀只有影响收益、防守、追回或战报处理时才计入主排行
玩家不会为了刷分攻击低价值对象
被攻击玩家能看到后续处理入口
```

不适用情况：玩法目标就是纯击杀竞赛，且没有收益抢夺或组织协作。

### 14.3 军团排行要给非高战玩家贡献位置

适用前提：军团内有明显战力差异，且排行会影响群体目标。

判断标准：

```text
低战和普通活跃成员能通过任务、试炼、保护、补回贡献
高战玩家能决定上限，但不能独占全部分数
军团榜不会让多数成员觉得自己只是旁观
```

不适用情况：玩法只面向少数核心玩家，不承担全军团参与目标。

### 14.4 排行页要能反向推荐行动

适用前提：排行不是只做结算，而要驱动玩家继续参与。

判断标准：

```text
榜单能显示哪类分落后
榜单能给出对应玩法入口
玩法结算后能回到排行查看变化
```

不适用情况：排行只用于赛季末领奖，不承担过程组织。

## 16. 总结

FF 首周军团积分不应只是一个军团榜，也不应从“个人被抢后求助”单点出发。它应承担类似威望的公共数值职责：把多个玩法结果汇总为军团级排名，并让排名反向影响军团下一步行动。

它把四件事连在一起：

```text
公共收益 = 军团参与公共目标
高风险争夺 = 军团成员在 PVP 中拿收益、防损失
成员协助 = 军团处理成员遇到的问题
共同任务 = 军团稳定推进首周目标
```

放回首周链路里看，军团积分的位置是：

```text
D4 世界狩猎 / 公共 Boss
→ D5 寻血 / 入侵 / 防守
→ D6 战报求助 / 成员协助
→ D7 军团试炼 / 军团榜
→ 后续沙盘 / 战役 / 长线军团争夺
```

它最重要的设计价值有三点：

1. 让首周多个玩法汇总成一个军团共同目标。
2. 让玩家知道不同玩法如何影响军团排名。
3. 让不同层级玩家都有为军团排行贡献的位置。

最大的风险也来自积分结构：如果高风险争夺积分过强，排行会变成高战击杀榜；如果共同任务积分过强，排行会变成日常活跃榜；如果分玩法展示不清，玩家只会看到总分，不知道下一步该做什么。

因此，军团积分设计的关键不是先填具体数值，而是先控制四个关系：

```text
公共收益与高风险 PVP 的关系
个人战报与成员协助的关系
高战贡献与普通成员贡献的关系
总排行展示与下一步玩法引导的关系
```

只要这四个关系稳定，军团积分排行就能把 FF 首周从“功能开放”推进到“军团共同目标”。
