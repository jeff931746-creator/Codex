# FF｜7日强社交功能链路梳理

## 1. 背景与结论

本轮整理基于新版立项文档，重新梳理 FF 首周功能链路。

新版立项的核心不是单纯竞技场或异步 PVP，而是：

> 竖屏横版多人在线 RPG + 传奇-like 强社交生态

首周设计不应理解为 7 天内做完军团沙盘、帮战、国战，而是要在 7 天内完成一条可落地的玩家认知链路：

```text
我能变强 → 这不是单机 → 好东西要抢 → 被抢会记仇 → 我需要军团 → 后续有军团共同目标
```

对应功能链路为：

```text
单人成长 → 多人感知 → 资源争夺 → 轻 PVP 冲突 → 军团归属 → 军团共同目标 → 后续军团沙盘/战役预期
```

## 2. 现有文档支撑度判断

现有需求文档可以支撑若干单点玩法上线，但还不足以支撑完整强社交生态。

当前支撑较好的模块：

| 模块 | 当前判断 |
|---|---|
| 冒险系统 | 可支撑基础战斗与成长入口 |
| 装备系统 | 必须保留，是战力、掉落、换装、爆装心流的价值载体 |
| 任务系统 | 可支撑首周目标与日常循环 |
| 世界狩猎 | 是目前最接近公共资源争夺、PVEVP、抢 Boss 的模块 |
| 寻血玩法 | 是目前最接近入侵、防守、复仇、临时收益争夺的模块 |
| 军团系统 | 可支撑军团基础组织，但不足以支撑军团对抗 |
| 军团试炼 | 可支撑军团日常活跃和首周军团目标 |
| 职业竞技场 | 可作为支线 PVP 与商业化补充，但不是首周主生态发动机 |

主要缺口：

| 缺口文档 | 作用 |
|---|---|
| 7日功能开放节奏总表 | 定义 D1-D7 每天开放什么、为什么开放、流向哪里 |
| 首周强社交生态链路 | 串起单人成长、多人、资源争夺、PVP、军团 |
| PVEVP基础规则 | 统一世界狩猎、寻血、后续沙盘的攻击、死亡、复活、奖励权 |
| 玩法背包/临时收益系统 | 支撑“杀人爆装但不伤核心资产” |
| 军团承接规则 | 说明个人冲突如何导向军团，军团如何承接世界狩猎/寻血/试炼 |
| 军团沙盘/战役活动 | 承接 D7 之后的长期军团共同目标 |
| 区服生态与合服规则 | 承接新服、一合、二合、合服活动和服务器生态修复 |

## 3. 7日主链路

| 天数 | 主目标 | 核心功能 | 玩家心理 |
|---|---|---|---|
| D1 | 单人变强 | 冒险、装备、自动战斗 | 我会玩，我能变强 |
| D2 | 成长目标 | 技能、宠物、任务、七日活动 | 我知道接下来养什么 |
| D3 | 多人感知 | 同屏、排行、聊天、他人信息 | 这不是单机 |
| D4 | 资源争夺 | 世界狩猎、Boss 奖励权、复活 | 好东西要抢 |
| D5 | 轻 PVP 冲突 | 寻血、入侵、防守、战报、复仇 | 抢人和被抢会产生情绪 |
| D6 | 军团归属 | 加入军团、捐献、任务、商店 | 形成军团基础目标 |
| D7 | 首周收束 | 军团试炼、军团榜、沙盘预告 | 军团共同目标升级 |

## 4. 三个核心循环

### 4.1 成长循环

```text
战斗 → 掉落 → 养成 → 战力提升 → 解锁更高关卡/更多玩法
```

作用：

- 解决玩家为什么每天上线。
- 支撑 D1-D3 的留存与基础爽感。
- 为 D4 世界狩猎和 D5 寻血提供战力前置。

承接功能：

- 冒险系统
- 装备系统
- 任务系统
- 自动战斗
- 基础付费权益：首充、月卡、七日嘉年华

### 4.2 资源争夺循环

```text
高价值资源 → 公共/半公共场景 → 争夺 → 奖励权变化 → 战报/仇人/复仇入口
```

作用：

- 解决玩家为什么想变强。
- 让玩家感知“好东西不是纯单机产出，会被别人抢”。
- 把 D4 世界狩猎自然导向 D5 寻血冲突。

承接功能：

- 世界狩猎
- Boss 奖励权
- 死亡/复活
- 区域热度
- 战报/复仇入口

注意：

- D4 的资源争夺重点应是 Boss、公共资源、奖励权。
- 如果“矿点”指寻血矿，应归入 D5 寻血，不应放在 D4。

### 4.3 军团承接循环

```text
个人冲突受挫 → 查看对方信息/军团 → 加入或创建军团 → 军团任务/捐献/商店 → 军团试炼/军团榜 → 后续沙盘预期
```

作用：

- 解决玩家为什么需要军团。
- 把个人层面的被抢、被入侵、复仇情绪，沉淀为组织需求。
- 让军团不是聊天群，而是后续资源争夺和战役的组织答案。

承接功能：

- 军团系统
- 军团任务
- 军团捐献
- 军团商店
- 军团试炼
- 军团榜
- 军团沙盘/战役预告

## 5. 商业化节点修正

本轮修正过几个容易误导的商业化位置：

| 原问题 | 修正口径 |
|---|---|
| 月卡挂在 D4 | 月卡是 D1/D2 起出现的基础付费权益，贯穿首周 |
| 门票挂在 D5 PVP 消耗 | 门票更适合归属竞技场/副本次数/月卡权益，不直接挂寻血冲突 |
| 战令只挂在 D7 | 战令应区分竞技场战令、版本战令、合服战令；D7 只做版本战令/长期目标预告 |
| 矿点放在 D4 | 若指寻血矿，应归入 D5 寻血和玩法背包 |
| D6 只表达“一个人不够稳” | D6 应表达“形成军团基础目标” |
| D7 表达“下周干大事” | D7 应表达“军团共同目标升级”，并预告沙盘/战役 |

商业化按类型挂接：

| 类型 | 位置 | 内容 |
|---|---|---|
| 基础付费权益 | D1-D2 起，贯穿首周 | 首充、月卡、七日嘉年华 |
| 资源效率付费 | D4 压力增强 | 掉落加速、多倍点数消耗、复活 |
| 冲突场景付费 | D5 | 复活、保护、追回、复仇加速 |
| 长期目标付费预期 | D7 | 军团目标、后续沙盘、版本战令预告 |

## 7. 下一步建议

按落地优先级，后续应先补三类文档：

1. `7日功能开放节奏总表`
   - 每天开放什么。
   - 触发条件是什么。
   - 核心奖励是什么。
   - 玩家心理目标是什么。
   - 流向下一个功能的理由是什么。

2. `PVEVP基础规则`
   - 公共场景攻击关系。
   - Boss 奖励权。
   - 死亡/复活/离场。
   - 战报、仇人、复仇。
   - 世界狩猎、寻血、后续沙盘之间的共用规则。

3. `玩法背包/临时收益系统`
   - 核心资产不掉。
   - 未入账收益进入临时包。
   - 抢夺比例。
   - 保护规则。
   - 追回/复仇收益。

最终目标是让首周链路从“功能堆叠”变成“玩家行为递进”：

```text
先让玩家变强，再让玩家看见别人，再让玩家和别人抢，再让玩家产生情绪，最后让玩家需要军团。
```
