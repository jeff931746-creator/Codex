# FF｜7日强社交功能链路梳理

## 1. 首周链路结论

FF 首周功能链路的核心目标，不是把军团沙盘、帮战、国战等长期组织玩法压缩进 7 天，而是在首周完成玩家对强社交生态的认知递进。

新版立项的核心表达是：

> 竖屏横版多人在线 RPG + 传奇-like 强社交生态

首周需要让玩家从个人成长进入多人感知，再进入资源争夺、轻 PVP 冲突和军团归属。玩家在 7 天内形成的认知链路应是：

```text
我能变强 -> 这不是单机 -> 好东西要抢 -> 被抢会记仇 -> 我需要军团 -> 后续有军团共同目标
```

对应的功能链路是：

```text
单人成长 -> 多人感知 -> 资源争夺 -> 轻 PVP 冲突 -> 军团归属 -> 军团共同目标 -> 后续军团沙盘/战役预期
```

因此，这份文档的判断结论是：现有需求文档可以支撑首周强社交链路的起点，但还不能单独支撑完整强社交生态。后续补文档应围绕 `PVEVP 基础规则`、`玩法背包/临时收益系统` 和 `军团承接规则` 展开。

## 2. 当前文档支撑范围

现有需求文档已经具备基础战斗、成长、任务、世界狩猎、寻血和军团日常的单点支撑。它们能帮助首周链路成立，但还缺少跨系统的攻击关系、奖励权、损失边界、复仇回流和军团承接规则。

当前支撑较好的模块如下：

| 模块 | 当前判断 |
|---|---|
| 冒险系统 | 可支撑基础战斗与成长入口 |
| 装备系统 | 必须保留，是战力、掉落、换装、爆装心流的价值载体 |
| 任务系统 | 可支撑首周目标与日常循环 |
| 世界狩猎 | 是目前最接近公共资源争夺、PVEVP、抢 Boss 的模块 |
| 寻血玩法 | 是目前最接近入侵、防守、复仇、临时收益争夺的模块 |
| 军团系统 | 可支撑军团基础组织，但不足以支撑军团对抗 |
| 军团试炼 | 可支撑军团日常活跃和首周军团目标 |
| 职业竞技场 | 可作为支线 PVP 与商业化补充，但不是首周主生态发动机 |

主要缺口集中在跨系统链路上：

| 待补文档 | 承担作用 |
|---|---|
| 7日功能开放节奏总表 | 定义 D1-D7 每天开放什么、为什么开放、流向哪里 |
| 首周强社交生态链路 | 串起单人成长、多人、资源争夺、PVP、军团 |
| PVEVP基础规则 | 统一世界狩猎、寻血、后续沙盘的攻击、死亡、复活、奖励权 |
| 玩法背包/临时收益系统 | 支撑“杀人爆装但不伤核心资产” |
| 军团承接规则 | 说明个人冲突如何导向军团，军团如何承接世界狩猎、寻血和试炼 |
| 军团沙盘/战役活动 | 承接 D7 之后的长期军团共同目标 |
| 区服生态与合服规则 | 承接新服、一合、二合、合服活动和服务器生态修复 |

## 3. D1-D7 功能递进

首周 7 天的设计重点，是让玩家的收益状态和社交关系逐步升级。D1-D3 建立个人成长与多人感知，D4-D5 把高价值收益放入公共争夺和轻 PVP 冲突，D6-D7 再把个人冲突沉淀为军团目标。

| 天数 | 主目标 | 核心功能 | 玩家心理 |
|---|---|---|---|
| D1 | 单人变强 | 冒险、装备、自动战斗 | 我会玩，我能变强 |
| D2 | 成长目标明确 | 技能、宠物、任务、七日活动 | 我知道接下来养什么 |
| D3 | 多人感知 | 同屏、排行、聊天、他人信息 | 这不是单机 |
| D4 | 资源争夺 | 世界狩猎、Boss 奖励权、复活 | 好东西要抢 |
| D5 | 轻 PVP 冲突 | 寻血、入侵、防守、战报、复仇 | 抢人和被抢会产生情绪 |
| D6 | 军团归属 | 加入军团、捐献、任务、商店 | 形成军团基础目标 |
| D7 | 首周收束 | 军团试炼、军团榜、沙盘预告 | 军团共同目标升级 |

这条链路成立的关键，不是每天新增一个孤立功能，而是每天都要把玩家推向下一层关系：先有个人收益，再看见他人，再争夺公共收益，再产生具名冲突，最后需要组织承接。

## 4. 三条行为循环

### 4.1 成长循环支撑首周留存

成长循环承担 D1-D3 的基础留存和爽感。玩家通过战斗、掉落、养成和战力提升获得稳定目标，并为 D4 世界狩猎和 D5 寻血提供战力前置。

```text
战斗 -> 掉落 -> 养成 -> 战力提升 -> 解锁更高关卡/更多玩法
```

承接功能包括：

- 冒险系统
- 装备系统
- 任务系统
- 自动战斗
- 基础付费权益：首充、月卡、七日嘉年华

### 4.2 资源争夺循环把成长价值公共化

资源争夺循环承担 D4 的社交转折。它让玩家意识到高价值收益不再只是个人产出，而会在公共或半公共场景中被其他玩家影响。

```text
高价值资源 -> 公共/半公共场景 -> 争夺 -> 奖励权变化 -> 战报/仇人/复仇入口
```

D4 的重点应放在 Boss、公共资源和奖励权上。若“矿点”指寻血矿，应归入 D5 寻血和玩法背包，不应放在 D4 世界狩猎中承担资源争夺。

承接功能包括：

- 世界狩猎
- Boss 奖励权
- 死亡/复活
- 区域热度
- 战报/复仇入口

### 4.3 军团承接循环把个人冲突组织化

军团承接循环承担 D6-D7 的关系升级。军团不能只是签到、捐献和商店，而要回答玩家在被抢、被入侵、复仇受挫后为什么需要组织。

```text
个人冲突受挫 -> 查看对方信息/军团 -> 加入或创建军团 -> 军团任务/捐献/商店 -> 军团试炼/军团榜 -> 后续沙盘预期
```

军团在首周至少需要承接三类需求：保护、协助、收益放大。D7 的军团试炼和军团榜不是长线 GVG 的替代品，而是把首周个人冲突导向后续沙盘、战役和区服生态的预告入口。

承接功能包括：

- 军团系统
- 军团任务
- 军团捐献
- 军团商店
- 军团试炼
- 军团榜
- 军团沙盘/战役预告

## 5. 商业化挂接边界

首周商业化不能抢走强社交链路的主线。付费点应服务于成长效率、资源争夺压力、冲突回流和长期目标预期，而不是把具体商品误放成某一天的主玩法。

本轮需要稳定的修正口径如下：

| 原口径 | 修正口径 |
|---|---|
| 月卡挂在 D4 | 月卡是 D1/D2 起出现的基础付费权益，贯穿首周 |
| 门票挂在 D5 PVP 消耗 | 门票更适合归属竞技场、副本次数、月卡权益，不直接挂寻血冲突 |
| 战令只挂在 D7 | 战令应区分竞技场战令、版本战令、合服战令；D7 只做版本战令或长期目标预告 |
| 矿点放在 D4 | 若指寻血矿，应归入 D5 寻血和玩法背包 |
| D6 只表达“一个人不够稳” | D6 应表达“形成军团基础目标” |
| D7 表达“下周干大事” | D7 应表达“军团共同目标升级”，并预告沙盘/战役 |

商业化按类型挂接：

| 类型 | 位置 | 内容 |
|---|---|---|
| 基础付费权益 | D1-D2 起，贯穿首周 | 首充、月卡、七日嘉年华 |
| 资源效率付费 | D4 压力增强 | 掉落加速、多倍点数消耗、复活 |
| 冲突场景付费 | D5 | 复活、保护、追回、复仇加速 |
| 长期目标付费预期 | D7 | 军团目标、后续沙盘、版本战令预告 |

## 7. 下一步拆分顺序

后续补文档应先补链路成立所依赖的底层规则，而不是先扩写长期军团玩法。优先级如下：

1. `7日功能开放节奏总表`

   这份表先把每天开放内容、开放条件、核心奖励、玩家心理目标和下一功能流向固定下来。它决定 D1-D7 是否是递进链路，而不是功能堆叠。

2. `PVEVP基础规则`

   这份规则统一公共场景攻击关系、Boss 奖励权、死亡、复活、离场、战报、仇人、复仇，以及世界狩猎、寻血、后续沙盘之间的共用规则。它决定 D4-D7 的冲突是否能稳定复用。

3. `玩法背包/临时收益系统`

   这份系统定义核心资产不掉、未入账收益进入临时包、抢夺比例、保护规则、追回和复仇收益。它决定“杀人爆装”能否成立，同时不破坏玩家核心资产安全感。

完成以上三类文档后，首周链路才能从“功能堆叠”变成“玩家行为递进”：

```text
先让玩家变强，再让玩家看见别人，再让玩家和别人抢，再让玩家产生情绪，最后让玩家需要军团。
```
