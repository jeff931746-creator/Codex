# FF｜首周军团积分与后续沙盘威望预留方案

> 本文是 `FF-首周军团积分排行设计拆解GDD.md` 的后续预留文档，不修改现有首周 GDD。  
> 目标：说明首周军团积分如何作为后续沙盘玩法的前置公共数值，并预留“威望阶梯 / 沙盘奖励包装 / 长线军团目标”的承接接口。

---

## 1. 核心判断

首周军团积分不应只被理解为一个 7 日榜单。它更适合作为后续沙盘玩法的前置训练层：

```text
首周军团积分
  -> 让玩家理解哪些行为能推进军团目标
  -> 让军团形成围绕公共收益、PVP、协助、任务的组织习惯
  -> 让军团看到自己和其他军团的差距
  -> 为后续沙盘威望提供行为来源和数值认知
```

后续沙盘可以沿用这套公共数值逻辑，但不一定继续叫“军团积分”。更推荐做一层包装：

```text
首周展示名：军团积分 / 军团排行
后续展示名：军团威望 / 战区威望 / 沙盘声望
```

这样首周降低理解成本，后续提高奖励感、地位感和长期目标感。

## 2. 为什么要预留

如果首周军团积分只是临时榜单，会出现三个问题：

```text
D7 结算后目标断掉
玩家不知道首周排行和后续沙盘有什么关系
后续沙盘需要重新教育一套军团公共数值
```

预留威望承接后，首周积分可以承担更清楚的作用：

```text
D4-D7：教会玩家如何为军团加分
D7 结算：把首周表现转成军团初始威望或威望阶梯
沙盘开启：用威望决定初始权益、奖励档位或目标难度
沙盘进行中：继续通过公共收益、PVP、协助、任务产出威望
```

这里的关键不是把首周奖励做大，而是让玩家感到“首周做的事情会影响后面的军团位置”。

## 3. 首周积分与后续威望的关系

### 3.1 关系定义

首周军团积分是短周期表现值，后续威望是长周期公共地位值。

| 项目 | 首周军团积分 | 后续沙盘威望 |
|---|---|---|
| 周期 | D4-D7 或首周活动周期 | 沙盘赛季 / 战役周期 |
| 作用 | 排行、追赶、引导下一步玩法 | 地位、权益、奖励档位、沙盘目标 |
| 反馈 | 今日新增、排名变化、分玩法占比 | 威望阶梯、沙盘称号、权限或奖励 |
| 主要价值 | 建立军团目标认知 | 延续军团竞争和长期协作 |
| 数值表现 | 明确、轻量、易理解 | 更有包装、更有阶段感 |

### 3.2 继承原则

首周积分不建议 1:1 无损转成长期威望，否则前期强军团可能直接滚雪球。更适合采用折算或阶梯映射。

推荐原则：

```text
首周积分决定初始威望阶梯
首周排名决定沙盘开启时的展示位置或基础奖励
首周分玩法表现决定后续沙盘的推荐目标
首周不直接决定后续沙盘胜负
```

## 4. 威望阶梯方案

### 4.1 阶梯定位

威望阶梯不是另一个货币，而是军团在沙盘周期中的公共等级。

它回答的问题是：

```text
我们军团现在处在什么战区地位
我们离下一档还差多少威望
我们下一步应该打公共目标、争夺据点、协助成员还是完成军团任务
```

### 4.2 阶梯结构

首版可以采用 5 档阶梯，避免过细导致理解成本过高。

| 阶梯 | 定位 | 展示包装 | 适合奖励 |
|---|---|---|---|
| 威望 I | 刚进入沙盘 | 初入战区 | 基础参与奖励、沙盘引导 |
| 威望 II | 有稳定参与 | 稳定驻军 | 小额资源加成、共同任务奖励 |
| 威望 III | 有组织能力 | 区域强军 | 公共 Boss 额外奖励、战区商店档位 |
| 威望 IV | 有争夺能力 | 战区名门 | 据点奖励加成、稀有资源投放 |
| 威望 V | 顶级竞争者 | 战区霸主 | 赛季展示、专属称号、高档结算奖励 |

阶梯名称可以后续包装，但结构上需要保留：

```text
当前威望阶梯
当前威望值
距离下一阶梯差值
本周期主要威望来源
下一步推荐玩法
```

### 4.3 首周到威望阶梯的映射

首周结算时，不直接把所有积分变成长期资源，而是映射成初始阶梯和沙盘入场状态。

示例：

| 首周结果 | 后续沙盘预留结果 |
|---|---|
| 首周总积分达到基础线 | 沙盘开启时获得威望 I |
| 首周进入服务器前 50% | 沙盘开启时获得威望 II |
| 首周进入服务器前 20% | 沙盘开启时获得威望 III |
| 首周进入服务器前 5% | 沙盘开启时获得威望 IV |
| 首周榜首或特殊目标达成 | 沙盘开启时获得威望 V 预告或限时展示 |

如果担心强弱差距过大，可以只给入场展示和小额奖励，不给强战斗属性。

## 5. 分玩法来源如何沿用到沙盘

后续沙盘不需要重建一套完全不同的威望来源。首周四类积分可以继续作为沙盘威望的来源骨架。

| 首周积分来源 | 沙盘威望来源 | 后续包装 |
|---|---|---|
| 公共收益积分 | 公共目标威望 | 世界 Boss、资源点、区域事件 |
| 高风险争夺积分 | 争夺威望 | 据点争夺、入侵、防守、收益追回 |
| 成员协助积分 | 协防威望 | 求助处理、驻防支援、成员保护 |
| 共同任务积分 | 建设威望 | 军团建设、补给、试炼、共同进度 |

这样做的好处是：

```text
玩家首周学会的行为在沙盘继续有效
军团管理者仍然能通过分项判断短板
后续只需要替换包装和奖励，不需要重做底层认知
```

## 6. 奖励包装预留

后续沙盘可以把“威望阶梯”包装成更强奖励感，但首版要避免过早绑定复杂奖励。

### 6.1 可预留的奖励类型

```text
威望阶梯奖励
沙盘入场奖励
战区商店档位
据点收益加成
公共 Boss 额外奖励
军团称号或旗帜展示
赛季结算展示
```

### 6.2 不建议首周直接开放的奖励

```text
强战斗属性压制
长期不可追赶的永久加成
直接决定沙盘胜负的初始资源
只有高战成员能获得的个人奖励
```

原因是首周军团积分的主要职责是建立军团目标，不是提前决定沙盘格局。

## 7. UI 与信息预留

首周 UE 可以不展示完整威望系统，但需要预留两个轻量入口。

### 7.1 D7 结算预告

在军团榜 D7 或首周结算时展示：

```text
本周军团表现将影响后续沙盘威望起点
当前预计威望阶梯：威望 II
继续提升军团积分，可提高沙盘开启时的威望档位
```

### 7.2 沙盘入口预告

沙盘未开放时，在军团排行页增加弱提示：

```text
后续沙盘玩法将沿用军团积分表现，转化为军团威望阶梯。
```

这个提示不应抢主流程，只作为“为什么现在要争军团榜”的解释。

## 8. 数据与配置预留

为了后续能平滑接入沙盘威望，首周军团积分需要保留以下数据。

| 数据 | 用途 |
|---|---|
| 首周总积分 | 映射初始威望阶梯 |
| 四类积分分项 | 判断军团擅长方向和后续推荐 |
| 首周最终排名 | 映射展示档位或结算奖励 |
| 每日积分变化 | 观察军团活跃和追赶能力 |
| 主要交手军团 | 后续沙盘推荐对手或区域关系 |
| 成员贡献分布 | 判断是否过度依赖少数高战 |

需要预留的配置项：

```text
首周积分到威望阶梯的映射表
威望阶梯奖励表
威望每日上限
四类来源权重
赛季重置规则
弱势军团追赶系数
```

## 9. 关键边界

### 9.1 首周仍然叫军团积分

首周不建议一开始就叫威望。原因是玩家尚未进入沙盘语境，直接给“威望”会显得抽象。

更好的节奏是：

```text
首周：军团积分，强调哪些玩法影响军团排行
D7：提示积分会影响后续沙盘威望
沙盘开启：正式包装为军团威望或战区威望
```

### 9.2 威望不等于个人兑换货币

威望是军团公共地位，不是个人商店货币。个人奖励可以来自贡献、功勋或任务奖励，但威望本身应服务军团目标。

### 9.3 不让首周结果锁死沙盘

首周可以影响沙盘起点，但不能决定沙盘结局。

推荐控制：

```text
首周只给阶梯起点、展示和小额收益
沙盘主胜负仍由沙盘周期内的争夺、协防和建设决定
弱势军团保留追赶路径
```

## 10. 推荐落地路径

### 10.1 首周版本

```text
完成军团积分排行
完成四类积分读数
完成下一步推荐玩法
完成 D7 沙盘威望预告
保留积分分项和最终排名数据
```

### 10.2 沙盘预告版本

```text
增加预计威望阶梯
增加沙盘开启倒计时
增加威望阶梯说明页
增加首周积分到威望阶梯的映射展示
```

### 10.3 沙盘正式版本

```text
军团积分包装为沙盘威望
四类积分来源包装为四类威望来源
威望阶梯影响奖励档位和沙盘展示
沙盘内继续通过公共目标、争夺、协防、建设产出威望
```

## 11. 风险与控制

| 风险 | 表现 | 控制方式 |
|---|---|---|
| 玩家以为首周榜只是临时活动 | D7 后目标断层 | D7 提前提示后续威望承接 |
| 强军团滚雪球 | 高排名军团沙盘起点过强 | 首周只映射阶梯和小额奖励 |
| 威望理解过重 | 首周玩家看不懂 | 首周仍用军团积分，沙盘再包装威望 |
| 奖励过度个人化 | 玩家只刷个人贡献 | 威望作为军团公共值，个人奖励另走贡献 |
| 沙盘重新教育成本高 | 后续玩法像新系统 | 沿用四类来源和下一步推荐逻辑 |

## 12. 总结

首周军团积分应该被设计成后续沙盘威望的前置层，而不是一次性排行。

它在首周承担三个任务：

```text
建立军团公共目标
训练玩家理解四类军团行为
记录可迁移到沙盘的军团表现
```

后续沙盘再把这套逻辑包装成威望阶梯：

```text
军团积分
  -> 首周排行和行为教学
  -> D7 结算与沙盘预告
  -> 初始威望阶梯
  -> 沙盘威望、奖励档位和长期军团目标
```

因此，当前 GDD 不需要改成完整沙盘设计，但需要在后续文档和实现中保留“积分可折算、分项可继承、阶梯可包装、奖励可扩展”的接口。
