# FF-指尖战记

成熟项目资料入口。

## 关键词

- FF
- 指尖战记
- 指尖

## 归档范围

凡是明确属于 FF / 指尖战记 / 指尖 项目的资料、需求、方案、评审、会议纪要、素材说明、研发协作内容，后续统一放入本目录。

不确定是否属于本项目的内容，先放入 `资料/待归类/`，确认后再移动到对应部门或阶段目录。

## 目录约定

- `立项/`：历史立项材料、项目背景、已确认方向
- `策划/输入/`：需求、参考、约束、上游输入
- `策划/输出/`：GDD、系统方案、玩法方案、配置说明
- `开发/输入/`：开发需求、接口约定、技术约束
- `开发/输出/`：实现说明、联调记录、构建说明
- `美术/输入/`：美术需求、风格参考、资产清单
- `美术/输出/`：美术交付说明、验收记录
- `运营/输入/`：运营需求、活动目标、投放或数据输入
- `运营/输出/`：运营方案、活动配置、数据复盘
- `评审/`：方案评审、版本评审、问题清单
- `会议纪要/`：项目会议记录和决议
- `资料/`：项目参考资料、待归类材料、外部信息
