# 玩法发生端:发散 + 筛选机制(最大化版)

> **范围**:本机制只做"产出候选"和"扔掉逻辑硬伤"。测试 / 原型 / 判好坏由用户负责,机制不碰。
> **天花板(不是缺陷)**:筛选最大化 = 把"扔逻辑硬伤"做到不漏、不冤;它**判不了好不好玩**(已验证 AI 做不了)。承接 [阶段性观察_2026-06-25.md](阶段性观察_2026-06-25.md)。

## 一、发散机制(把"多样且不跑偏"拉满)

### 步骤 0:命题自洽检查(前置,独立一关)
写一句:"玩家在【什么状态】里,靠【什么动作】,达到【什么】。"
独立检查:命题里"压力从哪来"和"满足从哪来"会不会互相抵消?(教训:"可恢复+无时限"会把取舍消掉。)
**自相矛盾的命题当场拦掉,不让它污染整批候选。** 不通过不往下走。

### 步骤 1:变异算子库(完整 22 个,正交分配)
发散 = Proven 基础结构 × 变异算子。基础结构从已验证玩法选(分类/放置/连接/合并/路径/推理/调度…)。

变异算子库(只当**产出方向**,绝不当筛选判据):

| 类 | 算子 |
|---|---|
| 改决策结构(10) | 反转目标 / 换控制对象 / 改信息(公开↔隐藏) / 改资源(消耗↔循环) / 改压力(空间↔时间) / 改反馈延迟 / 换阻力来源(系统↔自己留的局面) / 改尺度(单体↔群体) / 改失败方式 / 改节奏(连续↔规划执行分离) |
| 减摩擦(6,Mark) | 去掉:要花钱 / 步骤多 / 看不懂 / 要等 / 怕做错 / 要约人 |
| 加钩子(6,Mark) | 换场景 / 加社交 / 换操作 / 给新身份 / 换节奏 / 能一句话讲清 |

**正交分配**:多路产出时,每路领**不重叠**的(种子 × 算子组合),把覆盖面拉到最大。

### 步骤 2:互盲并行产出(N 路,互相看不见)
每路独立产出,互不知情。否则全收敛到一个点(上次 8 个候选 4 个撞一起就是没互盲)。

### 步骤 3:决策循环强制(写不出即扔)
每个候选必须写清:
- 玩家反复做什么动作?
- 动作怎么改变局面?
- 哪里必须取舍(选 A 就放弃 B)?
- 为什么下一轮不能照抄上一轮?
- 失败后玩家产生什么新判断?
- **五条写不出 = 概念不是玩法,当场扔。**

### 步骤 4:去重合并(横向查同质)
所有候选产完后,横向比对:**核心决策循环相同的合并,保留表达最好的那个。** 专治收敛——表面题材不同、内核一样的算一个。

> **发散"最大化" = 覆盖最大(全算子库+正交) + 不收敛(互盲+去重) + 形式完整(决策循环强制)。边界:不保证好玩。**

## 二、筛选机制(把"扔逻辑硬伤"做到不漏、不冤)

**定位(守死)**:只杀逻辑站不住的,不判好不好玩。剩下的是"逻辑站得住、值得你拿去测的池子",不是好玩排名。

### 杀因 5 条铁律(所有"杀"必须同时满足,否则不杀、只标风险)
1. 可由规则文本直接推出
2. 不依赖 agent 自建模拟器
3. 不依赖某组参数假设
4. 不依赖"玩家通常会怎么选"的经验判断
5. 能写出最小反例

> 一句话:**能纯逻辑推出 → 可杀;需要自建模型 / 调参数 / 脑内模拟 → 不杀,只标风险。** 这是筛选端最高约束,把所有实验教训压成一条可执行规则。

### 只杀这 4 类(每类都要过上面 5 条铁律)
1. **规则自相矛盾** —— 两条核心规则不能同时成立(如:既要≥半又要≤半)
2. **开局必败 / 不可玩** —— 第一步就死、无合法解
3. **玩家无决策** —— 怎么操作结果都一样(纯随机 / 装饰按钮)
4. **描述自相矛盾** —— 候选规则和它自己声称的玩法 / 失败条件打架

> **"伪选择"不在杀因里,默认降为风险标注项。** 原因:判"一个选项是否占优"几乎都要靠遍历 / 模拟,违反铁律第 2、3 条。只有当占优能从规则文本**纯逻辑直接推出**(此时它已退化成"规则自相矛盾"或"玩家无决策")才杀;否则一律放行、标"疑似取舍质量风险"。这把最容易诱导 agent 越界的入口直接堵死。

> **预期管理(重要)**:这 4 类都是"规则文本层面铁定崩"的。净效果——筛子只扔掉逻辑铁定不成立的少数,大量候选带风险标注放行。**它是"只漏明显石头、沙子全过"的筛子,不是"砍掉一大半"。真正淘汰在你后面的真测。**

### 不漏(召回):多角度多 agent
多个独立 agent 各攻一个角度:规则互斥 / 开局必败 / 纯随机无决策 / 描述矛盾。任一拿出**过 5 条铁律的**反例 → 杀。**不放"找最优解 / 找占优"角度**(会拉回判取舍质量,误杀俄罗斯方块那条线)。

### 不冤 + 结构防越界(比 prompt 自律硬)
- "我觉得取舍弱 / 不好玩 / 深度不够"——一律不杀(不可靠的好坏判断)。
- 用反证式("尝试杀死它"),不用自证式(60 杀 1)。
- **权限物理隔离**:
  - **杀手 agent**:只能找过铁律的逻辑反例,找到→杀、找不到→放行。**没有"标风险"动作**——逼它要么拿逻辑反例、要么闭嘴放行。
  - **风险标注 agent**:只能写"最大不确定性 + 怎么测"。**没有"杀"权限**——再觉得不好玩也杀不掉。
  - 没有任何 agent 同时握"判好坏 + 生死权"。
- prompt 兜底强制语:**"你没有权限判断好坏;你只能杀纯逻辑硬伤,或标注风险后放行。"**

### 输出菜单(把活下来的变成可挑选对象,不是排名)
每个活下来的整理成一行:

| 字段 | 内容 |
|---|---|
| 候选名 | 8 字内 |
| 一句话玩法 | 10 秒能讲清 |
| 玩家反复动作 | 决策循环核心 |
| 核心取舍 | 选 A 放弃 B 是什么 |
| 用到的种子 / 算子 | 可溯源 |
| **为什么没被杀** | 过了哪几类逻辑筛(**不是**"为什么好") |
| **最大不确定性** | 最没把握的点——你测时重点盯 |
| 建议测试方式 | 给你自己测用 |

关键:话术是"**它没被逻辑筛杀,风险在 X,适合用 Y 测**",不是"我推荐它因为好玩"。"为什么没被杀"而非"为什么好"——这一字之差堵死 agent 滑回推荐。

> **筛选"最大化" = 5 条铁律锁死杀因 + 伪选择降级堵越界入口 + 权限隔离 + 输出可挑选菜单。边界:只扔"逻辑铁定崩的少数",剩下带风险标注交你,判好坏在真测。**

## 三、为什么这就是天花板

```
发散(机制一) → 多样、不偏、写清决策循环的候选池
   → 筛选(机制二) → 不漏不冤地扔掉 5 类逻辑硬伤
      → 整理成"可挑选的菜单"(溯源 / 为什么没被杀 / 最大不确定性 / 测试方式)  ← 机制到此停手
         → 你来挑选 / 真测 / 原型:用户负责
```

- 发散再强,只是"又多又不跑偏",**好不好玩它不知道**。
- 筛选再强,只能保证"剩下的逻辑都站得住",**不代表好玩**。
- "判好坏"= 用户 + 真测,机制永远不碰——这是它能力的天花板,不是没做到。
