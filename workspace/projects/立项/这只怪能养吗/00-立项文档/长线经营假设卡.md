# 长线经营假设卡

项目名：这只怪能养吗
目标市场：微信小游戏
主要变现方式：内购（待定）

---

## 1. 长线目标定义

- **长线成功的定义**：在微信小游戏抓宠肉鸽品类建立先发优势，形成稳定的付费留存结构
- **关键观察周期**：D1 / D7 / D30 留存，首周付费率
- **目标区间**：待小测后填写

---

## 2. 玩家体验三层

### 第一层：积累（玩家持有什么）

- **局内积累**：肉鸽临时技能组合（单局 Build，出地牢消失）
- **局外积累**：宠物队伍 + 宠物解锁的基础技能 + 肉鸽技能池大小
- **可支撑局数**：依赖宠物数量和技能池扩展速度，初步估计 20-30 局内不重复（待验证）

### 第二层：兑现（积累在哪里发挥价值）

- **上线动因**：想继续养宠物解锁更多技能 / 想再跑一次地牢验证新 Build
- **下线时惦记什么**：上次没抓到的稀有宠物 / 还没试过的技能组合
- **付费在放大什么**：抓宠数量（更多选择）/ 养成速度（更快解锁技能池）

### 第三层：刷新

- **无更新自然支撑时长**：待定，依赖宠物种类数量和地牢层数设计

---

## 3. 重复付费链

- **首付理由**：待定——变现方式未确定，需结合具体付费点设计
- **重复付费理由**：新宠物解锁欲望 + 想扩展技能池 + 想挑战更深地牢
- **高付费追求**：收集全部稀有宠物 / 解锁完整技能池
- **非付费玩家仍会留下的原因**：每次地牢 Build 不同的肉鸽重玩价值，免费体验完整

---

## 4. 内容与运营引擎

- **最小内容单元**：新宠物（1 只）/ 新地牢主题（1 个）/ 新肉鸽技能（2-3 个）
- **每周供给**：待定
- **每月供给**：待定
- **最高成本项**：宠物美术资产
- **供给风险**：宠物美术成本是主要瓶颈，需评估外包 vs 自研成本

---

## 5. 创意持续性

- **当前素材角度**：
  - 抓宠场景（遇到稀有宠物的惊喜感）
  - Build 爆发（技能组合打出高伤害）
  - 养成成长（宠物解锁新技能的满足感）
- **可反哺新素材的更新**：新宠物上线 / 新地牢主题 / 限时活动宠物
- **创意疲劳风险**：抓宠题材素材角度丰富，疲劳风险相对低
- **刷新方案**：限时活动宠物 / 联名题材 / 新地牢环境

---

## 6. 后续验证节点

- **原型阶段**：肉鸽 Build 爽感是否成立 / 抓宠随机事件频率是否合适 / 单局时长是否在 10 分钟内
- **小测阶段**：D1/D7 留存 / 首付率 / 核心买量素材 CTR
- **扩量阶段**：长线 LTV / D30 留存 / 付费深度
- **上线后**：内容供给效率 / 创意疲劳出现时间

---

## 7. 止损条件

- **条件1**：小测 D1 留存低于行业均值 20% → 核心玩法承接失败，退回玩法设计
- **条件2**：肉鸽 Build 爽感测试不成立（玩家感知不到局内变化）→ 退回数值体系设计
- **条件3**：即时战斗与抓宠随机事件的节奏冲突无法调和 → 评估回退回合制或重新设计抓宠方式
