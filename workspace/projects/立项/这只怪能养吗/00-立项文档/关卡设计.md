# 关卡设计 — 这只怪能养吗

> 最后更新：2026-05-26

---

## 一、设计目标

- 单局时长：早期地牢 <10 分钟
- 每局给玩家至少 1 次肉鸽选择节点（由配方中 🎁 自选节点数量决定）
- 支持线性、分叉、混合三种拓扑，由关卡设计配置

---

## 二、底层生成模型

### 2.1 三层结构

```
构成层（固定）→ 排列层（随机）→ 约束层（有限 / 纯）
```

| 层级 | 说明 |
|---|---|
| **构成层** | 每局配方固定：指定各房间类型的数量，生成房间池 |
| **排列层** | 房间池随机排列成序列 |
| **约束层** | 对排列结果做合法性检查，不合法则重排；约束层可关闭（纯随机模式） |

### 2.2 生成流程

```
1. 读取当前地牢配方 → 生成房间池
2. 随机打乱房间池 → 得到初始序列
3. 过约束检查：
   - 不合法 → 局部重排后重检
   - 合法 → 输出最终序列
4. 按最终序列构建地图节点
```

### 2.3 有限随机约束（默认开启，可按地牢配置关闭）

| 约束 | 规则 | 说明 |
|---|---|---|
| 连续上限 | 同类型最多连续 2 间 | 防止单调 |
| 早期保护 | 精英房不出现在前 40% 位置 | 给玩家积累购买的时间 |
| 事件分布 | 事件房必须分布在前后两段各 ≥ 1 间 | 事件房不全堆在同一半段 |
| Boss 锚定 | Boss 始终排在最后 | |
| 自选节点 | 至少 1 个自选节点出现在 Boss 前 2 间内 | Boss 前保证一次肉鸽选择；分叉地牢下对每条分叉子序列末尾独立检查，若后段长度 ≥ 2 则后段内满足亦可 |

## 三、地牢配方

配方定义每局房间池的构成，是关卡设计的核心数据。

### 3.1 早期地牢配方（示例）

| 房间类型 | 数量 | 说明 |
|---|---|---|
| ⚔️ 战斗房 | 6 | 主要战斗来源，出口触发购买 |
| 💀 精英房 | 1 | 强敌，出口掉落更强选项 |
| ❓ 随机事件 | 2 | 抓宠 / 特殊奖励 |
| 🎁 自选节点 | 1 | 免费选 1，不花货币 |
| 🏆 Boss | 1 | 固定最后 |
| **合计** | **11 间** | |

### 3.2 配方可调变量（进阶地牢）

| 变量 | 早期 | 中期 | 后期 |
|---|---|---|---|
| 总房间数 | 10–12 | 13–15 | 16–18 |
| 精英房数量 | 1 | 1–2 | 2 |
| 事件房数量 | 2 | 2–3 | 2–3 |
| 🎁 自选节点数量 | 1 | 待定 | 待定 |
| 约束层 | 开启 | 开启 | 可选关闭 |

## 四、拓扑结构

拓扑由关卡设计配置，生成系统支持以下三种：

### 4.1 线性

```
[A] → [B] → [C] → [D] → [Boss]
```
- 无路线选择，出口图标仅预告下一间类型
- 适合教学关卡、早期简单地牢

### 4.2 分叉

```
         ┌→ [B1] ─┐
[A] → 选─┤        ├→ [D] → [Boss]
         └→ [B2] ─┘
```
- 玩家在分叉点选择路线，不同路线房间类型不同
- 出口图标辅助选路
- 适合中后期地牢，增加重玩价值

#### 配方结构：段级独立子配方

```
完整分叉配方 = 前段子配方 + [分叉A子配方 | 分叉B子配方] + 后段子配方
```

- **前段**：分叉点之前的主干，独立子配方，按线性逻辑生成
- **分叉A / 分叉B**：各有独立子配方，独立定义房间类型和数量，互不共享房间池
- **后段**：分叉汇合后至 Boss，独立子配方
- **约束层**：对每个段独立运行，连续上限、早期保护等约束在各段内部生效

设计意图：两条路可有意做成不同方向（高难高回报 vs 探索抓宠），提供有意义的路线选择。

**早期分叉配方示例：**

| 段 | 房间类型 | 数量 | 路线定位 |
|---|---|---|---|
| 前段 | ⚔️ 战斗 | 2 | 共用 |
| 分叉A | ⚔️ 战斗 / 💀 精英 / 🎁 自选 | 2 / 1 / 1 | 高难高回报 |
| 分叉B | ⚔️ 战斗 / ❓ 随机事件 / 🎁 自选 | 1 / 2 / 1 | 探索抓宠 |
| 后段 | 🏆 Boss | 1 | 共用 |

### 4.3 混合

- 部分节点线性，部分节点分叉
- 分叉位置由关卡设计指定

## 五、奖励节点结构

每种房间类型在出口给予不同类型的奖励。奖励分三类，体验价值完全不同：

| 奖励类型 | 说明 | Build 驱动价值 |
|---|---|---|
| **肉鸽选择** | 免费 N 选 1，选临时放大器 | 核心——决定本局打多狠 |
| **货币购买** | 花费局内货币，购买池选项 | 辅助强化 |
| **直接奖励** | 按事件类型直接触发，无选择界面 | 随机收益 |

**房间类型 → 奖励类型映射：**

| 房间类型 | 奖励类型 | 内容 |
|---|---|---|
| ⚔️ 战斗房 | 货币购买 | 出口弹出购买窗口，3 选项，花费局内货币 |
| 💀 精英房 | 货币购买（强力） | 出口 4 选项，精英池，花费货币，选项质量更高 |
| ❓ 随机事件 | 直接奖励 | 按事件类型直接触发（抓宠 / 特殊奖励等），无选择界面 |
| 🎁 自选节点 | **肉鸽选择** | 免费 3 选 1，全池随机，选临时放大器，不花货币 |
| 🏆 Boss | 通关结算 | — |

**每局肉鸽选择次数：**

由配方中 🎁 自选节点的数量决定。早期配方 1 个自选节点 = 每局 1 次肉鸽选择。若体验测试发现 Build 感不足，优先增加配方中的自选节点数量，而不是将货币购买系统改造成肉鸽系统。

**货币购买频率参考（辅助强化，非 Build 指标）：**

- 6 个战斗房 × 3 选项 = 18 次展示
- 1 个精英房 × 4 选项 = 4 次展示
- 玩家实际购买 7–8 次，其余为主动跳过
