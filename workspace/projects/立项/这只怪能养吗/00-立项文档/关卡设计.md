# 关卡设计 — 这只怪能养吗

> 最后更新：2026-05-27

---

## 一、设计目标

**T1：Build 积累预期感**
> 玩家在地牢探索过程中应感受到 Build 一步步成型的预期感，因为奖励节点的节奏分布让玩家始终感知到"下一间还有机会强化"

**T2：节奏有规律而不单调**
> 玩家在地牢行进中应感受到地牢节奏有规律但不可完全预测，因为有限随机约束保证不出现连续同类房间堆积的单调序列

**T3：分叉路线的真实取舍**
> 玩家在分叉地牢的选路点应感受到取舍权衡而非随机碰运气，因为两条分叉路线各有明确的风险-回报定位，出口图标给足信息辅助决策

---

## 二、系统流程

```
配置关卡（策划，每关一次）
  ↓ 选配方 + 选路线结构 + 开约束
地牢生成（每局开始，自动）
  ↓ 约束组运行，生成合法房间序列
房间探索（循环：玩家逐房推进）
  ↺ 每间：进入 → 完成挑战 → 触发奖励 → 前进
  └─ 分叉点：选路（仅分叉地牢）→ 探索所选路线 → 汇合
  ↓ 玩家 Build 状态（货币 + 已选肉鸽）随探索积累
Boss 房（固定最后一间）
  ↓ 通关 / 失败
```

**各设计目标在流程中的位置：**

| 设计目标 | 主要生效阶段 |
|---|---|
| T1 Build 积累预期感 | 房间探索循环（奖励触发）+ 地牢生成（自选节点位置约束） |
| T2 节奏有规律不单调 | 地牢生成（约束组控制排列合法性） |
| T3 分叉路线真实取舍 | 分叉点选路 |

## 三、配置说明

策划通过以下三项配置组合出一个关卡。

---

### 3.1 配方

配方决定每局的房间类型和数量。

**可配置项：** 战斗 / 精英 / 事件 / 自选 / Boss 各类型的间数

**规则：**
- Boss 必须恰好 1 间；多或少均不允许保存
- 自选节点不允许为 0（为 0 时 T1 体验消失，保存时警告并标记风险）
- 总间数建议 10–18 间

**早期推荐配方：**

| 房间类型 | 间数 | 说明 |
|---|---|---|
| ⚔️ 战斗 | 6 | 主要挑战来源，完成后可购买 |
| 💀 精英 | 1 | 强敌，掉落更强选项 |
| ❓ 随机事件 | 2 | 抓宠 / 特殊奖励 |
| 🎁 自选节点 | 1 | 免费 3 选 1，不花货币 |
| 🏆 Boss | 1 | 固定最后 |
| **合计** | **11 间** | |

**进阶调参参考（非强制）：**

| 阶段 | 总间数 | 精英 | 事件 | 自选 | 约束层 |
|---|---|---|---|---|---|
| 早期 | 10–12 | 1 | 2 | 1 | 开启 |
| 中期 | 13–15 | 1–2 | 2–3 | 待定 | 开启 |
| 后期 | 16–18 | 2 | 2–3 | 待定 | 可选关闭 |

---

### 3.2 路线结构

路线结构决定地牢的形态，分三种：

**线性**
```
[A] → [B] → [C] → [D] → [Boss]
```
- 无路线选择，出口图标只预告下一间类型
- 适合教学关卡、早期简单地牢

**分叉**
```
         ┌→ [B1] ─┐
[A] → 选─┤         ├→ [D] → [Boss]
         └→ [B2] ─┘
```
- 玩家在分叉点选择路线，出口图标展示两条路各自的下一间类型
- 两条路线使用独立子配方，不共享房间池

**混合**
- 部分节点线性，部分节点分叉，分叉位置由关卡设计指定

**分叉/混合的子配方格式：**
```
前段配方:   战斗 N
分叉A配方:  战斗 N / 精英 N / 自选 N   ← 独立定义
分叉B配方:  战斗 N / 事件 N / 自选 N   ← 独立定义
后段配方:   Boss 1
```

---

### 3.3 约束规则

约束规则控制地牢生成时的排列合法性，防止出现单调序列。整体可关闭（纯随机模式），或对每关独立开关。

**各约束规则：**

| 约束 | 规则 | 关闭后的影响 |
|---|---|---|
| 连续上限 | 同类型房间最多连续 2 间 | 可能出现大量同类房间连排 |
| 早期保护 | 精英房不出现在前 40% 位置 | 精英房可能在开局出现 |
| 事件分布 | 事件房前后两段各至少 1 间 | 事件房可能全堆在同一半段 |
| Boss 锚定 | Boss 始终排在最后 | — |
| 自选节点位置 | 至少 1 个自选节点在 Boss 前 2 间内 | Boss 前可能没有免费选择机会 |

**默认：** 全部开启。分叉/混合路线下，每段子序列独立运行约束。

---

### 3.4 房间奖励映射（锁定，不开放配置）

每种房间类型固定对应一种奖励，此映射由设计锁定。如需调整 Build 密度，通过配方增减自选节点数量，不改映射关系。

| 房间类型 | 奖励 |
|---|---|
| ⚔️ 战斗 | 出口触发购买窗口，花费局内货币 |
| 💀 精英 | 出口触发购买窗口，精英池，质量更高 |
| ❓ 随机事件 | 直接触发，无选择界面 |
| 🎁 自选节点 | 免费 3 选 1，不花货币 |
| 🏆 Boss | 通关结算 |

## 四、规则

### 路线结构对约束的影响

| 路线结构 | 约束运行方式 |
|---|---|
| 线性 | 约束对整段序列全局运行 |
| 分叉 / 混合 | 约束对每段（前段/分叉A/分叉B/后段）独立运行 |
| 约束全关 | 进入纯随机模式，无合法性校验 |

分叉地牢下，自选节点位置约束对每条分叉子序列末尾独立检查；若后段长度 ≥ 2，后段内满足亦可。

---

### 约束冲突时的优先级

同一位置同时触发多条约束时，按以下顺序处理（序号越小越优先）：

1. Boss 锚定
2. 早期保护
3. 自选节点位置
4. 事件分布
5. 连续上限

---

### 异常处理

| 场景 | 处理方式 |
|---|---|
| Boss 数量不为 1 | 阻断保存，提示修正 |
| 自选节点合计为 0 | 允许保存，标记风险配置并警告 |
| 约束冲突导致无合法序列 | 按优先级顺序降低最低级约束重试，记录日志 |
| 分叉段长度为 0 | 阻断保存，提示修正 |

## 五、配置示例

### 示例 1 — 早期线性地牢

**目标：** T1 Build 积累预期感

**配置思路：** 线性地牢无路线选择压力，让玩家专注 Build 积累；约束全开确保自选节点在 Boss 前触发，精英房不在前期出现。

```
路线结构: 线性
目标时长: 8 分钟

配方:
  战斗: 6
  精英: 1
  事件: 2
  自选: 1
  Boss: 1   （共 11 间）

约束: 全部开启
```

**预期效果：** 每局约 7–8 次货币购买机会 + 1 次免费肉鸽选择；Boss 前自选节点是最后一次爆发确认。

---

### 示例 2 — 中期分叉地牢

**目标：** T3 分叉路线的真实取舍

**配置思路：** 分叉拓扑创造选路节点；A 路高难高回报，B 路探索型；两条路都保留自选节点，保证无论选哪条 T1 体验不消失。

```
路线结构: 分叉
目标时长: 10 分钟

前段配方:
  战斗: 2

分叉A配方:              ← 高难高回报
  战斗: 2
  精英: 1
  自选: 1

分叉B配方:              ← 探索抓宠
  战斗: 1
  事件: 2
  自选: 1

后段配方:
  Boss: 1

约束: 各段独立，全部开启
```

**预期效果：** Build 偏战斗放大的玩家选 A；当局想抓宠或补强宠物的玩家选 B；产生策略判断而非盲目猜测。
