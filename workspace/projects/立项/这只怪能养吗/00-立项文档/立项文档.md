## 核心玩法与爽点

### 玩法框架

```
进地牢（即时探索）
  → 遇到随机事件：发现野生宠物 → 捕捉
  → 遇到地牢怪物：即时战斗
  → 肉鸽节点：选临时技能（局内 Build 核心）
  → 通关奖励：养成材料 + 通关解锁

宠物养成（局外）
  → 消耗材料 → 解锁基础技能 + 扩展肉鸽技能池
  → 更大的技能池 → 进更深地牢
```

### 三层爽点

1. **肉鸽 Build 爆发**：临时技能倍率远高于基础，组合成型时高伤害爽感
2. **抓到新宠物**：地牢随机事件触发，稀有宠物强化收集欲
3. **养成突破**：宠物解锁新技能，技能池扩展，进入更难的地牢

### 单局时长目标

- 前期关卡：10 分钟以内
- 时间分配原则：战斗 + 肉鸽选择占主导，探索是连接剂

## 数值体系

来源：向僵尸开炮底层数值体系

| 层级 | 机制 |
|---|---|
| 基础数值 | 宠物基础属性，养成提供少量增长 |
| 技能倍率 | 核心输出来源，肉鸽临时技能倍率远高于基础技能 |
| 属性克制 | 属性对怪物的克制关系，命中克制大幅提升输出 |
| 公式 | 伤害 = 基础 × 技能倍率 × 克制系数 |

---

## 战斗系统

- **战斗类型**：即时制
- **抓宠方式**：地牢随机事件（独立于战斗流程）
  - 前期：无条件捕捉
  - 后期：循序渐进增加条件/成功率

---

## 养成体系

- **基础技能**：通过宠物养成解锁，跨局永久持有，战斗底盘
- **肉鸽技能池**：通过宠物成长扩展，决定每次地牢能抽到的选项范围
- **养成材料来源**：地牢掉落材料 + 通关奖励
