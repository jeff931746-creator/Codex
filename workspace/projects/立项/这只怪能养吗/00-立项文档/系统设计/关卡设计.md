# 关卡设计 — 这只怪能养吗

> 最后更新：2026-05-27

---

## 一、设计目标

**T1：Build 积累预期感**
> 玩家在地牢探索过程中应感受到 Build 一步步成型的预期感，因为奖励节点的节奏分布让玩家始终感知到"下一间还有机会强化"

**T2：节奏有规律而不单调**
> 玩家在地牢行进中应感受到地牢节奏有规律但不可完全预测，因为有限随机约束保证不出现连续同类房间堆积的单调序列

**T3：分叉路线的真实取舍**
> 玩家在分叉地牢的选路点应感受到取舍权衡而非随机碰运气，因为两条分叉路线各有明确的风险-回报定位，出口图标给足信息辅助决策

---

## 二、系统流程

```
[配置关卡]（策划操作，每关一次）
  进入：策划新建/编辑关卡
  操作：选房间配方 + 选路线结构 + 设规则开关
  退出：Boss=1 且 自选节点≥1 且 各段长度>0，校验通过后保存
  输出：合法关卡配置文件
  ↓
[地牢生成]（系统自动，每局一次）
  进入：玩家进入该关卡
  操作：生成规则运行，将配方排列成合法房间序列
  退出：所有已开启约束均满足，序列生成完毕
  输出：完整房间序列（含拓扑展开，每间房类型已确定）
  ↓
[房间探索]（循环）
  循环条件：当前房间不是 Boss 房
  每轮：进入房间 → 完成挑战 → 触发奖励 → 选择前进方向
  ↓
  ├─ [分叉选路]（条件触发）
  │    触发条件：当前节点是分叉点 且 路线结构为分叉或混合
  │    操作：展示两条路线各自的下一间类型 → 玩家选择一条
  │    退出：玩家完成所选分叉段的所有房间 → 汇合至后段
  │    分叉段内：仍按房间探索循环执行
  │
  ↓ 当前房间变为 Boss 房时，循环退出
[Boss 房]（单次）
  进入：玩家完成所有非 Boss 房间
  操作：Boss 战
  退出：Boss 战结束（通关或失败）
  输出：通关/失败结果
```

**各设计目标生效位置：**

| 设计目标 | 生效阶段 |
|---|---|
| T1 Build 积累预期感 | 房间探索循环（奖励触发密度）+ 地牢生成（自选节点位置约束） |
| T2 节奏有规律不单调 | 地牢生成（生成规则控制排列合法性） |
| T3 分叉路线真实取舍 | 分叉选路（路线定位差异 + 信息辅助决策） |

**删除测试：**

| 删除的阶段 | 体验影响 | 结论 |
|---|---|---|
| 配置关卡 | 无法控制房间类型构成，T1/T2 均无法实现 | 保留 |
| 地牢生成（生成规则） | 序列纯随机，T2 节奏保证消失，T1 关键节点无法保证 | 保留 |
| 房间探索（奖励映射） | 无奖励触发，T1 消失 | 保留 |
| 分叉选路 | 无路线选择，T3 消失 | 保留（仅分叉/混合拓扑需要） |
| Boss 房 | 无终点，关卡无法结束 | 保留 |

## 三、节点定义

### 3.1 配置关卡（策划操作，单次）

| 字段 | 内容 |
|---|---|
| **进入条件** | 策划新建或编辑关卡 |
| **可配置项** | 地牢配方 + 路线结构 + 生成规则 |
| **强制规则** | Boss 必须恰好 1 间；自选节点合计必须 ≥ 1 间；各段长度必须 > 0 |
| **推荐范围** | 总间数：默认 11 间，可配置 10–18 间 |
| **输出** | 合法关卡配置文件（房间配方 + 路线结构 + 各段子配方 + 规则开关） |
| **完成条件** | 校验全部通过（Boss=1，自选≥1，各段>0），保存成功 |

#### 房间配方

策划定义每局各类型房间的数量。

**可配置项：** 战斗 / 精英 / 事件 / 自选 / Boss 各类型的间数

**规则：**
- Boss 必须恰好 1 间，多或少均阻断保存
- 自选节点必须 ≥ 1 间，为 0 时阻断保存（T1 体验消失，不允许配置）
- 总间数建议 10–18 间（非强制，仅作参考）

**早期推荐配方：**

| 房间类型 | 间数 | 说明 |
|---|---|---|
| ⚔️ 战斗 | 6 | 主要挑战来源，完成后可购买 |
| 💀 精英 | 1 | 强敌，掉落更强选项 |
| ❓ 随机事件 | 2 | 抓宠 / 特殊奖励 |
| 🎁 自选节点 | 1 | 免费 3 选 1，不花货币 |
| 🏆 Boss | 1 | 固定最后 |
| **合计** | **11 间** | |

**进阶调参参考（非约束）：**

| 阶段 | 总间数 | 精英 | 事件 | 自选 | 生成规则 |
|---|---|---|---|---|---|
| 早期 | 10–12 | 1 | 2 | 1 | 开启 |
| 中期 | 13–15 | 1–2 | 2–3 | 待定 | 开启 |
| 后期 | 16–18 | 2 | 2–3 | 待定 | 可选关闭 |

#### 路线结构

策划决定地牢的形态，选择以下三种之一：

**线性：**
```
[A] → [B] → [C] → [D] → [Boss]
```
- 无路线选择，出口图标只预告下一间类型
- 适合教学关卡、早期简单地牢

**分叉：**
```
         ┌→ [B1] ─┐
[A] → 选─┤         ├→ [D] → [Boss]
         └→ [B2] ─┘
```
- 玩家在分叉点选择路线，出口图标展示两条路各自的下一间类型
- 两条路线使用独立子配方，禁止共享房间池

**混合：**
- 部分节点线性，部分节点分叉，分叉点数量和位置由关卡设计指定

**分叉/混合的配方格式（各段独立定义）：**
```
前段配方:   战斗 N
分叉A配方:  战斗 N / 精英 N / 自选 N
分叉B配方:  战斗 N / 事件 N / 自选 N
后段配方:   Boss 1
```

#### 生成规则

控制地牢生成时的排列合法性。整体可关闭（纯随机模式），或对每关独立开关。

**各约束规则：**

| 约束 | 规则 | 默认 |
|---|---|---|
| 连续上限 | 同类型房间最多连续 2 间 | 开启 |
| 早期保护 | 精英房不出现在前 40% 位置 | 开启 |
| 事件分布 | 事件房前后两段各至少 1 间 | 开启 |
| Boss 锚定 | Boss 始终排在最后 | 开启 |
| 自选节点位置 | 至少 1 个自选节点在 Boss 前 2 间内 | 开启 |

### 3.2 地牢生成（系统自动，每局一次）

| 字段 | 内容 |
|---|---|
| **进入条件** | 玩家进入该关卡 |
| **可配置项** | 生成规则（执行排列，将配方转化为房间序列） |
| **强制规则** | 生成结果必须满足所有已开启的约束 |
| **推荐范围** | 生成规则默认全部开启 |
| **输出** | 完整房间序列（每间房类型已确定，拓扑已展开） |
| **完成条件** | 所有开启的约束均满足，序列生成完毕 |

**约束的分段适用规则：**

分叉/混合路线下，约束对每段（前段/分叉A/分叉B/后段）独立运行。各约束的分段适用条件如下：

| 约束 | 适用条件 | 不满足适用条件时 |
|---|---|---|
| 连续上限 | 段长度 ≥ 3 | 段长度 ≤ 2 时自然满足，跳过检查 |
| 早期保护 | 段内有精英房 且 段长度 ≥ 3 | 精英房 = 0 或段长度 < 3 时跳过 |
| 事件分布 | 段内事件房 ≥ 2 间 | 事件房 ≤ 1 时跳过（无法"前后各 1"） |
| Boss 锚定 | 仅含 Boss 的段 | 无 Boss 的分叉段不检查 |
| 自选节点位置 | 仅含 Boss 的段，或后段 | 纯分叉段（无 Boss）不检查 Boss 前 2 间；若后段长度 ≥ 2，在后段内满足即可 |

---

### 3.3 房间探索（循环）

| 字段 | 内容 |
|---|---|
| **进入条件** | 玩家完成当前房间，准备前进 |
| **循环条件** | 当前房间不是 Boss 房 |
| **可配置项** | 奖励节点映射（锁定，不开放配置） |
| **强制规则** | 自选节点只能提供免费肉鸽选择，禁止改为货币购买；映射关系锁定 |
| **推荐范围** | 早期 11 间配方：约 18 次购买机会展示，玩家实际购买约 7–8 次 |
| **输出** | 玩家 Build 状态（当前货币量 + 已选肉鸽选项列表） |
| **完成条件** | 当前房间变为 Boss 房，循环结束 |

**奖励节点映射（锁定）：**

| 房间类型 | 奖励类型 | 触发时机 |
|---|---|---|
| ⚔️ 战斗 | 货币购买机会 | 完成挑战后，退出房间前 |
| 💀 精英 | 高质量货币购买机会 | 完成挑战后，退出房间前 |
| ❓ 随机事件 | 直接奖励（无选择界面） | 进入房间时直接触发 |
| 🎁 自选节点 | 免费 3 选 1，不花货币 | 完成挑战后，退出房间前 |
| 🏆 Boss | 通关结算 | Boss 战结束后 |

**购买/奖励边界规则：**

| 场景 | 处理方式 |
|---|---|
| 玩家关闭购买窗口不购买 | 货币不变，选项消失，可正常前进 |
| 玩家货币不足以购买某选项 | 该选项灰化不可购买，其余选项正常；玩家可选择跳过 |
| 奖励生成失败（服务端异常） | 重试 1 次；重试后仍失败 → 跳过本次奖励，记录日志，不阻断流程 |
| 玩家在购买界面时离线 | 重连后恢复到购买界面；购买界面关闭前不允许前进 |
| 玩家在挑战中途离线 | 重连后从当前房间挑战起点重新开始；已获得的奖励保留 |

---

### 3.4 分叉选路（条件触发）

| 字段 | 内容 |
|---|---|
| **进入条件** | 当前节点是分叉点 且 路线结构为分叉或混合 |
| **可配置项** | 路线结构（分叉A子配方 / 分叉B子配方） |
| **强制规则** | 两条路线使用独立子配方，禁止共享房间池；生成规则对每条路线独立运行 |
| **推荐范围** | 建议两条路线有明确风险-回报差异（如：高难高回报 vs 探索抓宠） |
| **输出** | 玩家选定路线及该段完整房间序列 |
| **完成条件** | 玩家完成所选分叉段所有房间，汇合至后段 |

---

### 3.5 Boss 房（单次）

| 字段 | 内容 |
|---|---|
| **进入条件** | 玩家完成所有非 Boss 房间（含分叉段） |
| **可配置项** | 无（不开放策划配置） |
| **强制规则** | Boss 必须是该关卡最后一间；每关有且仅有 1 个 Boss |
| **推荐范围** | — |
| **输出** | 通关/失败结果 |
| **完成条件** | Boss 战结束 |

## 四、规则

### 路线结构与生成规则的关系

| 路线结构 | 规则运行方式 |
|---|---|
| 线性 | 各项规则对整段序列全局运行 |
| 分叉 / 混合 | 各项规则对每段独立运行；适用条件见 3.2 |
| 生成规则全关 | 进入纯随机模式，无合法性校验 |

### 规则冲突时的优先级

多条约束同时影响同一房间位置时，按以下顺序处理（序号越小越优先）：

1. Boss 锚定
2. 早期保护
3. 自选节点位置
4. 事件分布
5. 连续上限

### 异常处理

| 场景 | 处理方式 |
|---|---|
| Boss 数量 ≠ 1 | 阻断保存，提示修正 |
| 自选节点合计 = 0 | 阻断保存，提示修正（T1 体验消失，不允许此配置） |
| 任意段长度 = 0 | 阻断保存，提示修正 |
| 规则冲突导致无合法序列 | 按优先级顺序降低最低级规则重试，最多重试 3 次；3 次后生成失败，提示策划检查配方，记录日志 |

## 五、配置示例

### 示例 1 — 早期线性地牢（T1 为主）

**目标：** T1 Build 积累预期感

**决策理由：** 线性地牢无路线选择压力，让玩家专注 Build 积累；约束全开确保自选节点在 Boss 前触发，精英房不在前期出现。

```
路线结构: 线性

配方:
  战斗: 6      ← 6 次购买机会，每次 3 选项，共 18 次展示
  精英: 1      ← 1 次高质量购买机会，4 选项
  事件: 2
  自选: 1      ← 1 次免费肉鸽选择，3 选 1
  Boss: 1

生成规则: 全部开启
```

**预期效果：** 约 18 次购买展示，玩家实际选购约 7–8 次；Boss 前 2 间内有自选节点，是最后一次爆发确认。

---

### 示例 2 — 中期分叉地牢（T3 为主）

**目标：** T3 分叉路线的真实取舍

**决策理由：** 分叉拓扑创造选路节点；A 路高难高回报，B 路探索型；两条路都保留自选节点，保证无论选哪条 T1 体验不消失。

```
路线结构: 分叉

前段配方:
  战斗: 2

分叉A配方:              ← 高难高回报
  战斗: 2
  精英: 1
  自选: 1

分叉B配方:              ← 探索抓宠
  战斗: 1
  事件: 2
  自选: 1

后段配方:
  Boss: 1

生成规则: 各段独立，全部开启
```

**预期效果：** Build 偏战斗放大的玩家选 A；当局想抓宠或补强宠物的玩家选 B；产生策略判断而非盲目猜测。
