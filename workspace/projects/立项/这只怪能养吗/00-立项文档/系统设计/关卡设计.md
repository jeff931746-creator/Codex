# 关卡设计 — 这只怪能养吗

> 最后更新：2026-05-27

---

## 一、核心目标

- **T1：Build 积累预期感** — 玩家应始终感知到"下一间还有机会强化"，因为奖励节点的节奏分布保证了这一点
- **T2：节奏有规律不单调** — 地牢节奏有规律但不完全可预测，因为生成规则控制排列避免同类房间堆积
- **T3：分叉路线的真实取舍** — 分叉选路点让玩家真正权衡，因为两条路线各有明确的风险-回报定位

---

## 二、关卡流程

```
[策划配置关卡]（单次，每关一次）
  ↓ 传递：房间配方 × 路线结构（线性/分叉/混合）× 生成规则开关
[地牢自动生成]（单次，玩家进入时触发）
  ↓ 传递：已排列房间序列（含分叉拓扑和选路节点位置）
[房间探索]（循环：直到进入 Boss 前室）
  ↺ 每间循环：进入房间 → 完成挑战/触发事件 → 领取奖励 → 出口选择
      · 线性地牢：单出口，直接前进
      · 分叉/混合：选路节点展示两路类型，玩家选 1 继续
  ↓ 传递：玩家当前 Build（已选放大器列表 × 货币余额）
[Boss 战]（单次）
  ↓ 传递：通关状态
[通关结算]（单次）
```

| 目标 | 主要生效阶段 |
|---|---|
| T1 Build 积累 | 房间探索（奖励节点触发）+ 地牢生成（自选节点位置保证） |
| T2 节奏规律 | 地牢生成（生成规则控制排列） |
| T3 路线取舍 | 分叉选路（双路线定位差异 + 信息可见） |

## 三、配置关卡

*策划新建或编辑关卡时完成，每关一次。校验通过后保存生效。*

### 房间配方

定义每局各类型房间的数量。

| 房间类型 | 推荐（早期） | 强制规则 |
|---|---|---|
| ⚔️ 战斗 | 6 | — |
| 💀 精英 | 1 | — |
| ❓ 随机事件 | 2 | — |
| 🎁 自选节点 | 1 | **≥ 1，为 0 时阻断保存**（T1 依赖此项） |
| 🏆 Boss | 1 | **必须恰好 1，多或少均阻断保存** |
| 合计 | 11 | 建议 10–18（非强制） |

**进阶调参参考（非强制）：**

| 阶段 | 总间数 | 精英 | 事件 | 自选 | 生成规则 |
|---|---|---|---|---|---|
| 早期 | 10–12 | 1 | 2 | 1 | 开启 |
| 中期 | 13–15 | 1–2 | 2–3 | 待定 | 开启 |
| 后期 | 16–18 | 2 | 2–3 | 待定 | 可选关闭 |

### 路线结构

选择地牢形态，决定玩家的行进路径：

**线性**
```
[A] → [B] → [C] → [D] → [Boss]
```
无选路节点，出口图标只预告下一间类型。适合教学关卡和早期简单地牢。

**分叉**
```
         ┌→ [B1] ─┐
[A] → 选─┤         ├→ [D] → [Boss]
         └→ [B2] ─┘
```
玩家在分叉点选择路线，出口图标展示两条路各自的下一间类型。两条路使用独立子配方，不共享房间池。

**混合**
部分节点线性，部分节点分叉，分叉点数量和位置由关卡设计指定。

**分叉/混合的配方格式（各段独立定义）：**
```
前段配方:   战斗 N
分叉A配方:  战斗 N / 精英 N / 自选 N
分叉B配方:  战斗 N / 事件 N / 自选 N
后段配方:   Boss 1
```

### 生成规则

控制地牢生成时的排列合法性。**开关在此处配置；规则在玩家进入地牢、地牢自动生成阶段执行。** 可整体关闭（纯随机模式），或对每关独立开关。

| 规则 | 效果 | 默认 |
|---|---|---|
| 连续上限 | 同类型房间最多连续 2 间 | 开启 |
| 早期保护 | 精英房不出现在前 40% 位置 | 开启 |
| 事件分布 | 事件房前后各至少 1 间 | 开启 |
| Boss 锚定 | Boss 始终排最后 | 开启 |
| 自选位置 | 至少 1 个自选节点在 Boss 前 2 间内 | 开启 |

> **系统自动执行**：
> - 校验通过（Boss = 1 且自选 ≥ 1 且无段长 = 0）→ 关卡配置保存生效
> - 传递给地牢自动生成：房间配方 × 路线结构 × 生成规则开关

## 四、房间奖励

*映射关系由系统固定，不开放策划配置。*

| 房间类型 | 完成后触发 | 时机 |
|---|---|---|
| ⚔️ 战斗 | 货币购买机会（3 选项） | 完成挑战后，退出房间前 |
| 💀 精英 | 高质量货币购买机会（4 选项） | 完成挑战后，退出房间前 |
| ❓ 随机事件 | 直接奖励（无选择界面） | 进入房间时直接触发 |
| 🎁 自选节点 | 免费 3 选 1，不花货币 | 完成挑战后，退出房间前 |
| 🏆 Boss | 通关结算 | Boss 战结束后 |

> **系统自动执行**：
> - 玩家关闭奖励界面 / 跳过购买 → 解锁出口，可前进至下一间
> - 传递给下一间：玩家当前 Build（已选放大器 + 货币余额）

## 五、规则

### 配置校验（保存时执行）

- Boss ≠ 1 → 阻断保存，提示修正
- 自选节点合计 = 0 → 阻断保存，提示修正（T1 体验消失，不允许此配置）
- 任意段长度 = 0 → 阻断保存，提示修正

### 规则冲突优先级

多条规则影响同一房间位置时，按以下顺序处理（序号越小越优先）：

1. Boss 锚定
2. 早期保护
3. 自选位置
4. 事件分布
5. 连续上限

规则冲突无法解决时：按优先级顺序临时降低最低级规则，最多重试 3 次。3 次仍失败 → 提示策划检查配方，记录日志。

### 生成规则分段适用条件（分叉/混合地牢）

各段独立运行生成规则；以下条件决定每条规则在某一段是否参与检查：

| 规则 | 适用条件 | 不满足时 |
|---|---|---|
| 连续上限 | 段长度 ≥ 3 | 段长度 ≤ 2 时自然满足，跳过 |
| 早期保护 | 段内有精英房 且 段长度 ≥ 3 | 精英 = 0 或段长 < 3 时跳过 |
| 事件分布 | 段内事件房 ≥ 2 间 | 事件 ≤ 1 时跳过（无法"前后各 1"） |
| Boss 锚定 | 仅含 Boss 的段 | 纯分叉段不检查 |
| 自选位置 | 含 Boss 的段或后段 | 纯分叉段不检查；后段长 ≥ 2 时在后段内满足即可 |

### 异常处理

| 场景 | 处理方式 |
|---|---|
| 玩家关闭购买窗口不购买 | 货币不变，选项消失，可正常前进 |
| 玩家货币不足 | 该选项灰化不可购买，其余选项正常；玩家可跳过 |
| 奖励生成失败（服务端异常） | 重试 1 次；仍失败则跳过本次奖励，记录日志，不阻断流程 |
| 玩家在购买界面时离线 | 重连后恢复购买界面；购买完成前不允许前进 |
| 玩家在挑战中途离线 | 重连后从当前房间起点重新开始；已获得的奖励保留 |
| Boss 通关结算时离线 | 重连后恢复结算界面；结算奖励发放完成前局不计结束 |
| Boss 通关结算发奖失败（服务端异常） | 重试 1 次；仍失败则标记本局待补发，下次登录时优先发放；不阻断局结束流程，记录日志 |

## 六、配置示例

### 示例一：早期线性地牢（专注 T1）

**体验目标**：玩家在地牢探索中应始终感知到"下一间还有机会强化"，因为奖励节点的节奏分布保证了这一点（T1）

**决策理由**：选线性而非分叉——T1 只需要奖励节奏稳定，分叉结构会把玩家注意力分散到选路压力上，稀释 Build 积累的专注感。全部规则开启——早期玩家依赖生成规则保证体验稳定：自选位置规则确保 Boss 前有最后一次强化机会；早期保护规则避免玩家在尚未适应前遭遇精英房。

**流程配置**：
- 路线结构：线性
- 房间配方：战斗 6 / 精英 1 / 事件 2 / 自选 1 / Boss 1（合计 11 间）
- 生成规则：全部开启
- 房间探索循环：直到进入 Boss 前室（11 间非 Boss 房间完成后退出循环）

**预期效果**：约 18 次购买展示，玩家选购约 7–8 次；Boss 前 2 间内有自选节点，是最后一次爆发确认；全程无选路压力，专注在 Build 积累上。

---

### 示例二：中期分叉地牢（专注 T3）

**体验目标**：分叉选路点让玩家真正权衡，因为两条路线各有明确的风险-回报定位（T3）

**决策理由**：选分叉而非线性——T3 体验的核心是选路取舍，线性无法产生这个决策。A 路高难高回报（精英房 + 自选节点），B 路低风险探索型（事件房 + 自选节点），两路差异定位明确，才能让玩家基于自身状态做真实权衡而非随机选择。两条路都保留自选节点，是因为 T1 体验不能因选路而消失——如果只有 A 路有自选节点，选了 B 路的玩家会丧失 Build 积累感。

**流程配置**：
- 路线结构：分叉
- 段配方：
  - 前段：战斗 2（共享热身段）
  - 分叉 A：战斗 2 / 精英 1 / 自选 1（高难高回报）
  - 分叉 B：战斗 1 / 事件 2 / 自选 1（探索抓宠）
  - 后段：Boss 1（固定终点）
- 生成规则：各段独立，全部开启
- 房间探索循环：直到进入 Boss 前室（前段 2 间 + 所选分叉段 4 间完成后退出循环）

**预期效果**：Build 偏战斗放大的玩家选 A；当局想抓宠或补强宠物的玩家选 B；产生策略判断而非盲目猜测；T1 体验在两条路线上均得到保证。
