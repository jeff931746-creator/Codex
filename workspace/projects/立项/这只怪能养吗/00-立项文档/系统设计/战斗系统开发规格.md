# 战斗系统开发规格 — 这只怪能养吗

> 面向开发的技术规格文档。配置表字段定义、枚举值、表关联关系、数值公式均以本文档为准。
> 底层架构参考向僵尸开炮配置表体系，改动点见第十节。
> 最后更新：2026-05-26

---

## 一、系统架构总览

### 1.1 表关联图

```
TrPet（宠物定义）
  ├─ SkillID[]       → TrSkill（技能定义）
  └─ GrowthID        → TrPetGrowth（养成配置）

TrHeroSkill（主角技能定义）
  └─ SkillID         → TrSkill

TrSkill（技能定义）
  └─ EffectID        → TrSkillEffect（技能模组）
                          └─ BuffList → TrBuff（Buff定义）
                                          ├─ AttrEffectID         → TrBuffAttrEffect
                                          ├─ PeriodEffectID       → TrBuffPeriodEffect
                                          ├─ RealTimeEffectID     → TrBuffRealTimeCalEffect
                                          │                            └─ ConditionID → TrBuffCondition
                                          ├─ StackChangeEffectID  → TrBuffStackChangeAttrEffect
                                          └─ ConvertEffectID      → TrBuffConvertEffect
                                                                       └─ ConditionID → TrBuffCondition

TrRoguelikeUpgrade（肉鸽放大器）
  ├─ TargetSkillID   → TrSkill（空 = 全体）
  └─ 增强效果通用参数（无专属枚举）

TrComboSkill（合击配置）
  ├─ RequiredPetIDs  → TrPet
  └─ SkillID         → TrSkill

TrSkillPool（放大器随机池）
  └─ UpgradeID       → TrRoguelikeUpgrade
```

### 1.2 分表原则

| 表 | 职责 | 不包含 |
|---|---|---|
| TrRoguelikeUpgrade | 局内肉鸽放大器 | 养成数据、皮肤数据 |
| TrPetGrowth | 局外宠物养成 | 肉鸽随机池数据 |
| TrComboSkill | 合击配置 | 独立表，不挂在技能表上 |

| Value | int | 值 |
| ConditionID | int | 激活条件ID → TrBuffCondition（空=无条件常驻） |
| MinValue | int | 属性值下限（含），空=不限 |
| MaxValue | int | 属性值上限（不含），空=不限 |

### 5.4 TrBuffCondition — 条件表

| 字段名 | 类型 | 说明 |
|---|---|---|
| ConditionID | int | 条件唯一ID |
| LogicType | enum | `None`=单条件 / `And`=条件且 / `Or`=条件或 |
| Conditions#N.Type | enum | 条件类型，见下 |
| Conditions#N.Value | int | 条件值 |
| Conditions#N.ComparisonType | enum | `Eq`=等于 / `Gt`=大于 / `Gte`=大于等于 / `Lt`=小于 / `Lte`=小于等于 |

**条件类型枚举（ConditionType）：**

| 值 | 说明 | Value含义 |
|---|---|---|
| `EntityType` | 目标实体类型 | 对应TargetType枚举值 |
| `IsFlying` | 是否飞行怪 | 1=是 |
| `CurrentHPPercent` | 当前血量百分比 | 万分比，如5000=50% |
| `Probability` | 概率 | 万分比，如3000=30% |
| `AttrValue` | 指定属性值 | 配合AttrType使用 |
| `PetInTeam` | 队伍中包含指定宠物 ⭐新增 | PetID |
| `ComboReady` | 合击就绪状态 ⭐新增 | ComboSkillID |

支持最多 **5个条件** 的 AND/OR 组合。

### 5.5 AttrType 属性类型枚举

`AttrValue` 的精度取决于 AttrType：**万分比**类用整数万分比（10000=100%）；**布尔**类固定填 `1`；**绝对值**类直接填实际数值。

| 值 | 说明 | AttrValue 精度 |
|---|---|---|
| `AtkIncrPercent` | 增加攻击比例 | 万分比 |
| `AtkDecrPercent` | 减少攻击比例 | 万分比 |
| `DmgIncrPercent` | 增加造成伤害比例 | 万分比 |
| `DmgDecrPercent` | 减少造成伤害比例 | 万分比 |
| `TakeDmgDecrPercent` | 减少受到伤害比例 | 万分比 |
| `SpeedIncrPercent` | 增加移动速度比例 | 万分比 |
| `SpeedDecrPercent` | 减少移动速度比例 | 万分比 |
| `CDDecrPercent` | 减少技能CD比例 | 万分比 |
| `CritRateIncr` | 增加暴击率 | 万分比 |
| `CritDmgIncr` | 增加暴击伤害 | 万分比 |
| `ElementResist` | 属性抗性 | 万分比 |
| `Freeze` | 冻结状态（无法移动，可叠加时间） | 布尔（填1） |
| `Stun` | 眩晕状态（无法行动） | 布尔（填1） |
| `Slow` | 减速幅度（与SpeedDecrPercent叠加计算） | 万分比 |
| `Untargetable` | 不可被选中 | 布尔（填1） |
| `Invincible` | 无敌 | 布尔（填1） |

### 5.6 TrBuffStackChangeAttrEffect — 叠层属性效果

> 属性加成随 Buff 叠层数线性增长，适用于"每层 +X% 攻击力"类效果。

| 字段名 | 类型 | 说明 |
|---|---|---|
| BuffEffectID | int | 效果唯一ID |
| AttrType | enum | 属性类型，见 §5.5 |
| ValuePerStack | int | 每层属性增量（万分比） |
| BaseValue | int | 叠0层时的基础值（万分比），通常填0 |

实际生效属性 = `BaseValue + ValuePerStack × CurrentStackCount`，叠层上限由 `TrBuff.MaxStackCount` 控制。

### 5.7 TrBuffConvertEffect — Buff 转换效果

> 当指定条件满足时，将当前 Buff 转换为另一个 Buff，适用于"满层后升级"类机制。

| 字段名 | 类型 | 说明 |
|---|---|---|
| BuffEffectID | int | 效果唯一ID |
| ConditionID | int | 触发转换的条件ID → TrBuffCondition（填0=附加时立即转换） |
| TargetBuffID | int | 转换目标 BuffID → TrBuff |
| RemoveOriginal | bool | 转换后是否移除原 Buff（`true`=移除，`false`=两者同时存在） |
| TransferStack | bool | 是否将原 Buff 的叠层数传递给目标 Buff |

## 八、肉鸽放大器与合击配置表

### 6.1 TrRoguelikeUpgrade — 肉鸽放大器池

> 只包含局内随机选牌逻辑，不含养成数据、皮肤数据。

| 字段名 | 类型 | 说明 |
|---|---|---|
| ID | int | 放大器唯一ID |
| TargetSkillID | int | 作用技能ID → TrSkill（0=作用于全体输出单元） |
| TargetType | enum | 作用对象：`Skill`=指定技能 / `PetType`=宠物类型 / `Hero`=主角技能 / `Combo`=合击 / `All`=全体 |
| Rarity | enum | `Common`=普通 / `Rare`=稀有 / `Epic`=史诗 |
| IconRes | string | 图标资源ID |
| NameID | int | 名称文本ID |
| DescID | int | 描述文本ID |
| Upgrades#N.Type | enum | 增强效果类型，见 §6.2 |
| Upgrades#N.TargetID | int | 目标ID（技能ID / BuffID，依Type而定） |
| Upgrades#N.Field | string | 修改字段名（如 `DamageRate` / `CD` / `Duration`） |
| Upgrades#N.Op | enum | 操作：`Add`=增加 / `Sub`=减少 / `Mul`=乘以 / `Set`=替换 |
| Upgrades#N.Value | int | 值（万分比） |

每个放大器最多配 **4个增强效果**。

### 6.2 增强效果类型枚举（通用，无专属枚举）

**设计原则：策划通过 TargetID + Field + Op + Value 的组合描述任何数值修改，不允许为单个技能开专属枚举类型。**

`Modify*Param` 系列的 Field 填目标表的**数值型字段名**，不支持枚举型字段（如 TargetPriority / CDType）。

| Type值 | TargetID 含义 | Field 含义 | Op | Value 含义 |
|---|---|---|---|---|
| `ModifySkillParam` | 技能ID → TrSkill | TrSkill 数值型字段名（如 `CD` / `SkillRadius`） | Add/Sub/Mul/Set | 万分比（Mul）或毫秒/像素（Add/Sub/Set，依字段单位） |
| `ModifyEffectParam` | EffectID → TrSkillEffect | TrSkillEffect 数值型字段名（如 `DamageRate` / `SkillDuration`） | Add/Sub/Mul/Set | 同上，依字段单位 |
| `ModifyBuffParam` | BuffID → TrBuff | TrBuff 数值型字段名（如 `CDTime`）或效果子表字段名 | Add/Sub/Mul/Set | 同上，依字段单位 |
| `OnHitApplyBuff` | BuffID → TrBuff | —（留空） | —（留空） | 触发概率（万分比） |
| `UnlockSkill` | 技能ID → TrSkill | —（留空） | —（留空） | —（留空，无需Value） |
| `ModifyGlobalAttr` | —（填0） | AttrType 枚举值（如 `DmgIncrPercent`）⚠️此处 Field 填枚举值，非字段名 | Add/Sub | 万分比 |

> ⚠️ `ModifyGlobalAttr` 的 Field 语义与其他 Type 不同：其他 Type 的 Field 是目标表的字段名字符串，`ModifyGlobalAttr` 的 Field 是 AttrType 枚举值。开发侧需对 Type=ModifyGlobalAttr 单独分支处理。

示例：

```
原"暴风雪持续时间增加"专属枚举 → 改为：
Type     = ModifySkillParam
TargetID = 9000400（暴风雪技能ID）
Field    = SkillDuration
Op       = Add
Value    = 2000

原"命中添加冻结Buff" → 改为：
Type     = OnHitApplyBuff
TargetID = 900401（冻结BuffID）
Value    = 3000（30%概率）
```

| SkillID | int | 触发的合击技能ID → TrSkill |
| IconRes | string | 合击按钮图标资源 |
| NameID | int | 合击名称文本ID |
| DescID | int | 合击描述文本ID |

## 九、数值规范

### 7.1 万分比系统

全系统数值统一使用万分比（整数），避免浮点精度问题：

```
10000 = 100%
5000  = 50%
1000  = 10%
300   = 3%
```

### 7.2 伤害公式

```
伤害 = 基础攻击力 × (DamageRate / 10000) × 克制系数
```

| 变量 | 来源 |
|---|---|
| 基础攻击力（宠物） | TrPet.BaseAtk + 养成加成（TrPetGrowth，Demo阶段写死到TrPet） |
| 基础攻击力（主角） | 主角固定属性，Demo阶段写死为常量，正式开发由独立的 TrHero 表管理 |
| DamageRate | TrSkillEffect.DamageRate（万分比） |
| 克制系数 | TrBuffRealTimeCalEffect 实时计算（属性克制命中时激活增益） |

**克制系数的实现方式**：不在伤害公式里硬编码分支，而是通过 TrBuffRealTimeCalEffect + TrBuffCondition 实现：

```
ConditionID → 条件：攻击属性 = 目标弱点属性
AttrType    = DmgIncrPercent
Value       = 5000（克制时 +50% 伤害）
```

### 7.3 每秒最大伤害次数

```
常量 BuffMaxDamageTimesPerSecond = 500
```

单个目标每秒受到伤害次数上限，防止多个持续AOE叠加导致帧率问题。

### 7.4 放大器数值参考梯度

参考向僵尸开炮天赋卡梯度，5档设计：

| 档位 | 增益值（万分比） | 说明 |
|---|---|---|
| Lv1 | 10000 | +100% |
| Lv2 | 14000 | +140% |
| Lv3 | 18000 | +180% |
| Lv4 | 22000 | +220% |
| Lv5 | 26000 | +260% |

每档递增 4000（+40%），最高档是最低档的 2.6 倍。

## 十、与向僵尸开炮的改动对照

| 改动项 | 原设计 | 本项目设计 | 原因 |
|---|---|---|---|
| 技能增强专属枚举 | 每个技能特色效果开专属枚举（写死） | 通用 `ModifySkillParam / ModifyEffectParam` + 字段名 | 策划可自助配置，不依赖程序开发新类型 |
| 增强表分职责 | 肉鸽选牌+养成+皮肤混用同一张表 | 分三张表：TrRoguelikeUpgrade / TrPetGrowth / 变现表 | 各系统独立迭代，避免表膨胀 |
| 攻击方向 | 固定朝向路线方向 | 新增 AttackDirectionType（朝目标/朝移动方向/全向） | 即时地牢宠物跟随移动，需要方向判断 |
| 跟随位置 | 无（塔防固定位置） | 新增 FollowDistance + PositionOffset | 宠物需要在主角周围特定位置输出 |
| 合击系统 | 无 | 新增 TrComboSkill + 时间CD机制 | 本项目核心体验之一 |
| 条件判断 | 实体类型/血量/概率等 | 新增 `PetInTeam` / `ComboReady` 条件类型 | 支持合击就绪判断 |
