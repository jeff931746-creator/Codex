# 战斗系统设计 — 这只怪能养吗

> 立项阶段系统规格文档，记录战斗和技能体系的底层规则定义。
> 最后更新：2026-05-26

---

## 一、系统定位

战斗系统的核心体验目标：

- **轻操作**：默认全自动战斗（移动 / 普攻 / 宠物技能 / 主角技能 / 合击都能自动跑），玩家进关可以只看不操作
- **持续爽感**：宠物自动输出，战场时刻有动静，伤害反馈密集
- **手动可选的额外收益**：愿意操作的玩家可手动走位、手动卡技能 / 合击时机，打得更快更爽——但只提升效率和手感，不决定能否通关
- **Build 对齐奖励**：局外选配的队伍组合 × 局内放大器方向对齐时，输出远高于随机堆砌

> **胜负判定原则**：能不能通关，只由宠物养成强度 + 本局 Build 决定，全自动即可达到通关基准线。手动操作只是让你打得更快、减员更少，不构成通关门槛——这与下文「属性克制是额外奖励、不是必须达到的门槛」是同一原则。

参考基准：宠物等同于向僵尸开炮的技能单元——独立攻击单元，各有攻击模式，叠加构成总输出。

---

## 二、战斗输出单元

战斗内的输出来源分三类，共用同一套数值公式：

```
总输出 = 主角技能输出 + 所有宠物输出 + 合击输出（触发时）
```

### 2.1 主角技能

| 属性 | 规则 |
|---|---|
| 选配方式 | 局外从已解锁的主角技能池中选 1-2 个带入地牢 |
| 解锁方式 | 宠物养成解锁（指定宠物养成至指定等级，解锁对应主角技能） |
| 释放方式 | 默认 CD 满自动释放；玩家可手动点提前放，卡聚怪时机 |
| 瞄准方式 | 自动瞄准最近 / 最密集敌人，降低操作门槛 |
| 技能定位 | 爆发型，与宠物的持续输出形成互补；手动卡时机能多吃几个敌人，不卡也照样清 |
| 槽位数量 | Demo：1 个；中期养成解锁第 2 个；后期可扩展到 3 个 |

**技能类型参考（设计方向，非最终列表）：**

| 类型 | 描述 | 手动价值 |
|---|---|---|
| 范围 AOE 爆发 | 大范围高伤，有短暂蓄力动画 | 等敌人聚集再放，收益翻倍 |
| 单体高爆发 | 精准高伤，打 Boss 脆弱窗口 | 时机判断 |
| 位移 + 伤害 | 冲刺穿越敌群并造成伤害 | 走位操作 |
| 控场 | 低伤带大范围减速 / 定身 | 危机响应，为宠物制造输出窗口 |

---

### 2.2 宠物

| 属性 | 规则 |
|---|---|
| 战斗行为 | 跟随主角，全自动普攻 + 自动技能（CD 满自动触发） |
| 攻击模式 | 由宠物种类决定，见下表 |
| 同时出战数 | 可配置，Demo 阶段具体数字待定 |
| 操作要求 | 玩家无需操作宠物，专注走位和手动技能时机 |

**宠物攻击模式分类：**

| 类型 | 攻击模式 | 特点 |
|---|---|---|
| 近战型 | 高频近距离输出 | 稳定 DPS，需要主角带它靠近敌人 |
| 远程单体型 | 低频高伤，精准 | 输出高但慢，适合有肉盾时 |
| 范围型 | AOE，低频 | 清群效果好，单体伤害低 |
| 持续型 | 弹幕 / 连射，高频低伤 | 命中率高，适合合击蓄力节奏 |
| 控制型 | 低伤 + 减速 / 定身 | 辅助其他宠物输出，配合主角手动技能 |

---

### 2.3 合击

| 属性 | 规则 |
|---|---|
| 触发条件 | 特定宠物对 / 宠物组共同出战（预设组合，非属性公式） |
| CD 机制 | 时间 CD：组合凑齐后，每隔 X 秒触发一次（X 待定） |
| 释放方式 | 默认 CD 满自动触发；玩家可手动点，对准 Boss / 密集敌群窗口 |
| 瞄准方式 | 自动瞄准，与主角技能一致 |
| 效果 | 每对组合有独立设计的高倍率效果，非公式化 |
| Demo 范围 | 只做 1-2 对，验证发现组合 → 释放合击的体验爽感 |

**组合定义方式：宠物对，不是属性组合**

每对合击预设为特定宠物的专属联动，而非属性自动匹配。原因：
- 合击是稀缺的高光时刻，泛滥后失去冲击力
- 发现隐藏组合本身是收集乐趣的一部分，与养怪题材高度契合
- 属性组合矩阵庞大，每种都要设计效果，工作量不可控

## 三、技能体系

### 3.1 两层技能的层次关系

```
基础技能（局外永久）
└── 宠物养成解锁，战斗底盘，跨局持有
    性质：宠物的固有攻击能力，定义攻击模式

肉鸽放大器（局内临时）
└── 地牢肉鸽节点选择，出地牢后消失
    性质：纯数值放大，不产生新攻击单元
```

两层关系：基础技能定义"怎么打"，放大器决定"这局打多狠"。

---

### 3.2 基础技能（局外永久）

- 随宠物养成解锁，养成越深解锁越多技能选项
- 跨局永久持有，不受地牢结果影响
- 是宠物的固定攻击模式（普攻 + 固定技能），决定该宠物的战斗角色
- 同时解锁主角技能（对应宠物养成到指定等级）

---

### 3.3 肉鸽放大器（局内临时）

| 类型 | 作用对象 | 倍率级别 | 备注 |
|---|---|---|---|
| 全体放大器 | 所有输出单元 | 低 | 通用，无论队伍配置都有效 |
| 宠物专属放大器 | 指定类型宠物 | 高 | 特化，需要队伍有对应宠物 |
| 主角技能放大器 | 主角技能 | 最高 | 因手动时机有隐性加成，数值设计时打折 |
| 合击放大器 | 合击输出 | 高 | 需凑齐对应组合才能用 |

**技能池扩展规则：**
- 宠物养成扩展肉鸽放大器的可抽种类（不是直接给，是加入抽取池）
- 养成越深，可抽到的放大器种类越多，Build 空间越大

---

### 3.4 协同体系

**被动协同（简单层）：**
- 满足条件时自动触发，低调存在
- 示例：同属性 2 只宠物共存 → 全体攻击速度小幅提升
- 设计原则：被动协同是选队伍时的锦上添花，不是必须凑的强制条件

**主动合击（高光层）：**
- 见 2.3 合击章节

## 四、数值框架

### 4.1 伤害公式

```
伤害 = 基础攻击力 × 技能倍率 × 属性克制系数
```

适用范围：主角技能、宠物普攻 + 宠物技能、合击，共用同一套公式。

---

### 4.2 倍率分层

| 层级 | 来源 | 倍率范围（待定） |
|---|---|---|
| 基础攻击力 | 宠物属性 + 养成提升 | 基准值，提升幅度小 |
| 技能倍率 | 技能本身配置 | 普攻 < 基础技能 < 肉鸽放大后的技能 |
| 肉鸽放大倍率 | 放大器叠加系数 | 数值远高于基础技能（核心爽点来源） |
| 属性克制系数 | 属性克制关系命中时 | 倍率显著提升（具体系数待定） |

**设计原则：**
- 养成提供少量基础提升（15-30% 量级），不是核心输出来源
- 高伤害靠技能倍率实现，肉鸽放大器是局内伤害的最大变量
- 属性克制系数是"额外奖励"，不是必须达到才能通关的门槛

---

### 4.3 属性克制

- 公式中的 `属性克制系数`：命中克制关系时触发，明显提升该次输出
- 玩家感知方式：视觉特效反馈（克制命中时有额外特效）
- 策略价值：进地牢前知道 Boss 弱点，有意选对属性宠物和主角技能

## 五、操作设计

### 5.1 操作模型：自动为底，手动可选

战斗默认全自动运行，玩家不操作也能正常推进。界面提供「自动战斗」开关；想介入的玩家可随时手动走位、手动点技能 / 合击。

```
默认全自动：
├── 移动（自动走位 / 寻路）
├── 普攻（主角 + 宠物）
├── 宠物技能（CD 满自动触发）
├── 主角技能（CD 满自动释放）
└── 合击（凑齐组合后 CD 满自动触发）

可选手动介入（不开也能通关）：
├── 虚拟摇杆：手动接管走位
├── 主角技能键：手动点，卡聚怪时机
└── 合击键：手动点，对准 Boss / 密集窗口
```

---

### 5.2 自动 / 手动分配原则

| 行为 | 默认 | 玩家可手动 | 手动的收益（只提速，不设门槛） |
|---|---|---|---|
| 移动 / 走位 | 自动 | 拖摇杆接管 | 躲掉部分伤害，减员更少，刷得更稳 |
| 普攻 | 自动 | 否 | — |
| 宠物技能 | 自动 | 否 | 宠物是自主战斗单元，不需要玩家盯 |
| 主角技能 | CD 满自动放 | 手动点 | 卡聚怪时机，AOE 多吃几个；不卡也能清 |
| 合击 | 凑齐后自动触发 | 手动点 | 对准 Boss 脆弱窗口，伤害更高；自动也放得出 |

设计要点：自动是通关基准线，手动只优化效率和手感。手动技能均自动瞄准，玩家手动时只决定"什么时候放"，不需要管"放向哪里"。能不能赢取决于养成强度和本局 Build，不取决于玩家手速（见一、系统定位「胜负判定原则」）。
