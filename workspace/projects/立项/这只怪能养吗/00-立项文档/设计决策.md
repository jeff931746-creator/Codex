## 玩法流程骨架（已确认）

```
【局外】
选宠物队伍 → 进入地牢

【局内 — 单次地牢】
探索地图（房间制）
  ↓ 接触敌人
即时战斗
  ↓ 到达肉鸽节点
肉鸽选择（选临时技能）
  ↓ 触发随机事件点
抓宠 / 其他事件
  ↓ 抵达 Boss 房
Boss 战 → 通关结算

【局外结算】
获得材料 + 新宠物 → 养成 → 进入更深地牢
```

## 各模块已确认决策

### 探索模块
- **地图结构**：房间制 + 路线选择
- **路线透明度**：部分透明——出口显示房间类型图标，不显示具体内容
- **图标类型**：⚔️ 战斗房 / ❓ 随机事件 / 💀 精英房 / 🎁 自选节点 / 🏆 Boss 房
- **敌人可见**：地图上可见敌人，非随机遇怪
- **拓扑结构**：开放，由关卡设计决定（支持线性 / 分叉 / 混合）

#### 关卡随机生成底层模型

| 层级 | 规则 |
|---|---|
| 构成固定 | 每局配方固定（类型种类和数量有保证），房间池从配方生成 |
| 位置随机 | 房间在序列中随机排列 |
| 随机模式 | 有限随机为主（约束层开启），兼容纯随机（约束层关闭） |

**有限随机约束（默认开启）**

| 约束 | 规则 |
|---|---|
| 连续上限 | 同类型房间最多连续 2 间 |
| 早期保护 | 精英房不出现在前 40% 位置 |
| 事件分布 | 事件房不全堆在同一半段 |
| Boss 锚定 | Boss 始终最后 |
| 自选节点 | 必须出现在 Boss 前 2 间内 |

详细设计见 `关卡设计.md`

### 战斗模块
- **战斗类型**：即时制
- **操作方式**：虚拟摇杆移动 + 自动普攻
- **主角技能**：手动按钮释放（1-2 个，Demo 阶段 1 个）
- **宠物技能**：自动释放（CD 满自动触发）
- **合击**：手动按钮释放，独立 CD，CD 满后按钮高亮
- **自动瞄准**：主角技能和合击均自动瞄准，玩家只决定时机

### 主角设定
- **主角**：固定角色（类似 Hades 的 Zagreus）
- **主角技能**：可选配，局外从已解锁技能池中选 1-2 个带入地牢
- **技能解锁**：宠物养成解锁（养指定宠物至指定等级）
- **养成重心**：宠物养成为主，主角技能作为第 N+1 个输出单元
- **装备**：Demo 不做

### 宠物系统
- **出战数量**：可配置（Demo 阶段具体数字待定）
- **战斗行为**：跟随主角，自动普攻 + 自动技能
- **等同定位**：宠物 = 向僵尸开炮的技能单元，各自是独立攻击单元
- **攻击模式**：近战型 / 远程单体型 / 范围型 / 持续型 / 控制型
- **协同**：同条件宠物组合触发被动协同增益（锦上添花量级）

### 合击体系
- **触发条件**：特定宠物对共同出战（预设宠物对，非属性公式）
- **CD 机制**：时间 CD（凑齐组合后每隔 X 秒可释放，X 待定）
- **效果**：每对组合独立设计高倍率效果
- **Demo 范围**：1-2 对合击验证体验
- **发现机制**：玩家探索发现，不主动提示所有组合

### 肉鸽模块
- **定位**：纯放大器，不产生新攻击单元
- **技能作用域**：出地牢后消失（纯临时）
- **放大类型**：全体放大器 / 宠物专属放大器 / 主角技能放大器 / 合击放大器
- **技能池**：由宠物养成扩展（跨局永久，养成解锁更多可抽种类）

### 抓宠模块
- **触发方式**：随机事件房，进入独立捉宠场景（非主地牢战斗）
- **交互形式**：回合式，每回合选择 [攻击 / 投球 / 使用道具]
- **机制参考**：宝可梦核心逻辑——削血降低 HP → 提高投球成功率
- **成功率**：物种基础率 × HP系数 × 球类型加成 × 状态加成
- **逃跑**：每回合触发逃跑判定，HP 越低逃跑概率越低
- **反击**：捉宠过程中宠物会攻击出战宠物（有代价）
- **捉宠球**：消耗品，地牢战斗掉落；多种类型，加成倍率不同
- **难度演变**：前期普通宠物基础率高可直接投球；后期稀有宠物需削血 + 高级球
- **详细设计**：见 `系统设计_捉宠.md`

### 养成模块
- **养成解锁**：基础技能 + 扩展肉鸽技能池
- **材料来源**：地牢掉落 + 通关奖励

### 数值模块
- **公式**：伤害 = 基础 × 技能倍率 × 属性克制系数
- **来源**：参考向僵尸开炮底层数值体系
- **特点**：养成提供少量基础，高伤害靠技能倍率实现
