# 这只怪能养吗 - 可玩 Demo

零依赖静态浏览器 demo，按 `00-立项文档/系统设计` 实现完整地牢体验：**局外大厅 → 约束随机地牢 → 实时走房间 → 结算 → 跨局养成**。美术为像素风（参考《元气骑士》），全程纯 Canvas 程序化绘制、零素材依赖。

## 操作 / 流程

- 拖左下摇杆或 WASD / 方向键**走位**；战斗自动为底（可关），主角横扫 + 宠物弹幕割草
- 房间打完 / 事件结算后**出口门发光打开**，走到门口进入下一间；分叉点是两扇门，走哪扇选哪条路（另一条永久关闭）
- 左上角**小地图**显示房间序列、分叉与当前位置

## 运行

```bash
cd playable-demo && python3 -m http.server 4173
# 打开 http://127.0.0.1:4173/
```

## 战斗（割草 + 成长，自动为底手动可选）

- **割草**：怪成群（一波十几到二十几只）从四周涌向主角；主角近身横扫 + 宠物弹幕 + 主角 AOE 技能清场，连杀计数、漫天伤害数字
- **成长感（本局）**：开局只带 1 只宠物，**抓宠把新宠物加入本局队伍**，HUD「战力」实时增长（实测一局 100 → 400+，清场时间 14s → 6s）
- **决策质变 Build**：放大器优先做改变打法的质变——贯穿（子弹穿透清群）/ 连环爆（击杀连锁爆炸）/ 分裂（弹幕翻倍）/ 火海（陨火留持续燃烧地带），一眼看出战场两样
- **手动可选**：拖摇杆 / WASD 走位、点 F（主角技能）/ X（合击）卡时机；自动能过通关基准线，手动更快更稳
- 伤害 = 基础 × 技能倍率 × **属性克制系数**（火/水/影/草/光，克制命中金色「克制」高亮 + 额外伤害，是奖励不是门槛）

## 捉宠成功率（按文档公式）

```
成功率 = 物种基础率 × HP系数 × 球加成 × 状态加成
HP系数 = (3·MaxHP − 2·HP) / (3·MaxHP)   // 满血约0.33，残血约1.0
逃跑率 = 基础逃跑率 × HP修正 × 状态修正   // 满血逃跑率高，自然引导先削血
```

## 美术：像素风（参考《元气骑士》，纯 Canvas 程序化、零素材依赖）

- 俯视像素地牢：棕石地块 + 草簇碎石 + 顶部墙体 + 暗角，关闭抗锯齿走硬像素
- 像素精灵：深发冒险者主角、像素小怪/精英/Boss（带角+发光眼）、宠物，y 轴深度排序
- 像素血条/属性点、像素伤害数字（克制高亮）、像素粒子/弹丸、受击白闪、连杀大字、屏幕震动

> 精灵用字符网格 + 调色板程序化生成（`SP_HERO` / `SP_CRIT`），非外部图集。要达到商业成品精度仍需美术出正式精灵图集与动画帧。
