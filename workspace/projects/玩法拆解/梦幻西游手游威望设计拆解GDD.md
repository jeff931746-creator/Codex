### 0.2 版本边界

公开资料里，“威望值”和“势力值”在不同版本语境中承担相近职责：都是帮派占领城池、参与赛季竞争、结算帮派奖励时使用的帮派级排行数值。本文统一用“威望”作为专题名；遇到旧资料中的“势力值”，按同类帮派级赛季积分处理。

| 版本语境 | 与威望相关的确认内容 |
|---|---|
| 2023 测试期 | 占领城池可获得威望值；每个城池的占领威望值随占领次数衰减；等级越高的城池，各次占领获得的威望值越高；宣战超出上限时，最低威望值帮派会被取消宣战 |
| 2024 全服上线期 | 威望值衡量赛季中帮派整体实力；每周所有帮派固定获得一定威望值；开疆拓土、帮战胜利、帮派车轮战胜利可获得额外威望值；夺取或丢失城池会按城池等级获得或丢失威望值；赛季结束按威望排行结算 |
| 2025 轻享服 | 文本更多使用“势力值”；夺取或丢失城池按城池等级获得或丢失势力值，城池等级越高数值越高，赛季结束按势力值排行结算奖励 |

### 0.3 术语说明

| 术语 | 含义 |
|---|---|
| 威望值 | 帮派级赛季积分，衡量帮派在开疆拓土赛季中的整体竞争结果 |
| 势力值 | 轻享服资料中出现的同类帮派级排行指标，本文并入威望讨论 |
| 城池等级 | 城池价值层级，高等级城池提供更高威望或势力值 |
| 宣战排序 | 多个帮派争夺同一城池时，威望会影响宣战资格或匹配排序 |
| 功勋 | 个人参与开疆拓土获得的兑换货币，不等同于威望 |
| 贡献度 | 个人赛季评价数值，不等同于威望 |

## 1. 需求目的

威望的核心目的不是“再给一个排行榜”，而是把帮派在赛季里的行动转成一个可比较、可结算、可反向影响下一步决策的公共数值。

没有威望时，开疆拓土会只剩三个松散行为：

```text
管理发车
成员护车/劫车
帮战决定城池归属
```

这些行为本身有参与感，但缺少一个能回答“为什么要抢这座城、为什么要防守、为什么要追排名、为什么要打长期赛季”的总目标。威望把城池归属、宣战资格、帮派奖励和赛季排名串在一起，使帮派行为有明确的长期方向。

### 1.1 面向帮派的目的

- 让帮派拥有跨日、跨周的赛季目标，而不是只打单场帮战。
- 把城池等级、城池数量、进军路线、防守压力转化为帮派排名。
- 让管理者在“稳拿低级城、争高级城、防守已有城、打断敌方进军”之间做取舍。
- 让强帮的领先优势可以被看见，也可以因为丢城而下降。

### 1.2 面向成员的目的

成员不直接花费威望，也不把威望当个人货币使用。威望对成员的价值来自帮派目标反向分配任务：

- 帮派需要威望，管理者才会组织发车、宣战、防守。
- 管理组织行动后，成员通过护车、劫车、攻城、守城获得功勋。
- 帮派威望越高、赛季排名越好，成员能获得更高的帮派赛季奖励。
- 高等级城池提升商店或元身相关条件时，个人成长也会被帮派目标带动。

### 1.3 面向长期循环的目的

威望解决的是状态固化问题和长期目标问题。

```text
如果城池只是一张地图上的归属标记，
玩家很快会只关心短期功勋。

如果城池能转化为威望，
威望又影响宣战竞争、帮派排名和赛季奖励，
帮派才会持续组织成员参与下一轮争夺。
```

## 2. 玩法总览

### 2.1 一句话定义

威望是《开疆拓土》中把城池争夺结果转化为帮派赛季排名、宣战竞争资格和帮派奖励结算的帮派级积分。

### 2.2 总循环

```text
帮派观察地图与威望排名
→ 选择目标城池
→ 发起补给车进军
→ 成员护车，敌方劫车
→ 补给车抵达后宣战
→ 帮战决定城池占领或防守结果
→ 根据城池等级获得或丢失威望
→ 威望影响排名、宣战竞争和赛季奖励
→ 帮派重新选择下一轮目标
```

### 2.3 威望在开疆拓土中的位置

| 上游行为 | 威望处理 | 下游影响 |
|---|---|---|
| 占领城池 | 按城池等级获得威望或势力值 | 提升帮派排名，推动赛季奖励 |
| 丢失城池 | 按城池等级丢失一定威望或势力值 | 排名下降，防守变得有意义 |
| 多帮派宣战同一城池 | 威望参与排序或低威望淘汰 | 让威望影响下一轮争夺资格 |
| 帮战胜利、车轮战胜利等帮派战绩 | 获得额外威望值 | 让非占城战绩也能贡献赛季排名 |
| 赛季结束 | 按威望或势力值排行结算 | 转化为帮派赛季奖励 |

## 3. 核心玩法循环

### 3.1 帮派目标循环

```text
查看威望排名
→ 判断当前名次和奖励档位
→ 选择能提升排名的城池
→ 组织进军、宣战、攻城
→ 获得城池威望
→ 进入更高排名或守住现有档位
```

这一层服务帮派管理者。威望把地图上的“占领”翻译成赛季目标，让管理者可以根据差距、档位、时间和城池等级做决策。

如果没有威望，管理者只是在地图上扩张；有了威望，扩张会变成可计算的排名行为。

### 3.2 宣战竞争循环

```text
多个帮派想争同一城池
→ 城池宣战名额有限
→ 威望较低者可能被取消宣战或在排序中吃亏
→ 帮派需要通过前置战绩提高威望
→ 更高威望带来下一次争夺资格
```

这使威望不只是“赛季结束才看的分数”。它会在赛季过程中影响能不能进入关键城池争夺。

这种设计会强化领先帮派的竞争优势，因此需要通过城池被夺扣分、占领收益衰减、宣战名额、赛季刷新等规则控制滚雪球。

### 3.3 城池价值循环

```text
低级城提供稳定威望
→ 高级城提供更高威望
→ 中心或关键城成为排名争夺目标
→ 高价值城池更容易被宣战
→ 防守成功保住威望，防守失败损失威望
```

威望让城池等级不只是地图层级，而是排名价值。高等级城池越值钱，帮派越需要投入更多组织成本。

### 3.4 个人参与回流

```text
帮派为了威望组织进军和宣战
→ 成员参与护车、劫车、攻城、守城
→ 成员获得功勋、贡献度、元身成长材料或商店兑换机会
→ 成员战斗表现提高
→ 帮派更容易获取或保住威望
```

个人不直接使用威望，但个人行为会支撑帮派威望。帮派威望又通过排名奖励、商店条件、城池目标把个人收益带回给成员。

## 4. 系统规则拆解

### 4.1 威望来源

已确认规则：

- 占领城池可获得威望值。
- 城池等级越高，各次占领获得的威望值越高。
- 2024 资料称每周所有帮派会固定获得一定威望值。
- 2024 资料称参与开疆拓土、帮战胜利、帮派车轮战获胜可获得额外威望值。
- 轻享服资料称夺取城池会根据城池等级获得势力值。

设计判断：

- 固定获得的威望用于降低弱帮完全掉队的风险。
- 战绩获得的额外威望让帮派不能只靠早期占城躺赢。
- 城池等级差异让地图推进有目标层次。

资料未覆盖：

- 每周固定威望的具体数值。
- 各城池等级对应的威望表。
- 帮战胜利、车轮战胜利对应的威望数量。

### 4.2 威望损失

已确认规则：

- 在开疆拓土中丢失城池会根据城池等级丢失一定威望值或势力值。
- 已夺取城池被对方宣战并夺取时，原占领帮派会丢失一定威望。

设计判断：

- 威望损失让防守成立。否则帮派只需要不断向外抢城，不需要为已有城池投入组织资源。
- 丢失城池扣威望，使高等级城池同时具备高收益和高风险。

资料未覆盖：

- 丢城扣除比例是否等于占领收益。
- 防守成功是否直接获得额外威望。
- 城池多次易手后的威望扣减公式。

### 4.3 占领次数衰减

2023 资料明确提到：每个城池的占领威望值会随着占领次数不断衰减。

这条规则很关键。它解决的是“同一座城池反复刷分”的问题。

```text
如果同一城池每次占领都给满额威望，
强帮或结盟帮派可以围绕同一目标反复制造易手，
把地图争夺变成刷积分。

占领收益衰减后，
帮派需要继续向更高等级、更难争夺、更远距离的城池移动。
```

资料未覆盖：

- 衰减是全服共享、城池独立，还是按帮派独立计算。
- 衰减是否随赛季阶段恢复。
- 衰减最低值是多少。

### 4.4 宣战排序与名额

已确认规则：

- 宣战同一城池的帮派会按照威望值排序匹配帮战，极端情况除外。
- 每个城池可宣战帮派数量有上限。
- 如果宣战帮派超过上限，则当前最低威望值的帮派会被取消宣战。
- 不能对我方已占领城池和盟友城池宣战。

威望在这里承担“竞争资格”的功能。

```text
低威望帮派不是完全不能参与，
但当热门城池名额不足时，
低威望帮派更容易被挤出。
```

这会让帮派更重视前期积累，也会让关键城池更集中在高威望帮派之间。它的好处是提高关键战的强度；风险是弱帮可能逐渐失去争夺核心目标的机会。

### 4.5 赛季结算

已确认规则：

- 赛季结束时，帮派会根据威望值或势力值排行结算赛季奖励。
- 资料中存在天冲组、地魁组等分组奖励展示。

威望在赛季末把过程行为汇总成结果。它不是单日积分，而是帮派整个周期的竞争记录。

资料未覆盖：

- 赛季长度。
- 完整奖励档位。
- 分组规则与跨组晋降级规则。

## 5. 威望解决的问题

### 5.1 威望把地图行为翻译成排名行为

城池本身是空间资产。玩家能看到它属于谁，但仅有归属并不足以形成长期目标。

威望让每次占领、丢失、防守都进入同一套赛季评价：

```text
占了哪座城
→ 这座城给多少威望
→ 帮派排名变化多少
→ 离下一档奖励还差多少
→ 下一步该争哪座城
```

这让帮派管理者的选择变得可比较。

### 5.2 威望让防守有收益压力

如果只奖励占城，不惩罚丢城，帮派会倾向于一直向外扩张，防守会变成情绪性行为。

威望丢失让防守变成理性选择：

```text
丢高级城
→ 威望下降
→ 排名档位可能下降
→ 赛季奖励变差
→ 必须安排守城或重新夺回
```

这样守城不是“帮派面子”，而是排名保护。

### 5.3 威望让弱帮和强帮都有不同目标

强帮目标：

- 抢高等级城。
- 保住高威望城池。
- 在宣战排序中保持优势。
- 争取赛季前列奖励。

中等帮派目标：

- 争取稳定城池数量。
- 避免热门城池宣战被挤出。
- 通过低中等级城池积累排名。
- 在关键节点偷取高价值城池。

弱帮目标：

- 获得固定威望和基础占城收益。
- 避开强帮正面争夺。
- 通过劫车、防守、低等级城池获得参与价值。
- 争取不被赛季排名完全拉开。

威望本身能提供目标差异，但如果宣战排序过度偏向高威望，弱帮会被压到只剩陪跑。

### 5.4 威望让联盟关系有边界

资料确认不能宣战盟友城池，联盟也能影响护车和目标选择。威望在这里让联盟不只是社交关系，而会影响城池价值分配。

```text
盟友城池不能宣战
→ 联盟内部需要分配目标
→ 城池对应威望
→ 目标分配影响赛季排名
```

如果联盟范围过大，可能出现大量城池不被争夺；如果联盟限制过强，弱帮会缺少保护。威望排行能放大联盟分配的利益问题。

## 6. 资源结构

### 6.1 产出总览

| 资源/产出 | 来源 | 用途 | 为什么需要它 |
|---|---|---|---|
| 威望值/势力值 | 占领城池、每周固定获取、开疆拓土战绩、帮战胜利、车轮战胜利 | 帮派排行、宣战排序、赛季结算 | 给帮派长期目标和竞争比较 |
| 城池归属 | 补给车抵达、宣战、帮战胜利、防守成功 | 威望来源、地图推进、商店或元身条件 | 让空间目标产生实际价值 |
| 功勋 | 护车、劫车、进军成功、城池争夺 | 功勋商店兑换 | 给个人日常参与回报 |
| 贡献度 | 劫车、护车、帮派竞赛人物对战等 | 个人赛季奖励评价 | 评价个人整个赛季投入 |
| 帮派赛季奖励 | 赛季末按威望排行结算 | 帮派成员长期奖励 | 把帮派排名转成成员收益 |
| 宣战资格 | 威望排序、城池宣战名额、进军完成条件 | 进入城池争夺 | 控制热门目标参与数量 |

### 6.2 威望为什么不是个人货币

威望如果做成个人货币，会和功勋抢功能：玩家会关心自己兑换什么，而不是帮派争哪座城。

现在的结构更清楚：

```text
功勋回答：我今天参与有什么收益？
贡献度回答：我整个赛季个人贡献如何？
威望回答：我们帮派这个赛季处在什么位置？
```

三者分工不同，能减少目标混乱。

### 6.3 威望的来源、存量、消耗与清理

| 项 | 当前判断 | 资料状态 |
|---|---|---|
| 来源 | 固定周获取、占领城池、开疆拓土参与、帮战胜利、车轮战胜利 | confirmed |
| 存量 | 累计到帮派赛季排名中 | inferred，资料未给上限 |
| 损失 | 丢失城池会按城池等级损失威望或势力值 | confirmed |
| 使用 | 宣战排序、宣战名额淘汰、赛季结算 | confirmed |
| 清理 | 赛季结束后进入新周期 | inferred，资料确认赛季结算但未写完整清零公式 |

威望不是被玩家主动消耗的货币。它更像帮派当前赛季状态：会增加、会减少、会参与排序，赛季结束后完成结算。

### 6.4 威望过多、过少、缺失的影响

| 情况 | 会坏在哪里 | 表现 |
|---|---|---|
| 威望产出过多 | 排名变化过快，城池价值膨胀 | 单次城池易手导致档位剧烈波动，玩家觉得前期努力不稳定 |
| 威望产出过少 | 帮派行动反馈弱 | 抢城后排名变化不明显，管理组织动力下降 |
| 丢城扣分过重 | 防守压力过高 | 帮派不敢扩张，只守已有城池 |
| 丢城扣分过轻 | 防守不成立 | 强帮只外扩，不需要保卫后方 |
| 宣战排序过度依赖威望 | 强帮优势持续扩大 | 弱帮难以进入核心城池争夺 |
| 没有威望 | 城池争夺缺少长期比较 | 帮派只刷功勋和短期奖励，不关心地图格局 |

---

## 7. 威望与城池的关系

### 7.1 城池等级决定威望价值

资料确认：城池等级越高，提供的威望或势力值越高。

这让地图天然分成目标层级：

| 城池类型 | 对帮派的意义 | 对威望的意义 |
|---|---|---|
| 低等级城池 | 入门扩张、稳定占领、弱帮目标 | 低风险低收益 |
| 中等级城池 | 中期争夺、路线连接、排名推进 | 稳定拉开差距 |
| 高等级城池 | 强帮争夺、赛季档位变化、终局目标 | 高收益高风险 |
| 中心或关键城池 | 决定赛季后段冲榜 | 可能成为威望差距的主要来源 |

### 7.2 占领次数衰减防止刷同一目标

占领收益衰减让帮派不能一直围绕同一座城反复获取满额威望。

它会推动两种行为：

- 向更高等级、更远、更难的城池推进。
- 在赛季后段争夺还没有严重衰减的关键目标。

这条规则会增加路线规划的重要性。管理者不能只问“这座城能不能打下来”，还要问“这座城现在还值不值得打”。

### 7.3 丢城扣威望让占有带来责任

占有城池不只是收益，还会带来防守责任。

```text
占领高级城
→ 获得高威望
→ 被其他帮派盯上
→ 需要安排防守
→ 防守失败会损失威望
```

这让领先者不能只靠早期扩张长期领先。

---

## 8. 与宣战、帮战和补给车的关系

### 8.1 补给车是威望争夺的前置成本

威望不能直接获得。帮派必须先完成进军：

```text
选择可连接城池
→ 发起补给车
→ 成员护车提升速度
→ 敌方劫车削耐久
→ 成功抵达后才能宣战
```

这意味着威望背后有时间成本、体力成本、成员响应成本和帮派资金成本。

### 8.2 宣战规则让威望影响下一轮机会

当多个帮派争夺同一城池，而名额有限时，威望低的帮派可能被取消宣战。

这种设计让威望形成过程影响：

```text
上一轮表现好
→ 威望更高
→ 下一轮更容易保住宣战资格
→ 更容易进入高价值城池争夺
```

风险也在这里：如果缺少追赶机制，落后帮派会越来越难进入关键争夺。

### 8.3 帮战把威望争夺落到战斗结果

资料确认：宣战后通过帮战决定城池占领归属，四帮帮战中需要胜利且在同一城池宣战帮派中帮战积分最高。

威望没有替代战斗结果。它影响入口和排序，但最终仍要通过帮战胜负转化为城池归属。

这能避免威望榜直接决定城池，让成员战斗仍然有价值。

---

## 9. 不同玩家的参与难度与门槛

### 9.1 门槛总览

威望是帮派数值，但它把不同玩家拉进不同工作分层。

| 用户层 | 参与入口 | 主要门槛 | 与威望的关系 |
|---|---|---|---|
| 低战低操作成员 | 护车、跟随攻城、防守响应 | 时间、通知、体力 | 通过保证补给车抵达支持帮派获得威望 |
| 普通活跃成员 | 护车、劫车、攻城、功勋兑换 | 体力、基础战斗、元身理解 | 提高进军成功率和城池争夺参与度 |
| 中高战玩家 | 劫车、敌城攻防、关键守城 | 操作、连续战斗、召唤灵配置 | 打断敌方威望获取，保护本帮威望 |
| 高战核心 | 热门城池攻防、关键帮战 | 战力、战术、疲劳控制 | 在决定高价值城池归属时放大影响 |
| 管理/指挥 | 路线、发车、宣战、防守、联盟 | 信息判断、组织动员、责任 | 直接决定帮派如何获取和保护威望 |

### 9.2 管理玩家的威望压力最高

威望让管理者必须持续判断：

- 当前排名是否需要抢更高等级城。
- 现有城池是否值得防守。
- 目标城池是否有宣战名额风险。
- 当前威望是否足以保住宣战资格。
- 联盟关系是否会影响本帮威望空间。
- 成员是否能在发车和守城时间响应。

管理者的难度不是单场战斗，而是连续多天的信息判断和组织执行。

### 9.3 普通成员看到的是任务，不是威望公式

普通成员未必关心威望计算，但会被威望目标转化成具体任务：

```text
帮派要抢城
→ 成员上车护车
→ 敌方来劫车
→ 中高战反劫或进攻敌车
→ 帮战时参与攻城/守城
→ 个人拿功勋，帮派拿威望
```

如果管理通知清楚，威望可以把多人行动组织起来；如果通知混乱，威望只会停留在排行榜上，普通成员不理解自己为什么要行动。

### 9.4 弱帮的被排除风险

威望参与宣战名额淘汰后，弱帮可能遇到两个问题：

- 热门城池宣战时被更高威望帮派挤出。
- 高等级城池被强帮和联盟长期占住，弱帮只能打低收益目标。

因此弱帮需要可行的低级城目标、固定威望来源、劫车扰动空间和分组保护。否则威望会变成强帮继续领先的工具。

---

## 10. 难度变化

### 10.1 难度来源

| 难度来源 | 表现 |
|---|---|
| 城池等级 | 高等级城池威望更高，争夺更激烈 |
| 宣战名额 | 热门城池名额有限，低威望帮派可能被取消宣战 |
| 运输过程 | 补给车可能被劫，威望目标要先经过进军成本 |
| 防守压力 | 已占城池被夺会丢威望 |
| 帮战强度 | 城池最终归属仍由帮战胜负和积分决定 |
| 联盟分配 | 盟友城池不能宣战，目标分配会影响威望空间 |
| 赛季阶段 | 后期排名接近时，高价值城池和防守更重要 |

### 10.2 赛季难度曲线

```text
开季：低等级城池铺开，威望差距小，目标是建立路线和基础排名
中期：中等级城池争夺增加，宣战排序开始影响热门目标
后期：高等级城池和关键城池决定奖励档位，防守和偷城价值上升
结算前：威望差距、城池易手、防守成功率决定最终排名波动
```

### 10.3 威望让领先者有成本

领先帮派拥有更高宣战优势，但也更容易成为目标。高威望通常意味着占有更多或更高级城池，防守责任也会增加。

如果领先者没有足够成本，赛季会过早失去悬念；如果领先成本太高，强帮会觉得努力占城反而被惩罚。威望设计要在这两者之间保持稳定。

---

## 11. 长期状态刷新

### 11.1 威望为什么需要赛季

威望天然会积累。如果不重置，早期领先会长期保留，后进入或落后的帮派很难追上。

赛季的作用是让威望竞争进入周期：

```text
本赛季争夺
→ 威望排名结算
→ 奖励发放
→ 进入下一轮地图和威望竞争
```

### 11.2 已确认与未确认

已确认：

- 赛季结束会根据威望值或势力值排行结算帮派奖励。
- 元身会在新赛季切换时重置。
- 功勋在退帮、切换赛季时会清除；不同版本有每周清零或保留上限差异。

资料未覆盖：

- 威望值在赛季切换时的具体清零公式。
- 城池归属在赛季切换时的完整重置规则。
- 下一赛季是否调整城池威望表。
- 分组是否随赛季表现变动。

### 11.3 状态刷新变量

| 对象 | 可能的刷新方式 | 作用 |
|---|---|---|
| 威望 | 赛季结算后清理或进入新周期 | 避免历史积分永久固化 |
| 城池归属 | 赛季地图重置或阶段重开 | 让下一季重新争夺 |
| 占领衰减 | 按城池、赛季或阶段重置 | 避免同城刷分，同时恢复新赛季价值 |
| 功勋 | 周期清理或保留上限 | 控制个人奖励兑换节奏 |
| 元身 | 新赛季重置 | 控制玩法内战力滚雪球 |

---

## 12. 关键平衡点

### 12.1 威望要能改变目标，但不能替代战斗

威望应该影响帮派选择和宣战资格，但不能直接决定城池归属。城池归属仍要通过补给车、宣战、帮战、防守产生。

否则玩法会变成“高威望者继续拿城”，成员战斗价值下降。

### 12.2 高等级城池要高收益，也要高暴露

高等级城池如果只给高威望、不带来防守压力，强帮会稳定扩张。高等级城池如果太容易被夺，强帮又会觉得投入不稳定。

合理状态是：

```text
高等级城值得抢
高等级城也值得守
守不住会有可感知损失
但一次丢城不应直接毁掉整个赛季
```

### 12.3 宣战排序不能把弱帮完全排除

宣战名额需要限制，否则热门城池会过载；但如果低威望帮派总被取消宣战，弱帮会失去目标。

可观察的健康状态是：

- 弱帮仍能稳定争夺低中等级城池。
- 中等帮派有机会通过路线和时间差进入高价值城池。
- 强帮在核心城池相互竞争，而不是只压制弱帮。

### 12.4 威望和功勋不能互相替代

威望负责帮派目标，功勋负责个人回报。两者必须保持分工。

如果个人功勋太强，玩家会只刷个人奖励，不关心帮派排名。  
如果威望奖励太强，普通成员会觉得自己在为管理和高战打工。  
健康状态是：个人参与能拿到功勋，帮派成功能提高赛季奖励，二者同时成立。

## 14. 验证指标

### 14.1 帮派目标是否成立

| 验证问题 | 观察指标 |
|---|---|
| 帮派是否围绕威望组织行动 | 发车频次、宣战率、目标城池等级变化 |
| 威望是否能影响管理决策 | 结算前目标选择变化、低分帮派追分行为 |
| 高等级城池是否真的被争夺 | 高等级城池宣战次数、易手次数、防守参与率 |
| 防守是否成立 | 被宣战城池防守率、防守成功率、丢城后反打率 |

### 14.2 分层是否健康

| 用户层 | 验证重点 | 观察指标 |
|---|---|---|
| 低战成员 | 是否因帮派目标参与护车 | 护车参与率、被击败后重新护车率 |
| 中战成员 | 是否能通过劫车影响敌方威望目标 | 劫车尝试率、劫车成功率、补给车失败率 |
| 高战成员 | 是否在关键城池发挥作用但不过度碾压 | 连战胜场、疲劳后胜率、关键帮战贡献集中度 |
| 管理者 | 威望目标是否带来合理组织压力 | 发车取消率、宣战失败率、成员响应率 |
| 弱帮 | 是否仍有可参与目标 | 低中等级城池占领率、宣战被取消比例、赛季后段活跃 |

### 14.3 威望经济是否稳定

| 验证问题 | 异常表现 |
|---|---|
| 威望差距是否过早拉开 | 开季数日后前三帮不可追 |
| 威望变化是否过于剧烈 | 单次城池易手导致奖励档位频繁大幅变化 |
| 宣战排序是否过度压制弱帮 | 低威望帮派长期被取消热门城池宣战 |
| 占领衰减是否有效 | 同一城池反复易手刷分 |
| 丢城扣分是否合理 | 帮派只守不攻，或完全不防守 |

## 16. 总结

威望不是开疆拓土里的单独奖励点，而是帮派赛季玩法的总评价数值。

它把四件事连在一起：

```text
城池归属 = 威望来源
威望排名 = 帮派长期目标
宣战排序 = 过程中的竞争资格
赛季结算 = 最终奖励出口
```

放回开疆拓土总结构里看，威望的位置是：

```text
补给车运输线攻防
→ 城池归属变化
→ 威望增减
→ 宣战资格和赛季排名变化
→ 帮派继续组织下一轮进军、防守、劫车和攻城
```

它最重要的设计价值有三点：

1. 让城池争夺从“占一格地图”变成“影响帮派赛季排名”。
2. 让防守从“情绪性护城”变成“避免威望损失和奖励降档”。
3. 让帮派管理的路线、宣战、联盟、防守都能被同一个赛季目标约束。

最大的风险也来自同一个地方：威望如果过度参与宣战资格，强帮会更容易继续获得高价值城池；如果丢城惩罚和占领衰减设置不好，赛季要么过早固化，要么排名波动过大。

因此，威望设计的关键不是“给多少分”，而是控制四个关系：

```text
占城收益与丢城损失的关系
高等级城价值与防守压力的关系
威望排序与弱帮参与机会的关系
个人功勋收益与帮派威望目标的关系
```

只要这四个关系稳定，威望就能让开疆拓土从单次帮战扩展成有长期目标的帮派沙盘赛季。
