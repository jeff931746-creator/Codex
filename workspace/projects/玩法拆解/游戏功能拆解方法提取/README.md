# 游戏功能拆解方法提取

这个目录提取当前正在使用的游戏功能拆解方法，方便单独查看。

它不是新的正式标准。正式验收标准仍以 `reference/部门标准/策划/机制拆解/拆解质量标准.md` 为准。

## 文件说明

- `01-拆解方法总览.md`：说明这套方法到底在拆什么。
- `02-功能拆解模板.md`：开始拆一个功能时可直接套用的工作稿结构。
- `03-自检清单.md`：交付前检查是否仍停留在功能清单或规则说明。
- `04-FF首周强社交功能拆解骨架.md`：把最近 FF / 指尖战记的拆解方式抽成示例骨架。

## 一句话概括

当前拆法不是先列按钮、规则、奖励，而是先判断：

这个功能如果删掉，游戏会在哪里变弱；它通过什么玩家行为、资源变化和玩家关系变化，支撑更长时间的玩法。
