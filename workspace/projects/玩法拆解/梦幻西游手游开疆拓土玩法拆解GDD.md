## 1. 需求目的

开疆拓土是大型帮派沙盘竞技玩法。它的目标不是提供单场 PVP，而是把帮派组织、地图推进、运输攻防、城池归属、个人功勋、元身成长和赛季结算串成一个可持续循环。

### 1.1 面向帮派的目的

- 让帮派拥有长期空间目标，而不是只参与固定时间的帮战。
- 通过城池、道路、补给车、宣战、防守，把帮派管理者的路线决策和成员组织能力转化为赛季结果。
- 让帮派成员人数、在线响应、战斗强度、管理调度都对胜负产生影响。

### 1.2 面向玩家的目的

- 为低操作玩家提供护车入口，让他们能通过简单响应贡献帮派并获得功勋。
- 为中高活跃玩家提供劫车、攻城、守城等主动对抗入口。
- 为研究型玩家提供元身配置、召唤灵搭配、目标选择和收益效率空间。
- 通过功勋商店和赛季奖励，把参与行为转化为可感知收益。

### 1.3 面向长期循环的目的

- 用地图推进形成周期内的开局、中盘、终局节奏。
- 用元身形成玩法内成长线。
- 用状态刷新机制控制历史积累和滚雪球。
- 用势力值/威望排行形成帮派长期目标与周期结算。

## 2. 玩法总览

### 2.1 一句话定义

开疆拓土是一个以补给车运输为过程、以城池攻防为结果、以功勋和元身为个人成长、以势力值/威望为帮派赛季目标的帮派沙盘玩法。

### 2.2 总循环

```text
帮派管理选择目标城池
→ 发起补给车进军
→ 成员护车提升速度
→ 敌方劫车削减耐久
→ 补给车抵达或失败
→ 成功后攻城/宣战
→ 占领或防守城池
→ 获得/损失势力值或威望
→ 个人获得功勋与成长资源
→ 帮派进入下一轮目标选择
→ 赛季结算与重置
```

### 2.3 玩法模块

| 模块 | 主要作用 | 面向对象 |
|---|---|---|
| 地图与城池 | 提供空间目标和赛季排行基础 | 帮派、管理者 |
| 补给车运输 | 将攻城资格过程化，可被协作和干扰 | 全帮派 |
| 护车 | 低门槛贡献入口，提高运输速度 | 低战、普通成员 |
| 劫车 | 主动干扰敌方进军，高风险高收益 | 中高活跃、高战玩家 |
| 攻城 | 把运输结果转化为城池归属 | 中高战、组织成员 |
| 守城 | 保持己方城池，防止势力流失 | 核心在线玩家 |
| 元身 | 赛季内战力构筑和召唤灵强化 | 全层玩家 |
| 功勋商店 | 个人奖励出口与成长回流 | 全层玩家 |
| 赛季结算 | 帮派与个人长期目标 | 全体玩家 |

## 3. 核心玩法循环

开疆拓土不是单一循环，而是四层循环叠加。

### 3.1 帮派战略循环

```text
观察地图与敌我势力
→ 选择目标城池
→ 安排发车时间
→ 组织护车与反劫车
→ 成功抵达后宣战/攻城
→ 占领或防守城池
→ 调整下一步路线
```

这一层服务帮派管理者。乐趣来自路线、时机、联盟、资源调度和成员动员。

关键体验：

- 管理者有可决策目标。
- 帮派组织度能影响结果。
- 成员不是被动参战，而是能参与运输过程。

### 3.2 运输攻防循环

```text
补给车出发
→ 己方成员护车
→ 敌方玩家劫车
→ 护车队列与劫车玩家战斗
→ 补给车耐久变化
→ 抵达或失败
```

这一层是玩法核心。补给车把“攻城资格”拆成了一个可被双方玩家反复干预的过程。

设计价值：

- 护车人数越多，补给车越快，低战成员有组织价值。
- 劫车能阻止敌方进军，中高战玩家有进攻价值。
- 耐久、距离、时间窗口、体力消耗共同构成战略成本。

### 3.3 个人战斗循环

```text
选择参与方式
→ 消耗体力/次数/神行符
→ 进入战斗
→ 状态继承、疲劳增加
→ 获得功勋与贡献
→ 调整元身和召唤灵配置
→ 进入下一次参与
```

这一层强调连续战斗，而不是满状态单场竞技。血量、魔法、召唤灵状态、疲劳都会影响后续战斗。

### 3.4 赛季成长循环

```text
参与护车/劫车/攻城/守城
→ 获得功勋、贡献、资源
→ 挑战元身并获得碎片
→ 强化召唤灵
→ 提升开疆拓土战斗表现
→ 获取更高功勋与贡献
→ 赛季切换重置
```

元身是这层循环的核心。它不是普通奖励，而是赛季内临时战力构筑。

## 4. 系统规则拆解

### 4.1 地图与城池

已确认规则：

- 帮派通过占领城池获得势力值或威望。
- 城池等级越高，提供的势力值/威望越高。
- 赛季结束时，帮派根据势力值/威望排行结算赛季奖励。
- 2023 资料提到道路随赛季进程逐步开放，帮派从据点向中心区域推进。

设计推断：

- 城池是赛季地图的空间资产。
- 高等级城池不仅提供排行价值，也可能影响元身星级、商店解锁和赛季奖励强度。
- 地图开放节奏决定赛季是否有开局、中期、后期。

资料未覆盖：

- 各城池等级对应势力值/威望表。
- 完整地图结构。
- 城池产出与元身星级的精确绑定表。

### 4.2 补给车运输

已确认规则：

- 帮派管理选择目标城池并发送补给车。
- 补给车成功抵达后，可对目标城池宣战或开启攻城。
- 护车人数越多，补给车速度越快。
- 补给车被劫车方攻击后会损失耐久。
- 2025 轻享服补给车耐久上限为 25。
- 2024 全服资料中补给车耐久上限为 50。
- 进军时间结束后，2025 轻享服资料称补给车保留当前状态并停止移动。

设计作用：

- 把帮派战略目标过程化。
- 让敌对帮派可以在攻城前拦截，而不是只在城战中交锋。
- 让普通成员通过护车影响帮派进度。

关键调节变量：

| 变量 | 调节作用 |
|---|---|
| 补给车耐久 | 决定劫车是否能有效阻止进军 |
| 护车人数加速系数 | 决定普通成员的组织价值 |
| 运输距离 | 决定目标选择风险 |
| 进军时间窗口 | 决定在线组织压力 |
| 同时进军数量 | 决定帮派多线作战复杂度 |
| 失败惩罚 | 决定帮派是否敢挑战高风险目标 |

### 4.3 护车

已确认规则：

- 2025 轻享服护车时间为 15:00-20:00。
- 玩家点击护车后，可直接退出开疆或退出游戏。
- 系统控制参与护车战斗，无需玩家手动操作。
- 被敌方劫车击败后，玩家获得少量功勋并退出护车队列。
- 再次护车需要手动加入，并扣除 10 点体力。
- 补给车抵达后，所有护车人员获得功勋。
- 护车单次功勋上限最高 250。

设计定位：

```text
低操作入口 + 帮派人数价值 + 普通成员贡献口
```

适合用户：

- 低战玩家。
- 低操作玩家。
- 时间碎片化玩家。
- 愿意配合帮派通知但不愿手动战斗的成员。

主要门槛：

- 资格门槛：需要具备参与开疆拓土资格。
- 时间门槛：需要在发车窗口上线。
- 组织门槛：需要看到帮派通知并及时上车。
- 复投门槛：被打掉后需要重新护车。

### 4.4 劫车

已确认规则：

- 2025 轻享服劫车时间为 15:15-20:00。
- 玩家可对地图中的补给车发起劫车。
- 劫车会按照敌方护车队列顺序发起战斗。
- 若敌方无护车人员，则劫车玩家与护车将领交战。
- 每次击败护车将领，补给车失去 1 点耐久。
- 近距离劫车消耗 30 点体力，远距离增加 20 点，合计 50 点。
- 劫车需要手动战斗。
- 战斗胜利后会保留人物、助战、召唤灵当前状态进入下一场。
- 连续战斗会积累疲劳，疲劳越高受到伤害越高。
- 劫车单次功勋上限最高 500。

设计定位：

```text
主动干扰入口 + 高操作战斗入口 + 高收益高风险入口
```

劫车考验：

- 目标选择：打哪辆车、是否打悬赏车、是否打远距离车。
- 战斗续航：能否支撑车轮战。
- 召唤灵配置：攻宠、法宠、配速、生存单位是否合理。
- 资源规划：体力是否用于劫车、护车或攻城。

### 4.5 攻城

已确认规则：

- 成功护送补给车后，可对指定城池宣战或开启攻城。
- 攻城目标分为无主城池和敌帮城池。
- 无主城池主要进攻系统怪，包括城池守将和守军。
- 敌帮城池优先进攻敌帮驻守玩家。
- 当不存在可攻击玩家时，攻击城池守将。
- 攻击敌帮守军胜利后，会继承当前战斗数据并进入连战。
- 战斗上限为 8。
- 连战会积累疲劳，逐次增加受击伤害。
- 首次攻城不需要体力，第二次及后续攻城消耗 30 体力。

设计定位：

```text
地图归属结算入口 + 高强度战斗入口 + 高战影响力释放口
```

### 4.6 守城

已确认规则：

- 己方城池被敌帮攻击时，玩家可以驻守己方城池。
- 驻守后以随机顺序匹配出阵迎击进攻方。
- 守城不能挂机，需要第一时间手动迎战。
- 若未及时迎战，守城无效，敌方可能直接攻击系统守卫。
- 首次守城不需要体力，第二次及后续守城消耗 30 体力。

设计定位：

```text
高责任入口 + 实时响应入口 + 城池保有入口
```

守城对低在线玩家不友好，但对核心成员和高战玩家有高价值。

### 4.7 元身

已确认规则：

- 元身用于装备召唤灵，强化属性并赋予相关技能。
- 元身挑战难度分为 9 级。
- 难度越高，掉落碎片越多。
- 帮派占领等级越高，元身星级越高。
- 挑战时间为周一至周五 10:00-22:00。
- 试炼在开启时间内整点刷新，每次持续 60 分钟。
- 挑战采取先到先得，超出试炼气血值则排队。
- 20 回合内未挑战成功视为失败。
- 每次挑战消耗 1 枚神行符，失败返还。
- 每周活跃达到 500 的玩家，周一至周五每天 0:00 获得 4 枚神行符。
- 神行符最多持有 20 枚。
- 持有的元身会在新赛季切换时重置。
- 赛季中更换帮派或切换开疆资格，不影响本赛季已获取元身。

设计定位：

```text
赛季内战力构筑 + 召唤灵分层强化 + 地图目标回流
```

元身不是外部永久养成，而是玩法内临时成长。它让开疆拓土拥有自己的战斗构筑和成长节奏。

## 5. 元身的设计作用

### 5.1 不是普通奖励，而是赛季内构筑层

如果开疆拓土只复用玩家原有战力，强帮和强号会稳定碾压。元身提供了赛季内重新成长的空间，让玩家在玩法内通过参与、挑战和配置提升战斗表现。

### 5.2 绑定召唤灵，强化连续战斗

开疆拓土战斗采用 1 玩家 + 1 助战 + 5 召唤灵的模式。劫车、攻城、守城又存在状态继承和疲劳，因此召唤灵不是附属单位，而是连续作战的核心资源。元身强化召唤灵，就等于强化玩家在车轮战里的续航、输出和抗压能力。

### 5.3 与城池等级形成回流

```text
占领更高级城池
→ 获得更高星级元身条件
→ 成员战斗力提高
→ 更容易护车、劫车、攻城、守城
→ 更容易占领或防守高级城池
```

这个回流能强化帮派目标，但也有滚雪球风险。因此需要赛季重置、神行符限制、挑战次数、难度分层来控制。

### 5.4 元身流派分层

| 元身流派 | 主要价值 | 适合用户 | 典型场景 |
|---|---|---|---|
| 生存型 | 提高存活、复活、抗压和续航 | 低战、中战、守城、劫车玩家 | 连续作战、疲劳后抗压 |
| 物攻型 | 提高点杀和削减效率 | 高战、主动劫车玩家 | 劫车、攻城突破 |
| 法攻型 | 提高面伤和清场效率 | 中高战、攻城玩家 | 打系统守军、压制召唤灵 |
| 速度/控制型 | 抢节奏、打断、先手压制 | 核心战斗玩家 | 高端 PVP、守关键城 |

公开资料中推荐的生存方向包括地藏菩萨、菩提老祖等；物攻方向包括猪八戒、李天王等；法宠方向包括北海龙子、小白龙等。具体强度需以实际版本数值为准。

## 6. 产出结构

### 6.1 产出总览

| 产出 | 来源 | 用途 | 设计目的 |
|---|---|---|---|
| 功勋 | 护车、劫车、攻城、守城、进军成功 | 功勋商店兑换 | 日常参与回报 |
| 贡献度 | 多种参与行为累计 | 个人赛季奖励评价 | 赛季长期评价 |
| 势力值/威望 | 占领城池、守城、帮派战绩 | 帮派排行与赛季结算 | 帮派战略目标 |
| 城池归属 | 攻城、防守 | 地图推进、商店/元身条件 | 空间资产 |
| 元身 | 元身挑战 | 装备召唤灵 | 赛季内战力构筑 |
| 元身碎片 | 元身挑战、兑换 | 升级/合成元身 | 中期成长目标 |
| 神行符 | 活跃奖励、兑换 | 进入元身挑战 | 控制元身产出速度 |
| 体力 | 周期恢复或系统发放 | 护车、劫车、攻防消耗 | 控制行为频率 |
| 通用养成道具 | 功勋商店 | 主游戏养成 | 外部价值锚点 |
| 赛季奖励 | 个人贡献、帮派排行 | 高价值结算 | 长期目标 |

### 6.2 为什么是这些资源

功勋是日常参与货币，解决“今天参与有没有收益”。

贡献度是赛季评价货币，解决“整个赛季谁贡献更大”。

势力值/威望是帮派战略货币，解决“帮派为什么要争城”。

元身是玩法内战力货币，解决“开疆拓土内部有没有自己的成长深度”。

神行符和体力是行为限制货币，解决“高活跃玩家是否能无限刷爆产出”。

通用养成道具是外部价值锚点，解决“非核心玩家为什么要参与”。

### 6.3 商店奖励结构

公开资料提到的可兑换或推荐兑换内容包括：

- 神行符。
- 元身碎片。
- 仙气。
- 60 级制造书礼包。
- 法宝精华。
- 丹心锦囊。
- 金刚石。
- 高级兽诀。
- 内丹。
- 魔兽要诀福袋等高价值道具。

商店设计逻辑：

```text
神行符 / 元身碎片：回流玩法内部成长
兽诀 / 内丹 / 法宝 / 制造书：外溢到主养成
高价值礼包：提供赛季追求目标
限购与刷新：控制经济投放
城池等级解锁：把帮派目标和个人奖励绑定
```

## 7. 状态刷新与长期循环变量

### 7.1 上位问题：赛季不是目的

赛季不是玩法目的，而是一种状态刷新工具。拆解这类玩法时，优先回答的不是“有没有赛季”，而是：

```text
玩法如何制造下一轮目标？
如何避免地图、资源、战力和排行长期固化？
领先者的优势是否有成本？
落后者是否有重新进入竞争的入口？
产出的资源是否有消耗、回收或清理机制？
```

如果玩法采用赛季制，赛季承担这些问题；如果玩法没有赛季，也必须有其他变量承担状态刷新、目标更新、反固化和追赶功能。

### 7.2 开疆拓土当前是否采用赛季制

采用赛季制。

已确认依据：

- 资料明确提到赛季结束时按势力值排行结算赛季奖励。
- 轻享服资料明确写到，持有的元身会在新赛季切换时重置。
- 2023/2024 资料提到赛季切换、退帮会清空功勋或功勋相关数据。

因此，开疆拓土不是“因为有赛季所以成立”，而是因为它有城池归属、帮派排行、元身成长、功勋经济这些容易固化和滚雪球的系统，所以需要某种状态刷新机制；当前版本选择了赛季制来承担这件事。

### 7.3 已确认重置/清理对象

| 对象 | 当前判断 | 上层目的 |
|---|---|---|
| 元身 | 新赛季切换时重置 | 控制玩法内战力积累，避免永久滚雪球 |
| 功勋相关数据 | 赛季切换/退帮会清理，具体版本有差异 | 防止跨周期囤积，保持奖励追求 |
| 势力值/威望 | 用于赛季排行，赛季结算后进入新周期 | 形成帮派长期目标和周期结算 |
| 城池归属 | 资料未完整列出，但玩法结构强依赖重置或刷新 | 避免地图长期固化 |
| 个人贡献 | 作为赛季评价，结算后进入新周期 | 形成个人周期目标 |

### 7.4 状态刷新与长期体验调节变量

| 变量组 | 关键变量 | 调节体验 |
|---|---|---|
| 地图状态 | 城池等级、道路开放、中心城价值、城池归属刷新 | 空间目标是否变化 |
| 补给运输 | 耐久、速度、距离、时间窗口 | 帮派组织压力 |
| 城池攻防 | 连战上限、疲劳、守军强度 | 高强度对抗 |
| 元身成长 | 星级、难度、碎片、神行符、重置范围 | 玩法内战力成长和滚雪球控制 |
| 功勋经济 | 产出、上限、保留、商店价格 | 日常参与动力 |
| 重置保留 | 元身重置、功勋清理、地图刷新、局部保留 | 新周期公平性 |
| 追赶机制 | 弱势收益、低级城目标、截车收益、分组匹配 | 落后者是否仍有目标 |
| 优势成本 | 高级城维护、远距离成本、被宣战压力、疲劳 | 领先者是否能永久锁死局面 |

### 7.5 如果没有赛季，可以用什么替代

没有赛季的玩法仍然可以成立，但需要其他机制承担周期体验。

| 替代机制 | 可承担的功能 | 适合场景 |
|---|---|---|
| 每日/每周重置 | 提供短周期目标，控制资源产出 | 日常活动、副本、商店 |
| 周榜/月榜 | 提供竞争周期，但不清空主体成长 | 积分、排行、竞技 |
| 地图轮换 | 改变空间目标和路线选择 | 沙盘、领地、探索 |
| 事件轮换 | 改变收益目标和战斗条件 | 活动、经营、PVE |
| 资源衰减 | 防止长期囤积和优势固化 | 经济、领地、联盟 |
| 维护成本 | 让占有越多成本越高 | 领地、经营、SLG |
| 软重置 | 只重置局部状态，不清空账号成长 | 长线 MMO、帮派玩法 |
| 阶段开放 | 用内容开放替代赛季重启 | 养成、PVE 推进 |
| 动态追赶 | 给落后玩家或弱势帮派补偿 | 强竞争玩法 |
| 周期争夺点 | 固定时间刷新关键目标 | 世界 Boss、据点战 |
| 匹配分段 | 通过分池避免强弱长期碾压 | PVP、竞技、帮派战 |
| 局内构筑 | 每轮重新选择能力，但账号不重置 | 肉鸽、战场、活动玩法 |

通用拆解口径：

```text
先判断玩法是否存在状态固化风险；
再看它用赛季、周榜、地图轮换、资源衰减、维护成本、追赶机制还是局部重置来解决。
```

### 7.6 下一赛季元身是否变化

当前公开资料能确认的是：

- 元身会在新赛季切换时重置。
- 赛季内更换帮派或切换开疆资格，不影响本赛季已获取元身。

当前公开资料未确认的是：

- 下一赛季是否更换元身池。
- 是否调整元身技能。
- 是否调整元身星级上限。
- 是否调整挑战难度和碎片产出。

因此当前稳妥结论：

```text
已确定变化：本赛季元身数据会在新赛季切换时重置。
未确定变化：元身池、技能、星级、掉落、挑战规则是否调整。
```

## 8. 不同玩家的参与难度与门槛

### 8.1 门槛总览

开疆拓土不是只有战力门槛，而是多种门槛叠加：

```text
资格门槛
时间门槛
操作门槛
战力门槛
资源门槛
组织门槛
认知门槛
机会门槛
```

### 8.2 玩法入口门槛

| 入口 | 表层门槛 | 隐性门槛 | 主要用户 |
|---|---|---|---|
| 护车 | 点一下即可，可退出游戏 | 看帮派通知、及时补车、拥有体力 | 低战、低操作、普通成员 |
| 元身挑战 | 消耗神行符，选择难度 | 懂元身选择、碎片分配、召唤灵定位 | 全层玩家 |
| 劫车 | 手动战斗，消耗体力 | 判断目标、距离、护车强度、续航 | 中高活跃、高战玩家 |
| 攻无主城 | 偏 PVE，可多参与 | 基础战斗配置、时间在线 | 普通活跃玩家 |
| 攻敌方城 | PVP/PVE 混合 | 守城玩家、连战、疲劳、状态继承 | 高战、中高战 |
| 守城 | 实时响应、不能挂机 | 错过响应会让系统守卫被打 | 核心在线成员 |
| 帮派管理 | 权限、路线、宣战 | 信息判断、成员动员、风险决策 | 帮主/管理/指挥 |
| 功勋商店 | 有功勋即可兑换 | 判断换内部成长还是主养成 | 全体玩家 |

### 8.3 用户分层

| 用户层 | 能做什么 | 主要门槛 | 容易卡在哪里 |
|---|---|---|---|
| 轻度低战玩家 | 护车、低难元身、商店兑换 | 时间、资格、通知 | 不知道何时上车，被打掉后不补 |
| 普通活跃玩家 | 护车、低中难元身、无主城攻城 | 体力、基础配置 | 不懂元身和资源优先级 |
| 中战玩家 | 劫车、攻城、部分守城 | 操作、续航、目标判断 | 劫车失败成本高 |
| 高战玩家 | 高价值劫车、敌城攻防、关键守城 | 疲劳、连战、配置深度 | 单人强但被疲劳限制 |
| 研究型玩家 | 元身搭配、目标选择、效率刷功勋 | 认知、数据、试错 | 信息不透明 |
| 管理/指挥 | 路线、发车、宣战、防守、联盟 | 组织、策略、责任 | 成员不响应、目标判断失误 |

### 8.4 护车门槛

护车是最低门槛入口。

流程：

```text
有资格参与
→ 在发车时间上线
→ 点击护车
→ 可退出玩法或退出游戏
→ 系统代为战斗
→ 补给车抵达或被击败后结算功勋
```

优势：

- 操作低。
- 时间碎片化友好。
- 低战玩家也能产生帮派价值。
- 护车人数能提高补给车速度。

风险：

- 被打掉后如果不补车，贡献会中断。
- 收益上限低于劫车。
- 若帮派通知不到位，低活跃玩家容易错过。

### 8.5 元身门槛

元身是从低门槛到高门槛的过渡层。

低门槛部分：

- 低难度元身可作为入门。
- 失败返还神行符，降低试错损失。
- 周活跃 500 提供稳定神行符来源。

高门槛部分：

- 要理解元身给哪只召唤灵。
- 要判断生存、物攻、法攻、速度/控制的优先级。
- 要决定碎片分配和升级顺序。
- 要理解高等级城池与高星元身的关系。

### 8.6 劫车门槛

劫车是主动对抗入口，门槛明显高于护车。

主要门槛：

- 需要手动操作。
- 需要消耗 30 或 50 体力。
- 需要面对护车玩家或系统守将。
- 需要承受连续战斗状态继承。
- 需要处理疲劳递增。

劫车适合：

- 中高战力玩家。
- 愿意手动操作的玩家。
- 有召唤灵配置深度的玩家。
- 能判断目标价值的玩家。

### 8.7 攻城与守城门槛

攻守城是高强度参与层。

| 门槛 | 表现 |
|---|---|
| 在线门槛 | 需要在攻防窗口实时参与 |
| 操作门槛 | 手动战斗，不能挂机 |
| 战力门槛 | 可能遇到敌方驻守玩家 |
| 责任门槛 | 守城不响应会导致防守失效 |
| 连战门槛 | 连战最多 8 场，疲劳递增 |
| 配置门槛 | 要兼顾爆发、续航、复活、召唤灵分配 |

### 8.8 管理与指挥门槛

管理者要承担：

- 目标城池判断。
- 发车时机安排。
- 成员护车动员。
- 敌方劫车压力判断。
- 反劫车安排。
- 宣战与守城组织。
- 联盟关系处理。
- 赛季排名策略。

管理门槛不是战力最高，而是信息、组织和责任最高。

## 9. 难度变化

### 9.1 难度来源

| 难度来源 | 表现 |
|---|---|
| 地图难度 | 高等级城池价值更高，争夺更激烈 |
| 运输难度 | 距离越远，暴露时间越长，被劫风险越高 |
| 对手难度 | 有无护车玩家、护车玩家强度差异大 |
| 连续战斗难度 | 血蓝、召唤灵状态继承，疲劳递增 |
| 资源约束难度 | 体力、神行符、时间窗口限制参与次数 |
| 组织难度 | 帮派成员是否及时护车、守城、劫车 |

### 9.2 赛季难度曲线

```text
开季：低级城铺开，低难元身起步，帮派建立路线
中期：中级城争夺，补给车劫车频繁，元身逐渐成型
后期：高级城和中心区域成为决战目标，守城和反劫车价值上升
结算前：防守、偷城、截车决定排名波动
```

### 9.3 分层难度曲线

| 玩家层 | 初期难度 | 中期难度 | 后期难度 |
|---|---|---|---|
| 低战玩家 | 学会上车和低难元身 | 稳定获得功勋 | 避免被高战完全挤出 |
| 中战玩家 | 尝试劫车和元身配置 | 形成可用构筑 | 参与关键攻防补位 |
| 高战玩家 | 快速获得高价值功勋 | 通过元身拉开效率 | 受疲劳和组织对抗限制 |
| 管理玩家 | 建立路线和通知机制 | 判断城池优先级 | 处理排名、联盟、防守压力 |

| 元身产出是否过弱 | 元身系统变成摆设 |

| 体力是否过紧 | 玩家只能做一种行为，循环断裂 |
| 通用奖励是否过强 | 玩家只刷商店，不关心攻防 |
| 通用奖励是否过弱 | 非核心玩家不参与 |

### 10.4 竞争验证

| 验证问题 | 观察指标 |
|---|---|
| 强帮是否过度滚雪球 | 前三帮势力差距、城池长期垄断率 |

| 时间窗口是否合理 | 各时段参与分布、错峰掉线率、守城响应率 |

## 11. 关键平衡点

### 11.1 低战玩家不能只是陪跑

护车收益必须足够稳定，且护车人数对补给车速度的影响要能被帮派感知。否则低战玩家会觉得自己只是帮高战铺路。

### 11.2 中战玩家需要跨层路径

中战玩家需要通过元身和召唤灵配置，从“只能护车”逐步进入“可以劫车和攻城”的层级。元身系统如果成长太慢，中战玩家会卡在中间层。

### 11.3 高战玩家要强但不能无限穿透

高战玩家应该能在劫车、守城、攻城中发挥关键作用，但疲劳、状态继承、连战上限必须有效，防止单个强号穿透整个队列。

### 11.4 管理压力不能过载

玩法高度依赖管理发车、通知、宣战和守城。如果普通帮派管理负担过重，玩法会变成少数人的工作。需要系统通知、帮派公告、悬赏目标、自动提醒等工具降低组织成本。

### 12.1 状态刷新与长期循环变量

- 周期长度或目标刷新节奏。
- 地图开放节奏。
- 城池等级数量。
- 高等级城池价值。
- 中心城池价值。

### 12.2 日常参与变量

## 14. 总结

开疆拓土的设计中心不是“攻城”，而是“补给车运输线攻防”。

它把帮派战略目标拆成可执行、可干扰、可组织、可成长的连续循环：

```text
补给车 = 战略目标过程化
护车 = 低门槛协作入口
劫车 = 敌对干扰和高收益入口
攻城守城 = 地图归属结算
元身 = 玩法内战斗构筑
功勋 = 个人参与回报
势力/威望 = 帮派长期目标
商店 = 玩法价值外溢
状态刷新 = 控制固化与滚雪球，制造下一轮目标
```

如果只看规则，它像是护车、劫车、攻城、元身、商店五个功能点。真正的系统关系是：

```text
帮派通过补给车争取城池
玩家通过护车和劫车参与运输攻防
攻守城决定地图归属
城池影响帮派周期排名与成长条件（当前版本表现为赛季排名）
元身强化玩家在玩法内的战斗表现
功勋和商店把参与转化为奖励
状态刷新机制让下一轮竞争重新成立；赛季只是当前版本采用的实现手段
```

最关键的验证点是三条：

1. 低战玩家护车是否有稳定收益和组织价值。
2. 中战玩家能否通过元身成长跨入劫车和攻城层。
3. 高战玩家是否有关键影响力，但不会因连战碾压破坏赛季生态。
