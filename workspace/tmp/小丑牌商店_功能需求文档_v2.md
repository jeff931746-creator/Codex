## 需求目的

- 为玩家在每关结束后提供构筑决策节点，强化"买什么、卖什么"的策略深度
- 通过代金券的永久规则改写，制造差异化的局内成长路线，提升长线留存

---

## 需求概述

- 商店在每关结束后开启，包含随机槽、卡包槽、代金券槽三类购买货架
- 玩家持有的小丑牌和消耗牌在商店同屏可见，支持出售
- 支持手动刷新随机槽，费用逐次递增
- 代金券购买后永久生效，存在前置解锁链

---

## 功能概述

### 总流程

关卡结束 ➡️ 进入商店 ➡️ 浏览 / 刷新 / 购买 / 出售 ➡️ 离开商店 ➡️ 选择下一关

---

### 通用规则

#### 购买规则

适用于所有槽位的购买行为。

**价格公式**

```
实际价格 = 向下取整（(基础价格 + 版本加价) × 折扣系数）
```

版本加价：

| 版本 | 加价 |
|---|---|
| 闪光 | +$2 |
| 全息 | +$3 |
| 多彩 | +$5 |
| 负片 | +$5 |
| 无版本 | +$0 |

折扣系数默认 1.0，由代金券永久修改（清仓大甩卖 ×0.75，全面清仓 ×0.50）。折扣作用于含版本加价后的总价。

**购买流程**

进店时及每次持有状态变化后，系统自动更新所有商品的可购买状态（余额、槽位容量、代金券前置），无需点击触发检查。

可购买商品：玩家点击 ➡️ 弹出确认弹窗（显示实际价格与效果说明）➡️ 确认后扣款 ➡️ 商品转入对应持有槽 ➡️ 购买区槽位变空

**代金券例外**：确认后立即生效，不转入持有槽，购买区槽位直接变空。

灰置商品：玩家点击 ➡️ 仅弹出原因提示，不进入确认流程。

**金额不足**：商品灰置，点击仅弹提示"余额不足"。

**槽位已满**：商品灰置，点击提示"槽位已满"。（负片版本小丑牌除外，见小丑槽规则）

---

#### 出售规则

适用于持有区所有可出售物品。

**出售价格公式**

```
出售价格 = 向下取整（购买时实际价格 ÷ 2），最低 $1
```

出售价格锁定为购买时的实际价格，不受当前商店折扣影响。购买确认时或从卡包选牌时立即写入价格快照；所有可出售物品（小丑牌、消耗牌）均需存储，代金券无需存储。

**可出售 / 不可出售**

| 物品类型 | 可出售 | 说明 |
|---|---|---|
| 小丑牌 | ✅ | 任意时机可出售 |
| 消耗牌（塔罗/星球/幽灵） | ✅ | 激活使用中不可出售 |
| 代金券 | ❌ | 购买即生效，不占槽位 |
| 基础扑克牌 | ❌ | 不进入商店持有逻辑 |

**出售流程**

点击持有区物品 ➡️ 出售按钮可点击 ➡️ 弹出确认弹窗（显示出售价格）➡️ 确认后金额增加，物品从持有槽移除，槽位释放

**消耗牌激活中**：已点击使用进入激活流程的消耗牌，出售按钮灰置，只能继续使用或放弃（销毁，不返还金额）。

### 各槽位

#### 随机槽

**支持购买 / 不支持出售 / 特有规则：刷新**

随机槽是商店的核心货架，玩家进店时按权重随机填充，是构筑决策的主要来源。

**槽位配置**

- 默认数量：2（支持配置）
- 上限：4（通过代金券扩展）
- 购买后槽位变空，不自动补充

**填充权重（默认）**

| 商品类型 | 权重 |
|---|---|
| 小丑牌 | 约 70% |
| 塔罗牌 | 约 15% |
| 星球牌 | 约 15% |
| 幽灵牌 | 接近 0 |

权重受代金券动态修改，建议全部配置化。

**刷新规则**

仅刷新随机槽，卡包槽和代金券槽不受影响。

玩家点击刷新 ➡️ 检查余额是否足够 ➡️ 扣除费用 ➡️ 清空所有随机槽（含已购买的空槽）➡️ 按当前权重重新填满 ➡️ 刷新费用 +$1

| 时机 | 刷新费用 |
|---|---|
| 本次商店第一次刷新 | $5（支持配置） |
| 每次刷新后 | 上次费用 +$1 |
| 进入新商店 | 重置为初始值 |

余额不足时刷新按钮灰置，无法点击。初始费用可被代金券永久降低。

---

#### 卡包槽

**支持购买 / 不支持出售 / 特有规则：开包选牌**

卡包槽提供批量获取牌的机会，购买体验与随机槽不同，需进入独立的选牌流程。

**槽位配置**

- 固定数量：2（支持配置）
- 首次进商店保证含一个普通小丑包
- 进新商店时刷新，手动刷新不影响此槽

**卡包规格**

| 规格 | 价格 | 选牌规则 |
|---|---|---|
| 普通 | $4 | 展示 3 张，选 1 张 |
| 超大 | $6 | 展示 5 张，选 1 张 |
| 巨型 | $8 | 展示 5 张，选 2 张 |

**开包流程**

购买卡包 ➡️ 全屏弹出选牌界面 ➡️ 展示对应数量的牌 ➡️ 玩家选牌 ➡️ 选完后关闭，返回商店

选牌时若目标槽位已满（如选小丑牌但小丑槽已满），该牌灰置，无法选择，需先出售腾位。

---

#### 代金券槽

**支持购买 / 不支持出售 / 特有规则：前置链、独立刷新时机**

代金券是商店的规则改写层，永久修改通用购买规则、随机槽配置或刷新规则，是长线策略的核心选择节点。

**槽位配置**

- 固定数量：1（支持配置）
- 刷新时机：击败首领盲注后自动刷新，与商店初始化和手动刷新无关
- 每种代金券每局限购一次

**购买限制**

- 升级版代金券需先购入对应初级版方可解锁
- 已购入的代金券灰置，点击提示"本局已购买"
- 前置未满足时灰置，点击提示"需先购入 XX"

**前置解锁链**

| 初级 | 升级 | 效果说明 |
|---|---|---|
| 超量进货 | 超量进货升级 | 随机槽 +1 → 再 +1；升级版购买后立即按当前权重补满空槽 |
| 清仓大甩卖 | 全面清仓 | 全场折扣 ×0.75 → ×0.50 |
| 重掷优惠 | 重掷大放送 | 刷新初始费用 $3 → $1 |
| 塔罗商人 | 塔罗大亨 | 随机槽塔罗牌权重 ×2 → 再 ×2 |
| 星球商人 | 星球大亨 | 随机槽星球牌权重 ×2 → 再 ×2 |

**效果分类（按影响层级）**

| 影响层级 | 对应代金券 |
|---|---|
| 通用购买规则（折扣系数） | 清仓大甩卖 / 全面清仓 |
| 随机槽配置（槽位数量） | 超量进货 / 超量进货升级 |
| 随机槽配置（填充权重） | 塔罗商人 / 塔罗大亨 / 星球商人 / 星球大亨 |
| 刷新规则（初始费用） | 重掷优惠 / 重掷大放送 |

---

#### 小丑槽（持有区）

**不支持购买 / 支持出售 / 特有规则：容量限制**

小丑槽是玩家当前构筑的核心，商店阶段同屏可见，支持出售以回收资产或腾出槽位。

**槽位配置**

- 默认容量：5（支持配置）
- 可扩展：部分版本（负片）或特定效果可扩充上限

**容量规则**

小丑槽已满时，购买新小丑牌的按钮灰置，提示"槽位已满"。

**例外**：负片版本小丑牌自带 +1 小丑槽效果，购买时直接扩充上限而非占用现有槽位，满槽时仍可购入。

**出售规则**：适用通用出售规则。

---

#### 技能槽（持有区）

**支持购买（来自随机槽/卡包）/ 支持出售 / 支持使用**

技能槽存放玩家持有的消耗牌（塔罗牌、星球牌、幽灵牌），商店阶段同屏可见。

**槽位配置**

- 默认容量：2（支持配置）
- 满槽时无法从随机槽购买或从卡包选取新消耗牌，提示"槽位已满"

**使用规则**

任意阶段均可点击消耗牌激活使用，使用后从槽位移除。
激活使用中的消耗牌出售按钮灰置，只能继续使用或放弃（销毁，不返还金额）。

**出售规则**：适用通用出售规则（激活使用中除外）。

## 界面说明

### 商店主界面

**布局**

```
[ 随机槽 × 2~4 ]  [ 卡包槽 × 2 ]  [ 代金券槽 × 1 ]   ← 购买区
[ 小丑槽（持有）]  [ 技能槽（持有）]                    ← 持有区
[ 刷新按钮（显示当前费用）]  [ 离开按钮 ]  [ 当前余额 ] ← 操作区
```

**各区域按钮状态**

| 场景 | 表现 |
|---|---|
| 商品可购买 | 正常显示，价格标签亮起 |
| 余额不足 | 商品灰置，点击提示"余额不足" |
| 槽位已满 | 商品灰置，点击提示"槽位已满" |
| 代金券前置未满足 | 商品灰置，点击提示"需先购入 XX" |
| 代金券本局已购 | 商品灰置，点击提示"本局已购买" |
| 刷新余额不足 | 刷新按钮灰置，无法点击 |
| 消耗牌激活使用中 | 出售按钮灰置 |

**购买确认弹窗**：显示商品实际价格 + 效果说明，含确认和取消按钮。

**出售确认弹窗**：显示出售价格，含确认和取消按钮。

---

### 卡包选牌界面

购买卡包后全屏弹出，覆盖商店主界面。

- 展示 3 或 5 张牌（按卡包规格）
- 可选数量：1 或 2 张（按卡包规格）
- 目标槽位已满的牌灰置，无法选择
- 选完后自动关闭，返回商店主界面

## 打点需求

**购买流水**
- 商品类型（小丑牌 / 消耗牌 / 卡包 / 代金券）
- 商品稀有度 / 版本
- 实际购买价格
- 购买后余额

**出售流水**
- 商品类型
- 出售价格
- 出售后余额

**刷新流水**
- 刷新费用
- 刷新后余额
- 本次商店累计刷新次数

**代金券流水**
- 代金券名称
- 购买时所在 Ante

**曝光打点**
- 进入商店：各槽位商品类型 / 稀有度
- 刷新后：随机槽新商品类型 / 稀有度
- 卡包打开：展示牌列表、最终选择
