# FF｜7日强社交功能链路细化设计稿

> 基于 `FF-7日强社交功能链路梳理.md` 继续细化。本文是研究稿，不替代后续单功能 GDD。  
> 适用标准：`reference/部门标准/策划/gdd/GDD写作标准.md` v18。  
> 本版修正重点：保留资源争夺和军团承接，明确基础收益、临时收益、失败后的去向、不同玩家首周位置和低活跃玩家的参与方式。

---

## 一、细化目标

- 把首周强社交从“功能开放顺序”细化为“社交关系如何由浅入深”：先让玩家看到他人，再通过高价值产出把玩家带入同场竞争，再通过击杀战报、仇人、复仇和求助推动军团协作。
- 把 D4-D5 的资源冲突从“有 PVEVP / 杀人爆装”细化为“高价值产出吸引参与、竞争手段决定额外收益、击杀或被击杀形成战报、复仇与求助推动军团协作”的连续行为。
- 明确军团 D1 就可以出现，D6-D7 重点是让已有军团关系承担求助、协助和共同目标。
- 避免首周资源争夺过早变成头部玩家和强军团通吃：普通玩家进入公共场景要有基础收益，弱势军团要有保底目标，小 R / 非 R 要能通过活跃和协作贡献，低活跃玩家不被每日定时活动劝退。

## 二、设计口径

首周主线不是一次性开放所有强社交玩法，而是逐步建立从个人成长到军团协作的关系链。

- D1-D2：先确认个人产出、养成积累和战力提升有价值。
- D3：通过同屏、排行、聊天、他人信息和军团信息，让玩家看到其他玩家。
- D4-D5：用公共收益和高风险争夺制造收益差异、战报、仇人和复仇需求。
- D6-D7：用军团求助、成员协作、军团试炼、军团榜和沙盘/战役预告承接后续组织目标。

```text
个人产出循环成立
  -> 养成积累可释放
  -> 看到他人、比较战力、查看信息
  -> 高价值公共目标吸引同场参与
  -> 额外收益竞争形成弱竞争
  -> 高风险争夺产生击杀战报和仇人关系
  -> 被击杀后的复仇、求助带动军团协作
  -> 军团共同目标形成长期预期
```

对应的设计拆分是：

```text
D1 建立产出价值：推关、掉落、换装、战力提升、军团入口露出
D2 建立养成积累：装备、技能、宠物、任务、七日目标
D3 建立浅层社交关系：同屏、排行、聊天、他人信息、军团信息
D4 建立公共收益参与：世界狩猎、公共 Boss、额外收益竞争
D5 建立高风险争夺：寻血、入侵、防守、战报、仇人、复仇
D6 建立军团协作：求助、协助成员、共同任务、军团保护
D7 建立军团共同目标：军团试炼、军团榜、沙盘/战役预告
```

## 五、军团首周承接框架

军团在首周不应只作为签到、捐献、商店和聊天入口出现。它需要把前面已经建立的个人成长、公共收益、高风险争夺、战报仇人和复仇需求接住，让玩家从“我自己变强”转向“我需要一组固定的人一起处理收益和冲突”。

首周军团设计承担 7 项功能责任：

1. 将玩家聚集到军团。
2. 将个人成长接入军团目标。
3. 露出玩家与对手的组织身份。
4. 让公共收益进入军团承接。
5. 将仇人记录转成军团可协助对象。
6. 让成员协作产生可见结果。
7. 给出首周之后仍然成立的共同目标。

### 5.1 需求目的

- 让玩家在看到他人、参与公共收益和经历高风险争夺后，有明确的入团理由；手段是把入团入口放在他人信息、战报、仇人记录、求助和公共目标结算之后，而不是只放在主界面固定按钮里。
- 让个人成长不只服务个人推关和战力数字；手段是把成员战力、活跃、公共目标参与、协助行为计入军团任务、军团试炼和军团榜的可见进度。
- 让冲突对象可以被记住和处理；手段是在战报、仇人记录、复仇入口和敌方信息中展示双方军团，并允许玩家把个人战报发送给本军团请求协助。
- 让首周军团目标从日常活跃过渡到后续军团争夺；手段是在军团试炼、军团榜和沙盘/战役预告中展示成员共同完成的目标、可争夺的公共收益和潜在敌对军团。

### 5.2 需求概述

军团首周承接的是一条从个人成长到组织目标的行为序列：玩家先因为成长和公共收益看到其他玩家，再因为高风险争夺产生战报、仇人和复仇需求，最后通过军团求助、成员协助、共同任务和军团目标把个人冲突转成组织协作。本文只定义首周军团需要承担的功能行为和边界，不展开军团沙盘、战役活动和完整 GVG 规则。

```text
个人成长有价值
  -> 看到其他玩家和军团信息
  -> 参与公共收益争夺
  -> 战报记录攻击方、防守方和双方军团
  -> 玩家从战报进入复仇、求助或查看敌方军团
  -> 军团成员协助防守、反击或完成共同任务
  -> 军团试炼、军团榜和沙盘/战役预告给出后续共同目标
```

### 5.4 建立入团动机

本节用于建立军团在成长、收益和冲突处理中的必要性，避免军团只成为聊天入口。

1. 在军团任务、军团试炼或军团商店中放入首周急需的装备材料、强化材料、技能材料或其他稀缺成长资源，让入团与个人成长直接关联。
2. 让军团等级、军团活跃或军团共同进度解锁全体成员可见的公共收益，使玩家知道军团成长能带来持续收益。
3. 将战报、仇人、复仇和防守求助接入军团，让 PVP 损失可以被成员协助处理。

### 5.5 将个人积累沉淀为集体成长

本节用于把玩家已经形成的成长、活跃和协助积累沉淀到军团贡献、共同进度和军团榜中。

1. 玩家完成推关、装备提升、技能提升、宠物培养或战力阶段目标后，可推进军团任务、军团试炼或军团共同进度。
2. 玩家参与公共目标、寻血防守、复仇或成员协助后，可获得军团贡献，并进入军团榜或成员贡献记录。
3. 高战玩家贡献输出和反击能力，活跃玩家补目标和参与试炼，低战力玩家通过活跃、防守、协助获得贡献。

### 5.6 让公共争夺产生集体价值

本节用于在保留个人基础收益的前提下，把公共争夺中的额外收益、排名、补位和失败处理转成军团价值。

1. 世界狩猎、公共 Boss 和高风险争夺保留个人基础收益，未加入军团的玩家仍可参与。
2. 额外收益、排名奖励、协助补输出、防守补位和公共目标进度可计入军团贡献、军团共同进度或军团榜。
3. 公共目标失败、收益不足或被抢后，玩家可回到军团发起求助、补目标或组织下一轮参与。

### 5.7 个人冲突导向军团

本节用于把被抢、被入侵、复仇受阻等个人冲突，导向查看敌方军团、发送军团求助和触发成员协助。

1. 战报记录攻击者、防守方、双方军团、发生场景、损失内容、保留内容、复仇入口和求助入口。
2. 仇人记录合并展示最近冲突、累计损失和对方军团，避免重复战报淹没有效对象。
3. 玩家可从战报或仇人记录查看敌方军团、发起复仇、发送军团求助或继续成长。

### 5.8 形成成员协作

本节用于把求助、防守、反击、补目标和试炼缺口转成成员之间可见、可反馈的协作行为。

1. 成员协作入口来自战报求助、防守请求、公共目标请求、军团任务缺口和军团试炼缺口。
2. 成员进入协作时，应看到目标、场景、所需行为、可获得奖励和可推进的军团进度。
3. 协作完成后，求助者看到参与成员和处理结果，协助者获得个人奖励、军团贡献或共同进度。

### 5.9 建立军团共同目标

本节用于通过军团任务、军团试炼、军团榜和 D7 后续预告建立首周军团共同目标。

1. 军团任务、军团试炼和军团榜承接首周共同目标，展示成员贡献、阶段进度和已获得收益。
2. 阶段目标允许不同成员用输出、活跃、防守、协助和补目标推进，避免共同目标只由高战成员完成。
3. D7 展示后续沙盘/战役的目标类型、公共收益和潜在对抗对象，不展开完整沙盘、战役或 GVG 规则。
