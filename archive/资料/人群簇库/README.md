## 添加新人群簇

按 [填库工作流](../../../reference/部门标准/立项/三位一体框架/current/05-填库工作流.md) 操作:

1. 主 agent 先 plan,说明拟新增的人群簇(归到哪个 C0X)
2. 用户审批后,按 [人群簇模板](../../../reference/部门标准/立项/三位一体框架/current/模板/人群簇模板.md) 填写草稿
3. 自检:必填字段、boundary(至少 1 条)、代表案例 ≥3 个(跨媒介)、证据等级、媒介适配字段
4. 通过 v1.1 完整 6 步归类流程的复核
5. 分配 ID(`AUD-C{簇编号}-{实例编号}`)并归档
6. 更新 [人群索引](人群索引.md)
