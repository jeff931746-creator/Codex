# 战略库

游戏行业战略情报沉淀库。收集买量策略、市场趋势、产品动态、立项参考、行业方法论。

## 标准层级

```
reference/部门标准/信息收集/信息收集标准.md   ← 跨库通用标准
本目录/SCHEMA.md                             ← 战略库专属 Schema
archive/skills/skills/战略收集/SKILL.md      ← 收集执行工作流
```

## 使用方式

给 Claude 一个文章链接 → 运行 `战略收集` Skill → 自动完成：读取 → 提取 → 分类 → 评估 → 校验 → 归档 → 更新索引。

## 分类体系

| 分类 | 内容 |
|---|---|
| 买量与投放 | 广告策略、素材趋势、平台算法、投放工具 |
| 市场与趋势 | 品类数据、平台政策、大盘变化、用户行为 |
| 产品与设计 | 玩法创新、变现模型、留存策略 |
| 立项参考 | 赛道分析、竞争格局、立项判断 |
| 方法论 | 行业框架、可复用思维模型 |

## 目录结构

```
战略库/

```
