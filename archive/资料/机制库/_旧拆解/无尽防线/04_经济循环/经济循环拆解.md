# 经济循环拆解

| 资源 | 来源 | 用途 | 循环类型 |
|---|---|---|---|
| 银币（局内） | 击杀敌人 / 波次奖励 | 白天建造防御塔和设施 | 局内即时消耗 |

## 局内经济循环

```
击杀敌人 → 获得银币
             ↓
白天建造窗口 → 银币约束下选择防御塔种类和位置
             ↓
防御塔覆盖 → 提升夜晚防守效率 → 更多敌人被击杀 → 更多银币
             ↑_________________正反馈_______________↑

升级触发（经验积累）→ 三选一 BUFF
             ↓
选择骑士塔 BUFF → 生成骑士塔（不消耗银币，消耗选择机会）
选择属性 BUFF → 全局战力提升
选择技能 BUFF → 国王技能激活/强化
```

**关键约束点**：银币数量 = 白天决策的核心约束。银币充足则建造自由，银币匮乏则被迫放弃部分路线覆盖。这是局内策略张力的主要来源。

**局内循环是否自给自足**：是。银币从击杀中来，用于建造，建造提升击杀效率，形成正反馈回路。BUFF选择不消耗银币，是独立的构筑资源（时间成本 = 每次升级机会）。

## 局外经济循环

```
局外：灵魂结晶积累（日常挂机/关卡掉落）
             ↓
骑士升星 → 骑士塔基础属性提升（局内基础门槛上升）
             ↓
领地解锁地块 → 关卡可用建造位置增加
             ↓
设施建造 → 生产资源/加速挂机收益
             ↑___________________回路_______________↑
```

**局外循环的功能**：
1. 托底卡关流失：局外成长使卡关玩家可以通过升星解锁新属性后重试
2. 日活维持：挂机收益模式要求日常登录领取，维持日活
3. 付费切入点：骑士升星速度/材料是主要付费加速点

## 与向僵尸开炮经济循环对比

| 维度 | 向僵尸开炮 | 无尽防线 |
|---|---|---|
| 局内经济核心约束 | 时间（自动清怪节奏决定经验积累速度） | 银币（击杀积累+建造消耗形成约束） |
| 局内经济货币种类 | 经验（升级）/ 金币（少量） | 银币（建造）/ 经验（升级） |
| 局外经济货币 | 灵魂碎片/研究点 | 灵魂结晶/镜石（推断） |
| 失败补偿经济 | 失败仍输出灵魂碎片，换算局外进度 | 待验证是否同等机制 |
| 付费切入 | 角色皮肤/礼包/广告复活 | 骑士礼包/月卡/广告提速（推断） |

## 经济设计的核心判断

**白天建造约束是有效的**：银币限制迫使建造决策，是策略感的物质基础。若银币无限，白天阶段失去意义。

**局内与局外经济的解耦**：局内银币是即时消耗型，不流入局外；局外灵魂结晶不影响局内银币。两套货币体系解耦，避免局内体验被局外强度直接碾压（局外只影响基础属性门槛，不影响局内操作策略）。

**待验证的关键问题**：
1. 失败是否输出有意义的局外进度（失败补偿是否存在且足够）
2. 银币积累速度与建造消耗的平衡点（过松→无策略感；过紧→挫败感）
3. 广告变现的触发场景（是否影响局内公平性）
