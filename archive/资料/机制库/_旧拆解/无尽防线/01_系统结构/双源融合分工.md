## 层间接口关系

```
局外成长 → 执行层：
  骑士升星 → 骑士塔基础属性上限提升
  设施建造 → 白天可用塔型/建造速度影响
  地块解锁 → 关卡可用地形和位置选择扩展

构筑层 → 执行层：
  选择骑士塔 BUFF → 在领地生成该骑士塔实例
  选择技能 BUFF → 国王/防御塔获得主动/被动技能
  选择属性 BUFF → 全局伤害/防御属性修正

执行层 → 构筑层（反向）：
  每波通过 → 获得升级经验 → 触发下次三选一
  国王击杀 → 积累经验加速（正反馈）
```

## 关键融合约束

**约束 1：执行层决策时机分离**
白天建造（空间规划）+ 夜晚国王操控（实时反应）+ 升级BUFF选择（阶段策略）三种决策时机分离，认知负担可控。若三者同步要求，体验崩溃。

**约束 2：骑士塔不能是"自动行走"单位**
骑士塔是固定站位型，不能是跟随国王移动的NPC骑士。原因：若骑士也需要玩家指挥，与国王操控叠加形成操作冲突（参考 Thronefall 的暂停机制解决了这个问题，但手游没有暂停）。

**约束 3：构筑感依赖路线件质量**
若骑士塔 BUFF 之间无协同效果（仅独立数值强化），则三选一退化为纯数值选择，构筑感消失。这是最大的不确定性风险点。
