# 寻道大千 — 系统分层与接口

> 阶段二产出。基于阶段一全景清单，将所有系统按层级归类，标注接口关系。
> 信息来源：联网搜索（知乎、TapTap、豆瓣、九游、红手指、NBE、3DM 等攻略站）。未标注置信度的条目默认 confirmed。

---

## 一、层级归属表

### 执行层（玩家直接操作的最小单元）

| 系统 | 职责边界 | 置信度 |
|---|---|---|
| 砍树挂机 | 玩家点击/挂机砍树，产出仙桃、灵玉、装备；不负责装备属性计算，不负责战斗 | confirmed |
| 推图关卡 | 自动战斗 PVE，消耗仙桃推进关卡，验证养成强度；不负责资源产出调度（资源由通关奖励固定给） | confirmed |
| PVP 斗法 | 1v1 异步 PVP，消耗挑战券入场，排名产出奖励；不负责养成数值本身，只读取最终战力 | confirmed |
| 福地采集 | 派遣鼠宝采集仙桃/净瓶水/灵石等资源；不负责资源消耗，纯产出端 | confirmed |
| 妖王扫荡 | 每日扫荡已解锁最高妖王，消耗仙玉（首次免费），产出大量仙桃；修为等级决定解锁进度 | confirmed |
| 镇妖塔 | 逐层挑战 PVE 副本，产出仙草（灵脉激发材料）；进度受战力限制，提供周期性挑战目标 | confirmed |

### 路线层 / 构筑层（玩家做什么决策，决定养成方向）

| 系统 | 职责边界 | 置信度 |
|---|---|---|
| 流派系统 | 连爆/闪避/反击等流派选择，决定灵兽、精怪、神通、灵脉的搭配方向；不直接提供属性，是"选择框架" | confirmed |
| 灵兽养成/洗练 | 灵兽选择 + 技能词条洗练，核心付费深坑；洗练消耗涤仙露/不化岩；御灵石用于灵兽兑换和升级（非洗练）；流派决定洗练目标词条 | confirmed |
| 精怪系统 | 战斗效果触发（如鬼将全程触发），所有精怪属性加成永久生效无需上阵；与流派强绑定 | confirmed |
| 神通系统 | 主动/被动战斗技能，通过轮回殿付费抽取获取；流派决定优先升级哪些神通 | confirmed |
| 灵脉系统 | 消耗仙草激发灵脉，获得灵髓 → 觉醒血脉（朱雀/白虎/青龙/玄武/勾陈/螣蛇）；流派决定灵脉选择方向（如闪避流→四勾陈） | confirmed |
| 分身系统 | 同时运营三个角色，体验不同流派；每个分身独立选择装备/灵兽/流派 | confirmed |

### 底盘成长层（提供基础数值，不涉及方向选择）

| 系统 | 职责边界 | 置信度 |
|---|---|---|
| 修为/等级 | 分解装备获取修为 → 升级 → 解锁功能上限 + 解锁妖王等级；不决定流派方向 | confirmed |
| 装备系统 | 12 部位装备，提供基础属性；阶级重置时强制换代；不负责流派选择 | confirmed |
| 法宝系统 | 装备法宝提供额外属性；信息较少（存在但未深拆） | confirmed |
| 仙友系统 | NPC 好感度养成，提升属性和天赋；提供鼠宝采集效率加成（存在但未深拆） | confirmed |
| 内丹系统 | 灵兽附属强化（与灵兽轮回一同出现）（存在但未深拆） | inferred：仅从轮回殿活动资料推断 |
| 玄诀系统 | 精怪附属/搭配系统（与精怪轮回一同出现）（存在但未深拆） | inferred：仅从轮回殿活动资料推断 |
| 仙居系统 | 家园系统，功能建筑（灵田/炼丹炉/仙桃树）提供被动产出；仙居升级提升道友属性 | confirmed |

### 经济层（资源的产出、流转、消耗调度）

| 系统 | 职责边界 | 置信度 |
|---|---|---|
| 仙桃（桃子） | 体力货币：砍树/福地/妖王/月卡/广告产出 → 推图消耗；核心行为燃料 | confirmed |
| 仙玉 | 付费货币：充值/活动产出 → 购买御灵石/妖王扫荡/商店/轮回殿抽取；最高级通用货币 | confirmed |
| 修为 | 经验货币：分解装备获得 → 升级消耗；升级解锁妖王/功能 | confirmed |
| 涤仙露/不化岩 | 洗练货币：攻城战/活动/任务产出 → 灵兽技能洗练消耗；核心付费深坑的瓶颈资源 | confirmed |
| 御灵石 | 灵兽养成货币：100 仙玉 = 10 御灵石；福地/妖盟/轮回殿/仙缘任务产出 → 灵兽升级消耗 | confirmed |
| 灵石 | 神通升级货币：福地/活动产出 → 神通升级消耗 | confirmed |
| 挑战券 | PVP 入场券：每日自然恢复 → PVP 斗法消耗 | confirmed |
| 甘露/黄花 | 活动货币：妖盟活动产出 → 活动商店兑换 | confirmed |
| 净瓶水 | 仙树升级材料：福地/冒险/活动产出 → 仙树升级消耗（仙树等级提升砍树效率） | confirmed |
| 仙草 | 灵脉激发材料：镇妖塔/活动产出 → 灵脉激发消耗 | confirmed |

### 节奏框架层（控制游戏节奏和长线留存的结构性机制）

| 系统 | 职责边界 | 置信度 |
|---|---|---|
| 阶级重置 | 每 100 关强制装备换代，消解已有养成积累；不改变流派选择，只重置底盘数值 | confirmed |
| 轮回殿 | 按灵兽→精怪→神通→法宝顺序轮转（每轮 7 天），集中提供对应养成资源和付费返利；控制养成节奏 | confirmed |
| 赛季机制 | 活动赛季积分重置 + 新区/新服机制；赛季周期和完整重置范围资料不足 | confirmed（存在性）/ unknown（具体重置范围） |
| 仙树等级 | 砍树效率的元进度：净瓶水升级仙树 → 提升砍树产出上限 → 更多仙桃 | confirmed |

## 二、系统间接口关系

### 核心数据流（谁传递什么给谁）

```
砍树挂机 ──产出：仙桃/装备──→ 推图关卡（消耗仙桃推图）
                │                    │
                │                    ├──通关奖励：仙桃/净瓶水/装备──→ 砍树挂机（净瓶水升仙树）
                │                    │
                ├──产出：装备──→ 装备系统（穿戴/分解）
                │                    │
                │                    └──分解产出：修为──→ 修为/等级（升级）
                │                                          │
                │                                          └──解锁：妖王等级──→ 妖王扫荡（产出仙桃）
                │
                └──产出：灵玉/仙玉──→ 经济池
```

### 构筑层接口

| 接口 | 传递内容 | 置信度 |
|---|---|---|
| 流派系统 → 灵兽洗练 | 目标词条方向（如连爆流需要连击+暴击词条） | confirmed |
| 流派系统 → 精怪系统 | 精怪选择优先级（如闪避流优先鬼将） | confirmed |
| 流派系统 → 神通系统 | 神通升级优先级（如连爆流优先连击相关神通） | confirmed |
| 流派系统 → 灵脉系统 | 灵脉血脉选择（如闪避流→四勾陈，连爆流→四青龙） | confirmed |
| 流派系统 → 分身系统 | 每个分身可选不同流派，复用构筑层全套选择 | confirmed |
| 灵兽洗练 → 战斗执行 | 技能词条效果直接参与自动战斗计算 | confirmed |
| 精怪系统 → 战斗执行 | 精怪触发效果参与战斗（且全精怪属性永久生效） | confirmed |
| 神通系统 → 战斗执行 | 主动/被动技能参与战斗 | confirmed |
| 灵脉系统 → 战斗执行 | 血脉属性加成参与战斗 | confirmed |

### 经济层接口

| 接口 | 传递内容 | 置信度 |
|---|---|---|
| 仙玉 → 御灵石 | 100 仙玉兑换 10 御灵石（核心付费转化点） | confirmed |
| 御灵石 → 灵兽升级 | 灵兽升级/培养的主要消耗 | confirmed |
| 涤仙露/不化岩 → 灵兽洗练 | 技能词条洗练的瓶颈材料 | confirmed |
| 妖盟攻城战 → 涤仙露/不化岩 | 攻城战每次结算产出 50-80 不化岩 + 排名奖励涤仙露 | confirmed |
| 仙桃 → 推图关卡 | 推图消耗体力 | confirmed |
| 仙桃 → 仙树升级（间接） | 更多仙桃 → 更多推图 → 更多净瓶水 → 仙树升级 → 更高砍树效率 | confirmed |
| 灵石 → 神通升级 | 神通升级消耗 | confirmed |
| 仙草 → 灵脉激发 | 灵脉激发消耗 | confirmed |

### 节奏层接口

| 接口 | 传递内容 | 置信度 |
|---|---|---|
| 阶级重置 → 装备系统 | 每 100 关强制装备换代，清空当前装备价值 | confirmed |
| 阶级重置 → 修为需求 | 换代后需要重新分解装备获取修为 | inferred：基于阶级重置清空装备后需重新养成推导 |
| 轮回殿 → 灵兽/精怪/神通/法宝 | 按 7 天轮转窗口集中投放对应养成资源和付费礼包 | confirmed |
| 轮回殿 → 商业化 | 轮回殿是核心付费返利窗口，针对五大养成线刺激消费 | confirmed |
| 仙树等级 → 砍树产出 | 仙树等级越高，单次砍树资源产出越多 | confirmed |

## 三、层级结构总览（文本描述）

```
┌─────────────────────────────────────────────────────┐
│                    商业化层                           │
│  月卡 / 终身卡 / 基金 / 付费抽取 / 礼包 / 仙缘      │
│  （为所有层提供付费加速通道）                          │
└───────────────────────┬─────────────────────────────┘
                        │ 仙玉/资源注入
┌───────────────────────▼─────────────────────────────┐
│                   节奏框架层                          │
│  阶级重置 / 轮回殿 / 赛季机制 / 仙树等级              │
│  （控制养成节奏：何时消解、何时集中投放、何时重置）      │
└───────────────────────┬─────────────────────────────┘
                        │ 节奏约束
┌───────────────────────▼─────────────────────────────┐
│                    经济层                             │
│  仙桃 / 仙玉 / 修为 / 涤仙露 / 不化岩 / 御灵石       │
│  / 灵石 / 挑战券 / 甘露 / 净瓶水 / 仙草               │
│  （所有资源的产出-消耗调度）                           │
└──────┬──────────────────────────────┬───────────────┘
       │ 资源供给                      │ 资源供给
┌──────▼──────────┐          ┌────────▼──────────────┐
│   底盘成长层     │          │    路线层/构筑层       │
│ 修为/装备/法宝   │          │ 流派/灵兽洗练/精怪    │
│ /仙友/内丹/玄诀  │          │ /神通/灵脉/分身       │
│ /仙居            │          │ （方向选择 + 深度投入）│
│（基础数值底盘）   │          │                       │
└──────┬──────────┘          └────────┬──────────────┘
       │ 数值输入                      │ 构筑效果
┌──────▼──────────────────────────────▼──────────────┐
│                    执行层                            │
│  砍树挂机 / 推图关卡 / PVP斗法 / 福地采集 / 妖王扫荡 │
│  （玩家直接操作 + 战斗验证）                          │
└──────┬──────────────────────────────────────────────┘
       │ 社交需求/竞争压力
┌──────▼──────────────────────────────────────────────┐
│                    社交层                             │
│  妖盟 / 攻城战 / 巅峰妖盟战 / 各类战场 / 排行榜      │
│  / 好友 / 聊天 / 组队                                │
│  （提供竞争动机 + 稀缺资源产出端）                     │
└─────────────────────────────────────────────────────┘
```

说明：
- 社交层放在底部不代表优先级低，而是表示它从执行层/构筑层接收玩家战力数据，反向输出竞争压力和稀缺资源
- 商业化层覆盖所有层级，但主要付费深坑集中在构筑层（灵兽洗练）和节奏框架层（轮回殿）
- 箭头方向 = 数据/资源流向，不代表玩家操作顺序
