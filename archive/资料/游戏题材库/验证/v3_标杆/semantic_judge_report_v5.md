## 真实错例清单

### art_style(本轮重点)

- **《末世铁路王国》**:gold `日式3D写实` vs LLM `美式3D写实`。日式/美式画风桶判错,核心维度错位。

其余 29 款画风字段全部语义一致:
- 独特画风桶全部保留(雷顿"童话绘本"、动森/牧场/任天狗"Q 版萌系"、死亡细胞"像素风"细化为"美式像素"可接受、大金刚"美式卡通"/"美式 3D 卡通"等价、八方旅人"日式像素");
- 日式 3D 写实 / 日式 3D 动漫 / 日式 2D 动漫 / 美式 3D 写实 全部正确归桶;
- 2D/3D 判断 30/30 全对(v5 新增硬约束生效)。

### world_setting

- **《死亡细胞》**:gold `中世纪+末世` vs LLM `中世纪奇幻+孤岛`,缺"末世"这一关键背景。
- **《八方旅人 2》**:gold `古代奇幻+蒸汽朋克` vs LLM `中世纪奇幻`,缺"蒸汽朋克"(HD-2D 世界含工业要素)。
- **《雷顿教授》**:gold `蒸汽朋克+古代奇幻` vs LLM `古代奇幻+欧洲乡村`,缺"蒸汽朋克"。

### ip_skin

- **《宝可梦+信长的野望》**:gold `宝可梦+信长野望` vs LLM `宝可梦`,跨界 IP 只标了一半。
- **《任天狗 + 猫》**:gold 留空(原生作品) vs LLM `任天狗`,误把自有作品名当作 IP 皮。

### core_verb

- **《末世铁路王国》**:gold `经营+建造+列车搜打撤` vs LLM `铁路经营+生存策略`,缺"搜打撤"这一核心动词机制。

### core_object / narrative_core

无关键缺失,语义全通过。

## 总体质量判断

**5/5**。
总体命中 96.1%,art_style 从 76.7% 跃升到 96.7%,v5 新增的「2D/3D 硬约束 + 独特画风桶保留」两条规则完全奏效;30 款里 2D/3D 误判清零,独特桶(像素/绘本/Q 版/卡通)全部正确保留。剩余错例集中在跨界 IP 拆分、原生作品误标 IP、辅助世界设定缺失,这些是 prompt 边界问题而非系统性退步。
