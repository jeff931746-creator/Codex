# 30 款语义判分报告

判分原则:不字面比对,只看语义实质;同义不同字、顺序差异、更细同义词描述均视为通过。

## 真实错例清单

### 字段 ip_skin 错例(9 例,系统性遗漏)

LLM 在 9 款明显有 IP 的游戏上把 ip_skin 留空,这是最大的系统性问题:

- **怪物猎人 崛起** 黄金"怪物猎人" / LLM"" — 经典 IP 系列,不应留空
- **牧场物语 橄榄镇** 黄金"牧场物语" / LLM"" — 标题已含 IP
- **火焰之纹章 觉醒** 黄金"火焰之纹章" / LLM"" — 标题已含 IP
- **塞尔达传说 王国之泪** 黄金"塞尔达" / LLM"" — 同上
- **异度神剑 2** 黄金"异度神剑" / LLM"" — 同上
- **奇异人生 Switch 版** 黄金"奇异人生" / LLM"" — 同上
- **心跳文学部 Plus!** 黄金"心跳文学部" / LLM"" — 同上
- **模拟人生 4** 黄金"模拟人生" / LLM"" — 同上
- **八方旅人 2** 黄金"八方旅人" / LLM"" — 同上

为什么错:LLM 把"原创 IP/任天堂第一方"等情况判为"无 IP 皮"。但 ip_skin 字段定义是"系列/IP 名称",只要属于已建立的系列就应填,与是否第三方授权改编无关。判定规则不清晰。

### 字段 art_style 错例(5 例)

- **牧场物语 橄榄镇** 黄金"Q版萌系" / LLM"日式 3D 动漫" — 牧物 3D 版美术偏 Q 版萌系,LLM 用通用日式动漫覆盖,丢失了"萌系"特征
- **暗杀教室 杀老师大决战** 黄金"日式2D动漫" / LLM"日式 3D 动漫" — 该作是 2D 立绘+小游戏,LLM 误判为 3D
- **末世铁路王国** 黄金"日式3D写实" / LLM"蒸汽朋克美术" — LLM 把题材当美术风格描述,字段维度错位
- **雷顿教授** 黄金"童话绘本" / LLM"日式 2D 动漫" — 雷顿系列标志性的水彩童话绘本风未被识别
- **模拟人生 4** 黄金"美式3D写实" / LLM"美式卡通" — 风格判断分歧(此处遵从黄金标准)

### 字段 world_setting 错例(4 例)

- **异度神剑 2** 黄金["古代奇幻","云海"] / LLM["科幻","奇幻"] — "云海"这一标志性世界观缺失,且"科幻"定性不准
- **心跳文学部 Plus!** 黄金["校园","虚拟世界"] / LLM["现代都市","校园"] — 缺"虚拟世界",这是元叙事的关键世界观
- **死亡细胞** 黄金["中世纪","末世"] / LLM["中世纪奇幻","黑暗奇幻"] — "末世"被换成"黑暗奇幻",语义偏离
- **集合啦!动物森友会** 黄金["孤岛"] / LLM["现代都市","奇幻"] — 完全不沾边,核心世界观是无人岛而非现代都市

### 字段 core_verb 错例(3 例)

- **哈利波特 魔法觉醒** 黄金"卡牌构筑+决斗+社团社交" / LLM"卡牌构筑+即时对战+角色养成" — "社团社交"是该手游核心机制,被"角色养成"替代后丢失
- **异度神剑 2** 黄金"JRPG战斗+异刃收集羁绊" / LLM"3D角色扮演+自动攻击+技能连携" — "异刃收集羁绊"是核心系统,LLM 只给了战斗手感
- **女神异闻录 5 皇家版** 黄金"回合制JRPG+社交养成+怪盗潜行" / LLM"3D角色扮演+回合制战斗+日常养成" — "怪盗潜行"标志机制缺失

### 字段 narrative_core 错例(3 例)

- **火焰之纹章 觉醒** 黄金"战棋战斗+角色之间结婚生子+次代继承的羁绊养成" / LLM"在网格战场上指挥单位进行回合制战斗并培养角色关系" — "结婚生子+次代继承"是觉醒区别于其他 FE 作的关键卖点,LLM 用通用"角色关系"虚化
- **异度神剑 2** 黄金"巨神之上的世界探索+异刃收集养成+救世剧情" / LLM"在巨神兽身体上展开的开放世界日式角色扮演" — "异刃收集"机制再次缺失
- **押忍!战斗!应援团** 黄金"看一个个平凡人陷入困境→用节奏触屏指挥应援团帮他们解决" / LLM"以触屏节奏点击为核心、用应援团助威包装的音乐节奏游戏" — "平凡人困境的情景剧叙事"丢失,只剩节奏游戏壳

### 字段 core_object 错例(1 例)

- **押忍!战斗!应援团** 黄金"平凡人困境" / LLM"节拍标记/应援场景" — 同上,情景剧的叙事主体缺失

## 总体质量判断

**4 分(可用,需小修)**。LLM 整体能抓住玩法本体、避免上轮"把题材壳当本体"的教训,玩法动词、对象、叙事核心三个核心字段命中率都在 90% 以上;但有两个系统性问题需要修补——ip_skin 对原创/第一方 IP 漏填(9 例),art_style 偶尔会把"题材/年代"当成美术风格(末世铁路、雷顿教授)。

## 推荐下一步

**命中率 86.1% ≥ 85%,但建议先补两条 prompt 硬约束再全量重打 1562 款:**

1. **ip_skin 字段规则收紧**:明确"凡是属于已建立游戏系列(怪物猎人、塞尔达、宝可梦、模拟人生、异度神剑、心跳文学部、八方旅人等),即使是原创 IP 而非改编,也必须填该系列名;只有完全原创单作才留空"。
2. **art_style 维度对齐**:明确该字段只填"画面技法 + 美术风格"(如日式 3D 写实/Q 版萌系/童话绘本/像素风/美式卡通),不能填题材类(蒸汽朋克美术、末世风等)。
3. **关键机制保留**:对带标志性子系统的作品(异刃收集、怪盗潜行、社团社交、结婚生子+次代继承、情景剧叙事),要求 core_verb 或 narrative_core 至少其一保留原始关键词,避免被"角色养成/日常养成"等通用词稀释。

补好这三条 prompt 约束后即可启动全量重打。
