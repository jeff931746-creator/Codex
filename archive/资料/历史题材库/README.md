## 核心设计

### 主数据单元化

每部作品 = 一个 `.md` 文件 + yaml frontmatter,不再用汇总表。优势:

- 单作品的字段是机器可消费的真相源
- 任意维度的索引(按年份/按母题/按象限)从样本派生,不重复存
- 增量更新简单(新作品 = 新文件,改作品 = 改文件)

### SDT 三需求 + 任务态 T

情绪字段从旧的 6 大情绪(SUR/POW/EXP/HEA/GRO/BRE)改为 SDT 三需求(N-Comp/N-Auto/N-Rel)+ 任务态 T。理由:

- SDT 是用户底层心理锚点,跨题材稳定
- 直接对接人群簇 v1.2 / 玩法承接 v1.1 的 N 字段
- 母题归并仍按 6 大类做大类编号,但单作品判定走 SDT

### 母题归并独立目录

`母题归并/` 作为"历史题材库 ↔ 三位一体题材母题库"的桥梁。每个母题一份文件,聚合归属作品 + 代表作清单,反向喂给 02 标准。

### DeepSeek 跑批两阶段

- **任务 1**:逐条单作品打标,默认 mother_theme_id 填 THM-UNK-001
- **任务 2**:自下而上聚类形成 15-25 个正式母题,回写样本的 mother_theme_id

不要求 DeepSeek 一开始就有正确的母题列表。
