# 提示词 02:母题归并

> 用于:DeepSeek 跑批任务 2(母题归并 / 自下而上聚类)
> 配套:[SCHEMA.md](../SCHEMA.md) / [母题归并/README.md](../母题归并/README.md)
> 更新日期:2026-05-15

---

## 调用方式

任务 2 分两步,需要两次 DeepSeek 调用:

- **调用 A(聚类发现)**:按"母题情绪大类(02 标准的 SUR/POW/EXP/HEA/GRO/BRE)+ n_main(SDT 三需求)"双轴分组,让 DeepSeek 在组内自下而上聚类出 3-5 个母题候选
- **调用 B(代表作筛选)**:母题列表确定后,让 DeepSeek 从该母题的全部归属作品中挑 5-10 部代表作

> ⚠️ 概念区分:**6 大类(SUR/POW/EXP/HEA/GRO/BRE)是母题情绪分类**(来自 02-题材母题标准),**SDT 三需求(N-Comp/N-Auto/N-Rel)是底层心理需求**(来自 03-玩法承接标准)。两套轴并存使用,不要混称为"SDT 大类"。

---

## 调用 A — 聚类发现

### 系统提示

```
你是游戏题材分析师。我会给你一组作品(同一"母题情绪大类 + n_main"组合),请你基于作品的 environment / cultural_paradigm / narrative_core / core_conflict 四个字段,做自下而上聚类。

注意:
- **母题情绪大类**(SUR/POW/EXP/HEA/GRO/BRE)= 02-题材母题标准定义的 6 大母题情绪分类,描述母题层面的情绪基调
- **SDT 三需求**(N-Comp/N-Auto/N-Rel)= 03-玩法承接标准定义的底层心理需求,描述用户长期粘性来源
- 两者并存使用,不是同一个轴

聚类目标:从这组作品中识别出 3-5 个"题材母题"。

母题定义(参考 02-题材母题标准):
- 母题 = 玩家能识别的稳定情绪 + 冲突结构
- 母题数量在整个库内 15-25 个,本组贡献 3-5 个
- 母题名 ≤ 8 字,包含"情绪 + 冲突"两部分(如"末世求生"、"权力博弈"、"成长复仇")
- 避免具体题材标签(如"末世丧尸"是具体题材,不是母题)

聚类原则:
- 同母题的作品,其 core_conflict 应该结构相似
- 同母题的作品,其 narrative_core 应该指向相同情绪体验
- 一个作品可主属一个母题,可兼属 1-2 个副母题
```

### 用户提示模板

```
[输入]
母题情绪大类:{category}         # 02 标准的 SUR / POW / EXP / HEA / GRO / BRE 之一
n_main:{N-Comp / N-Auto / N-Rel}  # SDT 三需求
作品列表(共 {N} 部):

{对每部作品输出以下结构}
- work_id: WORK-ANI-00001
  work_name: 进击的巨人
  environment: "19世纪欧洲风奇幻世界 + 巨墙城邦"
  cultural_paradigm: "军事化抵抗 + 调查兵团体系"
  narrative_core: "在末日威胁中守墙并揭开世界真相"
  core_conflict: "人类对抗巨人 + 内部权力博弈"
  t_can_carry: [T2, T1]
  acquisition_score: 5
  roi_score: 4

...(N 部作品全部列出)

[输出要求]
按以下 yaml 模板输出 3-5 个母题候选,不要加额外解释:

motif_candidates:
  - motif_name: "末世求生"
    motif_name_en: "Apocalypse Survival"        # 选填,英文名
    core_emotion: "求生压力 + 紧张感"
    core_conflict: "在崩溃世界中守住自己和重要的人"
    theme_elements:
      environment: "母题适用的世界观范围,如'末世废土/核冬天/海底崩溃/奇幻末世'"
      cultural_paradigm: "母题导出的核心系统,如'资源管理 + 生存系统'"
      narrative_core: "母题的核心叙事张力"
    member_work_ids: [WORK-ANI-00001, WORK-TVW-00042, ...]    # 归属本母题的作品 ID
    representative_hint: [WORK-ANI-00001, WORK-TVW-00042, ...]  # 建议代表作 5-10 部(后续单独筛)
    confidence: high | medium | low
    notes: "为什么聚成这个母题,什么作品是临界样本"
  - motif_name: ...
  ...

orphan_works: []   # 无法归入任何候选母题的作品 ID 列表,等下一轮重判
```

### 聚类判定要点

- **不要按题材标签聚类**(如把所有"丧尸"作品聚一起)
- **按 core_conflict 结构聚类**:同样是 N-Comp + T2,"主角变强对抗外敌"和"主角破解世界秘密"是不同母题
- **临界样本进 confidence: medium 或 low**,在 notes 写明摇摆理由
- **完全无法归类的进 orphan_works**,不强行塞进某母题

## 调用 B — 代表作筛选

### 系统提示

```
你是游戏题材分析师。母题列表已经确定,现在请你从某个母题的全部归属作品中,挑选 5-10 部最具代表性的作品。

代表作选择标准:
1. acquisition_score + roi_score 综合分高(优先)
2. 跨媒介覆盖(动漫/影视/文学各有代表)
3. 跨年份覆盖(2000-2026 不同时代各有代表)
4. 母题特征清晰(能让人一眼看出母题特点)

输出代表作的同时,标记母题在该作品中的"特殊表达"(如《辐射》是"末世求生"的核武器+复古未来主义变体)。
```

### 用户提示模板

```
[输入]
母题:{mother_theme_id} {mother_theme_name}
母题描述:
  core_emotion: ...
  core_conflict: ...
  theme_elements: ...

归属作品(共 {N} 部):
{对每部作品给完整字段,同调用 A}

[输出]
representative_works:
  - work_id: WORK-ANI-00001
    work_name: "进击的巨人"
    rank_score: 9.0                      # acquisition + roi 综合,0-10
    特殊表达: "巨人压迫 + 立体机动战斗 + 反转世界观"
    representativeness: high              # high/medium
  - work_id: ...
  ...(5-10 部)

excluded_works:                          # 被排除作品的简要说明(选填)
  - work_id: WORK-XXX
    reason: "属于本母题但表达过于边缘"
```

---

## 调用后的脚本动作

1. **聚类发现后**:
   - 人工 review motif_candidates
   - 分配正式 mother_theme_id(THM-{category}-{编号})
   - 写入 `母题归并/THM-*.md`
   - 回写每个 member_work_id 对应样本的 mother_theme_id 和 motif_confidence

2. **代表作筛选后**:
   - 把 representative_works 写入 `母题归并/THM-*.md` 的 representative_works 字段
   - 在样本的 yaml 里**不**保存"是否代表作"字段(避免双向引用),代表作清单只在母题文件维护

---

## 边界情况

- **母题候选 < 3 个**:可能是分组太碎,合并相邻母题情绪大类重跑
- **母题候选 > 5 个**:可能是聚类粒度过细,提高聚类阈值或合并相似母题
- **orphan_works 比例 > 10%**:可能是大类划分不合适,重审 n_main 判定
- **新母题与已有母题(其他大类)重叠**:不允许,母题之间互斥;重叠时按 dominant 母题情绪大类归到一个
