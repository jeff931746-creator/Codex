# 提示词 03:交叉校验

> 用于:DeepSeek 跑批的一致性校验(可选,质量门禁加强)
> 配套:[SCHEMA.md](../SCHEMA.md) / [录入工作流.md](../录入工作流.md)
> 更新日期:2026-05-15

---

## 用途

任务 1 跑批是逐条独立调用,容易出现:

- 同类作品 N 字段判定不一致(如同是"丧尸生存"类,A 判 N-Comp,B 判 N-Rel)
- 同 IP 不同作品评分跨度过大(如《进击的巨人》动画 5/4 但同名漫画 3/2)
- 三要素字段在同题材中差异过大

本提示词用于**抽样交叉校验**,捕捉这些不一致。

---

## 触发场景

- 任务 1 全量跑完后,在归档前抽样 5-10% 做交叉校验
- DeepSeek 跑批中途质量飘移时(单批抽样)
- 任务 2 母题归并前的预筛查

---

## 系统提示

```
你是游戏题材分析师。我会给你一组主题相似或同 IP 的作品,请你检查它们在 SCHEMA 字段上的一致性,标出明显不一致的项。

校验维度:
1. n_main / n_others / rel_object — 同主题作品 N 字段应基本一致
2. t_can_carry — 同主题作品 T 字段应在合理范围内重叠
3. environment / cultural_paradigm / narrative_core — 同 IP 应基本一致
4. acquisition_score / roi_score — 同 IP 评分跨度不应过大(>2 算异常)
5. mother_theme_id — 任务 2 后,同主题应归属同一母题或相邻母题

输出:不一致清单 + 建议修正方向。
```

---

## 用户提示模板

```
[输入类型]
{select_one}:
  - "同 IP 多媒介":同 IP 的不同媒介改编(如《沙丘》小说 + 电影 + 剧集)
  - "同主题样本":同 mother_theme_id 或同聚类的多部作品
  - "随机抽样":随机抽 10 部检查整体质量

[作品列表]
{对每部作品列出完整 yaml frontmatter}

[输出]
inconsistencies:
  - field: n_main
    work_a: WORK-LIT-00012(沙丘 小说)
    work_a_value: N-Comp
    work_b: WORK-MVW-00088(沙丘 电影)
    work_b_value: N-Rel
    severity: high | medium | low
    suggested_fix: "电影更突出 N-Comp 战斗胜任,建议改为 N-Comp"
  - ...

quality_notes:
  - "整体字段一致性良好" 或 "建议复查 X 类作品"
```

---

## 校验后的脚本动作

1. severity: high 的不一致 → 自动把涉及的样本 review_status 改为 disputed
2. severity: medium/low → 写入跑批日志,人工 review 决定是否修正
3. 累计不一致率 > 5% → 暂停跑批,审查 01_单作品打标.md 提示词是否需要细化判据
