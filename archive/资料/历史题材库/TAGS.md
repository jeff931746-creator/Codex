## 一、三层标签设计

| 层 | 字段名 | 类型 | 数量 | 用途 |
|---|---|---|---|---|
| L1 主题大类 | `theme_primary` | 单选 | 30 个枚举 | 主目录 / 主筛选轴 |
| L2 子题材 | `theme_secondary` | 多选 2-5 个 | ~100 候选 | 细分筛选 |
| L3 视觉标签 | `visual_tags` | 多选 2-5 个 | ~100 候选 + 允许新增 | 素材定位 / 视觉聚类 |

**判定原则**:
- L1 必填,**严格**从枚举选,不允许自创
- L2 必填 2-5 个,**严格**从候选选,不允许自创(候选不够用时反向补充本文件)
- L3 必填 2-5 个,**半开放**:候选优先,LLM 可新增(新增标签后续脚本统计合并)

**L3 选择原则**:

**新增规则**:LLM 跑批时如遇候选不够用,可新增标签,跑完后由脚本统计相似度合并到候选库。

## 五、与现有字段的关系

| 字段 | 与新标签的关系 |
|---|---|
| `environment` | L1 + L2 的"描述形式"。三层标签是"枚举形式"。两者互补 |
| `cultural_paradigm` | 描述作品的核心系统,**与三层标签独立**,不重叠 |
| `narrative_core` | 描述核心叙事,**与三层标签独立** |
| `core_conflict` | 描述核心冲突,**与三层标签独立** |
| `material_hooks` | 视觉钩子(3-5 个),与 L3 视觉标签**部分重叠**,但更具体(如"巨人压迫感")。L3 是"分类标签",material_hooks 是"具体钩子" |
| `n_main / t_can_carry` | SDT 心理需求 / 任务态,**与三层标签独立**(独立维度的检索) |
