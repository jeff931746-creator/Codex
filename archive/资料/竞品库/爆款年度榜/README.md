# 爆款年度榜

按平台分目录，年份做文件名。

## 目录结构

```
爆款年度榜/
├── Steam/                  Steam 平台爆款（2015-2026）
├── 微信小游戏/             微信小游戏爆款（2015-2026）
├── 手游/                   iOS / Android 原生手游（预留，待补充）
├── 任天堂/
│   ├── Switch/             Nintendo Switch（预留，待补充）
│   └── NDS/                Nintendo DS / 3DS（预留，待补充）
└── _原始备份/              拆分前的旧结构 12 个年份合并文件，确认无误后可删除
```

## 命名约定

- 文件名：`{年份}.md`，例如 `Steam/2024.md`
- 一级标题：`# {年份} {平台} 爆款`
- 表格三列：`游戏名 | 类型标签 | 一句话特色`

## 新增平台

新增平台时在本目录下建同级子目录，遵循同样的文件命名与表格结构。
