# 竞品库

外部游戏产品信息沉淀库。新品上线、产品数据、榜单表现、玩法拆解。

## 核心原则

**新产品全入库，不筛选。** 信息不完整也入库，后续有新信息时更新同一文件。

## 标准层级

```
reference/部门标准/信息收集/信息收集标准.md   ← 跨库通用标准
本目录/SCHEMA.md                             ← 竞品库专属 Schema（产品级）
```

## 目录结构

```
竞品库/
├── README.md
├── SCHEMA.md
├── {品类}/           按主品类分目录，每个产品一个 .md
│   └── {产品名}.md
└── 索引/
    ├── 按时间.md
    ├── 按品类.md
    └── 按平台.md
```

## 与战略库的关系

同一篇文章可能同时产出：
- 竞品库条目（产品级信息：这个游戏是什么、数据如何）
- 战略库条目（文章级信息：行业分析、市场洞察）

两个库独立存储，通过 URL 关联。

## 快速入口

| 我要做什么 | 看哪里 |

| 了解产品级字段和规则 | [SCHEMA.md](SCHEMA.md) |
| 按时间查看最近发现的产品 | 索引/按时间.md |
| 按品类查看产品 | 索引/按品类.md |
