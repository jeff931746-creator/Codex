## 题材母题要解决的核心问题

**题材母题不是"题材分类的索引",是"被人性需求/心理任务调动的题材结构"的索引。**

服务对象:**基于人性需求探索新题材方向**。

不复制已有的常规题材(常规题材在买量端没有优势),目标是沉淀**未被充分开发但有内在契合论证**的题材方向。

## 核心逻辑链

立项时题材的真正功能:**激活用户的人性需求/心理任务**。

```
题材 (有现成调教来源)
  ↓ 激活
人性需求 / 心理任务清单
  ↓ 对齐
人群簇 (`reference/部门标准/立项/三位一体框架/current/01-人群簇标准.md`)
  ↓ 承接
玩法 (玩法库,待 v2 建立)
  ↓ 表达
买量素材
```

母题库的工作是**第一层和第二层**:把题材"激活什么心理任务"沉淀清楚,让后续层级可以反查。

## 与三位一体框架的对齐

三位一体框架要求题材母题:

- 命名 ≤ 8 字
- 情绪 + 冲突结构,**不带玩法、不带具体题材标签**
- 6 大主情绪分类(SUR/POW/EXP/HEA/GRO/BRE)
- 每个母题数量 3-5 个,总数 15-25 个
- 字段包括 representative_games / theme_examples / audience_ids / playstyle_ids

本地题材库在此基础上**追加两条硬约束**:

| 约束 | 内容 | 理由 |
|---|---|---|
| 中重度承接约束 | 母题入库必须有 ≥1 个中重度 ≥3 年长线产品 | 短线产品的题材逻辑不外推,常规化轻度题材淘汰 |
| 去短剧约束 | 母题的 representative_games / theme_examples 不允许来自短剧 IP(任何"小说/短剧""短剧/小说""短剧/动漫"混合来源都不进) | 短剧爆点结构和长线游戏调性冲突 |
| 反"常规"约束 | 母题不为常规题材服务(常规题材买量端无优势);要为"基于人性需求探索新题材"服务 | 用户明确表态:常规题材不入库 |

## 题材母题字段结构

每个母题字段表对应"题材激活心理任务"逻辑,字段如下:

### 必填字段(对齐三位一体框架)

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | 字符串 | 格式 `THM-{大类}-{编号}`,永不修改 |
| `name` | 字符串 | 母题名称(≤8字,情绪+冲突结构,不带玩法、不带"族") |
| `category` | 枚举 | SUR / POW / EXP / HEA / GRO / BRE |
| `core_emotion` | 字符串 | 核心情绪(一句话) |
| `core_conflict` | 字符串 | 核心冲突(一句话) |
| `representative_games` | 数组 | ≥3 个中重度长线代表游戏(非短剧来源) |
| `evidence_level` | 枚举 | S/A/B/C/D |

### 题材激活心理任务字段(本地扩展,服务"反推探索"逻辑)

| 字段 | 类型 | 说明 |
|---|---|---|
| `theme_three_elements` | 对象 | 环境/时代、文化范式/战斗体系、叙事 三要素 |
| `instinct_calibration` | 数组 | 本能调教来源(影视/游戏/小说/纪录片) |
| `activated_psych_tasks` | 数组 | 题材激活的心理任务清单,每条含:任务名、激活强度(强/中/弱)、对应人群簇 ID、用户脑内自动联想 |
| `verified_combos` | 数组 | 已验证的"心理任务子集 + 玩法承接"组合,每条含:激活子集、玩法承接、代表产品、验证年限 |
| `exploration_directions` | 数组 | 探索方向(未充分验证但内在契合论证成立),每条含:假设组合、内在契合论证(≥3 条)、参考接近产品、主要风险 |
| `incompatible_combos` | 数组 | 明确不契合的组合(心理任务冲突的)及失败原因 |
| `audience_ids` | 数组 | 关联的人群簇 ID 列表(直接引用 01-人群簇标准.md) |
| `playstyle_hints` | 数组 | 玩法承接提示(玩法库 v2 建立后改为 playstyle_ids 引用) |

### 选填字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `acquisition_score` | 整数 1-5 | 母题层面的有效获量评分 |
| `roi_score` | 整数 1-5 | 母题层面的 ROI 承接评分 |
| `quadrant` | 枚举 | 四象限定位 |
| `material_hooks` | 数组 | 典型素材钩子 |
| `related_motifs` | 数组 | 相似/可融合的其他母题 ID |
| `opposing_motifs` | 数组 | 对立/难融合的其他母题 ID |

## 内在契合论证(探索方向必填)

`exploration_directions` 中每条探索方向必须给出 ≥3 条内在契合论证。论证维度:

| 论证维度 | 内容 |
|---|---|
| 玩法内核验证 | 该玩法已在别的题材上被验证(给出代表产品) |
| 题材壳调教 | 该题材壳已被影视/游戏/小说反复训练用户(给出调教来源) |
| 结构同构性 | 题材的某种内在结构 和 玩法承接结构 同构(具体到结构落点) |
| 买量端表达 | 该组合在 15 秒素材内能讲清(给出钩子句式) |
| 解决传统组合痛点 | 该组合解决了哪个市场痛点(饱和/同质/世界观负担) |
| 人群簇匹配 | 题材激活的心理任务 和 玩法承接的心理任务 重合(对齐 audience_ids) |

满足 ≥3 条为"探索方向"入库,满足 ≥5 条为"强探索方向"。

## 题材母题命名原则

严格对齐三位一体框架 02-题材母题标准:

### 必须

- ≤ 8 字
- 情绪 + 冲突结构(如"末世+求生"、"权力+博弈"、"成长+复仇")
- 非短剧产物
- 服务"基于人性需求探索新题材"目标

### 禁止

- 不带玩法品类("SLG""卡牌""塔防""搜打撤"全部禁止)
- 不带具体题材标签("末世丧尸"是具体题材,不是母题)
- 不带"族"字、"系"字
- 不用心理学命名("巨物驯御""绝境守存"等)

## 工作流

### 第一阶段:种子母题(当前)

- 主 agent 写方法论(本文件、拆解标准、字段表模板)
- 主 agent 根据 6 大主情绪 + 反"常规"约束 + "服务探索"目标,提出 8-12 个种子母题清单
- deepseek-v4-pro 按方法论填字段表
- 主 agent + 用户审字段表质量

### 第二阶段:扩展母题

种子通过率 ≥ 80%,继续扩展至 15-25 个母题。

### 第三阶段:已有题材归并

把 133 条非短剧题材归到母题下作为 theme_examples;短剧来源题材不归并。

### 第四阶段:探索方向输出

汇总所有母题的 exploration_directions,形成立项可探索题材清单,作为立项决策输入。

## 不要做的事

- 不要在母题命名里出现玩法品类或"族"字
- 不要把短剧来源题材写入 representative_games
- 不要给常规已饱和的题材入库
- 不要做机制库式的多章节产品总档(那是机制库的工作)
- 不要做心理学论文(那是横向研究)
- 不要在母题里写抽象描述,所有字段必须具体到产品名、心理任务名、人群簇 ID
