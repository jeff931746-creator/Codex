# 归档说明:_run_seeds_wrong_naming

> 归档日期: 2026-05-14
> 归档原因: 命名方向错误,违反三位一体框架的题材母题命名规则
> 替代方案: 题材库 v1.0(本目录上一级)按"题材激活心理任务"逻辑重建

## 错在哪

刚开始重做时,我把"题材母题"和"机制库式产品总档"混淆,设计了以下命名:

- 末世SLG族
- 末世生存基建族
- 末世搜打撤族
- 三国SLG族
- 修仙宗门SLG族
- 修仙放置族
- 二次元卡牌养成族
- 卡通宠物收集族

错误三点:

1. **命名带玩法**:"SLG族""搜打撤族""卡牌养成族"等于把"做什么产品形态"锁定在命名里,违反三位一体框架 02-题材母题标准的"避免玩法混入"硬规则
2. **命名带"族"字**:不符合三位一体框架的母题命名规范
3. **同一题材壳被拆碎**:《明日之后》和《Last Shelter》同属末世,被拆到"末世生存基建族"和"末世SLG族"两个族,等于把"末世"这个题材壳拆碎了

更深的错误是逻辑层面:

- 这些命名等于在做"题材壳+玩法承接"的复合产品索引
- 但题材母题应该是"激活心理任务的题材结构"
- 同一个末世母题应该能承接 SLG/生存基建/搜打撤多种玩法,因为这些玩法都是末日激活的不同心理任务子集的承接

## 留下什么

- 8 份 markdown 文档:每份都是 deepseek-v4-pro 生成的产品级总档,质量本身不差
- 内含的代表产品、买量切口、商业化路径、变体讨论 → 可作为新母题字段表的素材
- `_meta/` 子目录:原 prompt、seeds.json、生成脚本

## v1.0 的正确路径

按"题材服务于激活人群簇的心理任务"逻辑重做:

```
题材定义(三要素:环境+文化范式+叙事)
  ↓ 激活的心理任务清单(对齐人群簇标准)
心理任务子集
  ↓ 可承接的玩法 + 未充分验证的探索方向
具体产品形态
```

新母题不带玩法、不带"族"字,严格遵循三位一体框架 02-题材母题标准。

## 不要做的事

- 不要回头复用本目录的命名结构
- 不要把"末世SLG族"这种命名误以为是母题
- 但可以从本目录的 markdown 内容中提取"代表产品""未验证变体"作为新母题字段表的素材
