# User Prompt 模板 — 单个题材族总档生成

## 任务

按 system prompt 的方法论标准与模板,为以下题材族写一份完整的总档。

## 目标题材族

```
题材族名称: __FAMILY_NAME__
预期定位: __EXPECTED_POSITION__
建议代表产品(参考,不强制全部使用): __HINT_REPRESENTATIVES__
预期边界排除(避免与这些族混淆): __ADJACENT_FAMILIES__
```

## 必须遵守

- 代表产品 ≥ 3 个,均非短剧来源
- 边界判据 ≥ 5 条,其中 ≥ 3 条必须满足项
- 中重度承接系统 ≥ 3 个
- 可立项变体 ≥ 3 个
- 商业化路径 ≥ 2 个验证组合
- 没有心理学抽象命名
- 没有互联网黑话
- 数据点估算必须标注"估算"

直接输出 markdown 总档,从 `## 基本信息` 开始。
