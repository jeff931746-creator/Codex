## 一句话结论

第一轮不建议用 16 个候选全量测试。建议先采用 **12 个主母题材 + 4 个观察/降级项** 的稳健方案进入 133 条盲归类。

原因很直接：当前 16 个候选里，`职业神能`、`暗杀渗透`、`异界直播` 更像二级切口或承接机制；`怪物压境` 虽有样本，但与 `绝境守存`、`异种进化`、`异能爆发` 的边界最危险，需要保留但降权测试。

## 推荐决策

推荐选择 **方案 A：稳健测试版**。

| 方案 | 进入 133 条盲归类的主母题材 | 处理方式 | 适用目标 |
|---|---:|---|---|
| 方案 A：稳健测试版（推荐） | 12 个 | 12 个主母题材参与主归类，4 个作为观察标签 | 先建立边界清楚的母题材骨架 |
| 方案 B：激进全量版 | 16 个 | 16 个全部参与主归类 | 快速暴露混淆，但结果噪声更大 |

我的建议是先走方案 A。母题材体系第一轮最怕“过宽 + 错层”，不是怕漏几个候选。漏掉的可以第二轮补，错层一旦写进主归类，会污染 133 条题材的心理任务判断。

## 逐项审核结论

### 1. 绝境守存：保留

成立理由：

- 主心理任务清楚：保住自己、队伍或据点。
- 可跨文化壳：丧尸、极寒、废土、铁路、基地车都能成立。
- 玩法承接清楚：塔防、基地经营、搜打撤、模拟经营均可承接。

重点边界：

- 与 `领地开拓` 的区别：前者核心是活下去，后者核心是建立秩序并扩张。
- 与 `怪物压境` 的区别：前者重安全边界，后者重敌群火力清剿。

### 2. 撤离夺宝：保留

成立理由：

- 主心理任务清楚：进危险区拿收益并活着带出。
- 与玩法承接高度稳定：搜打撤、肉鸽、地牢探索天然匹配。
- 商业化路径清楚：背包、保险、装备保值、稀有资源、局外升级。

重点边界：

- 与 `禁忌探索` 的区别：前者重“带出收益”，后者重“接近未知真相/禁忌力量”。
- 与 `暴富翻身` 的区别：前者收益服务局内风险循环，后者财富服务身份反转。

### 3. 怪物压境：不作为主母题材

降权理由：

- “大量怪物压来”经常是素材形态或玩法压力，不一定是一级心理任务。
- 它可以出现在 `绝境守存`、`异种进化`、`异能爆发`、`镇邪收容` 中。
- 如果作为主母题材，容易把塔防/割草/守线这类玩法承接误判成母题。

保留方式：

- 作为 `threat_pattern = 群体压境` 的观察标签。
- 只有当题材的主任务就是“面对群体异类威胁完成清剿/守线”且无法被其他母题解释时，才允许二轮复议。

### 4. 异种进化：保留

成立理由：

- 主心理任务清楚：通过融合、突变、孵化获得超常生命力量。
- 样本密集：基因、孢子、母巢、御兽、末日改造都可吸收。
- 商业化路径强：抽取、融合、进化、图鉴、稀有血脉。

重点边界：

- 与 `巨物驯御` 的区别：前者创造/改造新生命，后者控制既有危险生物。
- 与 `异能爆发` 的区别：前者力量发生在外部单位，后者发生在玩家自身。

### 5. 巨物驯御：保留但重点测边界

成立理由：

- 主心理任务明确：把恐惧对象转化为己方资产。
- 有跨壳能力：恐龙、深海巨兽、神话妖兽、吸血鬼血裔都可吸收。
- 商业化路径可承接：孵化、捕获、图鉴、养成、阵容。

风险：

- 容易和 `异种进化` 合并。
- 如果“巨物”只是首眼视觉吸量，而系统没有驯养、契约或控制循环，则应降级为素材标签。

### 6. 废械拼强：保留

成立理由：

- 主心理任务清楚：从废料和残件中拼出强战力。
- 与废土、赛博、机甲、义体、黑市均可兼容。
- 玩法和商业化承接强：零件、部位、蓝图、套装、继承。

重点边界：

- 与 `撤离夺宝` 的区别：前者核心是拼装变强，后者核心是带资源撤出。
- 与 `异能爆发` 的区别：前者力量来自外部装备，后者力量来自自身觉醒。

### 7. 禁忌探索：保留

成立理由：

- 主心理任务清楚：深入未知禁区，接触危险真相或禁忌收益。
- 可吸收古墓、深海、克苏鲁、遗迹、灵异探险。
- 可承接搜打撤、肉鸽、解谜、章节探索。

重点边界：

- 与 `撤离夺宝` 的区别是目标函数：发现真相 vs 带出收益。
- 与 `镇邪收容` 的区别是角色位置：探索者 vs 控制/封印者。

### 8. 镇邪收容：保留

成立理由：

- 主心理任务清楚：将异常威胁重新纳入控制。
- 可吸收天师、民俗怪谈、规则怪谈、鬼怪公寓、诡异收容。
- 玩法承接清楚：收容图鉴、封印建筑、法器升级、异常单位养成。

重点边界：

- 与 `禁忌探索` 的区别：镇邪收容重控制，禁忌探索重接近未知。
- 与 `职业神能` 的区别：镇邪收容的对象是异常威胁，不是专业服务场景。

### 9. 改命逆袭：保留

成立理由：

- 主心理任务清楚：用隐藏规则、先知、重生或命格改写失败命运。
- 能吸收算命、改命、重生、血肉飞升、玄学修仙。
- 与短剧/小说迁移路径强。

重点边界：

- 与 `暴富翻身` 的区别：改命逆袭的反转依据是命运规则，暴富翻身的反转依据是财富资源。
- 与 `异能爆发` 的区别：改命强调规则信息差，异能强调能力可视化爆发。

### 10. 暴富翻身：保留

成立理由：

- 主心理任务清楚：低资源低身份者通过财富获得社会承认。
- 能吸收鉴宝、财阀经营、赘婿商战、淘金、打脸短剧。
- 商业化路径明确：资产、店铺、投资、藏品、身份升级。

重点边界：

- 与 `权争上位` 的区别：暴富翻身要的是财富承认，权争上位要的是组织位置和支配权。
- 与 `撤离夺宝` 的区别：暴富翻身不是局内带出收益，而是长期身份反转。

### 11. 权争上位：保留

成立理由：

- 主心理任务清楚：在有限权力结构中夺取位置。
- 可吸收豪门、宫斗、海盗、吸血鬼议会、黑帮等题材。
- 玩法承接强：卡牌、模拟经营、SLG、联盟、势力养成。

重点边界：

- 与 `领地开拓` 的区别：权争上位的阻碍来自人际/组织权力，领地开拓的阻碍来自空间、资源和秩序建设。
- 与 `暴富翻身` 的区别：财富可以是手段，但不是最终心理承诺。

### 12. 领地开拓：保留

成立理由：

- 主心理任务清楚：从空白或弱小空间建立稳定秩序。
- 可吸收荒野、古城、星际殖民、宗门、矿场、基地。
- 商业化路径清楚：建筑升级、科技树、资源加速、扩张、联盟。

重点边界：

- 与 `绝境守存` 的区别：领地开拓主要承诺扩张和秩序，绝境守存主要承诺活下去。
- 与 `权争上位` 的区别：领地开拓是空间秩序，权争上位是人际权力结构。

### 13. 职业神能：降级

降级理由：

- 当前样本的主任务不稳定。
- `神医下山治病` 更接近“专业能力带来的身份确认/暴富翻身”。
- `阴阳堪舆建观`、`风水寻龙点穴` 很容易转向 `改命逆袭` 或 `镇邪收容`。
- 如果保留为一级母题材，会把“职业身份”误当成心理任务。

建议处理：

- 降级为二级切口簇：`专业破局切口`。
- 可挂靠：`改命逆袭`、`暴富翻身`、`镇邪收容`。

### 14. 暗杀渗透：暂缓

暂缓理由：

- 样本少，且高度依赖潜入、动作、搜打撤等玩法承接。
- “暗杀/潜入”更像行动方式，不一定是稳定心理任务。
- 若没有持续的身份风险、时机判断和隐蔽突破，它会退化成素材钩子。

建议处理：

- 暂不作为第一轮主母题材。
- 放入观察项：`高压渗透行动`。
- 如果 133 条中出现 6 个以上稳定样本，再二轮复议。

### 15. 异能爆发：保留但重点测边界

成立理由：

- 主心理任务可成立：普通身份突然获得超常能力并释放压抑。
- 样本足够：都市异能、裂缝异兽、血肉飞升、赛博修仙都能部分吸收。
- 玩法承接清楚：技能抽取、能力进化、流派构筑、RPG/割草。

风险：

- 容易退化为“技能表现”或“爽感素材”。
- 必须检查用户角色是否存在从普通到超常的心理跃迁。

### 16. 异界直播：降级

降级理由：

- 直播大多数时候是表达机制，不是一级心理任务。
- 只有当观众反馈直接进入资源、救场、成长和商业化循环时，它才可能升级。
- 当前样本中 `直播修仙带货` 可能实际主任务是 `改命逆袭` 或 `暴富翻身`，`灵异直播探险` 可能实际主任务是 `禁忌探索`。

建议处理：

- 降级为二级切口/承接机制：`观众反馈切口`。
- 作为字段记录：`audience_feedback_loop = yes/no`。

## 需要特别注意的 6 个高风险边界

| 边界 | 风险 | 测试时的判据 |
|---|---|---|
| 绝境守存 vs 领地开拓 | 末日/基地题材容易混 | 活下去优先，还是扩张秩序优先 |
| 撤离夺宝 vs 禁忌探索 | 古墓/深海/遗迹容易混 | 带出收益优先，还是发现真相优先 |
