## 审核门禁

| Gate | 名称 | 审核问题 | 通过标准 | 失败处理 |
|---|---|---|---|---|
| G0 | 声明完整 | 是否写清心理任务、情绪承诺、冲突、角色位置、反例 | 5 项全部明确 | 补写，不进入测试 |
| G1 | 错层剔除 | 是否只是题材壳、动作、玩法、素材爆点或反馈通道 | 去掉壳/动作/玩法后结构仍成立 | 删除或降级 |
| G2 | 主任务唯一 | 是否只有一个主心理任务 | 样本中 80% 以上可由同一主任务解释 | 拆分或降级 |
| G3 | 跨壳吸收能力 | 是否至少 3 个跨文化壳样本共享同一冲突结构 | 至少 3 个题材，且不全是同一皮肤变体 | 降级为切口 |
| G4 | 边界反例 | 是否能排除相邻题材 | 至少 3 个正例、3 个反例、2 个相邻母题材 | 暂停入库，进入混淆表 |
| G5 | 承接验证 | 是否能被至少 2 个不同核心循环结构承接 | 必须从下方核心循环结构清单中选 2 个；或自定义新结构并说明 | 标记为素材/切口，不入主母题 |
| G6 | 商业化反证 | 是否知道自己何时商业化失败 | 至少 2 个失败场景及触发条件 | 保持 HYPOTHESIS |
| G7 | 预测能力 | 是否能预测新题材在买量素材市场的表现 | 能提前判断 3 个应强、3 个应弱样本；核对方式见下 | 保持 HYPOTHESIS |

### G5 核心循环结构清单（Bug 4 修复）

承接验证不接受品类名堆叠（"塔防"、"卡牌"、"RPG"）。必须从以下结构中选择 2 个，或自定义新结构并说明判据：

| 编号 | 核心循环结构 | 典型玩家动作 | 反馈机制 |
|---|---|---|---|
| L1 | 资源-威胁-修复（防御循环） | 修补防线、补充资源、扩展据点边界 | 安全边界的反复加固 |
| L2 | 风险-收益-撤离（搜打撤循环） | 进入危险区、装填背包、抉择撤离 | 单局结算 vs 全损 |
| L3 | 抽取-融合-进化（养成循环） | 孵化、合成、突变、组合 | 个体能力可见跃迁 |
| L4 | 建造-扩张-治理（经营循环） | 建筑升级、空间扩张、资源调度 | 长期势力曲线 |
| L5 | 选择-后果-改命（剧情循环） | 卡牌选择、剧情判断、信息差利用 | 命运/局势节点变化 |
| L6 | 觉醒-展示-碾压（战力循环） | 技能释放、流派构筑、能力进化 | 战斗中的位阶反转 |
| L7 | 收集-图鉴-阵容（图鉴循环） | 抓取、收编、组合、阵容编排 | 图鉴/阵容完成度 |

新增结构需在测试报告中显式声明并给出至少 2 个承接样本。

### G7 预测对象与核对方式（Bug 5 修复）

预测对象：**该题材作为买量素材的爆款概率**。

核对方式：

```text
1. 候选作者在测试前先盲列出每个主母题预测的「3 个应强、3 个应弱」样本,
   写入测试报告附件(密封,不交给执行者)。
2. 测试完成后,盲归类执行者根据题材是否出现在
   archive/资料/买量组合库/题材总表.md 的高频题材区,反查每个预测样本。
3. 仲裁者裁定预测命中率,命中率 ≥ 70% 视为 G7 通过。
```

「高频题材区」定义：题材总表中累计出现 ≥ 3 次的题材为高频；< 3 次为低频。

如果候选作者无法提前列出预测样本，G7 视为不通过。

### 盲选预测样本（12，Bug 3 修复）

抽样规则（可口头复现）：

```text
1. 在 archive/资料/买量组合库/题材总表.md 中给 133 条题材
   按出现顺序编号 1-133（编号一次,作为固定 index）。
2. 由仲裁者抛硬币确定起始位置 N：
   正面 → N = 7；反面 → N = 13。
3. 从编号 N 开始,以步长 11 抽取 12 条题材（N, N+11, N+22, ...,
   超出 133 后回环,跳过正例吸收样本和混淆边界样本中已用的题材）。
4. 抽取结果先交给盲归类执行者,不先让候选作者调整定义。
5. 测试完成后再公开样本,用于评估 G7 预测能力。
```

如果抽样过程被候选作者干预或起始位置被预先泄露，本组样本作废，G7 自动不通过。

## 盲归类字段表（Bug 1 修复）

| 字段 | 说明 |
|---|---|
| `raw_theme` | 原题材名 |
| `culture_shell` | 文化壳/世界背景，如末日、深海、修仙、赛博 |
| `action_cut` | 动作切口，如挖矿、鉴宝、直播、暗杀 |
| `feedback_channel` | 反馈通道，如弹幕、打赏、热度；没有则空 |
| `threat_pattern` | 威胁形态，如虫潮、尸潮、巨兽；没有则空 |
| `primary_psych_task` | 主心理任务，只能填一个 |
| `emotion_promise` | 核心情绪承诺 |
| `conflict_structure` | 核心冲突结构 |
| `user_role_position` | 用户在题材中的角色位置 |
| `strongest_carrier_relation` | 最强承接关系，必须写"什么循环承接什么心理任务"，不接受品类名堆叠 |
| `monetization_fit` | 可持续商业化路径 |
| `commercial_failure_cases` | 至少 2 个失败场景及触发条件 |
| `primary_motif` | 12 个主母题材之一，或 `未归类` |
| `unassigned_reason` | 仅当 `primary_motif = 未归类` 时填写，枚举值见下 |
| `secondary_cut_cluster` | 二级切口归属（0-2 个），用于挂靠降级后的切口（如 `专家身份切口`、`观众反馈切口`），可空 |
| `observer_tags` | 可填 0-3 个观察标签 |
| `boundary_notes` | 和相邻母题材的边界判断 |
| `test_result` | pass / ambiguous / unassigned / fail |

### `unassigned_reason` 枚举

| 值 | 含义 |
|---|---|
| `no_matching_psych_task` | 没有匹配的主心理任务 |
| `conflict_structure_not_covered` | 冲突结构不在现有 12 个母题之内 |
| `only_observer_tag_matched` | 只命中观察标签，主母题未命中 |
| `insufficient_information` | 题材描述信息不足以判断 |

### `test_result` 状态区分

| 状态 | 含义 | 后续动作 |
|---|---|---|
| `pass` | 主归类成功，无边界争议 | 计入主归类率 |
| `ambiguous` | 跨多个主母题难裁定 | 进入边界混淆表，仲裁者裁定 |
| `unassigned` | 无主归类（合法状态） | 仅记录，第一轮结束后由仲裁者统一聚类 |
| `fail` | 题材内部结构不成立，无法测试 | 进入反证日志，标注原因 |

`unassigned` 与 `fail` 必须区分：前者是体系覆盖问题，后者是题材本身问题。

## 评审角色分离

| 角色 | 职责 | 不能做什么 |
|---|---|---|
| 候选作者 | 维护候选库和边界规则；测试前盲列 G7 预测样本 | 不能独自裁定盲选样本；不能干预盲选抽样起始位置 |
| 盲归类执行者 | 按字段独立给样本归类；执行盲选抽样 | 不能修改母题定义来适配样本 |
| 仲裁者 | 抛硬币定盲选起始；裁定 ambiguous / fail 样本；测试后聚类 unassigned 样本 | 不能无记录地覆盖执行者判断 |

最低执行方式：

- 如果只有一个执行者，也必须先冻结候选库 v0.2.1，再做归类。
- 测试中不得临时改母题定义；所有定义调整进入 `反证日志`，测试后统一处理。
- 无主归类样本第一轮**只记录**，仲裁者在测试完成后一次性聚类。

## 失败回退表

| 失败门 | 失败动作 | 落点 |
|---|---|---|
| G1 错层失败 | 删除或降级为字段 | 写入 `母题材反证日志_v0.1.md`；题材表中只作为 `culture_shell/action_cut/feedback_channel/threat_pattern` |
| G2 主任务失败 | 拆分或降级 | 拆分项进入候选库 v0.3；降级项进入 `secondary_cut_cluster` 字段 |
| G3 跨壳吸收失败 | 降级为二级切口 | 写入 `secondary_cut_cluster`，挂靠到 1-2 个主母题材 |
| G4 边界失败 | 暂停入库 | 写入 `母题材边界混淆表_v0.1.md`，二轮只测混淆边界 |
| G5 承接失败 | 标记为素材/切口 | 写入 `observer_tags`，不得作为 `primary_motif` |
| G6 商业化反证失败 | 保持 HYPOTHESIS | 不入正式库；必须补失败场景后复测 |
| G7 预测失败 | 保持 HYPOTHESIS 或 FALSIFIED | 若盲选样本错判率 >30%，回到候选库重写定义 |

## 无主归类处理与复议阈值（v0.2.1 新增）

无主归类样本第一轮**只记录**，不强行归类，不当场聚类。第一轮测试完成后，由仲裁者统一聚类。

聚类判定规则：

```text
两条无主样本属于同一簇,当且仅当:
- 主心理任务描述本质相同(不只是关键词相似)
- 冲突结构相似
- 用户角色位置相近
仲裁者负责聚类,候选作者不能自行裁定。
```

聚类完成后按以下复议阈值处理：

| 样本聚集情况 | 处理动作 | 落点 |
|---|---|---|
| 同一观察标签 ≥ 6 条 | 触发二轮候选母题复议，标签升格为候选母题候补 | 进入候选库 v0.3 草稿 |
| 同类无主样本簇 ≥ 6 条 | 触发二轮候选母题复议，该簇成为新候选母题 | 进入候选库 v0.3 草稿 |
| 同类无主样本簇 ≥ 3 且 < 6 条 | 保留为二级切口或观察簇 | 写入 `secondary_cut_cluster` |
| 单条无主样本 | 只记录，不扩库 | 写入反证日志 |

复议触发后，候选库 v0.3 必须显式回应每一个触发簇：要么升格为新母题，要么说明为什么不升格。

## 判定阈值

| 指标 | 通过线 | 失败线 |
|---|---:|---:|
| 主任务一致率 | ≥80% | <70% |
| 混淆样本可裁定率 | ≥75% | <60% |
| 盲选样本预测命中率 | ≥70% | <60% |
| 观察标签误作主母题率 | ≤10% | >20% |
| 商业化失败场景可说明率 | 100% | <100% |

主归类率不作为单独通过线，原因见下方覆盖率报告模板。

## 覆盖率报告模板（v0.2.1 新增）

测试报告不得只报"已归类率"。必须拆成 4 项：

| 指标 | 计算方式 | 用途 |
|---|---|---|
| 主归类率 | `primary_motif ≠ 未归类` 的样本占比 | 现有母题的解释力 |
| 无主归类率 | `primary_motif = 未归类` 的样本占比 | 体系覆盖缺口的规模 |
| 观察标签命中率 | 只命中威胁/动作/反馈标签的样本占比 | 观察标签的辨识能力 |
| 新候选触发数 | 达到复议阈值的无主样本簇数量 | v0.3 母题增量来源 |

判断规则：

```text
主归类率 < 60%       → 候选库设计偏窄,需扩库
无主归类率 > 30%     → 候选库设计偏窄,需扩库
观察标签命中率 > 25% → 至少一个观察标签具备升级潜力
新候选触发数 ≥ 2     → v0.3 必须做候选母题增删
```

主归类率作为参考指标，不作为通过/失败的唯一依据。一个健康的第一轮测试结果应当是：

- 主归类率在 60%-85% 之间
- 无主归类率在 5%-30% 之间
- 新候选触发数 ≥ 1

主归类率过高（> 90%）反而是危险信号，说明执行者可能被迫强行归类。
