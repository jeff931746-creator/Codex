# 母题材测试审核矩阵 v0.2

> 状态：草稿，用于启动 133 条题材第一轮盲归类。
> 生成日期：2026-05-13
> 上一版：`母题材测试审核矩阵_v0.1.md`
> 配套候选库：`母题材候选库_v0.2.md`
> 边界：本矩阵用于测试与证伪，不用于直接写正式 `THM-*`。

## v0.2 关键修订

1. G2 主任务唯一阈值从 70% 提升到 80%。
2. G3 与 G4 合并为“跨壳吸收能力”。
3. G6 从“至少 2 类玩法”改为“至少 2 个不同核心循环结构”。
4. G7 改为反向证伪：必须指出 2 个商业化失败场景及触发条件。
5. 样本池改为 50% 正例吸收、30% 混淆边界、20% 盲选预测。
6. 增加评审角色分离规则。
7. 增加失败回退表，明确降级后落到哪个字段或目录。

## 审核门禁

| Gate | 名称 | 审核问题 | 通过标准 | 失败处理 |
|---|---|---|---|---|
| G0 | 声明完整 | 是否写清心理任务、情绪承诺、冲突、角色位置、反例 | 5 项全部明确 | 补写，不进入测试 |
| G1 | 错层剔除 | 是否只是题材壳、动作、玩法、素材爆点或反馈通道 | 去掉壳/动作/玩法后结构仍成立 | 删除或降级 |
| G2 | 主任务唯一 | 是否只有一个主心理任务 | 样本中 80% 以上可由同一主任务解释 | 拆分或降级 |
| G3 | 跨壳吸收能力 | 是否至少 3 个跨文化壳样本共享同一冲突结构 | 至少 3 个题材，且不全是同一皮肤变体 | 降级为切口 |
| G4 | 边界反例 | 是否能排除相邻题材 | 至少 3 个正例、3 个反例、2 个相邻母题材 | 暂停入库，进入混淆表 |
| G5 | 承接验证 | 是否能被至少 2 个不同核心循环结构承接 | 说明“心理任务如何被循环承接”，不能只写品类名 | 标记为素材/切口，不入主母题 |
| G6 | 商业化反证 | 是否知道自己何时商业化失败 | 至少 2 个失败场景及触发条件 | 保持 HYPOTHESIS |
| G7 | 预测能力 | 是否能预测新题材表现 | 能提前判断 3 个应强、3 个应弱样本 | 保持 HYPOTHESIS |

## 样本池结构

第一轮建议测试 60 条。

| 样本组 | 占比 | 数量 | 目的 | 选择方式 |
|---|---:|---:|---|---|
| 正例吸收样本 | 50% | 30 | 验证候选母题是否能吸收典型样本 | 每个主母题材选 2-3 条正例 |
| 混淆边界样本 | 30% | 18 | 验证边界是否能裁定 | 选天然横跨两个母题的题材 |
| 盲选预测样本 | 20% | 12 | 验证预测能力，防止作者自证 | 由盲归类执行者从 133 条随机抽取，候选作者不预先指定 |

### 盲选预测样本（12）

盲选样本由执行者在测试当轮抽取，候选作者不预先指定具体题材。

抽取规则：

1. 从 133 条中排除正例吸收样本和混淆边界样本。
2. 使用固定种子 `2026-05-13-theme-motif-v02` 做随机抽样，抽 12 条。
3. 抽样结果先交给盲归类执行者，不先让候选作者调整定义。
4. 测试完成后再公开样本，用于评估 G7 预测能力。

## 盲归类字段

| 字段 | 说明 |
|---|---|
| `raw_theme` | 原题材名 |
| `culture_shell` | 文化壳/世界背景，如末日、深海、修仙、赛博 |
| `action_cut` | 动作切口，如挖矿、鉴宝、直播、暗杀 |
| `feedback_channel` | 反馈通道，如弹幕、打赏、热度；没有则空 |
| `threat_pattern` | 威胁形态，如虫潮、尸潮、巨兽；没有则空 |
| `primary_psych_task` | 主心理任务，只能填一个 |
| `emotion_promise` | 核心情绪承诺 |
| `conflict_structure` | 核心冲突结构 |
| `user_role_position` | 用户在题材中的角色位置 |
| `strongest_carrier_relation` | 最强承接关系，必须写“什么循环承接什么心理任务” |
| `monetization_fit` | 可持续商业化路径 |
| `commercial_failure_cases` | 至少 2 个失败场景及触发条件 |
| `primary_motif` | 12 个主母题材中选 1 个 |
| `observer_tags` | 可填 0-3 个观察标签 |
| `boundary_notes` | 和相邻母题材的边界判断 |
| `test_result` | pass / ambiguous / fail |

## 评审角色分离

| 角色 | 职责 | 不能做什么 |
|---|---|---|
| 候选作者 | 维护候选库和边界规则 | 不能独自裁定盲选样本 |
| 盲归类执行者 | 按字段独立给样本归类 | 不能修改母题定义来适配样本 |
| 仲裁者 | 裁定 ambiguous / fail 样本 | 不能无记录地覆盖执行者判断 |

最低执行方式：

- 如果只有一个执行者，也必须先冻结候选库 v0.2，再做归类。
- 测试中不得临时改母题定义；所有定义调整进入 `反证日志`，测试后统一处理。

## 失败回退表

| 失败门 | 失败动作 | 落点 |
|---|---|---|
| G1 错层失败 | 删除或降级为字段 | 写入 `母题材反证日志_v0.1.md`；题材表中只作为 `culture_shell/action_cut/feedback_channel/threat_pattern` |
| G2 主任务失败 | 拆分或降级 | 拆分项进入候选库 v0.3；降级项进入 `secondary_cut_cluster` 字段 |
| G3 跨壳吸收失败 | 降级为二级切口 | 写入 `secondary_cut_cluster`，挂靠到 1-2 个主母题材 |
| G4 边界失败 | 暂停入库 | 写入 `母题材边界混淆表_v0.1.md`，二轮只测混淆边界 |
| G5 承接失败 | 标记为素材/切口 | 写入 `observer_tags`，不得作为 `primary_motif` |
| G6 商业化反证失败 | 保持 HYPOTHESIS | 不入正式库；必须补失败场景后复测 |
| G7 预测失败 | 保持 HYPOTHESIS 或 FALSIFIED | 若盲选样本错判率 >30%，回到候选库重写定义 |

## 判定阈值

| 指标 | 通过线 | 失败线 |
|---|---:|---:|
| 主任务一致率 | ≥80% | <70% |
| 混淆样本可裁定率 | ≥75% | <60% |
| 盲选样本预测命中率 | ≥70% | <60% |
| 观察标签误作主母题率 | ≤10% | >20% |
| 商业化失败场景可说明率 | 100% | <100% |
