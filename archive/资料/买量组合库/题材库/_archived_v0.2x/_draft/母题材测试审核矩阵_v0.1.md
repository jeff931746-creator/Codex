# 母题材测试审核矩阵 v0.1

> 状态：草稿，用于审核 `母题材候选库_v0.1.md`。
> 生成日期：2026-05-13
> 数据来源：`archive/资料/买量组合库/题材总表.md`
> 注意：本矩阵用于证伪候选母题材，不用于直接给 133 条题材填写正式 `母题ID`。

## 审核目标

第一轮审核不追求“分类完整”，只解决三件事：

1. 候选母题材是否错层。
2. 候选母题材是否能稳定吸收 133 条题材中的多个样本。
3. 候选母题材之间是否能通过反例划清边界。

通过第一轮审核的条目最高只能到 `BOUNDARY_PENDING` 或 `BOUNDARY_VALID`，不能直接进入正式库。

## 审核门禁

| Gate | 名称 | 审核问题 | 通过标准 | 失败处理 |
|---|---|---|---|---|
| G0 | 声明完整 | 是否写清心理任务、情绪承诺、冲突、角色位置、反例 | 5 项全部明确 | 补写，不进入测试 |
| G1 | 错层剔除 | 是否只是题材壳、动作、玩法或素材爆点 | 去掉壳/动作/玩法后结构仍成立 | 删除或降级 |
| G2 | 主任务唯一 | 是否只有一个主心理任务 | 样本中 70% 以上可由同一主任务解释 | 拆分或降级 |
| G3 | 冲突稳定 | 换文化壳后冲突是否仍稳定 | 至少 3 个不同题材样本共享同一冲突结构 | 合并或重写 |
| G4 | 吸收能力 | 是否能吸收 3 个以上具体题材 | 至少 3 个题材，且不全是同一皮肤变体 | 降级为切口 |
| G5 | 边界反例 | 是否能排除相邻题材 | 至少 3 个正例、3 个反例、2 个相邻母题材 | 暂停入库 |
| G6 | 玩法承接 | 是否能被至少 2 类玩法承接 | 明确承接路径和错配玩法 | 标记为素材母题，不入题材母题材库 |
| G7 | 商业化承接 | 是否能解释长期付费/留存 | 至少 1 条可持续付费或留存路径 | 仅作买量素材，不作立项母题 |
| G8 | 预测能力 | 是否能预测新题材表现 | 能提前判断 3 个应强、3 个应弱样本 | 保持 HYPOTHESIS |

## 盲归类字段

对 133 条题材做第一轮测试时，每条题材只填以下字段，不先看候选母题材名称：

| 字段 | 说明 |
|---|---|
| `raw_theme` | 原题材名 |
| `surface_shell` | 文化壳/世界背景，如末日、深海、修仙、赛博 |
| `action_cut` | 动作切口，如挖矿、鉴宝、直播、抓宠、建造 |
| `primary_psych_task` | 主心理任务，只能填一个 |
| `emotion_promise` | 核心情绪承诺 |
| `conflict_structure` | 核心冲突结构 |
| `user_role_position` | 用户在题材中的角色位置 |
| `playstyle_fit` | 可承接玩法，不填品类名堆叠，要写承接关系 |
| `monetization_fit` | 可持续商业化路径 |
| `candidate_motif` | 盲归类后再填 |
| `boundary_notes` | 和相邻母题材的边界判断 |
| `test_result` | pass / ambiguous / fail |

## 通过标准

第一轮结束后，对每个候选母题材给出以下结论之一：

| 结论 | 条件 |
|---|---|
| 保留 | 通过 G0-G7，混淆样本少于 20% |
| 拆分 | 主心理任务不唯一，且两个方向各有 3 个以上样本 |
| 合并 | 与相邻母题材边界无法稳定区分 |
| 降级 | 只能解释一个动作切口或样本不足 3 个 |
| 删除 | 被证明只是题材壳、玩法、动作或素材爆点 |
