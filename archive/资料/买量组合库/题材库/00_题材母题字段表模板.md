## 自检表

完成后逐条勾选:

- [ ] 母题命名 ≤ 8 字,情绪+冲突结构,无玩法、无"族"、无心理学命名
- [ ] 激活心理任务 ≥ 4 个,每个有人群簇 ID
- [ ] 本能调教来源 ≥ 5 个具体作品
- [ ] 已验证组合 ≥ 3 个,代表产品非短剧、≥ 3 年长线
- [ ] 探索方向 ≥ 3 个,每个 ≥ 3 条内在契合论证
- [ ] 不契合组合 ≥ 2 个,带冲突原因
- [ ] 没有空位词("打通""赋能""场景"等互联网黑话)
- [ ] 没有形容词支撑论点(用"运营 8 年"代替"运营成功")
- [ ] 反"常规"约束通过: 不是已饱和常规题材
- [ ] 与三位一体框架对齐(命名规则 / 大类编码 / 人群簇 ID 引用)
