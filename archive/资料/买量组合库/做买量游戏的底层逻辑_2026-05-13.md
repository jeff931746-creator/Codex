# 做买量游戏，先把“对的人”买进“对的循环”

日期：2026-05-13  
定位：公司 / 团队内部分享文章  
适用：买量游戏立项、题材讨论、素材小测、产品承接复盘

## 开场：买量游戏最容易错在第一步

我们讨论买量游戏时，最常听到的问题是：

```text
现在什么题材吸量？
这个素材能不能跑？
这个品类 ROI 高不高？
```

这些问题都重要，但如果一开始就这样问，很容易把方向带偏。

因为买量游戏真正要解决的，不是“找到一个热门题材”，也不是“做出一条高点击素材”，而是完成一件更难的事：

```text
用可承接的成本，把对的人买进来，
并让这个人在产品里找到继续玩、继续付费的理由。
```

只要这件事没闭合，前面所有好看的信号都可能是错觉。

CTR 高，可能只是素材骗点。  
CPI 低，可能只是买到了一批产品接不住的人。  
题材热，可能只是说明别人已经把贵的人群买走了。  
竞品赚钱，可能只是说明它的产品循环和买量入口成立，不代表我们照着做也能回本。

所以，做买量游戏的第一性问题不是题材，而是：

```text
我们到底要买谁？
这个人为什么会被素材吸引？
他进来后为什么会留下？
他为什么愿意付费？
```

这四个问题如果连不起来，项目后面一定会用更贵的成本补课。

## 一、买量游戏不是六件事，而是一条闭环

题材、素材、人群、玩法、买量、付费，经常被分开讨论。但在买量游戏里，它们不是并列模块，而是一条前后相扣的商业闭环：

```text
主簇人群
→ 题材母题
→ 素材承诺
→ 平台参竞单元
→ 玩法承接
→ 留存 / 付费 / 回收
```

每一环都在回答一个问题：

| 环节 | 真正的问题 | 错了会怎样 |
|---|---|---|
| 主簇人群 | 我们要买哪类人？ | 素材数据有波动，但解释不了谁被吸引 |
| 题材母题 | 用什么内容承诺吸引他？ | 题材只是标签，不能变成欲望 |
| 素材承诺 | 前 3 秒到底答应了什么？ | 点击高，但进来的不是留存/付费人群 |
| 平台参竞单元 | 以什么资产、素材、载体、转化目标进竞价？ | 重复堆广告，内部挤压，跑量集中到少数素材 |
| 玩法承接 | 游戏里是否兑现这个承诺？ | 用户进来发现不是一回事，D1/D3 掉 |
| 留存/付费/回收 | 这个欲望能否持续变现？ | 有短期热闹，没有 LTV 和回本周期 |

这就是为什么很多项目表面上每一块都“有道理”，合起来却不成立。

题材看起来火，素材看起来能点，玩法看起来成熟，付费点也能设计。但如果买进来的人、素材承诺的人、产品留下的人、实际付费的人不是同一批人，项目就会在投放数据里慢慢露馅。

## 二、最常见的失败：点击人群、留存人群、付费人群不重合

买量实践里，最常见也最隐蔽的失败不是“没人点”，而是“点的人不对”。

一个项目可能出现这样的情况：

```text
素材靠剧情反转吸点击；
D1 靠轻度玩法留住一部分人；
付费却依赖重度成长或排名。
```

这时单看每个指标都能找到理由：

- CTR 不差，说明素材有吸引力。
- D1 不是 0，说明产品也有人玩。
- 付费有少量用户，说明商业化不是完全没有。

但三者不是同一批人，最后就很难放量，也很难解释问题到底出在哪里。

这就是为什么我们要拆“主簇”。

主簇不是年龄、性别，也不是“喜欢仙侠的人”“玩 SLG 的人”。主簇是用户在内容和游戏里反复处理的心理任务。比如：

- 有人想用强刺激覆盖疲惫和无聊。
- 有人想通过逆袭确认自己有价值。
- 有人想在联盟里获得位置和责任。
- 有人想把混乱世界整理成可控秩序。
- 有人想理解复杂规则，享受破解过程。

同一个题材可以服务完全不同的人。

“末日生存”可能吸引三类人：

| 人群 | 他想要什么 | 适合的承接 |
|---|---|---|
| 竞争压制型 | 我要比别人强，压制别人 | SLG、战斗、排名、联盟战 |
| 资源管理型 | 我要把资源和秩序安排好 | 模拟经营、基地建设、生产链 |
| 故事消费型 | 我要看人在极端处境下发生什么 | 剧情、选择、章节内容 |

如果素材吸引的是故事消费型，产品承接的是竞争压制型，就会出现“点击不错、回收不行”的典型错配。

所以立项时不能只说“做末日”“做仙侠”“做丧尸”。必须说清：

```text
我们要买的是哪一个主簇？
素材承诺的是不是这个主簇想要的东西？
产品里有没有系统兑现这个承诺？
付费点是不是自然服务这个承诺？
```

## 三、题材不是答案，题材是欲望包装

题材最大的误用，是把它当成答案。

比如说“仙侠商业化强，所以仙侠值得做”。这句话只说对了一半。

仙侠当然有商业化基础：境界、功法、法宝、灵宠、宗门、外观、战力都能付费。但这不代表传统仙侠在当前买量市场里一定成立。因为传统表达可能已经红海，用户已经见过太多飞剑、渡劫、爆战力，头部产品也长期占着高价值人群。

更准确的判断应该是：

```text
仙侠内核有 ROI 承接潜力，
但传统仙侠表达的获量成本可能过高。
除非我们能找到新的主簇入口、新素材表达或新玩法承接。
```

题材的任务，是把人群的心理任务翻译成一个一眼能懂的体验承诺。

弱题材是标签：

```text
修仙、三国、赛博朋克、末日、克苏鲁
```

强题材是承诺：

```text
在中式民俗怪谈里，通过轮回因果破解异常空间，逃出生天。
在冰雪末世里，通过炉火和资源系统建设营地，带领幸存者活下去。
在宗门权力结构里，通过联盟协作和资源争夺，建立自己的秩序。
```

好的题材不只是让人觉得“有味道”，还要能导出三个东西：

1. 素材第一眼能表达的冲突。
2. 玩家进游戏后能做的行为。
3. 长期留存和付费能围绕的目标。

如果题材只能形成美术氛围，不能导出行为和付费，它就只是包装，不是买量游戏的支柱。

## 四、素材不是吸人，而是筛人

很多团队对素材的理解停在“吸人”。但买量越来越贵之后，素材只吸人是不够的，甚至是危险的。

素材真正的作用应该是筛人。

它要在前 3 秒告诉用户：

```text
这里有你想要的心理任务。
如果你不是这个人，就不要点进来。
```

比如：

| 素材承诺 | 它应该筛出的人 | 产品必须兑现 |
|---|---|---|
| “一刀爆装，马上变强” | 强刺激泄压、自我确认 | 快反馈、爆装、战力成长 |
| “我来管理一个混乱世界” | 控制感重建 | 资源链路、建造、秩序优化 |
| “加入联盟，一起打赢别人” | 协作归属、系统统治 | 联盟责任、地图控制、组织分工 |
| “破解异常事件真相” | 认知扩展 | 线索、谜题、规则解码 |
| “轻松挂机，随手变强” | 低负荷转移 | 低操作、持续反馈、低压力收益 |

如果素材承诺的是 A，产品提供的是 B，用户很快会用行为投票。

这就是“骗点素材”的本质：

```text
素材用 A 把人骗进来，
产品却只能提供 B。
```

短期看，素材可能跑通；长期看，买进来的用户质量会把 ROI 拉垮。

所以素材评审不能只问：

```text
这条素材会不会点？
```

还要问：

```text
这条素材吸进来的人，D1 会留下吗？
留下的人，会为产品里的哪个系统付费？
```

## 五、买量越来越贵，不只是市场变卷

买量变贵不是一句“竞争激烈”能解释完的。它背后有几层结构性变化。

第一，用户注意力有限，但广告越来越多。同一类人被更多产品争夺，价格自然上升。

第二，AI 降低了素材生产门槛，也加速了素材同质化。一个能跑的桥段、一个首帧构图、一个剧情反转，很快会被大量复制。素材更多，不一定让买量更便宜，反而可能让疲劳来得更快。

第三，成熟题材的高价值人群被反复购买。仙侠、三国、SLG、传奇这些题材不是不赚钱，而是贵的人已经被反复买过。后来者如果没有新表达，就只能用更高成本和老素材去抢同一批人。

第四，平台也在改变规则。平台越来越不鼓励重复堆同一个广告结构，而是把“应用包/资产 × 素材 × 载体 × 转化目标”作为更核心的参竞单元。重复创建相似广告，不一定换来更多量，反而可能内部挤压。

这意味着过去那种“小预算、多账号、复制广告”的探索方式会越来越弱。团队要从“堆基建”转向“做真正不同的素材和承接”。

第五，买量最贵的浪费不是 CPI 高，而是买错人。买错人后，产品每一层数据都会被拖累：下载后不留、留了不付、付了不深，最后回本周期越来越长。

所以，买量变贵的本质不是单纯流量涨价，而是：

```text
买到正确用户的难度变高了；
用产品接住正确用户的要求也变高了。
```

## 六、新四象限：判断的是“买得到”和“接得住”

基于上面的逻辑，题材四象限也要改。

旧四象限容易问：

```text
这个题材吸不吸量？
这个题材商不商业化？
```

新四象限应该问：

```text
横轴：能不能以可承接成本买到目标主簇？
纵轴：产品能不能兑现主簇任务，并形成留存、付费、回收？
```

也就是：

```text
主簇有效获量（买入） × 主簇 ROI 承接
```

四个象限对应四种决策：

| 象限 | 判断 | 动作 |
|---|---|---|
| 高获量 + 高承接 | 买得到，也接得住 | 优先小测，但要防素材快速同质化 |
| 高获量 + 低承接 | 能吸人，但接不住 | 改玩法承接，或降级为 IAA / 轻 IAP |
| 低获量 + 高承接 | 内核能赚，但买量入口贵 | 换题材表达、素材切口或主簇入口 |
| 低获量 + 低承接 | 买不进，也赚不回 | 淘汰，或回到人群簇 × 母题 × 玩法重组 |

这张图的价值不是“画出位置”，而是强迫团队做决策。

候选不能模糊压线。压线说明证据不足，应该回到评审表补证，而不是用模糊位置替代判断。

右上也不等于马上立项。右上只代表“值得优先验证”。验证顺序还要看证据等级、象限位置和小测可执行性。

## 七、没有买量迹象，不等于题材不行

这里有一个容易误判的点：

```text
没有看到竞品买量，不等于这个题材不成立。
```

它只说明一件事：买量证据缺失。

后面要分情况看：

| 情况 | 判断 |
|---|---|
| 有内容需求，但没有买量竞品 | 可能是探索机会，需要小测 |
| 有竞品收入，但当前投放少 | 可能是自然量产品，也可能是买量难承接 |
| 没投放、没竞品、没内容需求 | 只能算灵感，不进候选池 |
| 没投放，但玩法承接很强 | 先验证素材表达，不直接否定 |

证据链的作用，是防止我们把灵感、热度、竞品、素材、小测混成一种判断。

一个方向当前只有内容热度，最多算 C/B 级假设；有广告素材库和榜单收入互相印证，才有可能到 A；有自有投放和产品数据，才是 S。

没有证据的分数，只能叫假设分。

## 八、团队应该怎么做

如果要把这套逻辑落到日常立项和买量讨论里，可以先做一个最小流程。

### 1. 任何方向先写一句闭环句

```text
这是一个【主簇】会被【题材表达】吸引，
通过【素材承诺】进入，
由【玩法系统】兑现，
并通过【付费动机】回收的买量方案。
```

如果这句话写不顺，方向还没有准备好进入评审。

### 2. 素材小测前先过四个门禁

```text
主簇是否明确？
点击 / 留存 / 付费三人群是否冲突？
素材承诺是否有玩法兑现？
参竞单元是否可扩展？
```

这四个问题过不了，小测数据很可能解释不了。

### 3. 小测不是只看 CTR

至少同时看：

- 谁点了。
- 谁留了。
- 谁付了。
- 素材承诺和产品体验是否一致。
- 换素材、换载体、换转化目标后信号是否还在。

只跑通一条素材，不能证明题材成立；只能证明那条素材在那个窗口有效。

### 4. 评审结论要受证据等级约束

内部评审里，建议把结论分成四类：

| 结论 | 适用情况 |
|---|---|
| 通过 | A/S 证据，双轴都强，进入切口明确 |
| 补证 | 方向有机会，但证据不足或承接未闭合 |
| 改写后复评 | 主簇、题材表达、素材承诺或玩法承接不清 |
| 淘汰 | 买不进、接不住，或无法通过重组修复 |

不要把“我觉得有机会”写成“通过”。这会让团队在后面用制作成本和投放成本替前期判断买单。

## 九、真正的变化：从找题材，变成做匹配效率

买量越来越贵之后，团队的竞争重点会变化。

过去可能更像是在找：

```text
哪个题材更吸量？
哪个品类更赚钱？
哪条素材能爆？
```

现在更应该问：

```text
哪个主簇还有可买空间？
什么题材表达能低成本筛出这个主簇？
什么素材承诺能和产品第一分钟一致？
什么玩法系统能把这个承诺变成留存和付费？
什么参竞单元能持续扩展，而不是只靠一条素材？
```

这就是从“找题材”转向“做匹配效率”。

题材、素材、玩法、买量，不再是不同部门各自完成自己的部分，而是围绕同一个主簇反复校准。

买量游戏不是把游戏做完后再交给投放团队找用户。它从第一天就要把“买谁、承诺什么、怎么兑现、怎么回收”放在同一张桌子上。

如果只看题材，会把过往成功误判成当前机会。  
如果只看素材，会把点击误判成需求。  
如果只看玩法，会把产品深度误判成商业成立。  
如果只看竞品，会把别人能回本误判成自己也能回本。

最后，买量游戏的底层逻辑可以压成一句话：

```text
不是找流量，而是用可验证的承诺，
把正确的人买进正确的产品循环里。
```

## 可带走的 5 句话

1. 做买量游戏，先问买谁，再问做什么题材。
2. 题材不是答案，题材是主簇欲望的包装。
3. 素材不是吸人，而是筛出产品能接住的人。
4. 买量变贵的核心，是买到正确用户的难度变高了。
5. 立项不是证明我们喜欢这个方向，而是证明它能买进来、接得住、赚得回。
