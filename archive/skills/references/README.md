# References

Use this directory for long-form material that should be loaded on demand.

Good candidates:

- coding standards that are too long for direct injection
- architecture notes
- API schemas
- domain glossaries
- large examples or troubleshooting guides

Keep entry rules and skills lean; point to these files only when needed.
