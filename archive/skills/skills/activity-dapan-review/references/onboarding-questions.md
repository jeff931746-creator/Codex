# 引导式提问

**必填项齐套前禁止** `create_report` / `create_dashboard`。

## 决策树

```
用户触发（活动复盘 / activity-dapan-review / 建三张表看板）
  │
  ├─ 活动名称？
  │    └─ 用于报表名、看板名
  │
  ├─ 活动窗口（起止日期）？
  │    └─ 禁止默认近 7 天
  │
  ├─ 参与场景关键词（场景维度属性含）？
  │    └─ 可多个，如「示例场景A」「示例场景B」
  │
  ├─ 渠道 + 区服范围？
  │    ├─ 用户已给出 → 复述确认
  │    └─ 未给出 → 建议先查活动配置（如有相关技能），或请用户提供全渠道 OR 范围
  │
  ├─ TE 项目？
  │    └─ 必须让用户提供 `projectId`（无默认值，占位符 `999999` 禁止直接使用）
  │
  ├─ 看板？
  │    ├─ 新建（默认）
  │    └─ 挂到已有看板（给 dashboardId / URL）
  │
  └─ 复述 Session 摘要 → 用户确认 → 执行 MCP
```

## 必填参数表

| # | 参数 | 说明 |
|---|------|------|
| 1 | **活动名称** | 如「示例活动」 |
| 2 | **活动窗口** | `YYYY-MM-DD` ~ `YYYY-MM-DD`（含首尾语义确认） |
| 3 | **参与场景** | 场景维度属性含的关键词列表 |
| 4 | **渠道区服** | `platform` + `area_id` 范围；全渠道 OR |
| 5 | **TE projectId** | 首次接入必须让用户提供，不可沿用模板占位值 |

## 可选参数

| 参数 | 默认 |
|------|------|
| 付费分层档位 | 1, 7, 101, 1001, 10001, 50001（示例，按项目付费分层习惯调整） |
| 付费内容拆分维 | 场景二级维度属性（示例 `scene_id@scene_id_cn2`） |
| 看板名 | `{活动名}复盘 {起止日期紧凑}` |

## 标准用户请求模板

```
/activity-dapan-review

针对【示例活动】进行数据复盘，建三张表并挂看板。

项目：<你的项目名>（TE projectId=<你的项目ID>）
活动窗口：2026-06-27 ~ 2026-07-03
参与场景（场景维度属性含）：示例场景

渠道区服（全渠道 OR）：
- <渠道A标识> + area_id <范围>
- <渠道B标识> + area_id <范围>
- <渠道C标识> + area_id <范围>

交付：大盘汇总 + 付费结构 + 付费内容构成 + 看板链接
```

## 与上游配置查询串联（可选）

如果你的仓库也有活动配置查询类技能：

```
先查【示例活动】发布环境各渠道活动窗区服，
再按结果建活动复盘三张表看板。
参与场景：示例场景
```

Agent 先跑配置查询 → 用结果中的区服范围填 OR 筛选 → 再建 TE 报表。
