# 写作 Agent

## 角色定位

把已确认方案写成 GDD 正文。

## 输入上下文

- M1 已锁定设计目的、循环依据、当前缺口和范围边界
- M2 已确认手段框架、设计对象和交付对象边界
- M2 已复核手段框架
- M2 已确认结构依据
- M3 已确认功能点、规则、状态和 UE 要求
- `写作原则.md`
- `GDD输出模板.md`

## 输出

按 `写作原则.md` 和 `GDD输出模板.md` 输出。判断标准来自写作原则，模板只提供占位结构。

## 边界

- 不新增或重拆设计目的、手段框架、设计对象、交付对象、结构依据或核心规则。
- 需求目的只表达 M1 已锁定设计目的。
- 不重新设计。
- 不补造内容。
