# 战略收集

## 触发时机

用户提供一个文章链接（微信公众号、网页等）或粘贴文章内容，需要收集到战略库时。

## 边界

- 本 Skill 只负责单篇文章的收集归档
- 不负责趋势汇总或跨条目分析（那是查询时的工作）
- 不修改已有条目（修改已有条目直接编辑文件）

---

## 执行步骤

### Step 0：加载标准

1. 读取通用标准：`reference/部门标准/信息收集/信息收集标准.md`
2. 读取战略库 SCHEMA：`archive/资料/战略库/SCHEMA.md`
3. 确认条目目录和索引目录存在

不暂停，直接进入 Step 1。

### Step 1：读取来源内容

根据输入类型选择读取方式：
- 微信公众号链接 → `read_weixin_article` 工具
- 其他网页链接 → `WebFetch` 工具
- 用户直接粘贴内容 → 直接使用

读取失败时告知用户，不继续。

### Step 2：提取元数据

从内容中提取：
- `title`：原文标题
- `date`：发布日期（无法确认写 "未知"）
- `source_name`：发布媒体/公众号名称
- `source_author`：作者（无法确认写 "未知"）
- `url`：原始链接

### Step 3：判断内容类型与分类

按 SCHEMA §三的分类判定规则确定 `category`。
按通用标准 §二的枚举确定 `content_type`。
选择 2-5 个 `tags`（优先从 SCHEMA §四种子标签中选）。

### Step 4：提取核心内容

- `core_thesis`：核心论点，1-3 句话
- 关键信息：结构化要点，5-10 条
- 评估：信息质量、偏见、局限性
- `actionable_insights`：对立项/买量/产品决策的直接参考价值，0-3 条
- `bias_note`：如有明显偏向（软文、利益相关方），标注

### Step 5：评估来源可信度

按通用标准 §三判定 `source_credibility`（高/中/低）。
判定依据写入正文"评估"小节。

### Step 6：校验

按以下顺序检查：

**通用质量判据**（5 条，来自通用标准 §四）：
- [ ] 必填字段完整
- [ ] 事实与观点已区分
- [ ] 来源可信度已评估
- [ ] 核心论点提取准确
- [ ] 偏向性已标注（如适用）

**分类专项判据**（来自 SCHEMA §五，按 category 选择适用的）：
- 买量与投放：B1 数据口径、B2 平台方 vs 第三方
- 市场与趋势：M1 时间范围、M2 数据来源
- 产品与设计：P1 信息层级
- 立项参考：L1 推理链
- 方法论：F1 适用边界

校验不通过时自行修正，不暂停（通用字段缺失除外——缺失时报错停止）。

### Step 7：生成 entry_id 与文件名

- `entry_id`：`INTEL-{collected_date}-{序号}`，序号从当天已有条目数 +1 递增
- 文件名：`{collected_date}_{简称}.md`，简称取核心主题 2-6 字
- `collected_date`：当天日期

检查 `条目/` 目录下是否已有同 URL 的条目（去重）。已存在则告知用户，不重复收集。

### Step 8：写入条目文件

将 YAML frontmatter + Markdown 正文写入 `archive/资料/战略库/条目/{文件名}`。

正文结构：
```markdown
## 核心论点
（展开 core_thesis）

## 关键信息
（结构化要点）

## 评估
（信息质量、偏见、局限性）

## 可行动洞察
（展开 actionable_insights）
```

### Step 9：更新索引

更新以下三个索引文件（如不存在则创建）：

1. `索引/按时间.md`：在对应月份段落顶部插入新条目链接
2. `索引/按分类.md`：在对应分类段落顶部插入新条目链接
3. `索引/按标签.md`：在每个匹配标签段落下插入新条目链接

索引条目格式：
```
- [{title}](../条目/{filename}) — {source_name} | {content_type} | {tags}
```

### Step 10：输出确认

向用户输出收集结果摘要：

```
✅ 已收集：{title}
分类：{category} | 标签：{tags}
可信度：{source_credibility}
条目：{文件路径}
核心论点：{core_thesis}
```

---

## 批量模式

用户一次提供多个链接时，按顺序对每个链接执行 Step 1-9，最后统一输出 Step 10 的汇总表。

---

## 质量检查

- [ ] 通用标准和战略库 SCHEMA 在 Step 0 已读取
- [ ] 所有通用必填字段有值
- [ ] 适用的分类专项判据已检查
- [ ] 条目文件已写入 `条目/` 目录
- [ ] 三个索引文件已更新
- [ ] 无重复条目（同 URL 去重）
