# 题材思维模式：本能行为拆解

> 来源：微信小游戏题材方法论推导过程中发现的一种题材切入思路。与三层观察链（从世界观出发）互补，不替代。

## 核心逻辑

游戏机制的每个核心动词，都可以映射到多种本能行为。这些本能行为自带情感驱动，是天然的体验钩子。

**题材 = 本能行为 × 世界观主题**

两个维度可以独立选择、独立测试：

- 本能行为决定"用户前 3 秒的情感反应是什么"
- 世界观主题决定"这个情感反应发生在什么世界里"

## 示例：机制动词"收集宠物"

| 本能行为 | 自带的情感驱动 |
|---|---|
| 孵蛋/孵化 | 期待感（里面是什么）、养育本能 |
| 捕捉 | 狩猎本能、征服感 |
| 繁殖/配对 | 创造欲、基因好奇 |
| 驯服 | 支配欲、建立羁绊 |
| 收留/拯救 | 保护欲、同情心 |
| 召唤/契约 | 力量感、神秘感 |

同一个世界观，搭配不同本能行为，产出完全不同的产品：

- 孵化 × 山海经 = 山海经孵蛋（期待+养育）
- 捕捉 × 山海经 = 山海经捕妖（狩猎+征服）
- 驯服 × 末日变异 = 末日驯兽（支配+羁绊）

## 关键价值：可独立测试，收束搜索空间

本能行为可以用最小成本独立测试（例如制作几条只体现行为差异的素材投放），不需要先确定世界观。

测试流程：
1. 从机制核心动词拆解出 3-5 种本能行为
2. 用极简素材测试哪种行为的情感驱动最强
3. 锁定行为后，再去找匹配的世界观主题

这把搜索空间从"所有行为 × 所有世界观"收束到"锁定行为 × 候选世界观"。

## 适用场景

- 已有明确的玩法方向，但不知道用什么题材切入时
- 观察链产出了世界观方向但缺体验钩子时（反向补充）
- 需要在同一世界观下找差异化角度时

## 与其他思维模式的关系

这是题材发现的多种思维模式之一，不是唯一路径：

- **从世界观出发**：三层观察链找世界观 → 再找切入角度（当前方法论 §4）
- **从本能行为出发**：拆解机制动词 → 测试行为 → 再找世界观（本文）
- 可能还有其他模式，待积累
