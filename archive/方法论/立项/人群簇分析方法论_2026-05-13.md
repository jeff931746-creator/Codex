# 人群簇分析方法论

> 沉淀日期：2026-05-13
> 版本：v1.0
> 来源：2026-05-12 ~ 2026-05-13 推演 + 50 样本反向验证
> 配套标准：[人群簇标准 v0.3](../../../reference/部门标准/立项/三位一体框架/current/01-人群簇标准.md)
> 上游框架：[三位一体框架](../../../reference/部门标准/立项/三位一体框架/current/00-框架定义.md)

## 一句话结论

```text
人群簇的公分母是用户在用内容处理什么半意识的心理任务。
品类、题材、玩法、付费、年龄、性别都是承接现象，
不能作为人群簇的第一性定义。
```

## 为什么需要这套方法论

立项决策中"卖给谁"的判断长期没有结构化答案。以往做法的失败模式：

| 错误路径 | 失败表现 |
|---|---|
| 用人口学定义（25-35岁男性） | 无法指导买量素材，CPI 不可控 |
| 用品类定义（SLG玩家） | 把承接当人群，无法跨品类迁移 |
| 用题材定义（修仙玩家） | 把表象当本质，新题材出来就失效 |
| 用产品定义（口袋奇兵核心用户） | 绑死单一产品，无法复用 |
| 用玩法定义（割草用户） | 把后验承接当人群，颗粒度错乱 |
| 用代表游戏堆砌 | 簇与簇之间没有公分母，新增条目无判据 |

这套方法论的目的：**找到一个能让所有人群簇站在同一公分母上的底层维度，使簇与簇之间可比、可区分、可演进**。

## 核心方法：从心理任务出发

### 第一性原理

人群簇不应该回答"这群人是谁"，而应该回答**"这群人在用内容处理什么"**。

```text
内容消费 = 用户在处理半意识心理任务
```

"半意识"是关键定语。它避开了两端的问题：

- **显性理由太浅**：用户说"无聊""随便看看"，没有分类价值
- **无意识动机太深**：解释力强但不可验证、不可落地
- **半意识恰好可用**：用户未必主动说出来，但能通过选择、停留、付费、评论反推

### 6 个心理任务（v1.0）

```
T1 情绪调节      处理焦虑、压抑、疲惫、无聊
T2 自我确认      确认我是谁、我有价值、我没掉队
T3 亲密连接      获得情感连接、被看见、被需要
T4 协作归属      在群体中有位置、有任务、被依赖
T5 认知扩展      理解世界、解码规则、满足好奇
T6 控制感重建    在不可控的生活中建立可控小世界
```

### 心理任务划分原则

- **互斥**：每个簇必须有 1 个主任务（用户长期留下来和付费的核心动机）
- **可识别**：必须能通过留存、付费、评论行为反推
- **跨媒介稳定**：同一任务能在小说、短剧、影视、游戏、社区中出现

## 二级维度：承接偏好

只有心理任务还不够，因为同样是"情绪调节"，有人选爽文有人玩消除有人看治愈剧。需要回答**"用户愿意用什么处理方式完成心理任务"**。

```
P1 强刺激覆盖    用爽、笑、吓、爆发压过原状态
P2 情感共鸣      用相似情绪疏导原情绪
P3 低负荷转移    用简单重复、低反馈把注意力挪走
P4 系统模拟      进入一个可计算、可反馈、可优化的小系统
```

### P4 系统模拟的内部分化

P4 系统模拟覆盖范围特别大（SLG/经营/建造/解谜/策略全归此），必须再分内部收益：

```
Y1 竞争排名      我比别人强
Y2 协作分工      我在组织里有位置
Y3 秩序优化      我能把系统变高效
Y4 规则解码      我能理解复杂规则
```

人群簇的公式：

```text
人群簇 ≈ 主心理任务 × 主承接偏好 [× 系统收益]
```

## 推演方法：6×4 矩阵收敛

人群簇不是枚举出来的，而是从矩阵推出来的。

### 推演步骤

1. **建 6×4 矩阵**：6 个心理任务 × 4 个承接偏好
2. **逐格判定**：标 ✅ 强簇 / ⚠️ 弱簇 / ❌ 空簇
3. **理由约束**：每格必须能说出"为什么是这个组合"或"为什么不可能是这个组合"
4. **空簇是反证**：如果 6×4=24 全是 ✅，说明维度无效

### v1.0 推演结果

矩阵自然收敛到 **12 个强簇**，没有刻意凑。具体定义见 [人群簇标准 v0.3](../../../reference/部门标准/立项/三位一体框架/current/01-人群簇标准.md) 中"12 簇定义表"。

### 关键观察

**观察 1**：维度有效性的反证存在

42 格中有 13 个 ❌（完全空簇），8 个 ⚠️（弱簇）。这些是按结构推出来的（如"亲密连接 × 强刺激覆盖" 本质上破坏亲密关系），反证维度自洽。

**观察 2**：系统模拟列过度集中

6 个任务里有 4 个的最强承接是"系统模拟"，说明系统模拟内部需要细分（即 Y1-Y4）。这与商业事实吻合：SLG/经营/构筑类都是付费深度最高的品类。

**观察 3**：易混簇成对出现

- C05/C12（竞争排名）：个体勇武 vs 系统统治
- C06/C11（秩序优化）：个体炫耀 vs 系统自洽

这反映了同一承接形式下，"作用域"（个体 vs 系统）会形成不同人群。**作用域不升为主维度，而是作为 boundary 判据**。

## 验证方法：50 样本反向归类

### 为什么必须反向验证

矩阵推演完成后，必须用真实样本测试：

- 是否有样本无法归入（→ 矩阵漏维度）
- 是否大量样本归类勉强（→ 簇定义不清）
- 是否归类冲突（→ boundary 不清）

### 验证设计

样本数：50 个
分布：国内重度手游 12 + 中轻度手游 8 + Steam/主机 8 + 短剧 6 + 网文小说 6 + 影视动漫 6 + 综艺社区 4

**选样原则**：
- 跨媒介（不只看游戏）
- 跨人群假设（覆盖 6 个主任务）
- 包含已知边界样本（二次元抽卡、女性向悬疑、棋牌、SLG 重氪）
- 包含成功+争议+失败案例

### 失败指标

| 指标 | 阈值 | 含义 |
|---|---|---|
| 无簇可归率 | >10% | 矩阵漏维度 |
| poor 质量率 | >15% | 簇定义不清 |
| 主簇不可解释率 | >20% | 主簇判断规则失效 |
| 副簇 > 2 个率 | >10% | 簇耦合或产品模糊 |

**复合归类率（含副簇）不再作为失败指标**。原因：

- 多数副簇是矩阵自洽的体现（如 SLG 主 C09 + 副 C12 是合理标注）
- 真正的失败信号是"主簇是否可解释"

### v1.0 验证结果

```
归类成功率：100%（无样本无簇可归）
Poor 质量率：0%
所有边界样本（棋牌、二次元抽卡、宫斗、悬疑）成功归类
8 个 marginal 样本暴露真实复合产品的归类难点
```

## 主副簇规则

每个产品/内容样本必须有 **1 个**主簇，**0-2 个**副簇。

### 主簇判断优先级

```
1. 用户为什么长期留下来？（留存动机）
2. 用户为什么愿意付费？（付费动机）
3. 素材钩子主要承诺什么？（点击动机）
```

**冲突时按 2 > 1 > 3 排序**。

例：SLG 大 R 的广告打"我是大佬"（C04 逆袭爆发），但实际付费来自联盟责任和资源控制（C12 系统统治），主簇按 C12。

### 副簇规则

- 允许 0-2 个，用于解释复合承接
- 超过 2 个 → 说明产品定位模糊或归类失败
- 副簇不影响付费/留存决策，只用于素材方向和承接形态

## 不进命名的维度：现实约束

**现实约束不是第一性维度，但决定承接形态和付费深度**。

```
时间结构   碎片 → 小游戏/放置；整块 → SLG/主机
认知带宽   低 → 强反馈/少规则；高 → 策略/构筑
经济能力   高ARPU → 排名/稀缺；低ARPU → IAA/轻订阅
```

每个人群簇正式条目要在"承接条件"字段填现实约束典型值，但不进入命名。

## 大簇处理：主簇不拆，承接形态下钻

反向验证中如果某个主簇样本占比明显偏高，不能直接按产品形态拆簇。先判断它到底是"分类失败"，还是"真实市场结构"。

判断规则：

```text
如果样本共享同一个主心理任务 + 主承接偏好，
但在操作深度、成长深度、商业化模式上不同，
则保留主簇，增加承接形态子标签。

如果样本连主心理任务或主承接偏好都不稳定，
则说明主簇定义过粗，需要拆簇或重写 boundary。
```

原因：人群簇的第一性是心理任务，不是产品形态。产品形态、操作深度、付费模式属于现实约束和承接路径，只能作为子标签或产品角色标注，不能反向覆盖主簇定义。

### C04 的处理结论

C04 逆袭爆发确认人群的底层不是"类魂玩家"或"武侠小游戏玩家"，而是：

```text
T2 自我确认 × P1 强刺激覆盖
= 通过战斗反馈、爆发成长、难度征服、数值碾压来确认"我变强了/我很强"。
```

因此类魂/动作、ARPG 刷宝、武侠修仙小游戏可以同属 C04，但立项时不能只写"C04"，必须加承接形态子标签：

| 子标签 | 承接形态 | 典型产品 | 关键差异 |
|---|---|---|---|
| C04-A 操作挑战型 | 高操作 + 单局体验 + 一次性/内容付费 | 类魂、硬核动作、动作 Roguelike | 用户为操作征服和难度反馈付出整块时间 |
| C04-B 装备刷宝型 | 中操作 + 长线刷宝 + 多次付费 | 暗黑、怪猎、ARPG、Path of Exile | 用户为装备循环、词条成长和掉落刺激留下 |
| C04-C 数值碾压型 | 低操作 + 数值养成 + 重氪/IAA/IAP | 武侠、修仙、传奇小游戏 | 用户为低门槛变强、战力压制和身份爽感付费 |

使用规则：

- 立项表述必须写成 `AUD-C04 + C04-A/B/C`，不能只写 `AUD-C04`。
- 子标签不生成新主簇 ID，不进入 12 簇矩阵。
- 如果一个产品同时覆盖多个 C04 子标签，按付费承接优先级选择主子标签，素材方向可标副子标签。
- 子标签不能替代市场判断。C04 成立只说明心理任务成立，不说明当前买量市场成立。

### C10 的待处理原则

C10 规则解码挑战人群也可能出现大簇现象，但它比 C04 更容易发生主簇异质性。C10 需要先单独验证：

| 候选子标签 | 承接形态 | 典型产品 |
|---|---|---|
| C10-A 解谜推理型 | 空间/叙事/线索解码 | 纪念碑谷、机械迷城、Disco Elysium |
| C10-B 构筑策略型 | 牌组/流派/概率解码 | 杀戮尖塔、Balatro、自走棋 |
| C10-C 4X/模拟硬核型 | 复杂系统/长期策略解码 | 文明、群星、矮人要塞、太吾绘卷 |

C10 是否只加子标签，取决于验证结果：如果三类都稳定落在 `T5 认知扩展 × P4/Y4 规则解码`，则加子标签；如果部分样本实际主任务是 T6 控制感重建或 T2 自我确认，则应改归 C11/C06，而不是强留在 C10。

### 产品角色标注

有些簇作为"主流人群"很少出现，但会作为产品中的衍生动机或顶部小众出现。为避免误删有效结构，新增产品角色标注：

| 产品角色 | 定义 | 用途 |
|---|---|---|
| 主流人群 | 能独立支撑产品留存/付费/获量 | 可作为主目标人群 |
| 衍生行为 | 常作为其他主簇的副动机出现，单独立项罕见 | 可做系统、副玩法、素材角度 |
| 顶部小众 | 样本少但 ARPU 或口碑影响强 | 可做高端承接或差异化模块 |

示例：C06 当前更像衍生行为，常体现为晒阵容、晒流派、攻略输出；C12 当前更像顶部小众，常在 SLG 大 R、宫斗深度玩家等高支配场景中出现。

## 跨媒介证据原则

人群簇的稳定性来自**多媒介反复出现**。游戏证据是承接证据，不是定义证据。

| 媒介类型 | 能证明什么 |
|---|---|
| 小说/短剧/影视 | 内容欲望、触发钩子、用户停留模式 |
| 社区/直播/评论 | 现实处境、心理任务、跨群体共性 |
| 游戏（留存/付费） | 承接形态、商业化路径、人群质量 |
| 广告素材 | 点击钩子、素材承诺、人群激活方式 |

**证据等级**：

- 单一媒介证据 → C 级（假设）
- 跨 2 类媒介 → B 级
- 跨 3+ 类媒介 → A/S 级

骨架阶段（人群簇库初建）允许游戏+影视反推，但条目晋升为 A/S 级前必须补跨媒介证据。

## 待演进路径

### 潜伏待定的第 7 个任务

```
价值秩序校准   看打脸/审判/伦理剧/复仇剧的核心驱动
```

当前归入 T2 自我确认 或 T6 控制感重建，但案例累积到一定量后可能需要独立。**触发条件**：连续出现 ≥10 个样本无法稳定归入现有 6 任务，且主驱动是"判断对错/确认价值观/惩恶扬善"。

### 习惯型消费的边界

棋牌、麻将、刷视频等"非内容驱动"的消费当前归入 T1×P3。**触发独立化的条件**：

- 连续出现 ≥10 个样本主驱动是"社交习惯/仪式延续"而非"内容任务"
- 这些样本无法用现有 boundary 规则区分

如果触发，可能新增第 7 个任务"习惯维持"。

### 矩阵演进规则

人群簇不锁死。演进路径：

```
新增任务（T7+）  : 需要 ≥10 个无法归入的样本 + 跨媒介证据
新增承接（P5+）  : 需要发现现有 4 类无法解释的处理方式
新增系统收益（Y5+）: 需要发现现有 4 类系统模拟收益之外的核心满足
拆簇/合簇        : 需要持续 ≥3 次归类冲突
```

每次演进都要重新跑反向验证。

## 哲学基础（参考层）

这套方法论的哲学基础不是从游戏研究来，而是从消费心理学/媒介研究来。可参考：

- **马斯洛需求层次**：T1-T6 对应安全、归属、尊重、自我实现的不同维度
- **使用与满足理论（Uses and Gratifications）**：人群簇 ≈ 用户的满足模式
- **半意识心理任务**：参考行为经济学中的"系统1/系统2"
- **承接偏好**：参考媒介生态学中"不同媒介承接同一需求的不同方式"

这些哲学基础**不进操作层**，只在方法论需要被质疑或扩展时作为参考。

# v1.1 修订章节：判据层重写

## 触发原因

230 真实爆款样本验证（2026-05-13 跑出）暴露了 5 个关键问题：

1. **C04 占 20% 内部异质性大**：类魂/刷宝/数值碾压三类承接形态混在一起，心理任务是否真的一致存疑
2. **C03 内部混三类不同心理任务**：真低负荷 / 修仙放置 / 棋牌习惯型
3. **C10 是杂物簇**：50 个样本里混了 ARPG/4X/解谜/构筑 4 类完全不同的人群
4. **C02/C06/C12 在游戏样本中主簇罕见**：但作为人群完整存在
5. **8 对相邻簇 boundary 不清**：LLM 按"看起来像"归类，归类成功率虽 100% 但稳定性不可靠

v1.0 的判据不足，**结构成立但判据层欠缺**。v1.1 重写判据层，不动 12 簇骨架。

## 核心原则：三层不能互换

人群簇方法论的根本原则是三层分离：

```
人群簇层 = 心理任务 × 承接偏好（第一性，进入 12 簇定义）
承接形态层 = 操作深度 / 成长结构 / 商业化模式 / 付费深度（次生，作为观察标签）
产品视角层 = 主流 / 衍生 / 顶部（应用注释，不进标准结构）
```

**三层不能互换**：

- 承接形态层不能反推人群定义（用玩法/付费分类人群是错的）
- 产品视角层不能定义人群（C12 不是"顶部小众人群"，是"在产品中常以高 ARPU 形态出现的完整人群"）

**最重要的一条新边界**：

```text
心理任务相同 ≠ 用户画像相同
心理任务相同 ≠ 渠道人群重合
心理任务相同 ≠ 素材可共用
心理任务相同 ≠ 商业模型可互迁
```

C04 不是"一个可直接买量的人群包"，而是一个心理任务簇。立项时只写"目标人群是 C04"不够，必须同时给出承接形态、媒介适配、现实约束。

## 观察标签：归类后的描述工具，不是归类工具

v1.0 的 C04-A/B/C 子标签曾被当作归类工具使用——这是错的。

**v1.1 修正**：

```text
观察标签只能用于"同一心理任务下的承接形态差异"。
不能用于掩盖"心理任务不一致导致的错归"。
```

观察标签的准入条件（必须全部满足）：

```text
1. 该簇内所有样本，通过"归类三问"重答，主任务收敛到同一个 T
2. 该簇内样本的产品外显结构（核心循环 + 付费驱动 + 卡点机制）一致指向该 T
3. 反向投射验证：隐藏簇 ID 让 LLM 重判，5 个样本中 ≥4 个归同一 T
4. 标签描述用承接术语（操作 / 付费 / 商业化），禁止用心理术语
5. 不生成新 ID，不进入 12 簇结构
```

**失败处理**：

```text
若反向投射显示 >30% 样本不归同一 T，不能强行保留观察标签。
此时该"承接形态"实际跨多个心理任务，应在簇定义里标注
"此承接形态在用户层面存在心理任务分化，立项时需明确目标 T"，
而不是用观察标签兜底。
```

## 完整归类流程（必须按顺序执行）

```
Step 1: 心理任务判定（T1-T6/T7-candidate）
  问：用户长期留下来的核心动机是什么？
  禁止：用品类 / 题材 / 玩法 / 操作强度反推

Step 2: 承接偏好判定（P1-P4）
  问：用户用什么处理方式完成这个心理任务？
  禁止：用付费深度反推

Step 3: 候选簇定位
  根据 T × P 落入候选簇

Step 4: boundary 排除复核
  对照该簇所有相邻簇的 boundary 硬判据
  必须显式回答"为什么不是 C-XX"

Step 5: 错归筛查（针对历史大簇 C03/C04/C10）
  如果落入 C03 → 走 C03 vs C04-C / T7-candidate 排除 checklist
  如果落入 C04 → 走 C04 vs C05/C10/C11 排除 checklist
  如果落入 C10 → 走 C10 vs C04/C11/C05/C07 强制排除 checklist
  排除规则不通过 → 重归

Step 6: 输出
  主簇 + 副簇（0-2 个） + 置信度（high/medium/low） + 错归筛查理由
```

**置信度判定**：

```text
high：三问 + 反向投射一致，无相邻簇候选
medium：三问一致，反向投射有边界样本，相邻簇候选 1 个
low：三问不一致，或反向投射不收敛，必须人工复核
```

## 三问硬规则

```text
归类三问：

1. 用户主要为什么留下？
   是为了爽一下、变强、被陪伴、和人协作、理解规则、控制系统？

2. 用户主要为什么付费或持续投入？
   是为了更快变强、赢别人、收集角色、组织责任、解锁系统、扩张秩序？

3. 素材承诺和真实留存是否一致？
   如果素材靠爽感点击，但留存靠经营/协作，主簇按留存和付费，不按点击。
```

**硬规则**：

```text
点击动机不能直接定主簇。
品类不能直接定主簇。
题材不能直接定主簇。
操作强度不能直接定主簇。
```

## 8 对相邻簇 boundary 硬判据

v1.0 只有 5 对 boundary，v1.1 扩到 13 对，覆盖 230 验证暴露的所有错归路径。

### 新增 8 对

| 边界 | 判据 |
|---|---|
| **C01 vs C03** | C01 是高唤醒、短时情绪冲击；C03 是低唤醒、低负荷注意力转移。跑酷/消除/找茬多数先判 C03，除非核心卖点是爆炸、暴力、恐怖、速度压迫 |
| **C01 vs C10** | 恐怖如果核心是"被吓/释放紧张"归 C01；如果核心是"探索未知、解谜、理解真相"归 C10 |
| **C03 vs C04-C** | 低操作不等于 C03。若长期目标是战力、境界、数值膨胀、碾压别人，归 C04；若只是消磨时间、重复轻反馈，归 C03 |
| **C04 vs C05** | C04 是战胜内容/怪/关卡后确认自己；C05 是战胜真人/排名/竞技系统后确认自己。PvP 撤离、竞技、排位优先判 C05 |
| **C04 vs C10** | ARPG 默认不归 C10。只有"理解规则/构筑/解谜"是核心留存时才归 C10；否则战斗成长归 C04。**显式机制歧义判据**：若两个产品都有"构筑"机制（如杀戮尖塔 vs 暗黑），用"最终满足来源"区分——构筑通向"我破解了规则"（解读完整后退场）→ C10；构筑通向"我变强了，下一关需要更强的我"（持续追求下一目标）→ C04。关键判据：用户完成当前构筑后，是否产生新一轮"我要更强"驱动 |
| **C04 vs C11** | 修仙若核心是境界压制、战力膨胀，归 C04；若核心是经营门派、资源秩序、生产链，归 C11 |
| **C07 vs C08** | C07 是我和角色/对象的亲密关系；C08 是我和团体的情感归属。武侠 MMO 不因有剧情情感就归 C07 |
| **C08 vs C09** | C08 是团魂、陪伴、情义；C09 是职责、分工、组织任务。临时合作和工具协作优先 C09 |
| **C10 vs C11** | C10 是破解规则；C11 是优化系统。文明/4X 如果满足来自"理解复杂规则"归 C10；如果满足来自"把国家/城市/资源链经营起来"归 C11 |

| 簇 | 游戏适配 | 内容适配 | 说明 |

## C10 强制排除 checklist

v1.0 的 C10 是杂物簇（50/230 = 21.7%）。v1.1 加强制排除规则。

**进入 C10 前必须排除（显式回答四个问题）**：

```text
1. 本样本是否主要靠战斗成长？
   是 → 排除 C10，归 C04
   否 → 继续

2. 本样本是否主要靠经营秩序？
   是 → 排除 C10，归 C11
   否 → 继续

3. 本样本是否主要靠竞技胜负？
   是 → 排除 C10，归 C05
   否 → 继续

4. 本样本是否主要靠剧情亲密/情感？
   是 → 排除 C10，归 C07/C02
   否 → 继续

四个都"否"，且满足下面任一条件，才能进 C10：
- 用户的核心快感来自"我理解了规则"
- 用户的核心快感来自"我破解了谜题"
- 用户的核心快感来自"我构筑出有效解"
- 用户的核心快感来自"我掌握了复杂系统的运行逻辑"
```

**复合产品的"主要靠"判定**——用"用户卡关时的本能反应"反推：

| 用户卡关时本能反应 | 主要靠 | 归簇 |
|---|---|---|
| "我等级不够，去刷怪/刷装备" | 战斗成长 | C04 |
| "这关有什么机制我没想到？" | 规则解码 | C10 |
| "我经济没建好/资源不够" | 经营秩序 | C11 |
| "对手太强，我得练手感/上分" | 竞技胜负 | C05 |
| "我想看主角和 NPC 关系发展" | 剧情亲密 | C07 |

这条"卡关反应"判据用于解决 Avowed / 暗区突围 / 太吾绘卷等**复合产品**的归簇歧义。

**C10 入簇时强制标注核心解码维度**（观察标签，不分簇）：

```yaml
c10_subdimension:
  - puzzle: 解谜推理（纪念碑谷、机械迷城、Disco Elysium）
  - build: 构筑策略（杀戮尖塔、Balatro、自走棋）
  - rule_decode: 复杂规则解码（文明、群星、矮人要塞、太吾绘卷）
```

## C03 错归筛查规则

v1.0 的 C03 内部混了三类样本，v1.1 强制走二次判定。

**进入 C03 前必须排除**：

```text
Step 1：低操作不是 C03 的充分条件
  问：该产品的主循环是否显式围绕战力、境界、等级、装备、资源效率、推图卡点、排行榜、付费加速展开？
  是 → 排除 C03，优先排查 C04-C 数值确认型
  否 → 继续

Step 2：判断是否承载固定社交/仪式关系
  问：该产品是否主要承载用户的熟人局、固定打卡、社交仪式？
  是 → 标记 T7-candidate（习惯维持候选），暂挂 C03? 不直接归 C03
  否 → 继续

Step 3：剩下的才是真正的 C03
  问：用户进入的目的是不费脑地转移注意力，失败可退出，不强刺激？
  是 → C03
```

**C03 vs C04-C 的产品外显结构 checklist**：

| 判据 | 倾向 C03 | 倾向 C04-C |
|---|---|---|
| 主循环 | 一局一局玩、轻目标、随进随出 | 签到、养成、推图、升战力 |
| 成长压力 | 弱，失败也可退出 | 强，卡点驱动养成/付费 |
| 数值系统 | 轻道具/关卡进度 | 战力、境界、装备、资源效率 |
| 付费点 | 去广告、复活、道具、体力 | 加速成长、资源包、战力、抽卡、冲榜 |
| 素材承诺 | 放松、解压、简单、有趣 | 变强、逆袭、渡劫、爆装、碾压 |

**C03 vs T7-candidate 的三维区分**：

| 维度 | C03 | T7-candidate |
|---|---|---|
| 用户连接对象 | 内容本身（消除、找茬、合成）| 社交场景 / 习惯仪式 |
| 替换性 | 容易被其他低负荷内容替代 | 难替代（熟人局、固定打卡）|
| 卸载阻力 | 低（不玩了就不玩了）| 高（社交关系/仪式中断）|

**关键判据**：该产品是否承载用户的固定社交/仪式关系？

- 是 → T7-candidate（即使表面是 C03 低负荷）
- 否 → C03

## T7 习惯维持（候选状态）

v1.1 引入候选任务状态，处理棋牌/麻将/仪式型消费。

**候选定义**：

```text
T7 习惯维持 / 仪式延续：
用户不是为了内容刺激、情绪疏导、变强、亲密、协作或解码，
而是为了维持日常节奏、熟人局、固定仪式和低成本社交惯性。
```

**候选状态记法**：`T7-candidate` 或 `C03?`，**不直接归 C03**。

**激活路径**（升级为正式任务）：

```text
1. 连续累积 ≥10 个标 T7-candidate 的样本
2. 这些样本的主驱动都不是 T1-T6 任意一个
3. 主留存来自固定习惯/仪式，而非内容反馈或系统成长
4. 触发新增任务 T7 的提案
```

**非激活路径**（撤回候选状态）：

```text
如果累积过程中样本实际可归 T1（消磨时间）或 T4（社交仪式），
说明 T7 没有独立必要，候选状态解除。
```

## 应用注释（取代 v1.0 的"产品角色标注"）

v1.0 用"主流/衍生/顶部小众"标注 C06/C12，**这是用产品视角定义人群，违反三层分离原则**。

**v1.1 修正**：删除"产品角色"维度，改为应用注释（描述性，不进结构）。

| 簇 | 应用注释 |
|---|---|
| C06 系统流派炫耀 | 在游戏产品中作主簇较少出现，常作为副动机（C04/C05/C09 用户的衍生行为：晒阵容、晒流派、攻略输出）。但作为人群完整存在，在内容媒介（社区、攻略、小说）中可作主承接 |
| C12 系统统治支配 | 在游戏产品中作主簇较少出现，但人数少不等于价值低——常作为高 ARPU、组织控制、服务器支配的深度付费动机出现。建议作为"低频主簇 / 高价值承接簇 / 产品内高权重人群"对待 |
| C02 情感舒缓陪伴 | 游戏产品中纯 C02 承接罕见（治愈型经营多归 C11），但在影视/小说/陪伴产品中是主承接簇 |

## 新验证指标

v1.0 用"归类成功率 100%"作为通过指标，被证明粒度太粗（任何样本都能塞进 12 簇）。

**v1.1 新验证指标**（多维度）：

```text
1. 错归率
   明显违反 boundary 的样本占比，目标 <5%

2. 相邻簇冲突率
   同一样本在 C04/C10、C03/C04 等之间摇摆的比例，目标 <10%

3. 主簇置信度分布
   high / medium / low。low 样本必须进入人工复核
   目标：high >70%，low <10%

4. 跨标注一致率
   同一批样本由两次独立标注（换 prompt 或换模型），主簇一致率
   目标 >80%

5. 预测有效性（长期，需要真实数据）
   主簇能否预测素材钩子、留存原因、付费动机
```

**新验证结论判定**：

```text
不是"能归类 = 通过"
而是"能稳定归类 + 能解释留存/付费 + 能指导素材 = 通过"
```

## 反向投射验证

观察标签准入和 C04 类大簇验证必须做反向投射，防止 LLM 复读原归类。

**反向投射设计原则**：

```text
A. 换 prompt：不给原簇结果，只问"这几个样本共享的心理任务是什么？"
B. 换输入粒度：隐藏原簇 ID 和归类理由，只保留产品名 + 核心循环 + 付费驱动 + 素材承诺
C. 换模型或换轮次：理想用不同模型，至少用新会话+新 prompt
```

**反向投射 prompt 强制要求**：

```text
对每个产品，回答以下三个问题，每个问题只能用 T1-T6 或 T7-candidate 之一：

1. 用户的核心留存驱动属于哪个心理任务？
2. 用户的核心付费动机属于哪个心理任务？
3. 素材承诺主要承诺哪个心理任务？（信息项，不参与主簇判断）

然后回答：5 个产品的"核心留存驱动"是否都收敛到同一个 T？
```

**拒绝答案**：

```text
- "它们都是 XX 品类" ❌
- "它们都需要 XX 技能" ❌
- "它们都有 XX 机制" ❌
这些都不是心理任务，必须要求 LLM 重答。
```

**通过标准**：

```text
5 个样本中 ≥4 个收敛到同一 T，且理由来自留存/付费/核心循环，而不是题材或操作表象
→ 允许观察标签
低于 4 个，或理由主要是"都低操作/都修仙/都动作"
→ 不允许观察标签，必须重归
```
