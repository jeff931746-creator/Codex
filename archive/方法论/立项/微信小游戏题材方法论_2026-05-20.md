# 微信小游戏题材方法论（生态型）

> 适用范围：买量驱动的微信小游戏，包括轻度（IAA 为主）和中重度（IAA+IAP 混合）。不适用于作品型产品（作品型见《题材发现方法论》）。

## §0 定位

帮助在选题阶段**找到值得测试的题材候选**，并将候选缩小到 3-5 个进入素材测试。

本方法论不能替代素材测试——获量成本只有数据能回答，推理能做的上限是缩小测试范围、降低试错成本。

### 与已有方法论的关系

| 已有方法论 | 本文复用了什么 |
|---|---|
| 题材选择方法论（四象限） | 有效获量 × ROI 承接评分、融合四原则 |

| 题材发现方法论（作品型） | 情绪一致性原则（生态型不走精神内核路径，走心智模型借用路径） |
| 人群簇标准 | 心理任务分类（T1-T6）、承接偏好（P1-P4） |
| 买量题材评估证据链标准 | 证据等级（S/A/B/C/D） |

## §1 底层原理：题材 = 心智模型借用

生态型小游戏的题材不是灵魂，是**认知入口**。

题材的本质工作：借用用户已有的心智模型，套在游戏机制上，让用户零成本启动"预测→操作→验证"循环。

"僵尸来了→我该防守"不需要教程，因为用户的僵尸片心智模型里已经内置了这个因果关系。"合成大西瓜"不需要解释为什么大水果好，因为"大的比小的值钱"是日常经验。

### 四个内在属性

| 属性 | 定义 | 决定了什么 |
|---|---|---|
| 共识度 | 多少人拥有这个心智模型 | 人群天花板 |
| 同构度 | 心智模型的因果结构与机制逻辑的匹配程度 | 首次操作的理解速度 |
| 情感负载 | 心智模型自带的情感强度 | 操作快感、对象主观价值 |
| 可叙述性 | 心智模型能否用一句日常语言传达 | 社交传播边界 |

属性与产品指标的映射：

- 共识度 × 同构度 → 首次操作转化率
- 可叙述性 × 情感负载 → 自然传播效率
- 情感负载 × 同构度 → 变现效率（损失厌恶 / 付费意愿）

### 四属性评级锚定

对候选做四属性三档评级（高/中/低）时，用以下案例锚定：

| 属性 | 高 | 中 | 低 |
|---|---|---|---|
| 共识度 | 不需要解释。锚定：水果、僵尸、交通工具、动物 | 一句话能解释。锚定：蚂蚁殖民地、深海生物、炼金术 | 需要一段话或依赖特定文化背景。锚定：克苏鲁、SCP |
| 同构度 | 题材因果 = 机制因果。锚定：水果合成→大的更好；僵尸来了→建塔防守 | 可类比但需要转译。锚定：军事→合成（军队"合并"？需要心理跳转） | 缺乏直觉映射。锚定：办公室→消除 |
| 情感负载 | 自带强烈情感反应。锚定：萌宠（保护欲）、僵尸（恐惧）、金币（贪婪） | 温和情感。锚定：烹饪（趣味）、种植（满足） | 情感中性。锚定：办公用品、交通标志 |
| 可叙述性 | 一句话说清且有传播欲。锚定："合成一个大西瓜"、"僵尸围城你能活几天" | 一句话说清但没传播欲。锚定："整理一个书架" | 说不清或说了没反应。锚定：抽象几何变换 |

淘汰线：任一属性为"低"且无明确补偿机制，直接淘汰。同构度评估必须指定配对机制，不能脱离机制单独评题材。

### 适用边界

以下情况题材做功权重下降，原理仍成立但需注意：

1. **机制直接对接物理直觉**（如俄罗斯方块、2048）：心智模型来自物理直觉层，题材价值降级为"提供情感负载和传播差异化"
2. **品类高度成熟**（如合成品类）：用户用品类心智模型替代题材心智模型，同构度权重下降，情感负载和差异化上位
3. **社交货币来自机制设计**（如羊了个羊）：传播驱动力不在题材可叙述性，而在机制制造的社交话题

## §2 题材的两个维度

题材不是一个单一选择，而是**两个独立维度的交叉**：

| 维度 | 解决的问题 | 示例 |
|---|---|---|
| **世界观主题** | 用户进入的是什么世界 | 山海经、冰封末日、水淹世界 |
| **体验钩子** | 用户前 3 秒的情感瞬间是什么 | 孵蛋（期待感）、捕捉（征服感）、守护弱小（保护欲） |

两个维度可以独立探索、独立测试：

- 体验钩子决定"用户想不想点进来"
- 世界观主题决定"点进来之后能撑多久"

**最终题材 = 体验钩子 × 世界观主题**。"山海经孵蛋"和"山海经捕妖"是同一世界观、不同体验钩子，产出完全不同的产品。

### 轻度与中重度的差异

| | 轻度（IAA 为主） | 中重度（IAA+IAP 混合） |
|---|---|---|
| 世界观粒度 | 符号级（水果、颜色、动物） | 世界观级（末日生存、修仙、三国） |
| 世界观来源 | 物理直觉、日常经验 | 影视/文学/游戏积累的文化符号 |
| 世界观的核心要求 | 一个符号即完成认知映射 | 既能压缩成符号获量，又能展开成世界撑长线 |
| 体验钩子来源 | 机制动词的本能表达 | 机制动词的本能表达（同轻度） |

**判断依据**：
- 核心循环在前 30 秒内完成且不需要世界观展开 → 轻度
- 产品需要世界观来支撑留存和付费深度 → 中重度
- **中间地带**：机制有深度但题材可以很轻（如 Thronefall 是中重度策略但题材极简）→ 不要预设"机制重就需要重型世界观"

## §3 题材发现：多种思维模式

题材发现没有唯一正确的路径。以下是几种经过验证的思维模式，根据你当前的状态选择合适的入口。

### 模式 A：本能行为拆解（从机制出发找体验钩子）

**适用场景**：已有明确的玩法方向，不知道用什么角度切入。

核心循环里的每个机制动词，都可以映射到多种本能行为。这些本能行为自带情感驱动，是天然的体验钩子。

操作方式：
1. 提取核心机制动词（收集、防守、合并、消除……）
2. 对每个动词列出本能行为映射（收集→孵化/捕捉/繁殖/驯服/收留/召唤……）
3. 每种本能行为自带不同的情感驱动（孵化→期待感、捕捉→征服感、收留→保护欲……）
4. 可以用极简素材独立测试哪种行为的情感驱动最强，不需要先确定世界观

**价值**：先锁定体验钩子，再找匹配的世界观——搜索空间从"所有行为×所有世界观"收束到"锁定行为×候选世界观"。

详见：[题材思维模式：本能行为拆解](题材思维模式_本能行为拆解_2026-05-21.md)

### 模式 B：跨媒介观察链（从已有作品找世界观）

**适用场景**：需要发现中重度世界观级题材，或寻找跨平台迁移机会。

从已有优质作品中发现可迁移的机会，三层证据梯度：

| 层级 | 观察对象 | 证据强度 | 潜在收益 |
|---|---|---|---|
| L1 影视/文学 | 正在冒头的题材趋势。观察源：流媒体热榜、小说平台排行、短视频热门标签 | 弱——只有文化共识 | 高——吃第一波 |
| L2 PC/主机 | 已验证的题材+世界观 | 中——有游戏化验证 | 中——手游蓝海 |
| L3 其他手游/小游戏 | 已跑通的题材 | 强——有完整数据 | 低——窗口期短 |

**观察约束**：产出单位是"具体作品+可迁移的具体体验"，不是品类标签。

- ❌ "山海经题材有潜力"——这是常识，不是观察
- ✅ "《中国奇谭·小妖怪的夏天》呈现了'底层小妖在大势力下求生存'的视角，这个弱者生存叙事可以映射到防守玩法"

每层观察记录：作品名 → 热度证据 → 可迁移的具体体验 → 与目标玩法的对应关系。找不到具体作品就诚实标注，不用品类常识填充。

**实际案例**：无尽冬日不是从"末日"品类想出来的——L1《后天》《雪国列车》呈现"极寒中的资源分配困境"；L2 冰汽时代验证了"冰封+城市管理"的游戏化可行性。迁移时保留的是"冰封求生"这个具体角度，不是"末日"大品类。

### 模式 C：竞品信号驱动（从市场数据出发）

**适用场景**：轻度选题，或需要快速跟进市场验证过的方向。

操作方式：
1. 扫描目标品类近期跑量的竞品素材，提取题材关键词
2. 识别"同机制换符号"的机会——竞品用水果跑通了合成，还有什么日常符号没被做过？
3. 已验证的题材类型优先尝试同类替换

这本质上是观察链 L3 的轻度版——观察粒度不同（看符号替换机会，而非世界观迁移）。

### 模式 D：心智模型层级矩阵（发散补盲区）

**适用场景**：竞品信号已充分消化，需要找盲区。

提取机制核心动词，在五个心智模型层级中找原型场景：

| 层级 | 来源 | 共识度特征 |
|---|---|---|
| 物理直觉 | 身体经验（重力、碰撞、容器） | 全人类共有 |
| 日常经验 | 生活场景（烹饪、整理、种植） | 极高，跨文化 |
| 职业/技能 | 专业知识或媒体间接获得（手术、建筑） | 中等 |
| 文化符号 | 影视/文学/游戏（僵尸、三国） | 因文化圈而异 |
| 社会关系 | 社会经验（养宠、育儿、竞争） | 高但情感色彩强 |

轻度题材主力在物理直觉和日常经验层。不是每个层级都适合每个动词，找不到自然的原型就跳过。

### 模式组合

几种模式不互斥，常见组合：

- **A→B**：先用本能行为拆解锁定体验钩子（如"孵化"），再用观察链找匹配的世界观（如山海经）→ 产出"山海经孵蛋"
- **B→A**：观察链发现了一个世界观方向但缺体验钩子 → 用本能行为拆解补上
- **C→D**：竞品信号消化完了，用矩阵发散补盲区

### 红海题材的差异化

已被充分符号化的世界观数量有限，多数是红海。两条出路：

**路径 A：在红海世界观里换环境变量**

保留大品类的世界观框架，替换环境/场景设定。典型案例："末日生存"红海 → 僵尸末日最红 → 冰封末日（无尽冬日）和水淹末日（疯狂水世界）是同框架的差异化入口。

**路径 B：发现"正在被符号化但还没完成"的新世界观**

从 L1（影视/文学）中寻找正在积累文化认知但还没进入游戏领域的题材。风险更高，但判断对了享受先发优势。关键判断：目标用户是否已经能"秒懂"——如果还需要解释"这是什么"，说明符号化还没完成。

## §4 题材校验：统一关卡

不管从哪种思维模式产出的候选，都必须过以下关卡。顺序固定，不通过即淘汰或降级。

### 关卡一：体验想象测试

**如果用这个题材做一条 3 秒素材，画面是什么？用户看到后会期待什么体验？**

三个判断点：
1. **画面自然度**：题材+玩法能否产生一个不需要解释的画面？
2. **期待匹配度**：用户看到画面后的期待，和进来后前 10 秒体验是否一致？
3. **情感直觉**：这个画面让你想点进去吗？

不通过 → 淘汰。

### 关卡二：品类承载力校验

体验想象测试只回答"想不想点进来"，没回答"能撑多久"。这一步反向校验题材深度是否匹配目标品类。

| 校验维度 | 轻度要求 | 中重度要求 | 不通过的表现 |
|---|---|---|---|
| 收集线深度 | 不需要或极浅 | ≥3 层可收集体系，每层有"我还差一个"驱动力 | 收集对象展开后层数不够（企鹅护蛋：蛋→企鹅→？断了） |
| 成长叙事 | 不需要 | 题材支撑"变强的理由"，内嵌在世界观里而非纯数值 | 情感内核不支持长线投入动机 |
| 付费锚点 | 广告即可 | 世界观中有用户主观认为"值钱"的对象，价值感来自题材本身 | 对象之间没有主观价值分层 |
| 社交/竞争 | 可选 | 加分但不一票否决 | — |

**判定**：中重度前三项必须全过。被拦住的题材标注"适合另一品类"留存备用。

### 关卡三：迁移判断（中重度必过，轻度跳过）

| 条件 | 判断内容 | 不通过的表现 |
|---|---|---|
| 符号可压缩性 | 能否压成 3 秒素材秒懂 | 需要解释背景才能理解 |
| 世界可展开性 | 能否撑住 7 日+ 留存的内容深度 | 只有一个符号，无法展开 |
| 机制可承接性 | 有没有合适的核心玩法来兑现题材承诺 | 题材暗示的体验和可用机制之间断裂 |

三项全过才继续。

### 关卡四：闭环句验证

> {某类人}，看到 {题材} 素材，期待 {承诺}，进来后通过 {机制} 兑现，因为 {留存理由} 留下来，因为 {变现理由} 付费/看广告。

此阶段"某类人""留存理由""变现理由"可以模糊——重点检查**题材承诺和机制兑现之间有没有断裂**。

### 关卡五：市场校正

校正维度：

- **竞争密度**：同题材同机制产品数量
- **素材疲劳度**：该题材近 3 个月的素材消耗情况
- **CPI 趋势**：当前获量成本走势
- **时机判断**：

| 证据层级 | 侧重 | 关键问题 |
|---|---|---|
| L1 影视/文学 | 是否太早 | 文化认知积累够不够？目标用户能秒懂吗？ |
| L2 PC/主机 | 窗口是否开启 | 手游端有没有人在做？做得好不好？ |
| L3 其他手游 | 窗口是否关闭 | 头部产品获量成本是否已推高？ |

数据来源：应用商店搜索、第三方素材监测（AppGrowing/广大大等）、广告平台后台。数据缺失时用手动搜索粗估，但必须标注为假设判断。

四象限定位：
- 高获量 + 高承接 → 首选
- 高获量 + 低承接 → 需加成长线
- 低获量 + 高承接 → 需换题材包装
- 低获量 + 低承接 → 淘汰

### 输出模板

```
题材：{体验钩子 × 世界观主题}
产品类型：轻度 / 中重度
体验钩子：{具体情感瞬间}
世界观来源：{日常经验 / 影视文化 / PC游戏验证 / 手游验证}
证据层级：{L1 / L2 / L3}
四属性评级：共识度_{高/中} 同构度_{高/中} 情感负载_{高/中} 可叙述性_{高/中}
闭环句：{完整填写}
市场定位：{四象限位置}
最大风险：{一句话}
验证方式：{素材测试计划}
```

**题材融合提示**：当单一题材四属性有短板时，可考虑主题材（70%）+ 辅题材（30%）的融合方案。融合需满足：主次分明 / 情绪兼容 / 逻辑自洽 / 受众重叠（详见《题材选择方法论》融合章节）。

## §5 常见失败模式

| 失败模式 | 表现 | 原因 |
|---|---|---|
| 轻度用了中重度题材 | 世界观太重，3秒内传达不了 | 没有区分题材粒度 |
| 中重度用了轻度题材 | 获量好但 7 日留存断崖 | 题材只是符号，展不开世界观 |
| 轻量题材硬做中重度 | 获量好但留存/付费断崖 | 跳过品类承载力校验，只看了 3 秒画面 |
| 题材高共识但低同构 | 用户秒懂但不知道该怎么操作 | 题材和机制之间缺乏因果映射 |
| 题材高情感但低可叙述 | 玩家自己嗨但不分享 | 体验难以用语言传递 |
| 题材高获量但低承接 | CPI 低但次留差 | 素材承诺与实际体验不一致 |
| 只看题材不看机制 | 题材好但和机制不匹配 | 跳过了锁定机制方向的前置步骤 |
| 红海题材无差异化 | 获量成本高 | 没找差异化环境变量或新世界观入口 |
| 题材符号化未完成就进入 | 素材转化低 | L1 进入太早，文化积累不够 |
| 品类级观察冒充题材发现 | 产出的是任何人都能想到的常识答案 | 观察停在品类标签，没落到具体作品的具体体验 |
| 热门缝合 | 题材看着时髦但各部分之间无内在逻辑 | 从市场热词出发拼凑而非从体验出发推导 |
