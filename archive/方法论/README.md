# 方法论目录

已沉淀、可复用的方法论文档。只有能指导后续立项、分析或复盘的稳定结论才放入本目录。

## 分类

| 目录 | 内容 |
|---|---|
| `立项/` | 通用立项框架：发现方向、评估卖相、选题材、拆解外部方法论 |
| `分析/` | 游戏拆解与产品分析框架 |
| `策划/` | 策划领域评审判据与设计方法论（数值、系统等） |
| `推演案例/` | 方法论在具体方向上的应用实例，可作为推演参考 |
| `元方法/` | 管标准类资产本身怎么演进维护的方法论，比业务方法论高一层 |

## 入库规则

- 通用框架 → `立项/` 或 `分析/`；管标准本身的元方法 → `元方法/`
- 具体方向推演记录 → `推演案例/`
- 只收稳定结论，草稿留在项目目录或 `workspace/tmp/`
- 知识流向：workspace → archive/经验 → archive/方法论 → reference
