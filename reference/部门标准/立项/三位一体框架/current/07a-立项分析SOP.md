# 立项分析 SOP

> 本 SOP 仅用于"自己尚未做的玩法构想"。已成功竞品的分析走 [07b-成功复盘SOP.md](07b-成功复盘SOP.md),两者方向相反,不可混用。

---

## 一、目的与适用场景

- **目的**:用 N / T / A / F 四层,提前找出**自己玩法构想**的承接缺陷
- **输入**:你打算做的玩法(还没做、还没投放)
- **输出**:5 大硬约束(H1-H5)逐条 check 结果 → 立项通过 / 失败 / 标记 boundary
- **不适用**:已经成功的竞品分析(必须走 07b 文档)

---

## 二、核心心法

> **找出我会失败的地方,不是找出"和成功产品一致的地方"。**

立项阶段的惯性陷阱是"找一款对标产品,论证我们和它像 → 所以我们能成功"。这是逆向偷懒,不是分析。真正的立项分析方向是:**先独立拆解自己的构想,再用硬约束抓自己的漏洞**,竞品只在最后一步用于差异定位。

---

## 三、强制流程(5 步)

### Step 1 [独立拆解,禁止参考竞品]

- 不参考任何竞品,**独立填**一份 v1.2 yaml(模板见 01 文档)
- 必填:`primary_N` / `T_main` / `AF_ref.A` / `AF_ref.F` / `THM_ref` / `theme_role` / `theme_sensitivity` / `cover_T_promise`
- **禁止**:此阶段说"它和 X 类似"、"对标 X"、"参考 X 的承接方式"
- **输出**:完整 yaml + 自己的拆解思路(为什么这样填)

### Step 2 [硬约束自检]

按 01 文档"立项 5 大硬约束"逐条核对:

- **H1 N 一致陷阱**:N 一致 ≠ 正确,必须四层(N / T / A / F)都对齐。跑"四层一致性检查清单"5 条
- **H2 A 真伪**:逐个 A 反问"对留存付费有直接贡献吗?玩家进入后会反复执行吗?",剔除伪 A(仅为获量素材服务的伪动作)
- **H3 卖相 vs 实际**:`cover_T_promise` vs `T_main` 必查,不一致立刻触发立项错位警告
- **H4 theme_role vs sensitivity**:目标簇 sensitivity 与 theme_role 错配 → 立项失败(同时赶跑两类用户)
- **H5 P-N 互斥**:Pr-Rnd / Pr-Lose / Pr-Cmp / Pr-Sct / Pr-Spd 主导 → 排除 N-Auto;Pr-Low 主导 → 排除 N-Comp

### Step 3 [失败定位]

任何硬约束触发 → 必须明确选 A / B / C 修正方案:

- **A**:改素材回归 T_main(投放重做,产品本身不动)
- **B**:改产品承接卖相(玩法调整,让 A / F 真正承接 cover_T_promise)
- **C**:接受错位,标 `cluster_status: boundary`,在 `evolution_note` 记录预期流失率

立项里"我们可以两个都做到"是错误答案,实际不可能。

### Step 4 [竞品对照,只做差异定位]

只在 Step 1-3 通过后,才进入竞品对照。规则:**只问"我们和 X 在哪一层不同",不问"我们和 X 哪里像"**。

| 差异层 | 含义 | 立项含义 |
|---|---|---|
| 同 N,不同 T | 底层需求相同,任务态不同 | 差异化机会 |
| 同 N+T,不同 A / F | 任务态相同,承接形态不同 | 承接形态差异(玩法差异化) |
| 同 N+T+A / F,不同 THM | 承接相同,题材不同 | 题材差异化 |
| 四层全部一致 | 你做的就是另一个 X | 需要重新论证为什么市场容得下两个 |

### Step 5 [立项判断]

- **通过**:5 大硬约束全过 + 与对标竞品有清晰差异层 → 进入立项执行
- **失败**:任一硬约束未选修正方案 → 回到 Step 1 重拆,或终止立项
- **boundary**:接受错位但记录在案 → 进入立项,但同步标注预期风险

## 四、强制元字段

所有立项分析产物必须在 yaml 顶部带:

```yaml
analysis_mode: project_review
```

用于和 07b 复盘产物在数据层区分,避免后续混入同一分析池。

---

## 五、典型错误模式

- **错误 1**:N 一致就放心 → 实际 T / A / F 错位。1455 样本 N-Comp 占 74.8%,N 维度区分力天然弱(详见 H1)
- **错误 2**:卖相承诺 T6 秩序掌控但实际承接 T2 价值确认(Thronefall 案例)→ 首日留存暴跌
- **错误 3**:在玩法里抽词条 Pr-Rnd / Pr-Lose 但目标人群是 N-Auto(无尽防线类常见误区)→ 玩家无法把控节奏,N-Auto 玩家流失
- **错误 4**:把"我们和 X 一样"当成立项依据,没有差异定位 → 市场上多一个同质化产品,不是新立项
