# 人群簇模板(v1.1)

按本模板新增人群簇条目。完整字段定义见 [01-人群簇标准.md](../01-人群簇标准.md)(v1.1)。

---

## 模板结构

```yaml
---
# ===== 必填字段 =====
id: AUD-C04-001                   # 格式 AUD-C{簇编号}-{实例编号},分配后不可修改
cluster_id: C04                   # 簇编号 C01-C12
name: 人群簇名称                  # ≤12 字,心理任务+承接结果,不含品类/题材/产品名/年龄段
main_task: T2                     # 主心理任务 T1-T6
main_carrier: P1                  # 主承接偏好 P1-P4
system_yield: "—"                 # P4 时填 Y1-Y4,非 P4 填 "—"
description: 一句话描述            # ≤30 字
secondary_clusters:               # 副簇 0-2 个,超过即归类失败
  - C10
boundary:                         # 与相邻簇的区别,1-3 条
  - "与 C05 的区别:战胜内容/怪/关卡 → C04;战胜真人/排名/竞技 → C05"
  - "与 C10 的区别:构筑通向'下一关更强' → C04;构筑通向'我破解了规则' → C10"
realistic_constraints:            # 现实约束典型值
  time: 任意                       # 时间结构
  cognition: 中带宽                # 认知带宽
  economy: 中ARPU                  # 经济能力
representative_cases:             # ≥3 个,覆盖游戏+至少 1 类其他媒介
  - 战神短剧(短剧)
  - 斗罗大陆(动画/小说)
  - 黑神话:悟空(游戏)
evidence_level: A                 # S/A/B/C/D
payment_pattern:                  # 付费习惯
  - 战力加速包
  - 装备/抽卡
  - 月卡

# ===== 媒介适配(v1.1 新增,必填)=====
media_fit:
  game_primary: high              # high / medium / medium-low / low
  content_primary: high

# ===== 选填字段 =====
acquisition_difficulty: 3         # 获量难度 1-5
ltv_potential: 4                  # LTV 潜力 1-5
emotion_hooks:                    # 触发情绪钩子
  - 逆袭
  - 碾压
  - 渡劫
info_channels:                    # 信息渠道
  - 抖音
  - 番茄小说
age_range: "20-40岁"              # 辅助参考,非聚类依据
gender_lean: male                 # male / female / neutral
geo:
  - 国内三四线
risk_notes: |
  - 素材疲劳快,需要持续换爆点
  - 数值膨胀过快会失活
---

## 详细描述

### 核心特征

(一段话描述该簇的核心识别特征:在用什么内容处理什么半意识心理任务,通过何种承接偏好完成)

### 典型行为画像

(用户的留存动机、付费动机、素材钩子是什么,三者如何串成闭环)

### 代表案例分析

(说明 ≥3 个代表案例为什么属于同一心理任务×承接偏好组合,跨媒介验证证据)

### 边界说明

(详细说明与最相邻簇的边界差异,引用 v1.1 标准的 13 对 boundary 硬判据)

### 错归筛查(C03/C04/C10 必填)

(显式回答错归筛查 checklist,例如:
- 是否主要靠 PvP 战胜真人? 否,主要靠 PvE 关卡推图
- 是否主要靠经营秩序? 否
- 是否主要靠规则解码? 否,构筑不是为了"破解",而是为了"下一关更强"
- 结论:通过 C04 错归筛查)

### 立项参考

(针对该簇做立项时的注意事项、典型素材策略、CPI 预期、商业化模型)
```

## 示例:AUD-C04-001 逆袭爆发确认人群(参考用,不入正式库)

```yaml
---
id: AUD-C04-001
cluster_id: C04
name: 逆袭爆发确认人群
main_task: T2
main_carrier: P1
system_yield: "—"
description: 通过强刺激爆发确认"我有价值/我变强了"的用户群体
secondary_clusters:
  - C01
boundary:
  - "与 C05 的区别:战胜内容/关卡/数值膨胀 → C04;战胜真人/排位/竞技 → C05"
  - "与 C10 的区别:构筑通向'下一关需要更强的我' → C04;通向'我破解了规则' → C10"
  - "与 C11 的区别:核心是境界压制/战力膨胀 → C04;核心是经营门派/资源秩序 → C11"
realistic_constraints:
  time: 任意
  cognition: 低-中带宽
  economy: 中-高ARPU
representative_cases:
  - 战神短剧(短剧)
  - 斗罗大陆(动画/小说)
  - 黑神话:悟空(游戏)
  - 咸鱼之王(放置游戏)
evidence_level: A
payment_pattern:
  - 战力加速包
  - 抽卡/装备
  - 月卡
  - 礼包

media_fit:
  game_primary: high
  content_primary: high

acquisition_difficulty: 2
ltv_potential: 4
emotion_hooks:
  - 逆袭
  - 碾压
  - 渡劫
  - 屌丝翻身
info_channels:
  - 抖音
  - 番茄小说
  - 短剧 App
age_range: "20-45岁"
gender_lean: male
geo:
  - 国内三四线
  - 国内一二线下沉
risk_notes: |
  - 素材疲劳快,3-7 天需要换爆点
  - 数值膨胀过快会快速失活
---

## 详细描述

### 核心特征

这个簇的核心是用强刺激爆发处理"我是否有价值/我是否掉队"的半意识心理任务。用户不一定真处于落后状态,但需要持续被"我刚才变强了/碾压别人了/渡劫成功了"的反馈拉回积极的自我评价。

### 典型行为画像

- **留存动机**:看到自己的等级/境界/战力/装备数值持续增长,被"我比之前的我更强"的爽感拉住
- **付费动机**:卡点处买战力加速、抽稀有装备、买月卡续命
- **素材钩子**:逆袭、碾压、渡劫、屌丝翻身、装备爆出特效

### 代表案例分析

战神短剧、斗罗大陆、黑神话:悟空、咸鱼之王 这四个案例分属不同媒介(短剧/动画/游戏/放置),但都满足:
- 主角从弱→强的可视化爆发
- 关卡/对手是"用来碾压的目标",不是"用来理解的谜题"
- 用户视角是"我成为这个角色",不是"我和这个角色的关系"

### 边界说明

- **vs C05**:同样追求"变强",C04 是战胜内容,C05 是战胜真人。PVP 排位归 C05
- **vs C10**:同样有构筑/养成,C04 构筑是为"下一关需要更强的我",C10 构筑是为"我破解了规则"(解读完整后退场)
- **vs C11**:同样有数值,C04 核心是境界压制/战力膨胀,C11 核心是经营秩序

### 错归筛查

- 主要靠 PvP 战胜真人? 否
- 主要靠经营秩序? 否
- 主要靠规则解码? 否,构筑/养成的最终满足是"我变强了",不是"我理解了"
- 结论:通过 C04 错归筛查

### 立项参考

- **素材策略**:逆袭/碾压/渡劫,3-7 天换钩子
- **CPI 预期**:30-80 元
- **留存关键**:前 7 天必须有可视化的"变强"反馈
- **商业化关键**:卡点付费 + 月卡 + 抽卡
```

## 注意事项

- ID 由用户批准后分配,不能自行决定
- `evidence_level` 低于 B 的条目不能进入正式库
- `boundary` 必须显式回答与最相邻 1-2 个簇的差异
- `media_fit` 必填,标注游戏/内容两类承接强度
- C03/C04/C10 必须显式通过错归筛查
- 超过 2 个副簇 → 归类失败,需重审
- 不允许用品类/题材/玩法/操作强度直接定主簇
