# U3-落地方向确认原则

## 适用节点

适用于用户确认 G4 产出的功能结构、关键规则、状态和 UE 方向。Agent 负责检查完整性和归属，不能替用户批准落地方案。

## Agent 检查材料

- 功能是否承接 U1/U2 确认的目的、手段和结构依据。
- 每个独立功能是否具有触发或成立条件、处理过程、状态变化和结果反馈。
- 权限、条件、次数、冷却、消耗、配置、反馈和异常是否归入实际生效功能。
- 规则是否可执行、状态是否闭合、UE 是否覆盖关键感知点。
- 是否出现技术实现越界或把附属内容升级为玩法本体。
- 未关闭问题、影响、修改选项和 Agent 推荐。

## 用户需要确认

- 功能结构及各功能归属。
- 关键规则、状态和 UE 方向。
- 方向验证保留项与正式 GDD 阻塞项。
- 是否接受当前风险进入 G5，或指定返回 G4/U2/U1。

## Agent 禁止事项

- 禁止自行删除、合并或新增核心功能后视为已确认。
- 禁止替用户接受功能断点、规则缺口或 UE 风险。
- 禁止自行决定返回阶段。
- 禁止在 U3 未确认前进入正文写作。
