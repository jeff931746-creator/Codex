# U2-手段与结构确认原则

## 适用节点

适用于用户从 G3 候选中选择手段框架、设计对象、交付对象边界和结构依据。Agent 只比较候选，不作选择。

## 提交给用户的材料

每个候选必须说明：

- 通过什么规则，把哪些输入转成什么结果。
- 如何承接 U1 确认的设计目的和循环缺口。
- 设计对象、交付对象边界和结构依据。
- 外部依赖、断点、风险和正式 GDD 阻塞项。
- 与其他候选相比的收益、代价和适用条件。
- Agent 推荐项及推荐理由。

## 用户需要确认

- 采用、组合、重做或放弃哪些候选。
- 最终手段框架、设计对象、交付对象边界和结构依据。
- 哪些风险接受进入 G4，哪些问题必须先补资料。
- 下一步是进入 G4、返回 G3/U1 或停止。

## Agent 禁止事项

- 禁止替用户选候选、组合方案或接受依赖风险。
- 禁止因为某个候选得分更高就自动推进。
- 禁止在 U2 直接拆功能或正文目录。
- 禁止在用户确认前进入 G4。
