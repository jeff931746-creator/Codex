# M2-循环闭环判断原则

## 适用节点

适用于 M2 主策确认循环。

## 判断目标

主策在 M2 只判断核心循环是否服务 M1 目标、是否闭环、是否能支撑玩家重复进入。

## 必须确认

- 循环是否服务 M1 已确认目标。
- 玩家进入、行动、反馈、状态变化、再进入理由是否完整。
- 收益状态变化是否可感知。
- 涉及社交、军团、协作或竞争时，关系变化是否明确。
- 循环断点是否可接受或可作为方向验证保留项。

## 通过条件

- 玩家行为和系统反馈可以形成闭环。
- 循环能解释首次进入和重复进入。
- 关键反馈能被玩家感知。
- 收益或关系变化足以支撑目标。
- 外部依赖没有阻断核心循环。

## 打回条件

- 循环不闭环：打回 G3。
- 反馈不可感知或收益变化无意义：打回 G3。
- 循环推演显示 M1 目标本身不成立或边界错误：回到 M1。

## 禁止事项

- 禁止在 M2 审 UI 细节。
- 禁止用“功能很多”代替循环成立。
- 禁止修改 M1 目标但不回到 M1。
