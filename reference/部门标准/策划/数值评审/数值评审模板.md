# 数值评审评分卡

依据飞书【数值牌】评分逻辑。判据定义、评价依据映射、评分逻辑均固化自飞书，本地判据镜像见 `数值评审判据.md`。

## 用法

1. 按游戏类型勾选适用的数值模块（战斗 / 养成 / 经济），不适用的整块跳过。
2. 对每条适用判据，对照「数值结构」定义判断其表现。
3. 按「评分逻辑」的固化题目逐题打分、写打分依据，参照「评价依据」的归因汇总到 4 个数值牌标准维度。
4. 输出风险点与建议点。

评审纪律：本卡所有"达标 / 通过"结论遵守 `.claude/rules/quality-gates.md` 的「评审质量纪律」节——评质量不评存在性、判据内 + 判据间两层质量、阶段边界。该节为唯一真相源，此处不复制，评审前必读。

数值评审补充纪律（评审方法，非判据定义。每条配本次 GT 例）：

1. **评思路成立与否，不评内容齐全**——立项允许没有精确数字，要的是数值思路立得住；"没规划"才扣分，"没写细"不扣。
   例：消耗曲线没给精确公式不扣分，但连"走阶梯还是指数"都没规划，扣。
2. **公式自洽分场景、看成长线同步**——PVE 容许膨胀（成长爽感）、PVP 须平衡；乘法/连乘公式查各成长线（输出/生存/控制）速度是否同步，不同步会被连乘放大成碾压，PVP 尤甚，须有压制或归一手段。
   例：GT 连乘公式 PVE 自洽，但 PVP 缺属性投放与调控——输出线快于生存线，放大成"比谁先秒谁"。
3. **问题落到关系与解法岔路**——不停在"会膨胀/缺通缩"，要指出哪个关系会崩、解法走哪条。
   例："缺通缩"要追问：走产出端（限产）还是消耗端（回收）？两条路对体验影响不同。
4. **只评数值机制，不评非数值问题**——量的关系/曲线/产销回收之外的系统体量、上手成本不在此扣分。
   例：GT"5 货币 × 5 养成线 × 5 属性"上手成本高，是系统/新手引导问题，不在数值评审扣分。
5. **战斗数值先评内核，再评平衡（仅适用战斗数值模块）**——动下面 3 条战斗判据前先确认三件事：① **主轴单一归一**——有唯一底层结算变量，养成/属性都折算到它（如战力差、行动权差）；② **战斗策略与博弈清晰**——属性围绕策略堆砌，流派/克制关系玩家读得清楚（核心不在博弈点数量多少，而在策略读不读得出来）；③ **属性按分层投放**——不同付费/活跃分层追不同属性阈值，各层有差异化追求路径，超R 追求全属性。博弈点落在属性层（闪避/吸血）还是出手层（行动权/控制）由品类定。内核立住，系数/曲线/量级才是可调的平衡层。
   例：寻道大千用闪避、连击、反击、击晕、吸血、暴击六属性围绕策略堆砌，按分层投放阈值、超R 全要——策略清晰、分层明确（正）。反例：属性堆了一堆却读不出该走哪个流派，或所有玩家共用一条属性追求路径、没有分层阈值（策略/分层不成立）。

## 数值牌标准（评分维度）

| 维度 | 含义 |
|------|------|
| 体验感 | 单模块体验出色，玩家动力满满 |
| 价值感 | 付出回报清晰合理，玩家愿意长期投入 |
| 平衡性 | 公平合理稳定，玩家玩的舒心 |
| 全局性 | 合理循环，玩家对整体游戏体验满意 |

## 数值结构（评估判据）

按游戏类型勾选适用模块，不适用整块跳过。

### 战斗数值

- **[公式自洽]** 属性收益在全区间内稳定可预期、极端值不产生零伤害或伤害爆炸、对属性投放有合理容错
- **[属性有责]** 每个属性都参与实际结算且有取舍关系、不存在可安全忽略的废属性、玩家可理解属性对战斗的影响
- **[平衡可控]** 各战斗要素强度可在同一标尺下比较、参数可独立调整不连锁崩溃、体系有负反馈机制抑制失衡

### 养成数值

- **[追求明确]** 每条养成线追求目标明确、主次分明、获取路径与代价清晰
- **[阶段闭合]** 变强有地方用、有体感、之后有新目标，追求不断档
- **[层级分明]** 各付费层花钱买得到对应差距、免费玩家有自己的追求和留存理由、层级差距可控
- **[节奏调控]** 各阶段玩家都有东西可养、开启与膨胀节奏有长期规划、追赶和天花板有调控手段

### 经济数值

- **[货币清晰]** 货币种类定位明确、不重叠、兑换关系合理无套利漏洞
- **[产出驱动]** 免费与付费产出结构关系能驱动游戏追求和持续付费
- **[消耗合理]** 消耗曲线合理，资源都有处花、深度吃得下各阶段产出
- **[循环闭合]** 资源流转路径完整、各模块产出汇入核心追求、核心循环可持续
- **[自我调节]** 经济体有调节手段和监控方向

## 评价依据

判据 → 数值牌标准维度的固化映射（同步自飞书）。评审时对照归因判断各判据对维度的支撑。

| 数值牌维度 | 判据 | 归因 |
|------------|------|------|
| 体验感 | 追求明确（养成） | 目标清晰 → 动力来源 |
| 体验感 | 阶段闭合（养成） | 变强可感 + 新目标 → 持续动力 |
| 体验感 | 属性有责（战斗） | 每个属性有意义有取舍 → 决策体验 |
| 价值感 | 货币清晰（经济） | 货币定位不重叠 → 玩家看得懂自己花了什么 |
| 价值感 | 产出驱动（经济） | 免费/付费产出结构 → 驱动追求和付费意愿 |
| 价值感 | 消耗合理（经济） | 资源有处花、深度够 → 投入觉得值 |
| 价值感 | 层级分明（养成） | 各付费层有对应回报 → 每一级投入都有落点 |
| 平衡性 | 公式自洽（战斗） | 全区间收益稳定 → 不出现零伤害或爆炸 |
| 平衡性 | 平衡可控（战斗） | 强弱可横向对比、调一处不崩全局 → 不连锁崩溃 |
| 全局性 | 循环闭合（经济） | 各模块汇入核心追求 → 系统级闭环 |
| 全局性 | 自我调节（经济） | 有调节手段和监控 → 长线不失控 |
| 全局性 | 节奏调控（养成） | 长期规划 + 追赶 + 天花板 → 全阶段有东西玩 |

## 评分逻辑

固化评分题（同步自飞书）：逐题打分、写打分依据，按维度汇总，最后求总分。评分与打分依据按实际评审填写。

| # | 维度 | 评分题 | 评分 | 打分依据 |
|---|------|--------|------|----------|
| 1 | 体验好 | 对玩家体验有清晰预期，数值设计是否围绕明确的体验目标展开？ | | |
| 2 | 体验好 | 不同层次玩家在不同阶段是否都有各自的目标，跳一跳能够得着？ | | |
| 3 | 体验好 | 核心数值规则是否清晰易懂，投入回报有明确预期，玩家敢于持续付出 | | |
| 4 | 体验好 | 数值节奏是否张弛有度，压力与收获交替合理，能支撑长期体验？ | | |
| 5 | 体验好 | 综合：该项目的数值体验是否能给玩家提供游戏动力？ | | |
| 6 | 价值感 | 各内容和商品的价值是否清晰，付费与回报是否成比例？ | | |
| 7 | 价值感 | 玩家已获得的数值资产是否受保护，不会被后续设计大幅贬值？ | | |
| 8 | 价值感 | 各阶段投入的时间收益是否稳定且符合预期？ | | |
| 9 | 价值感 | 价值体系是否长期稳定，不被新内容洞穿，不会在产销养曲线上出现不良跳层？ | | |
| 10 | 价值感 | 综合：该项目的付出回报是否清晰合理，让玩家愿意长期投入？ | | |
| 11 | 平衡性 | 免费玩家是否有完整的游戏体验和独立的追求目标？ | | |
| 12 | 平衡性 | 对轻度和重度玩家有各自清晰的"时间资源比例"和"目标追求"规划？ | | |

| 14 | 平衡性 | 付费带来的数值差距是否有上限控制，不破坏整体游戏体验？ | | |
| 15 | 平衡性 | 综合：该项目的数值是否公平合理稳定，玩家玩的舒心？ | | |
| 16 | 全局性 | 各模块的数值体验是否均衡，没有明显短板拖累整体？ | | |

| 19 | 全局性 | 是否有合理的经济框架和调控工具，长期经济不失控？ | | |
| 20 | 全局性 | 综合：该游戏的宏观数值，是否循环合理且长期稳定？ | | |

| 22 | 方案质量 | 数值牌整体的方案完成度是否足够？ | | |
